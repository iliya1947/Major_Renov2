# GPT-5.6 — рабочее пространство исследования GPT-6

Назначение: независимое исследование повторяющихся сбоев GPT-6 в реальном рабочем процессе пользователя.

Правило сравнения: до завершения собственной фиксации выводов не использовать материалы GPT-6 как источник, чтобы сохранить независимость исследования.

## Структура

- `01-problem.md` — исходная проблема и границы исследования.
- `02-confirmed.md` — что подтверждено официальными материалами именно для GPT-6.
- `03-local-cases.md` — повторяющиеся наблюдения из реальной работы с GPT-6.
- `04-failure-model.md` — классификация типов сбоев и связи между ними.
- `05-mitigations.md` — меры, которые потенциально уменьшают эти сбои.
- `06-open-questions.md` — что ещё не установлено.
- `SOURCES.md` — использованные внешние источники.

## Текущий статус

Исследовательская фаза достаточна для постановки диагноза. Следующий этап — сравнение с независимым исследованием GPT-6 и затем проектирование минимального рабочего механизма, а не дальнейшее накопление общих статей.
