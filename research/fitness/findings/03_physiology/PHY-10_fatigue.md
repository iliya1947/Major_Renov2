# PHY-10 — Fatigue

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-18**  
Область: 03 — Physiology

## 0. Core decision

Fatigue is a **task-specific reduction in sustainable performance capacity**, not one molecule or one mechanism.

Canonical organization model:

`task demand > momentary sustainable neuromuscular capacity`

where sustainable capacity depends on:

- voluntary neural drive;
- membrane excitability;
- excitation–contraction coupling / Ca²⁺ handling;
- contractile state;
- metabolic/ionic state;
- substrate availability;
- muscle–tendon/task mechanics;
- perceptual/systemic context.

The dominant limiter can change with time and task.

## 1. Fatigue vs task failure

Fatigue can develop before complete failure.

### Fatigue
Reduced ability to produce/sustain required performance.

### Task failure
The endpoint when the task requirement can no longer be maintained.

### Perceived fatigue
Subjective experience that can influence task continuation but is not identical to objective performance loss.

Project rule:

**fatigue ≠ task failure ≠ subjective tiredness.**

## 2. Neuromuscular fatigue

Neuromuscular fatigue is an umbrella reduction in neuromuscular force/power capacity.

It can contain:

- central fatigue;
- peripheral fatigue.

Project rule:

**neuromuscular fatigue is multidimensional.**

## 3. Central fatigue

Central fatigue = exercise-induced reduction in voluntary neural drive/activation.

Potential levels include supraspinal and spinal/motoneuronal processes.

Project rule:

**central fatigue is not synonymous with mental fatigue and cannot be quantified from surface EMG amplitude alone.**

Detailed mechanisms → NEU.

## 4. Peripheral fatigue

Peripheral fatigue = impairment distal to central motor drive.

Possible sites include:

- membrane/T-tubule excitability;
- E–C coupling;
- SR Ca²⁺ release;
- myofilament Ca²⁺ sensitivity;
- cross-bridge force generation;
- metabolic/ionic state.

Project rule:

**peripheral fatigue is a location class, not one mechanism.**

## 5. Central vs peripheral contribution

Both can coexist.

Their relative contribution changes with:

- intensity;
- duration;
- muscle mass;
- contraction type;
- rest/duty cycle;
- task failure proximity;
- measurement method.

Project rule:

**there is no universal central/peripheral fatigue percentage.**

## 6. Metabolic fatigue

High ATP turnover alters:

- PCr;
- Pi;
- ADP;
- pH/H⁺;
- substrates;
- ion transport;
- Ca²⁺ handling.

Project rule:

**metabolic fatigue is a mechanism family, not “lactate accumulation.”**

## 7. Pi / H⁺ / lactate

Pi can impair force production and Ca²⁺-related processes.

Severe intracellular acidosis can reduce:

- force;
- shortening velocity;
- power.

Lactate itself is not a simple toxic fatigue agent.

Project rule:

**no single metabolite universally explains fatigue.**

## 8. Excitation–contraction coupling

Fatigue can impair force between action-potential propagation and cross-bridge force generation.

Relevant processes include:

- membrane/T-tubule excitability;
- SR Ca²⁺ release;
- Ca²⁺ sensitivity.

Project rule:

**force can fall without primary central-drive failure.**

Animal/single-fiber mechanistic evidence is not used to assign quantitative human RT mechanism shares.

## 9. Substrate depletion

### PCr
Falls rapidly during high ATP turnover and constrains repeated high-rate energy supply.

### Glycogen
A resistance-training session can reduce muscle glycogen; greater set count/session duration generally increases depletion.

Project rule:

**glycogen can constrain repeated work/recovery but is not the universal immediate cause of short-set failure.**

Detailed energetics → BIO/NUT.

## 10. Ionic disturbances

Fatiguing contractions alter K⁺/Na⁺/Cl⁻/Ca²⁺ gradients and membrane excitability.

Project rule:

**ionic fatigue is an interacting excitability problem, not a one-ion switch.**

## 11. Reduced neural drive

Neural drive may decline during/after fatigue.

But peripheral impairment can dominate while voluntary drive remains relatively high.

Project rule:

**reduced neural drive is one possible limiter, not the universal endpoint.**

## 12. Local vs systemic fatigue

### Local/systemic
Describes distribution/scale.

### Central/peripheral
Describes physiological site/mechanism.

Project rule:

**these are independent classification axes.**

## 13. Acute vs accumulated fatigue

### Acute
Bout-related impairment resolving on outcome-specific timelines.

### Accumulated
Operational longitudinal label for persistent/recurrent impairment when recovery between stressors is incomplete.

Current evidence does not establish one unique physiological accumulated-fatigue substance/state.

Project rule:

**accumulated fatigue must be demonstrated by repeated outcome impairment.**

## 14. Task dependency

The limiting mechanism depends on:

- force requirement;
- duration;
- velocity;
- contraction pattern;
- muscle mass;
- duty cycle/rest;
- perfusion;
- environment;
- skill.

Project rule:

**ask what limits this task under these conditions.**

## 15. Effect on force / velocity / power

Fatigue commonly reduces:

- force;
- repetition velocity;
- power;
- RFD/performance.

Higher fatigue is generally produced by:

- longer sets;
- closer proximity to failure;
- larger volume;
- higher density.

Project rule:

**force/velocity loss are useful fatigue outcomes but are protocol/task specific.**

## 16. Effect on technique

Fatigue can change kinematics and kinetics.

Project rule:

**fatigue can change movement strategy, but there is no universal fatigued-technique pattern.**

Detailed consequences → MEC/TEC.

## 17. Recovery kinetics

Different fatigue domains recover asynchronously.

Examples:

- PCr/metabolites → relatively rapid;
- force/velocity → minutes to days;
- contractile impairment → can persist after some voluntary performance returns;
- soreness/damage markers → often delayed.

Project rule:

**there is no universal recovery clock.**

## 18. One-marker recovery error

Normalization of one marker does not prove complete recovery.

Project rule:

**recovery must be defined against the target function and time point.**

## 19. Training implications

1. **Do not maximize fatigue as a goal.**
2. **Manage stimulus–fatigue tradeoffs.**
3. **Near-failure, long-set, high-volume and high-density work generally increases acute fatigue.**
4. **Do not diagnose fatigue mechanism from lactate, EMG or soreness alone.**
5. **Use force/velocity/power changes as task-specific performance indicators.**
6. **Separate central/peripheral from local/systemic classification.**
7. **Treat glycogen as a repeated-work/recovery constraint rather than a universal short-set failure mechanism.**
8. **Treat recovery as multidimensional.**
9. **Infer accumulated fatigue from repeated impairment, not from presumed metabolite accumulation.**
10. **Match monitoring to the function that matters.**

## 20. Canonical project rules

1. Fatigue ≠ task failure.
2. Fatigue ≠ subjective tiredness.
3. Central and peripheral fatigue can coexist.
4. Peripheral fatigue ≠ one metabolite.
5. Lactate ≠ universal fatigue toxin.
6. Severe acidosis can contribute but is not the sole cause.
7. Pi is fatigue-relevant.
8. E–C coupling/Ca²⁺ handling can limit force.
9. Glycogen depletion occurs in RT but does not uniquely explain short-set failure.
10. Ionic fatigue is an interacting excitability problem.
11. EMG alone cannot partition neural fatigue.
12. Local/systemic ≠ central/peripheral.
13. Accumulated fatigue is a longitudinal operational state, not a hidden accumulating substance.
14. Fatigue is task dependent.
15. Recovery is outcome specific.
16. One normalized marker ≠ complete recovery.
17. Programming should manage, not maximize, fatigue.
