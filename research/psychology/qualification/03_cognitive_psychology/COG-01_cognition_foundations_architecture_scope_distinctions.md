# COG-01 — Cognition foundations: architecture, scope, and core distinctions

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a scientifically current working map of cognition before deeper topic blocks are opened.

The goal is not to impose one final modular architecture on the mind. The goal is to keep distinct inferential targets separate enough that later reasoning does not collapse:

- perception into attention;
- attention into cognitive control;
- temporary activation into long-term memory;
- language into thought;
- reasoning into memory retrieval;
- learning into memory;
- task performance into a pure cognitive process;
- a cognitive ability score into a mechanism.

## Core rule

**Cognition is a family of interacting information-processing functions, not one unitary faculty and not a simple serial pipeline.**

For this qualification line, use:

`sensory/environmental information ↔ perception ↔ attention ↔ working memory ↔ long-term knowledge/memory ↔ reasoning/language/action selection`

with recurrent influences from:

- learning;
- goals and cognitive control;
- motivation/emotion/arousal;
- metacognition;
- prior knowledge and context.

The arrows are deliberately bidirectional. This is an interaction map, not a claim that every cognitive episode follows the same sequence.

## 1. Scope: what counts as cognition here?

The cognitive-psychology domain concerns processes and representations involved in acquiring, selecting, transforming, maintaining, retrieving, combining, and using information.

For practical routing, the core families are:

1. perception;
2. attention;
3. working memory;
4. long-term memory and knowledge;
5. reasoning and inference;
6. language.

Learning and cognitive control are major interfaces but receive dedicated downstream domains.

NIMH RDoC currently represents the Cognitive Systems domain using attention, perception, declarative memory, language, cognitive control, and working memory. This is useful as an authoritative research framework, but it is **not** treated here as a complete or final taxonomy of cognition. NIMH's own assessment work has noted overlap among cognitive constructs and the absence of some important constructs such as reasoning/inference from the matrix.

## 2. Perception

### Working definition

Perception transforms sensory information into representations that support identification, prediction, interpretation, and action.

NIMH defines perception as processes that compute over sensory data to construct and transform representations of the external environment, obtain information about it, generate predictions, and guide action.

### Perception is not sensation

Sensation concerns sensory transduction/input.

Perception concerns the organization and interpretation of sensory information into usable representations.

The boundary is not perfectly sharp in biological processing, but the distinction is useful.

### Perception is not attention

Perception answers:

> What information is represented from sensory input?

Attention answers:

> Which information receives priority under competition and capacity limits?

Attention can change perceptual processing, but the concepts are not identical.

Contemporary work on cognitive penetrability also shows that the degree to which expectations, knowledge, and other cognitive states alter perceptual processing remains an active empirical/theoretical question across sensory modalities.

### Perception is not merely passive recording

Perceptual processing is selective, context-sensitive, and shaped by the structure of the sensory system and prior information.

Do not model perception as:

`world -> exact internal copy`.

## 3. Attention

### Working definition

Attention is a family of prioritization/selection processes that regulate access to capacity-limited processing and action systems.

NIMH emphasizes:

- capacity limitation;
- competition;
- selective attention;
- divided attention.

Current attention research further distinguishes influences such as:

- goal-directed/top-down priority;
- stimulus-driven/salience-based priority;
- selection history / learned priority;
- sustained attention/vigilance;
- spatial, feature-based, object-based, and temporal attention.

### Attention is not one homogeneous resource

Do not assume that every task labelled "attention" measures one common mechanism.

Different attentional demands can involve different selection problems and timescales.

### Attention is not identical to awareness

Attention can affect what reaches awareness, but conceptual and empirical work does not justify treating the terms as synonyms.

### Attention is not identical to cognitive control

Attention often implements prioritization.

Cognitive control more broadly regulates cognition and behavior according to goals, context, conflict, novelty, and performance feedback.

Top-down attentional control is therefore an interface between the two domains, not evidence that attention and control are one construct.

## 4. Working memory

### Working definition

Working memory is the temporary, capacity-limited maintenance and flexible updating of information needed for ongoing cognition and behavior.

NIMH currently identifies:

- active maintenance;
- flexible updating;
- limited capacity;
- interference control.

### Working memory is not merely "short-term memory"

The field uses "working memory" and "short-term memory" in partially different ways across theories.

A safe generic formulation is:

> working memory concerns temporarily heightened availability of information for ongoing processing, especially when active maintenance, updating, prioritization, or interference resistance is required.

Do not treat one historical component model as the definition of working memory itself.

### Working memory strongly overlaps with attention

Current reviews emphasize extensive interaction between selective attention, working memory, and long-term memory.

Attention can select internal representations within working memory.

Working-memory contents can guide attention to external information.

This overlap does not justify collapsing the constructs completely.

### Working memory overlaps with control but is not control

Maintaining a task goal is both a working-memory demand and part of cognitive control.

However, working memory can maintain non-goal information, whereas cognitive control includes functions such as context-sensitive response selection and performance adjustment.

## 5. Long-term memory and knowledge

Long-term memory refers to information retained across longer timescales than active temporary maintenance.

It is not one store with one mechanism.

### 5.1 Declarative memory

NIMH defines declarative memory in terms of encoding/acquisition, storage/consolidation, and retrieval of representations of facts and events.

Important subdivisions include:

- **episodic memory** — memory for events/episodes situated in context;
- **semantic memory/knowledge** — organized knowledge of facts, concepts, meanings, and regularities.

The distinction is useful but the systems interact substantially.

Recent neuroimaging and theoretical work continues to show both differentiating and overlapping mechanisms between episodic and semantic retrieval.

### 5.2 Memory is constructive, not a literal recording

Contemporary episodic-memory work treats remembering as involving stored traces plus reconstruction using context and prior knowledge.

Therefore:

`vivid memory -> exact historical record`

is invalid.

### 5.3 Nondeclarative/procedural memory is an interface

Skills, habits, conditioning, and other forms of nondeclarative memory cannot be reduced to episodic/semantic memory.

Detailed learning, habit, conditioning, and procedural mechanisms are routed to the LEA domain.

### 5.4 Working memory and long-term memory interact

The traditional separation is functionally useful, but modern evidence does not support treating them as isolated boxes.

Long-term knowledge shapes immediate working-memory representations and goal-directed behavior.

Working-memory processing can influence later long-term retention and retrieval.

## 6. Semantic cognition and concepts

Semantic cognition concerns the acquisition, representation, and context-sensitive use of meaning and conceptual knowledge.

It interfaces with:

- long-term memory;
- perception;
- language;
- action;
- cognitive control;
- reasoning.

A current trend in semantic-cognition research is away from a picture of fully isolated domain modules toward interacting learned mappings among sensory, motor, and linguistic representations plus control processes.

Canonical boundary:

**semantic knowledge != language.**

A concept can recruit linguistic representations without being reducible to words or syntax.

## 7. Reasoning and inference

### Working definition

Reasoning/inference concerns deriving conclusions, relations, predictions, or decisions that are not merely direct copies of currently presented information.

It can involve:

- deductive reasoning;
- inductive/generalization processes;
- probabilistic judgment;
- analogical/relational reasoning;
- causal reasoning;
- hypothesis testing;
- argument evaluation.

### Reasoning is not one agreed module

NIMH's cognitive-systems assessment work explicitly noted that reasoning/inference is important but not well represented in the current RDoC matrix.

For this qualification system, reasoning is therefore treated as a **functional family** rather than a single isolated mechanism.

### Reasoning depends on other systems

Reasoning commonly recruits:

- long-term knowledge;
- relational memory;
- working memory;
- attention;
- language in many tasks;
- cognitive control;
- learned representations.

Recent evidence also supports roles for relational memory structures in inferential behavior.

### Reasoning is not identical to rationality

Reasoning describes cognitive operations/processes.

Rationality additionally invokes normative standards about what beliefs, judgments, or decisions one ought to make.

The two must not be collapsed.

### Reasoning is not identical to decision-making

Decision-making concerns selection among actions/options under goals, values, uncertainty, and constraints.

Reasoning can contribute to decisions, but decisions can also be influenced by learning, affect, habits, motivation, and automatic processes.

Detailed judgment and decision science is routed to DEC.

## 8. Language

### Working definition

Language is a structured symbolic system supporting comprehension, production, communication, and representation of meaning.

### Language is not identical to thought

Current cognitive-neuroscience evidence supports partial functional dissociation between a core language network and systems involved in broader knowledge and reasoning.

Fedorenko and colleagues' 2024 review argues that the core language network is functionally distinct from both lower-level perceptual/motor systems and higher-level knowledge/reasoning systems, while interacting closely with both.

This does **not** establish that language has no effect on thought.

It establishes the safer boundary:

**linguistic processing and general thought/reasoning are distinguishable systems/process families.**

### Language tasks are cognitively mixed

Language comprehension and production can additionally recruit:

- perception;
- working memory;
- semantic knowledge;
- prediction;
- cognitive control;
- social cognition.

Therefore poor performance on a language-heavy task does not by itself localize the deficit to "language."

## 9. Learning

### Working definition

Learning is experience-dependent change in the system that alters later processing or behavioral potential.

A 2026 interdisciplinary review proposes an umbrella formulation in which information processing from the environment changes system properties in ways that alter future behavioral potential/responses.

### Learning is not the same thing as memory

Useful distinction:

- **learning** emphasizes the process of change through experience;
- **memory** emphasizes retained information/representations and their availability or retrieval.

In practice they are deeply coupled.

### Learning operates across multiple timescales and systems

Learning can alter:

- perceptual expectations;
- attentional priorities;
- working-memory strategies;
- semantic knowledge;
- procedural skills;
- habits;
- reward expectations;
- control policies.

Detailed conditioning, reinforcement learning, habit formation, extinction, reconsolidation, and prediction-error mechanisms are deferred to LEA.

## 10. Cognitive control / executive-function interface

Cognitive control concerns regulation of cognition and action in service of goals, especially when automatic/prepotent behavior is inadequate, contexts are novel, or competing alternatives must be resolved.

Badre's 2025 review emphasizes two broad control functions:

- selecting behavior based on context;
- monitoring ongoing behavior and adjusting it.

This domain interacts heavily with:

- attention;
- working memory;
- language;
- memory retrieval;
- reasoning.

It receives a dedicated EXE qualification domain and therefore should not be absorbed into COG.

## 11. Metacognitive interface

Metacognition concerns monitoring and regulation of one's own cognition, including judgments about:

- confidence;
- knowledge;
- memory;
- performance;
- uncertainty.

It acts on cognitive processes but is not identical to the processes it monitors.

Detailed metacognition is routed to MET.

## 12. Cognition is interactive rather than a rigid feed-forward pipeline

The simplest useful map is recurrent:

`sensory input`
↔ `perceptual representations`
↔ `attentional priority`
↔ `working-memory availability`
↔ `long-term knowledge/memory`
↔ `reasoning/language/action-relevant representations`

with cognitive control, learning, emotion/motivation, and metacognition changing processing throughout the system.

Examples of established interactions:

1. attention changes which perceptual information is prioritized;
2. long-term memory guides attention;
3. working-memory contents guide perceptual/attentional selection;
4. attention influences encoding and retrieval;
5. long-term knowledge shapes working-memory processing;
6. memory supports inference;
7. language accesses semantic knowledge while remaining distinguishable from general reasoning;
8. control changes how competing representations are selected and maintained;
9. learning changes future selection and representation.

Therefore avoid "boxology" in which one module simply hands a finished product to the next.

## 13. Process, representation, task, ability, and performance are different levels

This distinction is mandatory for later individualized reasoning.

### Process

A computation/operation such as selective prioritization, maintenance, retrieval, comparison, inhibition, or inference.

### Representation

The information format/content being operated on.

Examples:

- visual feature representation;
- phonological form;
- semantic concept;
- episodic relation;
- task rule.

### Task

An experimental or assessment procedure requiring several processes simultaneously.

### Ability

A relatively stable capacity inferred from patterns of performance across suitable tasks/contexts.

### Performance

What happened on a particular task under particular conditions.

Canonical rule:

**task performance != pure measure of one cognitive process.**

A working-memory task may also depend on:

- perception;
- attention;
- language;
- motor response;
- motivation;
- strategy;
- long-term knowledge;
- control.

The "task impurity" problem is especially prominent in executive-function research but applies broadly across cognitive tasks.

## 14. Cognitive task interpretation rules

Before assigning a task result to a cognitive function, ask:

1. What processes are required merely to understand the task?
2. What perceptual demands exist?
3. What attentional demands exist?
4. What working-memory demands exist?
5. What long-term knowledge or language demands exist?
6. What motor/response demands exist?
7. What strategy choices are possible?
8. What executive-control demands exist?
9. Is performance speed, accuracy, or a trade-off?
10. Does the task have demonstrated construct validity and reliability for the intended use?

Do not reason:

`poor Stroop/n-back/span score -> one specific mechanism is deficient`

without additional evidence.

## 15. Processing capacity is not one universal quantity

Capacity limits occur in several cognitive systems, but this does not imply one single pool with a fixed scalar capacity.

Examples include limits in:

- selective attention;
- working-memory maintenance;
- dual-task performance;
- processing speed;
- interference resistance.

A person's performance can depend on which bottleneck a task stresses.

Therefore "high/low cognitive capacity" should not be used as a mechanism without specification.

## 16. Automatic and controlled processing are not a simple binary

Cognitive operations can vary in:

- intentionality;
- awareness;
- controllability;
- speed;
- dependence on practice;
- dependence on goals;
- resource demands.

Modern attention and control work also shows that learned selection history can guide processing without fitting a simple "bottom-up versus top-down" split.

Use automatic/controlled as dimensions or functional descriptions unless a specific theory justifies a sharper dichotomy.

## 17. Domain-specific and domain-general processing can coexist

Current cognitive science does not require choosing between:

`everything is one general processor`

and:

`every function is an isolated module`.

Evidence supports both:

- specialized representations/processes in some domains;
- domain-general control, attentional, memory, and learning mechanisms that interact with them.

Language provides a clear example: the core linguistic network is functionally selective, while language behavior still depends on perceptual, semantic, control, and social systems.

## 18. Intelligence is not a synonym for cognition

"Cognition" names the broader family of information-processing functions.

"Intelligence" usually refers to individual differences in broad cognitive performance/capacity, often represented psychometrically through correlated abilities.

A high general cognitive ability score does not specify which cognitive mechanism produced a particular behavior.

Detailed intelligence/ability measurement belongs primarily in PSYCHOMETRICS and individual-differences work.

## 20. High-value failure modes

### Failure A — attention = perception

Incorrect.

Correct:

Attention prioritizes processing; perception constructs/updates sensory representations. They interact but are not synonyms.

### Failure B — working memory = attention

Incorrect.

Correct:

Attention is central to many working-memory operations, but working memory concerns temporary maintenance/updating of information and cannot be reduced to attentional selection alone.

### Failure C — working memory = long-term memory

Incorrect.

Correct:

They operate on different typical timescales/functions but interact continuously.

### Failure D — memory = recording

Incorrect.

Correct:

Memory is reconstructive and context-sensitive.

### Failure E — language = thought

Incorrect.

Correct:

Language and broader reasoning/knowledge systems are distinguishable while strongly interacting.

### Failure F — reasoning = one "System 2" module

Incorrect.

Correct:

Reasoning is a heterogeneous functional family recruiting several cognitive systems; dual-process terminology does not by itself identify one neural/cognitive module.

### Failure G — learning = memory

Incorrect.

Correct:

Learning is experience-dependent change; memory concerns retained representations/availability. They overlap but answer different questions.

### Failure H — cognitive control = all difficult cognition

Incorrect.

Correct:

Control is goal-dependent regulation of processing, not a label for every task that feels effortful.

### Failure I — task = process

Incorrect.

Correct:

Most cognitive tasks recruit multiple processes. Task impurity must be considered.

### Failure J — performance = stable ability

Incorrect.

Correct:

Performance reflects ability plus task demands, state, strategy, measurement error, motivation, and context.

### Failure K — cognitive domains are isolated boxes

Incorrect.

Correct:

Functional distinctions coexist with extensive recurrent interaction and overlapping implementation.

### Failure L — one general capacity explains everything

Incorrect.

Correct:

General individual differences can exist without implying one mechanistic bottleneck for every cognitive task.

## Canonical working rule

**Name the cognitive function precisely, separate it from neighboring functions, identify the representations and task demands involved, then model the interactions.**

Never:

**complex performance -> single cognitive label -> single mechanism.**

## Current-standard note

As of 2026-11-19:

- the NIMH RDoC Cognitive Systems domain still lists attention, perception, declarative memory, language, cognitive control, and working memory;
- NIMH's own assessment report explicitly acknowledges overlap among these constructs and notes reasoning/inference as an important construct not fully represented in the matrix;
- current reviews continue to favor interaction-rich accounts over isolated serial boxes, particularly for attention-memory, working-memory/long-term-memory, semantic cognition, language, and cognitive control.

## Scope note

This block is a routing architecture, not an attempt to settle every theoretical controversy.

Where the field contains multiple live theories—especially working-memory architecture, cognitive penetrability of perception, semantic representation, reasoning models, and language-thought relations—the block preserves the distinction and defers theory adjudication to the deeper topic file.
