# Part A — A well-formed question can still be a bad review question

## 1. Structure is necessary but not sufficient

A question can have:
- clear PICO/PICo/PCC;
- precise outcomes;
- defined time;
- explicit estimand;

and still be a poor candidate for a new deep review because:
- evidence cannot answer it;
- a high-quality current review already answers it;
- scope is unmanageable;
- decision value is negligible;
- the review would duplicate work;
- the likely output cannot change interpretation or action.

### Project rule

After scientific formulation, every major review question must pass a **viability/necessity gate**.

# Part B — FINER

## 2. Cochrane explicitly recommends FINER

### Established finding
**Confidence: HIGH**

Cochrane Chapter 2 identifies the FINER criteria:

1. **Feasible**
2. **Interesting**
3. **Novel**
4. **Ethical**
5. **Relevant**

and says these should be considered when review questions are formulated and again if the question is materially refined.

---

## 3. Feasible

### Established finding
**Confidence: HIGH**

Cochrane describes feasibility in terms including:
- whether the team can address the question;
- whether evidence exists;
- whether scope produces manageable information;
- whether an "empty review" is likely.

### Project decomposition

Feasibility has at least four distinct dimensions:

1. **Evidence feasibility**
   - are studies/data likely to exist?

2. **Methodological feasibility**
   - do available designs/data support the target claim?

3. **Operational feasibility**
   - can this project search, appraise and synthesize the material reliably?

4. **Scope feasibility**
   - is the literature volume and heterogeneity manageable without destroying the question?

These must not be collapsed into one yes/no impression.

---

# Part C — Answerability

## 4. Answerability is different from importance

A question may be very important but currently unanswerable.

Examples:
- important personalization factor with no interaction data;
- rare harm with no denominator data;
- mechanism question supported only by indirect models;
- precise dose-response question where studies use incompatible dose definitions.

### Project rule

Record separately:

1. **Decision importance**
2. **Current answerability**

Do not lower scientific standards because a question is important.

---

## 5. Evidence maturity can change the correct review design

### Established finding
**Confidence: HIGH**

Cochrane notes that sparse evidence may prevent informative synthesis and that broader contingencies may sometimes be needed.

Project routing:

### Mature enough
→ focused systematic review / focused deep synthesis.

### Sparse but landscape unclear
→ scoping-style evidence map.

### Clearly no direct evidence
→ evidence-gap statement + indirect evidence only if explicitly labeled.

### Very broad / overwhelming
→ narrow/split question or use logic-model structure.

### Existing strong synthesis
→ use existing review unless a justified update/re-analysis is needed.

# Part D — Interesting

## 6. "Interesting" is not merely reviewer curiosity

### Cochrane origin + project adaptation
**Confidence: HIGH**

FINER historically includes "Interesting" partly because review authors must remain committed to substantial work.

For this project, the more useful operationalization is:

> **Does resolving this question have enough intellectual or decision value to justify the work?**

Because the project is decision-facing, "interesting" is secondary to:
- relevance;
- uncertainty;
- downstream impact.

Project rule:
do not prioritize a question merely because it is scientifically interesting if it cannot affect:
- safety;
- program design;
- interpretation;
- measurement;
- adherence;
- later research architecture.

---

# Part E — Novel

## 7. Novel does not mean "nobody has ever studied the topic"

### Established finding
**Confidence: HIGH**

Cochrane defines novelty around addressing a genuine knowledge gap and explicitly recommends checking:
- published related/overlapping reviews;
- ongoing reviews such as PROSPERO.

### Project rule

A new review can still be justified when an existing review exists if the new work provides a material new contribution.

Possible reasons:

1. existing review is outdated;
2. important new studies have appeared;
3. methods are obsolete/seriously limited;
4. target population/context differs materially;
5. comparator differs;
6. critical outcomes/harms are missing;
7. effect-modification question is absent;
8. applicability is poor;
9. evidence certainty was not assessed adequately;
10. scope is broader/narrower for a justified decision reason;
11. underlying question type differs.

---

## 8. Existing review does not automatically block new work

### Established finding
**Confidence: HIGH**

Cochrane updating guidance states that reviews can become outdated and misleading as new evidence or methods emerge.

A review may warrant update when:
- the question remains important;
- new data or methods could meaningfully change findings.

### Project consequence

The existence of a review triggers an appraisal/necessity decision, not an automatic STOP.

---

# Part F — Preliminary existing-review check

## 9. Check for existing synthesis before launching a full review

### Established finding
**Confidence: HIGH**

Cochrane Chapter 2 recommends checking published related/overlapping reviews and ongoing reviews before beginning.

Current JBI guidance also requires a preliminary search for existing systematic reviews and, when one exists, an explanation of how the proposed review differs.

### Project rule

Before a full deep-review stream, perform a **preliminary synthesis scan**.

Minimum targets as relevant:
1. Cochrane Library;
2. JBI Evidence Synthesis;
3. PubMed/MEDLINE;
4. PROSPERO / ongoing review registries where applicable;
5. field-specific review databases when needed.

This is a reconnaissance check, not the final comprehensive search.

---

## 10. Preliminary scan must not silently become evidence synthesis

### Project rule
**Confidence: HIGH**

The purpose is to answer:

1. Does a relevant review exist?
2. How current is it?
3. What exact question did it answer?
4. What evidence cutoff did it use?
5. Is it applicable?
6. Is it methodologically credible enough to rely on?
7. What unresolved gap remains?

Do not extract selective conclusions from the first review found and call the topic solved.

Formal appraisal belongs later methodology passes.

# Part G — Review Necessity Gate

## 11. Existing-review decision tree

After the preliminary scan:

### A. No relevant review
→ proceed if evidence appears sufficient and question passes FINER.

### B. Current, high-quality, directly applicable review answers the question
→ **USE_EXISTING_REVIEW** as a major evidence source; do not duplicate full review without a specific reason.

### C. Relevant review exists but is outdated
→ **UPDATE / SUPPLEMENT** with post-search-date evidence.

### D. Review is current but question/applicability differs materially
→ **NEW FOCUSED REVIEW** with difference explicitly documented.

### E. Review quality is inadequate
→ **RE-REVIEW / RE-APPRAISE**, with defect documented.

### F. Literature maturity is unclear / heterogeneous
→ **SCOPING/MAPPING FIRST**.

### G. Direct evidence is essentially absent
→ **EVIDENCE GAP**, not fabricated precision.

# Part H — How current must an existing review be?

## 12. No universal fixed age cutoff

### Established methodological conclusion
**Confidence: HIGH**

Cochrane update guidance does not define a universal:
- 2-year;
- 5-year;
- 10-year
expiration threshold.

Need for update depends on:
1. pace of new research;
2. importance of new studies;
3. possibility of changed conclusions/certainty;
4. changed interventions/context;
5. improved review methods.

### Project rule

Never reject a review merely because it is "old".

Check:
- last search date;
- new evidence since then;
- field velocity;
- methodological relevance.

# Part I — Ethical

## 13. Systematic-review ethics includes opportunity cost

### Established finding
**Confidence: HIGH**

Cochrane Chapter 2 explicitly links ethics to:
- opportunity cost;
- prioritization;
- framing;
- possible effects on inequity.

### Project interpretation

A review can be ethically poor even without direct participant recruitment if it:
- wastes substantial effort duplicating settled evidence;
- frames a question in a misleading way;
- omits major harms;
- overstates weak evidence;
- creates unjustified confidence;
- ignores relevant equity implications.

---

## 14. "Ethical" does not mean IRB/consent is the main issue here

For secondary evidence synthesis, the main RES-01 ethics questions are:

1. Is the framing responsible?
2. Are benefits and harms both represented?
3. Could the synthesis mislead a decision?
4. Is duplication justified?
5. Is opportunity cost acceptable?
6. Are relevant disadvantaged populations being erased by scope choices?

Detailed research-ethics requirements for primary studies are outside RES-01.

# Part J — Relevant

## 15. Relevance means a real downstream use

### Established finding
**Confidence: HIGH**

Cochrane emphasizes questions important to decision-makers and stakeholders.

Project rule:
every Question Card must state:

> **What decision/model component changes if the answer is A versus B?**

If no plausible answer changes:
- decision;
- safety rule;
- evidence architecture;
- measurement choice;
- later research priority;

then the question is low priority even if answerable.

---

# Part K — "Empty review" is not automatically worthless

## 16. Empty review can identify a real evidence gap

### Established finding / project rule
**Confidence: HIGH**

Cochrane recognizes that a question may yield no eligible evidence.

This can be useful if:
- the absence itself is important;
- the search was adequate;
- the gap informs research or cautions against unsupported decisions.

But:

> "No studies found" does not answer an effect question with "no effect".

### Project output

Use:
**NO DIRECT EVIDENCE / EVIDENCE GAP**

not:
**NO EFFECT**.

---

# Part L — Broadening a sparse question

## 17. Broader contingencies must remain scientifically coherent

### Established finding
**Confidence: HIGH**

Cochrane allows prespecified broader groupings when sparse evidence prevents synthesis.

But broader grouping changes the question.

Project rule:
before broadening:
1. preserve decision relevance;
2. document what changed;
3. reassess applicability;
4. do not combine incompatible constructs merely to obtain a meta-analysis.

If broadening destroys the decision meaning:
keep the narrow evidence gap.

# Part M — Project viability statuses

## 18. Every major question gets one viability status

1. **PROCEED_FOCUSED**
   - important, answerable enough, justified.

2. **USE_EXISTING_SYNTHESIS**
   - current credible review already answers the question.

3. **UPDATE_OR_SUPPLEMENT**
   - existing review useful but materially stale/incomplete.

4. **SCOPING_FIRST**
   - evidence landscape/definitions are too unclear for focused synthesis.

5. **EVIDENCE_GAP**
   - direct evidence absent/insufficient; gap itself is the result.

6. **DEFER_LOW_VALUE**
   - answer would not materially affect project decisions.

7. **REFRAME**
   - question is important but current structure is not coherent/answerable.

No status implies scientific certainty; it controls research routing.

# Part N — Project Review Necessity / FINER Module

Use before starting a major deep-review stream.

## A. Decision value
1. What decision/model component will this answer inform?
2. What result would change action?
3. What result would not change action?

## B. Feasible
4. Is the scope operationally manageable?
5. Is there likely enough evidence?
6. Are appropriate study designs/data available?
7. Can the project appraise/synthesize them reliably?
8. Is the question too broad or too narrow?

## C. Interesting / importance
9. Is the question worth the research effort?
10. Is interest scientific only, or decision-relevant?

## D. Novel
11. Preliminary existing-review search completed?
12. Relevant published reviews found?
13. Ongoing reviews found?
14. Last search dates?
15. Is existing review current?
16. Is it methodologically credible enough for use?
17. Is it directly applicable?
18. What exact gap remains?
19. What new value would new work add?

## E. Ethical
20. Is duplication justified?
21. Could framing omit material harms?
22. Could output create misleading confidence?
23. Is opportunity cost justified?
24. Are relevant equity consequences considered?

## F. Relevant
25. Intended user/decision-maker?
26. Downstream decision?
27. Would uncertainty reduction matter?

## G. Answerability
28. Can available evidence estimate the actual target claim?
29. Is the required estimand/construct reported?
30. Is evidence mature enough for focused synthesis?
31. If not, should it route to scoping or evidence-gap status?

   - PROCEED_FOCUSED

# Part O — How this applies to this fitness project

## 19. Deep research is not synonymous with redoing every systematic review

Project goal is:
- the best practical evidence base for later program construction.

Therefore if a current high-quality review:
- matches the question;
- includes appropriate evidence;
- is current enough;
- has acceptable methods;

the efficient route may be:
1. use it as anchor;
2. inspect critical primary evidence where necessary;
3. update only the post-search-date gap;
4. triangulate with other evidence types if decision requires it.

This preserves rigor while avoiding pointless duplication.

---

## 20. Conversely, review existence does not authorize passive acceptance

A review may be unsuitable because:
- question mismatch;
- wrong population;
- wrong intervention/comparator;
- missing harms;
- no applicability to target use;
- outdated search;
- weak methods;
- effect-modifier question not addressed.

Project rule:
**existing review = evidence object to appraise, not automatic answer.**

Order:

1. Decision/use
2. Primary objective
3. Select question type
4. Build question with appropriate module
5. Stakeholder/applicability/equity check
6. Logic model if warranted
7. **FINER / Review Necessity Gate**
8. Decide research route
9. Build Search Concept Card
10. Execute evidence search/synthesis

This prevents detailed searches for questions that should have been:
- reused;
- updated;
- scoped;
- reframed;
- deferred.

## 22. Practical rules produced by PASS-12B

1. A technically well-formed question still needs a viability check.
2. Use FINER: Feasible, Interesting, Novel, Ethical, Relevant.
3. Separate decision importance from current answerability.
4. Separate evidence feasibility, methodological feasibility, operational feasibility and scope feasibility.
5. Perform a preliminary existing-review check before a major new review.
6. Existing review does not automatically eliminate the need for new work.
7. New work must state the material added value.
8. There is no universal age cutoff defining an outdated review.
9. Use search date, field velocity, new evidence and method changes to judge update need.
10. Do not let preliminary reconnaissance silently become the synthesis.
11. Route mature questions to focused review.
12. Route unclear landscapes to scoping/mapping.
13. Label absent direct evidence as an evidence gap, not no effect.
14. Broadening sparse questions must preserve scientific and decision coherence.
15. Treat opportunity cost, misleading framing and duplication as ethical considerations.
16. Require a downstream decision/model use for relevance.
17. Assign an explicit project viability status before deep review.
18. Place the Review Necessity Gate before the Search Concept Card.
19. Deep research does not require duplicating every existing high-quality review.
20. Existing reviews remain evidence objects requiring applicability/currentness/quality checks.
