# Private Model Update Card — BLANK TEMPLATE ONLY

**ВАЖНО:** этот файл — только generic protocol.

**Никогда не заполнять его персональными данными в GitHub.**

Заполненную карточку использовать только внутри приватного ChatGPT-проекта.

## 1. Proposed model change

Что предлагается:

- retain;
- strengthen;
- weaken;
- split;
- merge;
- revise relation;
- remove;
- add new hypothesis.

## 2. Triggering observation

Какое прямое наблюдение/серия наблюдений вызвали пересмотр?

## 3. Existing proposition affected

Какая текущая гипотеза/связь модели затронута?

## 4. Candidate explanations

Минимум:

- H1;
- H2;
- H3 / null-context alternative, если релевантно.

## 5. Direct individual evidence

Что поддерживает/противоречит каждой hypothesis?

## 6. Generic scientific evidence

Какие population-level rules релевантны?

Не использовать generic pattern как substitute for individual evidence.

## 7. Alternative / contradiction check

Что ещё объясняет те же данные?

## 8. Measurement check

Наблюдение direct или proxy?

Есть ли reliability/state/context проблемы?

## 9. Causal check

Есть ли:

- temporality;
- confounding;
- reverse causation;
- feedback;
- mediator/collider ambiguity?

## 10. Predictions

Если hypothesis верна, что должно наблюдаться дальше?

## 11. Disconfirmation trigger

Какой факт должен ослабить или опровергнуть hypothesis?

## 12. Confidence

До обновления: LOW / MODERATE / HIGH.  
После обновления: LOW / MODERATE / HIGH.

Числовую вероятность использовать только если есть реальное основание, не ради псевдоточности.

## 13. Error-regression check

Какие записи `ERROR_LEDGER.md` релевантны?

## 14. Decision

Что реально меняется в модели?

## 15. Revisit trigger

При каком новом evidence пересмотреть решение?

## Privacy rule

Completed card = private material.  
Do not commit it, quote it in PR, issue, commit message, or repo example.
