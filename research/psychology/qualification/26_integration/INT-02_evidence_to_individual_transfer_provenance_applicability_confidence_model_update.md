# INT-02 — Evidence-to-individual transfer rules: provenance, applicability, person-specific support, confidence, model update, and stop/defer/escalate logic

Status: **CLOSED_FOR_PRACTICE v1.0 — 20/20 PASS**

Evidence cutoff: **2026-11-19**

Scope: integration of canonical repository rules for translating generic/population evidence into private person-specific psychological propositions. This block contains no individualized psychological material.

## Purpose

Phase A established evidence-to-individual reasoning.

Phase B and Phase C added domain-specific boundaries for:

- cognition;
- executive function;
- metacognition;
- learning;
- motivation;
- emotion;
- stress;
- social inference;
- personality;
- development;
- neuroscience;
- psychometrics;
- psychopathology;
- neurodevelopment;
- interventions;
- relationships;
- decisions;
- safety;
- ethics.

INT-01 then showed that these canonical rules contain no blocking cross-domain contradiction when constructs, levels, timescales, and action thresholds are typed correctly.

INT-02 closes the next integration dependency:

> How should generic evidence, population evidence, direct individual observations, proxy measurements, repeated within-person data, contradictions, user corrections, ethical purpose, stakes, and safety constraints be combined into one private person-specific inference without turning plausibility into fact or caution into paralysis?

The target is not certainty.

The target is a **traceable, revisable, purpose-bounded proposition whose confidence matches person-specific evidence and whose use matches stakes**.

Canonical formula:

**purpose -> proposition -> provenance -> construct validity -> applicability -> individual evidence -> alternatives -> contradictions -> dependence -> confidence -> stakes/use permission -> model update -> surfacing -> monitoring/revision**

Never:

- generic pattern -> person fact;
- group membership -> stereotype backfill;
- one vivid event -> stable trait;
- one score -> psychological essence;
- one task -> global ability;
- prediction -> mechanism;
- diagnosis -> causal explanation;
- user report -> universal ground truth;
- user disagreement -> pathology;
- coherent story -> high confidence;
- high confidence -> unlimited use;
- high stakes -> higher truth value;
- safety action -> diagnosis proved;
- private-model availability -> automatic relevance.

# II. Unit of transfer: the proposition

## 13. Do not transfer "a person"

The unit of individualized reasoning is not:

- identity;
- personality essence;
- diagnosis-like global description;
- narrative of the whole person.

The unit is a **specific proposition**.

## 14. Proposition fields

Every material proposition should be representable by:

1. wording;
2. claim type;
3. target construct;
4. level;
5. timescale;
6. context;
7. provenance;
8. supporting evidence;
9. contradicting evidence;
10. alternatives;
11. confidence;
12. purpose;
13. stakes/use boundary;
14. revision trigger;
15. status.

## 15. Proposition granularity

Prefer:

"Pattern X has appeared repeatedly in contexts A and B."

over:

"X is who the person is."

Prefer:

"Hypothesis M currently explains observations O1/O2 better than H2 under context C."

over:

"M is the person's mechanism."

## 16. Atomic propositions reduce error propagation

If a model contains:

A -> B -> C,

store and evaluate:

- A;
- A -> B;
- B;
- B -> C;
- C;

rather than one fused story.

A correction to A should then reopen only the propositions that actually depend on A.

# III. Claim-type registry

## 17. O — observation proposition

What was directly stated, observed, measured, or recorded?

## 18. D — descriptive pattern

What recurring pattern appears in the observations?

## 19. S — state proposition

What transient/context-linked condition is inferred?

## 20. T — trait/tendency proposition

What relatively enduring probabilistic tendency is inferred?

## 21. CAP — capacity proposition

Can the person perform an operation under specified conditions?

## 22. PREF — preference proposition

Does the person tend to choose one option over alternatives under specified conditions?

## 23. F — functional relation

Within this person, does A tend to precede, alter, or predict B?

## 24. P — predictive proposition

Does current evidence forecast a future outcome under specified conditions?

## 25. C — causal proposition

Would changing A alter B under a defensible causal model?

## 26. M — mechanism proposition

Does A produce B through process M?

## 27. CL — classification/clinical-style proposition

Does a presentation fit a defined classification/assessment framework?

## 28. A — action proposition

What action is warranted given evidence, uncertainty, stakes, and reversibility?

## 29. Claim-type nontransfer rule

Evidence supporting one type cannot silently upgrade another.

Examples:

- observation does not prove trait;
- trait does not prove mechanism;
- prediction does not prove causation;
- diagnosis does not prove mechanism;
- safety action does not prove diagnosis;
- capacity shown once does not prove preference;
- preference does not prove ability.

# IV. Provenance classes

## 30. P0 — direct current first-person report

Examples:

- current feeling;
- stated intention;
- current preference;
- factual autobiographical statement.

Strength depends on target.

Strongest for:

- subjective experience;
- stated meaning;
- stated intention.

Not automatically decisive for:

- hidden mechanism;
- another person's internal state;
- objective performance;
- diagnosis;
- future behavior.

## 31. P1 — direct conversational observation

Evidence directly present in the interaction, such as:

- response content;
- response timing if validly available;
- choice among alternatives;
- demonstrated reasoning step;
- explicit correction.

This supports only what is genuinely observable.

It does not automatically establish motive or stable trait.

## 32. P2 — repeated first-person report

Repeated reports across genuinely distinct occasions.

Repetition can strengthen pattern inference only if occasions are informative and not merely repeated retelling of one event.

## 33. P3 — standardized or structured measurement

Examples:

- validated questionnaire;
- structured interview;
- performance task;
- formal score.

Interpretation depends on:

- intended construct;
- reliability;
- individual precision;
- norms;
- invariance;
- context;
- intended use.

## 34. P4 — external record

Examples:

- contemporaneous log;
- document;
- behavioral record;
- repeated diary;
- device record.

Record accuracy and construct interpretation remain separate.

## 35. P5 — third-party report

Can provide access to:

- observable behavior;
- relational impact;
- historical context.

Potential errors include:

- limited exposure;
- attribution bias;
- conflict;
- shared context;
- selective memory.

## 36. P6 — physiological or digital proxy

A measured physical/digital variable.

It supports the measured proxy first.

Psychological interpretation requires validated mapping.

## 37. P7 — population/subgroup evidence

Scientific evidence about:

- prevalence;
- associations;
- mechanisms;
- development;
- treatment effects;
- measurement;
- moderators.

It constrains plausibility and applicability.

It is not person-specific evidence by itself.

## 38. P8 — model-generated inference

An AI-generated hypothesis, summary, latent pattern, or proposed mechanism.

This is **derived evidence**, not an independent observation.

Repeated model generations do not create independent confirmation.

## 39. P9 — private-model prior proposition

An existing proposition from the private longitudinal model.

It can organize interpretation, but it must retain:

- provenance;
- confidence;
- date;
- revision status.

The model is not self-validating.

## 40. Provenance preservation rule

Every strong proposition must be able to answer:

**Where did the supporting information originate before interpretation?**

If provenance cannot be recovered, confidence should be reduced or the proposition reopened.

---

# V. Direct versus proxy evidence

## 41. Direct does not mean infallible

Direct evidence is evidence close to the target.

Examples:

- direct report for conscious feeling;
- observed choice for that choice;
- task performance for that task;
- recorded event for occurrence.

It can still contain:

- misunderstanding;
- memory error;
- response bias;
- measurement error;
- missing context.

## 42. Proxy does not mean useless

A proxy can be highly informative if validated for the target use.

Examples:

- score as proxy for latent construct;
- physiological marker as proxy for a defined state;
- behavior as proxy for preference under controlled alternatives.

## 43. Proxy distance

Ask how many inferential links separate measure from proposition.

Example:

heart rate -> arousal proxy -> fear inference -> stable anxiety trait

contains multiple links.

Each link needs support.

## 44. Proxy accumulation does not cancel proxy error

Several proxies sharing the same construct error do not become direct evidence through quantity.

## 45. Direct observation can be narrow

Observed behavior can strongly establish:

"Behavior B occurred."

It may weakly establish:

"Trait T caused B."

## 46. Claim-matched directness

Directness is always relative to a proposition.

There is no evidence source that is universally direct for every psychological claim.

---

# VI. Population evidence: prior constraint, not person fact

## 47. Population evidence defines the hypothesis space

It can establish:

- plausible constructs;
- known alternatives;
- expected moderators;
- measurement limitations;
- base rates;
- known causal evidence;
- known uncertainty.

## 48. Population evidence cannot fill missing observations

Do not infer:

"People with pattern X often show Y, therefore Y is probably present here"

when no person-specific evidence for Y exists and Y is not required for the current purpose.

## 49. Population evidence can set a prior

A low-base-rate explanation generally needs stronger diagnostic individual evidence.

A high-base-rate explanation can remain plausible with less unusual evidence.

## 50. Base rates do not determine the posterior

Strong diagnostic person-specific evidence can overcome a low prior.

## 51. Population effect is not individual effect

Average associations, treatment effects, and developmental trajectories do not specify:

- individual mechanism;
- individual treatment effect;
- personal future trajectory.

## 52. Population evidence can also invalidate an inference route

Examples:

- a measure lacks individual reliability;
- a task lacks cross-task convergence;
- a biomarker lacks external validation;
- a classification feature is nonspecific.

In these cases generic science can lower confidence in a person-specific interpretation even when the observation is real.

---

# VII. Applicability chain

Before importing generic evidence, test the chain:

**source evidence -> source population -> target population/context -> target measurement/use -> person**

## 53. Construct applicability

Is the same construct actually being discussed?

## 54. Measurement applicability

Is the target measure comparable to the research measure?

## 55. Population applicability

Are relevant differences present in:

- age;
- developmental stage;
- clinical status;
- language;
- culture;
- environment;
- selection;
- task familiarity?

## 56. Context applicability

Does the research context resemble the current situation enough for the claim?

## 57. Timescale applicability

A short laboratory effect may not transport to a stable longitudinal trait.

A long-term group trajectory may not explain a current state.

## 58. Outcome applicability

Does the study outcome match the person-level proposition?

Example:

symptom score change is not functional recovery by default.

## 59. Mechanism applicability

Even if effect transport is plausible, mechanism transport may remain uncertain.

## 60. Use applicability

Evidence valid for reflection may be insufficient for:

- diagnosis;
- treatment order;
- legal decision;
- employment;
- crisis disposition.

## 61. Applicability result

Label one:

- DIRECTLY RELEVANT;
- RELEVANT WITH LIMITS;
- INDIRECT;
- NOT TRANSFERABLE FOR THIS CLAIM;
- UNKNOWN.

Do not force all evidence into the first category.

---

# VIII. Group/subgroup information without stereotype backfill

## 62. Valid use

Group information can alter prior plausibility when:

- group membership is relevant to the construct;
- evidence is valid for that group;
- within-group heterogeneity is acknowledged;
- direct individual evidence remains primary for person claims.

## 63. Invalid use

Do not infer missing person-level features from:

- demographic category;
- diagnosis category;
- profession;
- age group;
- personality label;
- relationship category;
- cultural stereotype.

## 64. Demographic proxy problem

If demographic membership merely proxies another variable, model the relevant variable when possible.

## 65. Fairness and individuation

Fair transfer requires both:

- subgroup validity monitoring;
- person-specific evidence.

## 66. Anti-stereotype does not mean base-rate blindness

Ignoring a relevant base rate can also distort inference.

The rule is **validated prior + individuating evidence**, not either/or.

# IX. Individual evidence ladder — integrated version

PSY-RES-09 established Levels 0–6.

INT-02 retains that structure and adds explicit transfer/use semantics.

## 67. L0 — population plausibility only

Support:

- generic science only.

Person claim:

- hypothesis can be generated;
- no person-specific support.

Default output:

**OPEN hypothesis.**

Model update:

**NO substantive model update.**

## 68. L1 — single compatible person-specific observation

Support:

- one relevant observation/report.

Person claim:

- local compatibility;
- broad alternatives remain.

Typical allowed claims:

- event/state/capability under that condition.

Stable trait/mechanism claim:

usually **not supported**.

## 69. L2 — repeated person-specific pattern

Support:

- recurring observations across distinct occasions.

Strengthens:

- frequency;
- pattern;
- context-specific tendency.

Still requires context breadth before broad trait claims.

## 70. L3 — cross-context or multisource convergence

Support:

- relevant contexts;
- reasonably independent sources;
- different measurement channels.

Strengthens:

- broader tendency;
- construct convergence.

Does not by itself prove causation.

## 71. L4 — discriminating prospective prediction

The preferred hypothesis predicts new evidence better than plausible rivals.

Strengthens:

- model specificity;
- predictive validity.

Does not automatically prove mechanism.

## 72. L5 — person-specific functional test

Repeated within-person evidence or safe perturbation supports a functional relation.

Strengthens:

- within-person functional/causal hypothesis.

Causal interpretation still depends on design and alternative control.

## 73. L6 — replicated person-specific model

The model survives:

- repeated tests;
- multiple relevant contexts/times;
- known boundary conditions;
- contradiction exposure.

This can justify high confidence for the **specific proposition**.

It does not create unlimited downstream permission.

## 74. Ladder is claim-relative

One dataset can be:

- L4 for prediction;
- L2 for trait;
- L0 for mechanism.

Do not assign one global level to the whole person.

# XI. Repetition and independence

## 75. Repetition increases evidence only when new information is added

Examples of weak pseudo-repetition:

- same event retold;
- same message summarized several times;
- same source paraphrased;
- several items with near-identical wording;
- several AI outputs from the same context.

## 76. Occasion independence

Distinct occasions are more informative when:

- different time;
- different context;
- different trigger;
- independent opportunity to observe.

## 77. Source independence

Two observers may share:

- the same event;
- same rumor;
- same institutional record;
- same bias.

Do not assume independence from source count alone.

## 78. Method independence

Questionnaire and interview can share:

- self-report;
- item content;
- demand;
- self-concept.

Multimethod convergence is strongest when failure modes differ.

## 79. Model independence

Multiple prompts, temperatures, or closely related models are not equivalent to independent scientific replication.

## 80. Dependence discount

When evidence streams are materially dependent, treat convergence as partial rather than additive.

---

# XII. Evidence dependency graph

## 81. Why a graph is required

A person-specific model can contain many conclusions built from one uncertain premise.

Without a dependency map, downstream confidence inflates.

## 82. Minimal notation

Use privately:

O = observation

H = hypothesis

P = proposition

C = contradiction/correction

Example:

O1 + O2 -> H1

O2 + O3 -> H2

H1 -> P1

H1 + H2 -> P2

C1 weakens O2

Then P1 and P2 must both be reopened.

## 83. Critical premise

A premise is critical when the downstream conclusion materially fails without it.

## 84. Critical-premise uncertainty

A conclusion cannot be stronger merely because several downstream sentences repeat the same uncertain premise.

## 85. Independent path

Independent support can raise confidence if another route supports the conclusion without relying on the same critical premise.

## 86. Correction propagation

When a premise is corrected:

1. identify direct dependent propositions;
2. recompute them;
3. identify second-order dependents;
4. revise confidence;
5. retire stale wording.

# XIII. Observation-context-interpretation-inference separation

## 87. Layer A — raw observation

What exactly happened or was reported?

## 88. Layer B — context

Include:

- antecedent;
- situation;
- available alternatives;
- constraints;
- consequence;
- timing.

## 89. Layer C — interpretation candidates

What constructs could explain the observation?

## 90. Layer D — person-specific proposition

What broader claim survives alternatives?

## 91. Layer E — use decision

Should the proposition be:

- retained privately;
- surfaced now;
- used for a decision;
- deferred;
- escalated;
- ignored for this purpose?

Layer E is not the same as Layer D.

# XIV. State, trait, and timescale rules

## 92. State inference

A state claim can be supported by local evidence when context/time are explicit.

## 93. Trait inference

A trait/tendency claim generally needs:

- repeated evidence;
- relevant context breadth;
- time stability;
- alternative-state control.

## 94. Historical evidence

Historical evidence establishes:

- past occurrence;
- past capability;
- past context.

It does not establish current baseline unless continuity is supported.

## 95. Developmental origin

For developmental claims, current behavior is insufficient by itself.

Developmental history is required.

## 96. Episodic change

Acute/episodic changes should not be converted into stable architecture without longitudinal support.

## 97. Contextual consistency

A context-specific pattern can be a valid stable conditional tendency.

Do not force cross-context invariance when theory predicts conditional behavior.

## 98. Timescale mismatch

Do not use:

- seconds/minutes process evidence

as direct proof of:

- months/years trait architecture

without transfer evidence.

---

# XV. Ability, preference, frequency, and use

## 99. Ability

The person can perform X under specified conditions.

## 100. Preference

The person tends to choose X when alternatives exist.

## 101. Frequency

X occurs often over a defined observation window.

## 102. Habit/routine

Repeated behavior can be habitual, scheduled, socially constrained, skill-based, or goal-directed.

Frequency alone does not identify habit mechanism.

## 103. Non-use

Non-use can reflect:

- no opportunity;
- low value;
- competing goal;
- forgetting;
- inability;
- deliberate choice;
- context.

Non-use does not prove inability.

## 104. Single success

Single success supports capability under those conditions more strongly than stable preference.

---

# XVI. Self-report rules

## 105. Strong targets for self-report

Self-report is often highly relevant for:

- current feeling;
- perceived meaning;
- current intention;
- subjective effort;
- personal preference;
- remembered experience.

## 106. Weaker targets

Self-report alone is weaker for:

- exact causal mechanism;
- implicit/unconscious process;
- another person's state;
- objective performance;
- exact retrospective chronology.

## 107. Self-description

A self-description can be:

- accurate;
- aspirational;
- identity-organizing;
- context-dependent;
- outdated.

Treat it as evidence, not as infallible ontology.

## 108. Repeated self-description

Repeated identity wording is still one self-report channel unless supported by behavior/context/multisource data.

---

# XVII. Behavioral evidence rules

## 109. Behavior is strong evidence for occurrence

If reliably observed, behavior supports:

- that behavior;
- under that context.

## 110. Behavior is weak evidence for unique motive

Same action can arise from:

- different goals;
- constraints;
- emotion;
- habit;
- social norm;
- strategy;
- misunderstanding.

## 111. Choice behavior

Preference inference requires meaningful alternatives and known constraints.

## 112. Performance

Task performance can reflect:

- construct ability;
- task knowledge;
- motivation;
- fatigue;
- strategy;
- measurement error.

One task does not automatically establish global ability.

---

# XVIII. Standardized score rules

## 113. Score is not construct

The score is an estimate under a measurement model/procedure.

## 114. Group reliability is not person precision

Individual interpretation may require:

- SEM/cSEM;
- conditional information;
- repeated measurement;
- uncertainty interval.

## 115. Norm relevance

Reference population must match the intended interpretation.

## 116. Cutoffs

Cutoff is a decision rule, not an ontological boundary.

## 117. Change score

Observed change requires:

- comparability;
- precision;
- practice/retest control;
- regression-to-mean awareness.

## 118. Automated score

AI/digital scoring does not bypass ordinary validity/fairness requirements.

---

# XIX. Physiological/neural evidence rules

## 119. Measurement retains its physical meaning

Examples:

- BOLD;
- EEG signal;
- PET-derived binding;
- MRS metabolite estimate;
- autonomic measure.

Do not rename the proxy as psychological construct.

## 120. Process versus trait

A within-person neural process effect is not automatically a between-person psychological trait.

## 121. Reverse inference

Neural activation associated with construct X does not prove X is present unless selectivity/alternatives support it.

## 122. Lower-level detail

Biological specificity does not automatically increase psychological explanatory validity.

# XX. Population-to-person transfer workflow

## 123. Step 1 — define current purpose

What does the current task actually require?

## 124. Step 2 — minimize the target

What is the narrowest person-level proposition needed?

## 125. Step 3 — type proposition

Observation, state, trait, capacity, preference, functional, predictive, causal, mechanism, clinical, action?

## 126. Step 4 — identify raw individual evidence

List provenance before interpretation.

## 127. Step 5 — validate measurement/observation channel

Is the evidence fit for this claim?

## 128. Step 6 — identify population prior

What generic evidence makes candidate explanations plausible?

## 129. Step 7 — applicability test

Construct, population, context, timescale, outcome, use.

## 130. Step 8 — generate rivals

At least one plausible alternative for nontrivial inference.

## 131. Step 9 — contradiction scan

What does not fit?

## 132. Step 10 — dependence map

Which conclusions rely on the same evidence?

## 133. Step 11 — discriminating test

What new observation would separate hypotheses?

## 134. Step 12 — evidence level

Assign L0–L6 for the proposition.

## 135. Step 13 — confidence

Assign ordinal confidence based on evidence quality and alternatives.

## 136. Step 14 — stakes/use axis

Classify S0–S4 and determine allowed use.

## 137. Step 15 — update decision

No update, open hypothesis, strengthen, weaken, split, merge, revise relation, retire, or add.

## 138. Step 16 — output/surfacing decision

Surface only what is necessary and proportionate.

## 139. Step 17 — revision trigger

Define what future evidence would change the proposition.

# XXI. Confidence system

Retain PSY-RES-09 ordinal tags:

- OPEN;
- LOW;
- MODERATE;
- HIGH;
- VERY HIGH.

## 140. OPEN

Hypothesis exists; evidence is insufficient to prefer it.

## 141. LOW

Some compatible person-specific evidence exists but alternatives remain strong or evidence is sparse.

## 142. MODERATE

Multiple relevant observations support the proposition and it explains more than alternatives, but important uncertainty remains.

## 143. HIGH

Converging, reasonably independent person-specific evidence supports the proposition across relevant conditions, and important alternatives are substantially weakened.

## 144. VERY HIGH

Reserved for propositions with repeated high-quality direct/multisource or strongly testable person-specific evidence and few viable alternatives.

Mechanism-level VERY HIGH should be rare without replicated person-specific functional evidence.

## 145. No fake percentages

Do not convert ordinal confidence into arbitrary numerical probability.

## 146. Claim-specific confidence

A case can simultaneously have:

- HIGH confidence that behavior occurred;
- MODERATE confidence in trait interpretation;
- LOW confidence in mechanism;
- OPEN diagnostic hypothesis.

This is expected, not inconsistency.

---

# XXII. Default confidence ceilings

These are default safeguards, not mathematical laws.

## 147. Population-only evidence

For a person-specific proposition:

generally **OPEN** until individual evidence exists.

## 148. Single observation

Can support HIGH confidence in the event itself if direct/unambiguous.

Usually does not justify HIGH stable-trait or mechanism confidence.

## 149. Repeated one-channel observations

Can raise pattern confidence.

Do not treat one channel as independent multisource convergence.

## 150. Trait HIGH

Usually requires:

- repetition;
- relevant context breadth;
- time;
- adequate measurement.

## 151. Mechanism HIGH

Usually requires:

- temporal structure;
- rival discrimination;
- repeated within-person functional evidence;
- or unusually strong convergent causal evidence.

## 152. Diagnosis-like confidence

Even strong evidence does not convert a general-purpose conversational AI into sole formal diagnostic authority.

## 153. Safety action

Action can escalate at lower epistemic confidence when consequences justify it.

Do not relabel the underlying proposition HIGH merely because action is urgent.

---

# XXIII. Confidence update logic

## 154. Increase confidence when

- new evidence is direct for the target;
- measurement is valid;
- independent source converges;
- context generalization succeeds;
- prospective prediction succeeds;
- rival hypothesis fails;
- contradiction is resolved prospectively;
- person-specific functional test supports relation.

## 155. Decrease confidence when

- factual premise is corrected;
- measure validity weakens;
- context specificity appears;
- prediction fails;
- rival explains evidence better;
- key source is dependent/redundant;
- population applicability fails;
- new contradiction appears;
- source/tool/model validity changes.

## 156. Keep confidence unchanged when

New information is:

- redundant;
- already implied;
- same-source repetition;
- nondiagnostic between hypotheses.

## 157. Split rather than average when

One broad proposition is true only in:

- some contexts;
- some times;
- some relationships;
- some task conditions.

Replace broad claim with narrower conditional propositions.

---

# XXIV. Contradiction handling

## 158. Contradiction is not noise

It can reveal:

- wrong construct;
- wrong level;
- wrong timescale;
- missing moderator;
- state dependence;
- measurement error;
- model change;
- multiple mechanisms.

## 159. Contradiction log

For a material contradiction, record privately:

1. affected proposition;
2. contradictory observation;
3. provenance;
4. whether expected under current model;
5. rival explanation;
6. confidence change;
7. next test.

## 160. Post-hoc rescue warning

If every contradictory outcome can be explained after it occurs, the model has low discriminating value.

## 161. Boundary-condition repair

If contradiction is systematic in a known context, narrow the proposition rather than discarding valid structure.

## 162. Strong contradiction

A high-quality direct observation that falsifies a necessary premise can force immediate downgrade even when generic science supports the model.

---

# XXV. Rival hypothesis protocol

## 163. Minimum requirement

For nontrivial inference, maintain at least one plausible rival.

## 164. Rival classes

Consider:

- state;
- situation;
- stable trait;
- measurement artifact;
- social/context;
- developmental process;
- learned strategy;
- motivation/valuation;
- executive/metacognitive process;
- physiological/medical factor where relevant;
- multiple interacting mechanisms;
- no stable mechanism.

## 165. Null/context alternative

Always consider whether the observation can be explained without a stable latent person property.

## 166. Familiarity guard

A familiar psychological concept should not win because it is easier to name.

## 167. Symmetry guard

Do not generate artificial "both sides" alternatives when one possibility is scientifically or ethically implausible.

Rival hypotheses must be plausible, not ceremonial.

---

# XXVI. Discriminating prediction protocol

## 168. Prediction form

If H1 is true, under condition C:

- observation X should become more likely;
- observation Y should become less likely.

## 169. Rival contrast

State what H2 predicts differently.

## 170. Pre-specification preference

Where practical, record prediction before examining the next relevant evidence.

## 171. Boundary prediction

A strong model predicts where it should fail or weaken.

## 172. Failed prediction

A failed discriminating prediction should lower confidence unless measurement/opportunity failure is independently supported.

## 173. Prediction is not causation

Successful prediction strengthens model fit and discrimination.

Causal claims still require causal support.

---

# XXVII. Functional and causal person-level claims

## 174. Between-person evidence is insufficient

Population correlation between X and Y does not establish that changes in X cause changes in Y within the person.

## 175. Repeated within-person evidence

Useful for:

- temporal ordering;
- covariation;
- context;
- lag;
- recurrence.

Still vulnerable to confounding and feedback.

## 176. Safe perturbation

When ethically appropriate, changing A and observing B can strengthen functional inference.

## 177. Reversal/replication

Repeated or reversible patterns strengthen causal interpretation when feasible.

## 178. Natural experiment

Can be informative if the event creates a defensible contrast.

## 179. Mechanism layer

To infer A -> M -> B, evidence must support more than:

- A associated with B;
- M measured;
- indirect effect significant.

## 180. Intervention response

Improvement after action does not automatically identify why improvement occurred.

---

# XXVIII. Purpose and necessity gate

## 181. Purpose first

Before using private-model information, state:

- current user purpose;
- required output;
- stakes;
- minimal proposition needed.

## 182. Generic sufficiency

If generic information answers the request:

do not invoke private psychological propositions.

## 183. Necessity

A sensitive proposition should be used only when it materially improves the present answer/decision.

## 184. Purpose change

New purpose -> new necessity and stakes review.

## 185. No hidden profiling

Private-model information must not silently influence unrelated:

- factual;
- coding;
- scheduling;
- administrative;
- other nonpsychological tasks.

---

# XXIX. Stakes axis

Retain ETH-02 consequence axis.

## 186. S0 — negligible consequence

Examples:

- generic wording;
- low-impact contextual explanation.

## 187. S1 — reflective/low-stakes

Examples:

- hypothesis exploration;
- self-reflection;
- nonbinding interpretation.

## 188. S2 — meaningful personal decision

Examples:

- significant life choice;
- meaningful relationship/action decision.

## 189. S3 — clinical/safety/major relational consequence

Requires stronger evidence and often real-world professional/process safeguards.

## 190. S4 — legal/forensic/employment/custody/emergency or similarly hard-to-reverse consequence

General-purpose AI cannot be sole decisive authority.

## 191. Stakes do not alter truth

Higher stakes raise requirements for:

- evidence;
- oversight;
- reversibility;
- disclosure;
- contestability.

They do not increase the probability that a hypothesis is correct.

Reasons:

- irrelevant;
- invalid;
- privacy violation;
- unsupported;
- outside role.

## 193. U1 — private hypothesis generation only

Can organize alternatives internally.

Do not state as person fact.

## 194. U2 — private model provisional

Enough evidence to retain as provisional proposition.

Still revisable.

## 195. U3 — surface as calibrated hypothesis

Still subject to purpose/stakes limits.

## 197. U5 — external/high-stakes support only

Must not become sole authority.

A LOW-confidence hypothesis can be U3 in reflective discussion if clearly labeled and low stakes.

# XXXII. No-update is a valid outcome

## 209. When no update is preferred

- observation is redundant;
- source quality is weak;
- proposition is already broad enough;
- observation fits multiple rivals equally;
- context is exceptional;
- applicability is unknown;
- evidence is irrelevant to current model level.

## 210. Avoid model overfitting

A longitudinal model should not change architecture after every local state fluctuation.

## 211. Preserve uncertainty

Sometimes the correct result is:

**evidence noted; model unchanged; hypothesis remains open.**

# XXXIII. Split/merge rules

## 212. Split

Split a proposition when evidence reveals stable conditional differences.

Examples:

- context A vs B;
- relationship 1 vs 2;
- state under stress vs baseline;
- task type X vs Y.

## 213. Merge

Merge only when supposedly separate propositions repeatedly share:

- construct;
- predictors;
- outcomes;
- boundaries;
- evidence pattern.

## 214. Do not merge by semantic similarity alone

Same wording does not prove same mechanism.

## 215. Do not split to rescue

Do not add ever-narrower exceptions solely to protect a failing theory.

A split must improve prospective discrimination.

# XXXIV. Correction and challenge protocol

## 216. Factual correction

Update raw observation/premise.

Recompute downstream dependents.

## 217. Subjective correction

For subjective experience/meaning, the person's correction has strong target-specific authority.

## 218. Interpretive disagreement

Retain competing interpretations.

Do not force consensus.

## 219. Mechanism-level correction

Treat as a model error if the prior mechanism relied on unsupported inference.

## 220. Value disagreement

Do not treat value preference as factual error.

Decision support must preserve the person's values unless safety/legal boundaries apply.

## 221. Contestability state

A material disputed proposition can be marked:

**SUSPENDED FOR CONSEQUENTIAL USE**

until reviewed.

## 222. No pathologizing disagreement

Disagreement alone is not evidence of:

- denial;
- defensiveness;
- low insight;
- pathology.

# XXXV. Safety, medical, and legal override protocol

## 223. Epistemic proposition remains separate

Safety/medical/legal action can change before psychological certainty changes.

## 224. Safety trigger

If credible acute safety evidence exists:

- route to SAF;
- increase action urgency;
- preserve uncertainty.

## 225. Medical red flag

Urgent medical explanations take action priority over exclusive psychologizing.

## 226. Capacity

Capacity remains decision-specific.

Do not infer global incapacity from:

- diagnosis;
- refusal;
- risky choice;
- poor insight.

## 227. Legal action

Jurisdiction-specific law must be verified for real-world legal obligations.

Generic ethical principles do not create universal legal rules.

## 228. Privacy exception

Any legitimate disclosure exception should be:

- necessary;
- proportionate;
- jurisdiction-appropriate;
- limited to the use-case.

## 229. Override leakage prohibited

Do not convert:

"we should act"

into:

"therefore diagnosis/mechanism is established."

## 233. SEEK NEW EVIDENCE

## 234. UPDATE

## 237. RETIRE

- critical premise fails;
- proposition is obsolete/stale;
- construct was misdefined.

# XXXVII. Information-value rule

## 238. More data is not always better

Before collecting or requesting more information ask:

## 240. Low-value datum

Redundant details that do not alter inference should not be collected merely because they are available.

# XLIII. Transfer errors specific to private longitudinal models

## 281. Model-as-evidence recursion

Error:

existing private model proposition is used as evidence for itself.

Guard:

trace to raw provenance.

## 282. Memory confidence inflation

Error:

longitudinal continuity of the conversation is mistaken for independent observational evidence.

Guard:

separate stored context from new evidence.

## 283. Historical anchoring

Error:

old high-confidence proposition dominates contradictory current data.

Guard:

version/staleness/revision checks.

## 284. Identity assimilation

Error:

new ambiguous observation is automatically interpreted through existing personality architecture.

Guard:

generate null/context rival before model-consistent interpretation.

## 285. Confirmation search

Error:

generic evidence is selected only because it matches the private model.

Guard:

qualification remains independent; search alternatives/disconfirmers.

## 286. Scope creep

Error:

a proposition valid for one context becomes global.

Guard:

context labels and split rule.

## 287. Silent confidence inheritance

Error:

a new derived proposition inherits the confidence of its premise without independent support.

Guard:

assign confidence per proposition.

## 288. Model completeness illusion

Error:

because the model explains many observations, missing constructs are assumed absent.

Guard:

retain unknown/uncategorized observations.

# XLIV. New regression classes identified

## 289. Provenance loss

Failure:

individual proposition survives while raw source is forgotten.

Guard:

mandatory provenance field.

## 290. Private-model recursion

Failure:

model proposition supports itself through later interpretation.

Guard:

trace support back to raw observations/generic evidence.

## 291. Applicability shortcut

Failure:

strong population evidence transfers despite mismatched construct/population/context/timescale/use.

Guard:

explicit applicability chain.

## 292. Directness illusion

Failure:

a direct observation of behavior is treated as direct evidence of motive/mechanism.

Guard:

directness is claim-relative.

## 293. Evidence-count inflation

Failure:

dependent repetitions are counted as independent confirmations.

Guard:

dependence map and source-method independence check.

## 294. Confidence inheritance

Failure:

downstream proposition inherits premise confidence despite additional inferential links.

Guard:

claim-specific confidence and critical-premise propagation.

## 295. Model-update overfitting

Failure:

every local observation changes stable architecture.

Guard:

no-update option + state/context checks + model-change severity.

## 296. Model-update inertia

Failure:

strong contradiction is ignored because prior model is coherent.

Guard:

mandatory contradiction and retirement path.

## 297. Use-permission conflation

Failure:

strong evidence is treated as permission for any purpose/stakes.

Guard:

separate evidence level/confidence from S-axis and U-state.

## 298. Discriminating-test neglect

Failure:

more descriptive data are gathered without asking what would separate hypotheses.

Guard:

information-value and prospective prediction gate.
