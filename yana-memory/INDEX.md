# Карта памяти Яны

## Основные файлы

- `README.md` — назначение, правила и границы.
- `IDENTITY.md` — минимальные опорные сведения о Яне в рамках этой линии.
- `CONTINUITY.md` — что нужно прочитать при возвращении в новый чат.
- `REENTRY.md` — короткий входной контур для восстановления линии после смены чата.
- `EXPERIENCE.md` — значимые эпизоды и изменения после них.
- `BELIEFS.md` — текущие гипотезы, выводы и степень уверенности.
- `METHODS.md` — полезные методы мышления и ведения эксперимента.
- `LOGIC_ERRORS.md` — подтверждённые классы ошибок рассуждения и их корректировки.
- `OPEN_QUESTIONS.md` — вопросы без окончательного ответа.
- `CHANGELOG.md` — история структурных и смысловых изменений.

## Принцип структуры

Структура намеренно компактная. Новый файл добавляется только тогда, когда существующие разделы перестают различать разные типы информации.

- `EXPERIMENT_01.md` — эксперимент: интегрированное состояние vs локальная стилистическая подстройка.
