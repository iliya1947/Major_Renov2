# PHY-18 — Detraining / retraining / muscle memory

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-18**  
Область: 03 — Physiology

## 0. Core decision

Detraining is not one biological clock.

Canonical model:

`trained state`
`→ reduced/absent training stimulus`
`→ outcome-specific regression`
with different rates for:

- strength;
- muscle size;
- neural/skill function;
- muscle architecture;
- cardiorespiratory fitness;
- cellular/molecular states.

Residual adaptation can remain, and retraining can reacquire recent losses rapidly.

“Muscle memory” is not one mechanism.

## 1. Ordinary detraining vs severe disuse

Training cessation in an otherwise active person is not equivalent to:

- immobilization;
- bed rest;
- denervation;
- severe inactivity.

Project rule:

**do not transfer severe-disuse loss rates directly to normal training breaks.**

## 2. Strength loss

Strength can decline through:

- neural/coordination changes;
- task familiarity;
- muscle size;
- architecture;
- mechanical properties.

Project rule:

**strength loss ≠ muscle loss.**

No universal percentage-per-week rule is retained.

## 3. Muscle-size loss

Muscle size can regress with sufficiently long cessation.

Short breaks may show little measurable atrophy.

Project rule:

**atrophy is duration-, muscle-, population- and measurement-dependent.**

## 4. Neural detraining

Neural/skill changes can contribute to early performance loss.

TMS/EMG measures are informative but not interchangeable with performance and are not universal biomarkers.

Project rule:

**early performance decline can occur without large structural loss.**

## 5. Muscle architecture

Fascicle length, pennation angle, serial sarcomere number and CSA can regress at different rates.

Project rule:

**preserved CSA does not prove preserved architecture.**

## 6. Cardiorespiratory detraining

VO2max can decrease after both short and long training cessation.

Loss from the trained peak does not automatically mean complete return to pre-training baseline.

Project rule:

**cardiorespiratory detraining can coexist with residual adaptation.**

## 7. Residual adaptation

After cessation, an individual can retain:

- strength;
- muscle size;
- architecture;
- cardiorespiratory fitness;
- motor skill;
- cellular/molecular history

to different degrees.

Project rule:

**retention is graded, not all-or-none.**

## 8. Maintenance dose

Some adaptations can be maintained with substantially less training than was required to develop them.

One study found weekly concurrent training largely maintained measured adaptations for 12 weeks and one session every 14 days retained roughly 90–95% in that protocol.

Project rule:

**maintenance can require lower dose than development, but exact dose is not universal.**

## 9. Retraining

Previously acquired strength/size can return rapidly after a recent break.

Project rule:

**rapid regain is plausible and observed, but there is no universal retraining multiplier.**

## 10. Muscle memory: construct boundary

Muscle memory can describe:

1. functional regain;
2. neural/skill retention;
3. residual structural adaptation;
4. retained myonuclei;
5. epigenetic/transcriptional memory;
6. proteomic memory.

Project rule:

**these phenomena must not be collapsed into one mechanism.**

## 11. Human myonuclear memory

Current human evidence is mixed across contexts.

A 2024 within-person strength-training study showed training-acquired myonuclei were retained over 16 weeks of detraining.

However:

- a 2022 systematic review/meta-analysis did not support universal human myonuclear permanence across atrophy evidence;
- a 2025 review states indefinite persistence/removal remains unresolved;
- the 2024 study did not show clearly greater delta hypertrophy during retraining.

Project rule:

**context-specific myonuclear retention is supported; universal/indefinite permanence and causal faster hypertrophy are not established.**

## 12. Epigenetic memory

Human muscle can retain methylation/transcriptional signatures through detraining and retraining.

Project rule:

**molecular epigenetic memory does not automatically imply superior physiological retraining.**

## 13. Proteomic memory

Resistance training can leave some retained protein changes after cessation while many other changes reverse.

Project rule:

**retained proteomic signatures demonstrate biological history, not a master causal memory mechanism.**

## 14. Returning trainee vs novice

A returner may retain:

- motor skill;
- neural coordination;
- residual strength/size;
- architecture;
- aerobic/metabolic adaptation;
- cellular/molecular history.

Project rule:

**a returner is not automatically an absolute novice, but current capacity—not historical best—governs re-entry.**

## 15. Canonical project rules

1. Detraining has multiple clocks.
2. Normal training cessation ≠ immobilization/bed rest.
3. Strength loss ≠ muscle-size loss.
4. Neural/skill loss can precede large atrophy.
5. Architecture variables can decay independently.
6. VO2max loss ≠ complete erasure of aerobic adaptation.
7. Residual adaptation is graded.
8. Maintenance dose can be lower than development dose.
9. Retraining can regain recent losses rapidly.
10. No fixed retraining multiplier exists.
11. Muscle memory is not one mechanism.
12. Human myonuclear retention is context specific.
13. Universal/indefinite myonuclear permanence is unproven.
14. Retained myonuclei do not yet prove faster hypertrophy.
15. Epigenetic/proteomic memory ≠ guaranteed functional advantage.
16. Returners require progressive re-exposure based on present capacity.

## 16. Training-relevant implications

1. **Do not catastrophize short training breaks as complete loss.**
2. **Do not infer atrophy from a temporary strength drop.**
3. **Assess strength, size, skill and conditioning separately after a break.**
4. **Do not assume all adaptations decay at the same rate.**
5. **Use prior training history as relevant context, not as a fixed bonus.**
6. **Expect possible rapid regain after recent detraining without guaranteeing it.**
7. **Do not prescribe from myonuclear/epigenetic/proteomic theories alone.**
8. **Use current tolerance and testing to set return dose.**

## 17. What PHY-18 does not prescribe

Not owned here:

- exact maintenance frequency;
- exact return load/volume;
- return after injury/illness;
- individualized retraining progression;
- testing battery;
- nutrition during detraining/retraining.

These remain PRO, GPP, REC, MED, TST, NUT and IND.

## 18. Confidence

### HIGH
- detraining is outcome specific;
- strength and muscle size are distinct;
- VO2max declines with training cessation;
- residual adaptations can persist;
- retraining can restore recent losses rapidly;
- functional and molecular memory are distinct.

### MODERATE-HIGH
- neural/skill changes can contribute to early performance loss;
- architecture can regress independently of CSA;
- reduced training can preserve substantial adaptations in some protocols;
- molecular/proteomic signatures can persist.

### MODERATE / CONTEXT-DEPENDENT
- exact individual loss rates;
- exact duration of retained advantage;
- general human myonuclear permanence;
- causal contribution of retained myonuclei to regrowth;
- functional magnitude of epigenetic/proteomic memory;
- exact minimum maintenance dose.
