# Источники аудита области 08 — техника и выбор упражнений

Дата аудита: 2026-11-16.

1. NSCA — CSCS Exam Description  
   https://www.nsca.com/certification/cscs/certified-strength-and-conditioning-specialist-exam-description/

   Exercise Technique domain используется для проверки крупных категорий: movement preparation, free weights, machines, alternative modes/nontraditional implements, speed/agility/plyometric technique, energy-system and recovery techniques.

2. NSCA — CSCS Detailed Content Outline / Certification Handbook  
   https://www.nsca.com/globalassets/certification/certification-pdfs/nsca-certification-handbook.pdf

   Использовано для technique details:
   - body/limb positions;
   - movement mechanics;
   - breathing;
   - spotting/setup;
   - assess/cue/modify by competency and safety.

3. ACSM — Certified Exercise Physiologist Content Outline  
   https://www.acsm.org/wp-content/uploads/2024/12/ACSM-Certified-Exercise-Physiologist-Exam-Content-Outline.pdf

   Использовано для проверки:
   - teaching/demonstrating different modalities;
   - identifying improper/unsafe form;
   - cueing correction;
   - safe strength/flexibility application.

4. NSCA — Essentials of Personal Training excerpt: Types of Resistance Training Equipment  
   https://dxpprod.nsca.com/certification/nsca-cpt/essentials-of-personal-training--3rd-edition/excerpts/types-of-resistance-training-equipment/

   Использовано для modality/equipment classification and practical constraints.

## Ограничение

Конкретная техника каждого упражнения не считается установленной этой картой. Она будет исследоваться отдельно с anatomy/biomechanics evidence и с учётом индивидуальной антропометрии.
