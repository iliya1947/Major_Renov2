# RES-02 / PASS-06F2 — Q Methodology standalone study structures

Статус: **COMPLETE — Q METHODOLOGY TAXONOMY ESTABLISHED FOR RES-02 STRUCTURAL USE**  
Дата: 2026-11-18  
Topic: RES-02 — Study designs / what they answer

## Purpose

Этот PASS закрывает taxonomy-level архитектуру **Q Methodology** как отдельной parent methodology внутри F-ветки.

Главная задача:

> сохранить Q как самостоятельную методологию исследования субъективности, не сводя её ни к generic qualitative research, ни к generic mixed methods, ни к обычному R-mode factor analysis, и явно зафиксировать дизайн Q-set/P-set, Q-sort, by-person factor analysis, factor solution, interpretation, longitudinal variants, reporting, provenance и границы выводов.

---

# 1. Final project classification

Project route:

**Q_METHODOLOGY**

Q Methodology = систематическая методология исследования субъективных viewpoints / perspectives / configurations of meaning через:

1. concourse;
2. Q-set / Q-sample;
3. P-set;
4. condition of instruction;
5. Q-sort;
6. intercorrelation of Q-sorts;
7. by-person factor/component analysis;
8. factor extraction + retention + rotation;
9. defining Q-sorts;
10. factor arrays;
11. distinguishing / consensus statements;
12. interpretive construction of viewpoints;
13. optional but highly useful post-sort qualitative material.

### Critical classification rule

Author may call Q:

- qualitative;
- quantitative;
- mixed;
- hybrid;
- qualiquantological.

The project preserves that author label separately, but the enacted route remains:

**Q_METHODOLOGY**.

Q does not need to be reclassified into the generic mixed-method branch merely because it combines ranking/factor-analytic and interpretive operations.

---

# 2. Scientific product

The primary Q product is not:

- an effect estimate;
- prevalence;
- diagnostic accuracy;
- prediction;
- latent-variable measurement model;
- average attitude score.

The core product is:

> a set of empirically reconstructed shared configurations of subjectivity/viewpoints expressed through factor arrays and interpreted from the relative arrangement of the complete Q-set.

Therefore a Q factor is best routed as a **viewpoint configuration**, not as a conventional latent trait score.

---

# 3. Concourse

The **concourse** is the broader discourse/universe of communicability around the topic from which the Q-set is sampled.

Possible sources:

- interviews;
- focus groups;
- literature;
- policy documents;
- media;
- stakeholder materials;
- observations;
- prior qualitative research;
- combinations of these.

### Required project fields

1. concourse definition;
2. source types;
3. source population/context;
4. date/version boundaries;
5. language;
6. extraction procedure;
7. deduplication/merging rule;
8. excluded content;
9. stakeholder contribution;
10. provenance.

### Critical rule

A Q-set cannot be appraised only by its final number of statements.

Its validity depends strongly on whether the relevant discourse/viewpoint space was represented during construction.

---

# 4. Q-set / Q-sample construction

The **Q-set** is the finite set of items/statements participants rank.

Items may be:

- verbal statements;
- visual materials;
- other sortable stimuli.

Current 2026 methodological work provides a seven-step interview-derived Q-sample development route and emphasizes:

- broad viewpoint capture;
- mapping of themes/subthemes;
- coverage/balance;
- transformation of source material into sortable statements;
- preservation of participant language where possible;
- iterative editing;
- clarity and self-reference;
- piloting.

### Project rule

Store Q-set development as an explicit provenance chain:

source material  
→ candidate statements  
→ thematic/structural map  
→ inclusion/exclusion  
→ wording/editing  
→ expert/stakeholder review if used  
→ pilot  
→ final Q-set.

### Critical boundaries

- Q-set ≠ survey scale.
- Items need not represent one unidimensional psychometric construct.
- Cronbach alpha is not a default Q-set quality criterion.
- A statistically elegant factor solution cannot repair a materially incomplete or biased Q-set.

---

# 5. Structured vs unstructured Q-set sampling

Two broad routes should be retained.

## UNSTRUCTURED

Statements are sampled from the concourse through researcher-led interpretive coverage without a formal factorial sampling frame.

## STRUCTURED

Statements are sampled according to an explicit theoretical/conceptual sampling matrix.

### Project rule

Neither route is inherently superior.

Required:

- declare route;
- justify it;
- demonstrate coverage;
- preserve provenance.

---

# 6. Q-set size

There is **no validated universal Q-set size** applicable to all studies.

Empirical reviews show common practice around roughly 30–50 statements, but current methodological reviews explicitly note that required minima remain uncertain and context-dependent.

### Project rule

Do not encode:

> “Q studies require exactly N statements.”

Instead store:

- number of items;
- cognitive burden;
- breadth of concourse;
- redundancy;
- discrimination potential;
- population limitations;
- pilot evidence;
- rationale.

---

# 7. P-set / participant sampling

The participant sample is commonly called the **P-set**.

Its principal design purpose is usually:

> maximize relevant diversity of viewpoints / theoretical positions,

not:

> estimate population proportions.

Common sampling:

- purposive;
- theoretical/strategic;
- maximum-variation;
- stakeholder-based;
- convenience or snowball where justified.

### Critical rule

Probability sampling is not constitutive of Q Methodology.

A purposive P-set is compatible with the methodology because the inferential target is viewpoint structure rather than population prevalence.

---

# 8. P-set size

There is no universally established power-based sample-size rule for Q.

Published conventions vary substantially.

The 2023 multidisciplinary systematic review found:

- wide ranges of participant counts;
- frequent use of 20–50 participants;
- inconsistent rationales;
- no established universal minimum.

### Project rule

Do not turn common practice into a false requirement.

Store:

1. P-set N;
2. sampling logic;
3. anticipated viewpoint diversity;
4. stakeholder coverage;
5. relationship to Q-set size if used in planning;
6. factor-defining sort adequacy;
7. nonloading/confounded sorts;
8. attrition if longitudinal.

### Claim boundary

A larger P-set does not automatically convert Q into a prevalence study.

---

# 9. Condition of instruction

The **condition of instruction** determines the meaning of the ranking.

Examples:

- most agree ↔ most disagree;
- most important ↔ least important;
- most like me ↔ least like me;
- most acceptable ↔ least acceptable.

### Critical rule

The exact instruction is part of the measurement/meaning architecture.

The same Q-set under a different condition of instruction may answer a different scientific question.

Mandatory fields:

- wording;
- anchor meaning;
- time frame;
- reference target;
- language;
- instructions about ties;
- pre-sort procedure;
- researcher assistance.

---

# 10. Q-sort procedure

A Q-sort is the participant’s rank ordering/configuration of all Q-set items.

Common procedure:

1. familiarize with items;
2. optional preliminary piles;
3. place statements on grid;
4. refine relative ordering;
5. record final sort;
6. optional/expected post-sort explanation.

Data collection may be:

- face-to-face;
- online;
- postal/remote;
- assisted where population requires it.

### Project rule

The full configuration matters.

Q should not be reduced to independent item ratings.

---

# 11. Forced vs free distribution

A quasi-normal **forced distribution** is common but **not universally mandatory**.

The 2023 systematic review found both forced and free/nonforced approaches and substantial under-reporting of distribution choice.

### Project classification

Store:

- FORCED;
- NONFORCED/FREE;
- SEMI_FORCED;
- OTHER.

Also store:

- number of columns;
- symmetry/asymmetry;
- distribution shape;
- allowed slots per column;
- rationale.

### Critical rule

Do not infer methodological invalidity solely because the grid is not perfectly quasi-normal.

The choice must be explicit, justified and compatible with the analytic procedure.

---

# 12. Q-sort correlation matrix

Q analysis transposes the usual R-mode focus.

Instead of correlating variables across people, Q correlates **whole Q-sorts/persons with one another** based on their item configurations.

Result:

> a correlation matrix among Q-sorts.

This matrix becomes the basis for factor/component extraction.

### Critical boundary

Q by-person factor analysis is not interchangeable with conventional scale factor analysis.

---

# 13. Factor extraction

Common extraction methods include:

- centroid factor extraction;
- principal components analysis (PCA);
- less commonly other factor extraction methods.

The literature contains methodological disagreement and no single universally mandated extraction algorithm.

### Project rule

Record:

1. extraction method;
2. software/package;
3. software version;
4. number initially extracted;
5. rationale;
6. sensitivity analysis if performed.

### Critical rule

PCA use in Q is common practice, but its popularity does not make it universally superior to centroid extraction.

---

# 14. Factor retention / deciding number of factors

No single criterion is sufficient across all Q studies.

Commonly used information includes:

- eigenvalues;
- significant defining Q-sorts;
- Humphrey-type criteria;
- explained variance;
- scree plot;
- factor stability;
- simplicity/distinctness;
- theoretical/qualitative interpretability.

The 2023 systematic review found large heterogeneity and substantial non-reporting of the retention decision.

### Canonical project rule

A defensible solution should combine:

1. statistical support;
2. enough usable defining Q-sorts;
3. distinctiveness;
4. interpretability;
5. substantive coherence;
6. parsimony;
7. sensitivity to alternative factor solutions.

Do not use:

> eigenvalue > 1

as an automatic standalone rule.

---

# 15. Rotation

Common routes:

- Varimax;
- judgmental/manual rotation;
- mixed Varimax + manual;
- less commonly other rotations;
- occasionally unrotated solutions.

The healthcare review and later methodological studies show that rotation choice can materially change Q-sort loadings and interpretation.

### Project rule

Store:

- rotation method;
- sequence;
- rationale;
- whether rotation was theory-driven;
- operator decisions;
- alternative solutions inspected.

### Critical rule

Manual rotation is not automatically invalid, but its substantive rationale and operations must be transparent.

Rotation must not be treated as a hidden cosmetic step.

---

# 16. Factor loadings and defining Q-sorts

A factor loading represents the association/correlation between an individual Q-sort and a retained factor.

Q-sorts may be:

- defining a factor;
- non-significant/nonloading;
- confounded across multiple factors;
- negatively loading;
- involved in a bipolar factor.

### Project fields

1. loading threshold/criterion;
2. significance level if used;
3. exclusivity criterion;
4. defining-sort flag;
5. confounded-sort rule;
6. negative-loader rule;
7. bipolar-factor handling;
8. excluded sorts;
9. manual overrides;
10. rationale.

### Critical rule

Do not silently assign every participant to one factor.

A Q-sort may legitimately remain unassigned or confounded.

---

# 17. Bipolar factors

Bipolar factors require explicit handling.

Possible structures include:

- interpreting positive and negative poles separately;
- retaining one pole under justified conditions;
- splitting/otherwise restructuring the solution.

The 2023 reporting checklist explicitly requires reporting and justification of bipolar-factor handling.

### Critical rule

Negative loading is not simply “error”.

It can represent an inverse relation to the factor configuration, but its interpretation depends on the factor solution and substantive context.

---

# 18. Factor scores and factor arrays

For each retained factor, defining Q-sorts are combined to estimate statement-level factor scores / z-scores.

These are mapped back to a grid to form the **factor array**:

> an idealized / best-estimate Q-sort representing the shared viewpoint expressed by that factor.

### Critical rule

A factor array is not:

- one actual participant;
- a prevalence estimate;
- a mean Likert profile;
- a latent-trait score.

It is a reconstructed configuration.

---

# 19. Distinguishing statements

Distinguishing statements are items positioned sufficiently differently on one factor relative to the others.

They help identify what makes the viewpoint structurally distinctive.

### Project rule

Store:

- statement;
- factor position/z-score;
- comparison factors;
- statistical criterion;
- qualitative explanation;
- contextual interpretation.

---

# 20. Consensus statements

Consensus statements are items positioned similarly across retained factors.

They may reveal:

- common ground;
- shared priorities;
- universal objections;
- background assumptions.

### Critical rule

Consensus statements must not be ignored simply because they do not differentiate factors.

They may be highly relevant to intervention design, clinical communication or implementation.

---

# 21. Post-sort qualitative material

Post-sort interviews/comments commonly ask participants to explain:

- extreme placements;
- surprising items;
- difficult decisions;
- missing viewpoints;
- changes during sorting;
- personal meaning.

Evidence indicates these materials can materially improve factor interpretation.

### Project classification

Post-sort material is an **interpretive support layer** within Q.

It does not automatically transform Q into generic mixed methods.

### Required provenance

Link comments to:

- participant/Q-sort ID;
- statement or ranking;
- factor loading;
- factor interpretation.

---

# 22. Factor interpretation

Interpretation should integrate:

1. complete factor array;
2. extreme statements;
3. distinguishing statements;
4. consensus statements;
5. relative pattern across the whole array;
6. defining Q-sorts;
7. post-sort explanations;
8. participant/context characteristics where relevant;
9. theory/literature;
10. contradictory or awkward statements.

### Critical rule

Do not name a factor from one or two attractive statements.

The **configuration** is the interpretive unit.

---

# 23. Factor naming

Labels such as:

- viewpoint;
- perspective;
- discourse;
- type;
- profile

are common.

### Project preference

Use:

**VIEWPOINT / FACTOR**

unless the source has a theoretically meaningful alternative label.

Avoid “personality type” unless the study actually supports a stable trait claim.

---

# 24. Generalization and prevalence

This is the central claim boundary.

Q Methodology can support:

- existence of recurring viewpoints;
- structure/content of those viewpoints;
- similarities/differences among configurations;
- mapping of stakeholder perspectives;
- hypothesis generation;
- design/implementation implications.

Q Methodology alone does **not** estimate:

- population prevalence of viewpoints;
- population proportion belonging to each factor;
- population mean attitudes.

### Critical rule

The number or percentage of P-set participants loading on a factor is not a population prevalence estimate when the P-set is purposively sampled.

Example:

> “42% of this Q sample loaded on viewpoint A”

is a sample description.

It is not:

> “42% of the target population holds viewpoint A.”

---

# 25. Causal-effect boundary

Q can be nested before, during or after an intervention and can reveal:

- perceived mechanisms;
- subjective change;
- emerging viewpoints;
- barriers/facilitators;
- intervention acceptability;
- stakeholder priorities.

Q alone does not establish:

- treatment efficacy;
- causal mechanism;
- mediation;
- dose response.

Causal inference remains owned by the parent experimental/quasi-experimental design.

---

# 26. Longitudinal / repeated Q

Q can be used longitudinally or pre/post.

The 2022 systematic review of longitudinal Q studies found substantial heterogeneity.

Common approaches include:

1. factor-analyse all time-point Q-sorts together;
2. separate Q-factor analyses by time point;
3. correlate follow-up sorts with baseline factor arrays;
4. compare factor arrays across time;
5. use descriptive or inferential within-person statistics;
6. combine group-level Q analysis with qualitative trajectories.

### Project route

For repeated Q, preserve:

- PARTICIPANT_ID;
- TIMEPOINT;
- identical/modified Q-set;
- identical/modified condition of instruction;
- missing/attrited participants;
- analysis architecture;
- cross-time factor matching;
- factor-array correlation;
- individual trajectory;
- parent longitudinal/experimental design.

### Critical rule

A longitudinal Q analysis is not a standardized single design.

The analysis must be specified explicitly.

---

# 27. Pre/post intervention Q

A pre/post Q study may answer:

- did alignment with baseline viewpoints change?;
- did new viewpoints emerge?;
- did old viewpoints disappear?;
- how did individual subjective trajectories evolve?

But:

> observed subjective change ≠ causal intervention effect

unless the parent design supports causal attribution.

Even when inferential tests are added to repeated Q-sorts, small purposive samples and lack of control/comparison structures can preclude strong causal claims.

---

# 28. Q embedded in mixed methods or other frameworks

Q may coexist with:

- RCT;
- cohort;
- Realist Evaluation;
- DBR;
- HCD;
- mixed methods;
- intervention development;
- process evaluation.

### Project representation

parent study/framework  
+ **Q_METHODOLOGY component**  
+ exact relationship/integration.

### Critical rule

Do not erase Q into:

> “qualitative interviews”

or:

> “mixed-method component”.

Preserve the constitutive Q architecture.

# 29. Sport / exercise / rehabilitation relevance

Direct current and recent applications verify relevance.

## Rehabilitation technology — 2025

Home-based rehabilitation technology study:

- purposive N=21;
- 34 statements;
- forced Q-sort;
- follow-up explanation;
- by-person factor analysis;
- three viewpoints.

Scientific product:

- different patient configurations of what matters for adoption of home rehabilitation technology.

## Physical activity guidelines — 2025

Physical-education experts used Q Methodology to identify subjective typologies relevant to physical-activity program guidelines for older adults.

## Physical activity / musculoskeletal care — 2024

A realist synthesis plus Q Methodology used Q sorting to highlight priority areas for supporting physical activity among people with musculoskeletal conditions from underserved communities.

### Implication for the project

Q may later be useful for:

- exercise-adherence viewpoints;
- home-training preferences;
- rehabilitation technology;
- stakeholder priorities;
- barriers/facilitators;
- coaching/implementation perceptions.

It is not needed for ordinary hypertrophy/strength effect estimation.

# 34. Do-not-confuse matrix

| Do not confuse | Correct separation |
|---|---|
| Q Methodology vs Q-sort | parent methodology vs sorting technique |
| Q vs R-mode factor analysis | by-person viewpoint structure vs by-variable latent structure |
| Q-set vs psychometric scale | discourse sample vs scale items |
| P-set vs representative sample | viewpoint-diversity sample vs prevalence sample |
| factor size vs prevalence | number of defining/sample loaders vs population frequency |
| factor array vs participant | idealized configuration vs actual person |
| factor loading vs trait score | Q-sort association with viewpoint vs psychometric trait estimate |
| distinguishing statement vs importance | between-factor distinctiveness vs absolute extremity |
| consensus statement vs irrelevance | common position can be practically central |
| forced grid vs Q itself | common collection format vs constitutive methodology |
| PCA vs mandatory Q analysis | common extraction option vs universal rule |
| Varimax vs mandatory rotation | common rotation vs universal requirement |
| post-sort interview vs generic qualitative study | interpretive Q layer vs separate methodology |
| repeated Q vs causal intervention design | subjective change architecture vs causal identification |
| Q + interview vs generic mixed methods | Q remains standalone methodology |
| percentage loading on factor vs prevalence | sample configuration vs population estimate |

# 36. Known methodological uncertainties

The following are **not** resolved into universal laws:

1. optimal Q-set size;
2. optimal P-set size;
3. optimal participant-to-item ratio;
4. forced vs nonforced superiority;
5. centroid vs PCA superiority;
6. universal factor-retention rule;
7. universal rotation strategy;
8. universal minimum defining sorts per factor;
9. one standardized approach to bipolar factors;
10. one standardized longitudinal Q analysis.

### Project response

Do not invent false certainty.

Instead require:

- explicit decision;
- rationale;
- transparency;
- sensitivity where material;
- claim calibration.
