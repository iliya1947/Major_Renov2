## 1. Purpose / Question Card

### Decision

Build a bounded systems model of exercise physiology sufficient for later bioenergetics, neurophysiology, programming, recovery, GPP and individualization without:

- treating muscle, nervous, cardiovascular, respiratory, endocrine and metabolic systems as independent modules;
- reducing one set to one dominant pathway;
- assuming the full-session response is a simple linear sum of identical set responses;
- inferring chronic adaptation directly from one acute molecular signal;
- treating one circulating biomarker as a system-level state;
- assuming concurrent training necessarily causes molecular or performance interference;
- equating AMPK–mTOR coexistence with guaranteed long-term interference;
- ignoring sleep, nutrition/energy availability, stress and recovery between training exposures;
- treating one exerkine or one omic signature as a validated master regulator;
- replacing measurable training outcomes with speculative “network” language.

### Question type

Integrative / systems exercise physiology across acute bouts, sessions and repeated training.

### Closure criterion for this PASS

All 8 exact Section 19 items must be covered at content level; acute set → session → chronic adaptation must remain distinct; cross-system coupling must be explicit; recovery context must modify rather than sit outside the model; concurrent-training interference must be outcome-/dose-/population-specific; network physiology must remain a framework supported by multi-system evidence without inventing a single master pathway.

### Evidence rule

Integrated physiology is supported when multiple systems are demonstrably coupled through:
- mechanical work;
- neural command/feedback;
- blood flow and gas exchange;
- substrate/energy demand;
- endocrine/immune signaling;
- repeated recovery/adaptation.

A network framework does not license unmeasured causal claims.

Acute molecular signals are not automatically chronic outcomes.

## 3. Cross-system interaction

Exercise begins as a task demand but immediately recruits multiple coupled systems.

A bounded model:

`external task / force / movement demand`
`→ central motor command + motor-unit activation`
`→ muscle force + ATP demand + metabolite/heat production`
`→ local mechanical/metabolic feedback`
`→ autonomic/cardiorespiratory adjustment`
`→ blood flow + ventilation + substrate delivery / waste removal`
`→ endocrine/immune/exerkine signaling`
`→ continued task performance + recovery signaling`.

Important coupling examples:

- neural command changes muscle recruitment and simultaneously contributes to cardiorespiratory drive;
- contracting muscle changes local metabolites and activates group III/IV afferent feedback;
- cardiac output and ventilation determine delivery/clearance capacity but are themselves modified by neural, mechanical and metabolic signals;
- catecholamines, insulin/glucagon and local substrate state jointly regulate fuel availability;
- respiratory mechanics alter intrathoracic pressure and cardiovascular function;
- muscle-derived signals can communicate with adipose tissue, liver, vasculature, immune cells and brain.

Project rule:

**exercise physiology is a coupled control system, not a set of independent organs responding in parallel.**

---

## 4. One resistance-training set: integrated acute response

A single set is a short, non-steady-state perturbation.

Approximate sequence:

`motor command / recruitment ↑`
`→ force + intramuscular pressure + ATP turnover ↑`
`→ PCr use + glycolytic/oxidative flux + metabolite accumulation`
`→ local perfusion may become mechanically constrained during contraction`
`→ afferent + central autonomic drive ↑`
`→ HR / Q / BP / ventilation adjust`
`→ catecholamine and broader systemic signaling changes`
`→ recovery begins immediately after the set`.

The exact weighting depends on:

- load and velocity;
- repetition count;
- set duration;
- proximity to task failure;
- active muscle mass;
- contraction type;
- breathing/Valsalva;
- rest interval;
- training status.

Project rule:

**one set has no single “primary physiological response”; mechanical, neural, metabolic and cardiorespiratory responses are co-generated.**

---

## 5. One aerobic interval / continuous bout: integrated acute response

Dynamic endurance exercise emphasizes a different weighting of the same system.

`sustained ATP demand`
`→ neural drive + muscle metabolism`
`→ Q and active-muscle blood flow ↑`
`→ ventilation / alveolar gas exchange ↑`
`→ carbohydrate/fat mobilization adjusts`
`→ endocrine + thermal + fluid-regulatory responses`
`→ afferent feedback contributes to perception and cardiorespiratory control`.

At high intensity, limitations can emerge from combinations of:

- muscle metabolic capacity;
- oxygen delivery;
- ventilatory work;
- neural/afferent feedback;
- heat/fluid strain;
- accumulated fatigue.

Project rule:

**performance limitation is normally distributed across interacting constraints rather than assigned to one system by default.**

---

## 6. From one set to a full training session

A session is not a simple arithmetic sum of identical set responses.

Across repeated sets/intervals:

- phosphocreatine recovery can be incomplete;
- muscle glycogen/substrate state changes;
- metabolites accumulate and clear dynamically;
- cardiovascular/ventilatory responses begin from a changed baseline;
- central/peripheral fatigue can accumulate;
- tissue temperature rises;
- fluid shifts can occur;
- endocrine/immune signaling evolves over different time scales;
- technique/velocity/recruitment can change as fatigue develops.

Therefore set 8 performed after prior work is physiologically different from set 1 even if external load/repetitions match.

Project rule:

**session physiology is history dependent.**

## 7. Acute session response vs chronic adaptation

Acute exercise generates many candidate signals.

Chronic training adaptation requires repeated exposure plus successful recovery/remodeling.

A bounded model:

`acute perturbation`
`→ transient signaling + substrate disturbance + mechanical stress`
`→ recovery / protein turnover / gene expression / tissue remodeling`
`→ repeated exposures`
`→ structural + neural + metabolic + cardiorespiratory adaptation`.

Different systems operate on different clocks:

- metabolites and phosphorylation: seconds–hours;
- transcription/protein turnover: hours–days;
- neural performance changes: sessions–weeks;
- muscle/tendon/bone structural remodeling: weeks–months;
- cardiovascular/metabolic phenotype: weeks–months.

Human MoTrPAC evidence also shows shared and mode-specific temporal molecular responses to endurance and resistance exercise rather than one universal exercise signal.

Project rule:

**acute response magnitude or one pathway activation does not equal chronic adaptation magnitude.**

---

## 8. Mode specificity within an integrated system

Resistance and endurance exercise share many systems but weight them differently.

### Resistance-biased exposure

Higher emphasis on:

- force / motor-unit recruitment;
- intramuscular pressure;
- phosphagen/glycolytic stress;
- tissue-specific mechanical signaling;
- neuromuscular adaptation.

### Endurance-biased exposure

Higher emphasis on:

- sustained oxygen delivery/utilization;
- cardiac output;
- ventilation;
- oxidative metabolism;
- mitochondrial/capillary adaptation.

This is a continuum, not two isolated physiological categories.

Current human multi-omic evidence demonstrates both shared responses and modality-specific molecular programs.

Project rule:

**specificity changes the weighting of a shared physiological network rather than activating completely separate systems.**

---

## 9. Sleep, nutrition, energy availability and stress

Adaptation depends on what happens between exposures.

Training stimulus interacts with:

- total energy availability;
- carbohydrate/glycogen availability;
- protein/amino-acid availability;
- hydration;
- sleep duration/quality/timing;
- psychological/life stress;
- illness;
- preceding/following training.

Low energy availability can impair multiple neuromusculoskeletal adaptations and alter endocrine/metabolic physiology.

Sleep loss can impair performance/recovery domains, but the exact effect depends on task and exposure.

The 2026 “Sleep-Gated Adaptation” model is retained only as a **conceptual organizing framework**; it is not accepted as a validated biomarker or quantitative mechanism.

Project rule:

**training dose does not determine adaptation independently of recovery context.**

---

## 10. Competing adaptation signals

Different exercise modes can produce signaling programs that partly overlap and partly diverge.

Classic mechanistic concern:

- endurance-related energetic signaling often includes AMPK/PGC-1α-associated pathways;
- resistance/mechanical signaling includes mTORC1/protein-synthesis-associated pathways.

But:

- both pathway families are more complex than a binary switch;
- activation varies with timing, tissue, nutritional state and training status;
- acute phosphorylation/signaling does not map linearly to long-term phenotype;
- animal and acute molecular effects can overstate human chronic interference.

Project rule:

**“AMPK blocks mTOR” is too crude to serve as a concurrent-training prescription rule.**

## 11. Concurrent training as an integrated problem

Current 2026 umbrella evidence across 17 meta-analyses / 144 studies supports:

- CT improves aerobic capacity compared with RT alone;
- CT improves strength-related outcomes compared with ET alone;
- compared with RT alone, pooled strength, power and hypertrophy outcomes were broadly comparable in the umbrella synthesis;
- training-sequence effects were not consistently significant;
- highly trained/elite populations remain less well represented.

A 16-week human trial with long-interval HIIT + RT found:

- similar myofibrillar protein synthesis response;
- similar type-II fiber hypertrophy;
- lower strength gains with CT than RT;
- aerobic-capacity improvement only in CT.

Other 2026 meta-analyses similarly show that interference depends on:

- endurance modality;
- outcome (strength vs power vs hypertrophy);
- dose/volume;
- training status;
- recovery/separation;
- total workload.

Project rule:

**concurrent-training interference is an outcome- and context-dependent phenomenon, not a universal molecular incompatibility.**

Detailed concurrent programming remains GPP/PRO.

## 12. Inter-organ signaling / exerkines

Exercise-responsive factors can originate from:

- skeletal muscle;
- adipose tissue;
- liver;
- heart;
- bone;
- immune cells;
- other tissues.

Candidate mediators include:

- peptides/proteins;
- metabolites;
- lipids;
- nucleic acids;
- extracellular-vesicle cargo.

This supports real inter-organ communication.

However current exerkine evidence is heterogeneous across:

- species;
- exercise modes;
- sex;
- sampling time;
- transcript vs protein abundance;
- secretion vs tissue expression;
- receptor/target validation.

Cross-platform analysis of 40 proposed skeletal-muscle exerkines found only a subset with conserved regulation across species/conditions.

Project rule:

**inter-organ signaling is real; a proposed exerkine is not automatically a validated causal mediator or useful biomarker.**

---

## 13. Network / systems physiology

Integrated physiology is best treated as a framework with measurable nodes and links.

Relevant nodes:

- neural drive / sensory feedback;
- muscle force and local metabolism;
- cardiac output / regional flow;
- ventilation / gas exchange;
- substrate availability;
- endocrine/immune signaling;
- thermoregulation / fluid state;
- tissue repair/remodeling.

Relevant links:

- neural;
- mechanical;
- circulatory;
- metabolic;
- endocrine/paracrine;
- immune;
- behavioral/recovery.

Multi-omic research supports broad, time-dependent and tissue-specific exercise responses, but network complexity does not prove every inferred edge.

Project rule:

**network physiology organizes known interactions; it must not replace direct measurement with speculative systems language.**

## 15. Established project-level model

### Acute exposure

`task demand`
`→ neural command / muscle recruitment`
`→ force + ATP demand + metabolites`
`↔ afferent feedback`
`↔ cardiovascular + respiratory regulation`
`↔ substrate/endocrine/immune regulation`
`→ performance during the bout`.

### Session integration

`set/interval 1`
changes the internal state entering
`set/interval 2…n`.

Thus:

`same external task ≠ same internal physiological state`
across a session.

### Chronic adaptation

`repeated task-specific perturbations`
`+ recovery resources/context`
`→ tissue/system-specific remodeling on different time scales`
`→ changed future acute response and performance`.

### Concurrent exposure

`RT stimulus + endurance stimulus`
can produce:
- complementary adaptations;
- neutral coexistence;
- or outcome-specific interference

depending on total dose, mode, timing, training status and recovery.

## 16. Training-relevant implications

1. **Do not program from one pathway, hormone or biomarker.**
2. **Treat a set as a whole-system perturbation, not only a muscle event.**
3. **Treat later sets as physiologically history dependent.**
4. **Do not infer chronic adaptation from one acute signal.**
5. **Use specificity as relative system weighting rather than an all-or-none category.**
6. **Treat sleep, energy availability and nutrition as modifiers of adaptation, not side topics.**
7. **Do not assume concurrent training automatically blocks hypertrophy/strength.**
8. **Do not use “AMPK vs mTOR” as a stand-alone programming rule.**
9. **Treat exerkines as candidate communication mediators with evidence-specific certainty.**
10. **Use network models to organize measured physiology, not to invent unmeasured causality.**

## 18. Confidence / unresolved issues

### HIGH

- acute exercise requires coupled neural, muscular, cardiovascular, respiratory and metabolic regulation;
- session response is history dependent;
- acute molecular response is not identical to chronic adaptation;
- sleep/energy/recovery context modifies adaptation;
- resistance and endurance share systems but weight them differently;
- universal binary concurrent-interference models are unsupported.

### MODERATE-HIGH

- concurrent training can usually improve both aerobic and strength-related capacities in recreationally trained/healthy adults;
- average hypertrophy/strength interference is smaller and more context dependent than classic binary models suggest;
- inter-organ signaling through exercise-responsive factors is biologically real.

### MODERATE / CONTEXT-DEPENDENT

- exact limiting system in a specific exercise bout;
- exact contribution of neural vs peripheral feedback to one person's fatigue;
- exact concurrent interference for highly trained athletes;
- optimal same-day sequence/separation for every goal;
- causal importance of individual exerkines;
- exact network topology of human chronic exercise adaptation.
