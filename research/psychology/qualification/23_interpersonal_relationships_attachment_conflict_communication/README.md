# Interpersonal processes, attachment, conflict, and communication

## Purpose

This directory is the canonical storage location for the **REL** Phase C qualification domain.

REL covers generic interpersonal processes relevant to reliable psychological reasoning, including:

- attachment research and its limits;
- close-relationship dynamics;
- interpersonal regulation;
- conflict escalation/de-escalation;
- communication processes;
- trust, repair, rupture, boundaries, reciprocity;
- relationship satisfaction/stability;
- person × partner/context interaction;
- differential limits between relationship patterns, personality, psychopathology, and situational stress.
