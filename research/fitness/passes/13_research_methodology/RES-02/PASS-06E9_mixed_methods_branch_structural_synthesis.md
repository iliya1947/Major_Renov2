# 2. Final mixed-method definition

For RES-02:

> **Mixed-methods research = deliberate integration of quantitative and qualitative inquiry so that the relationship between the components contributes to an inference, explanation, development decision or program conclusion that cannot be reduced to two independent parallel studies.**

Necessary but not sufficient:

- QUAN exists;
- QUAL exists.

Additional requirement:

- intentional methodological relationship/integration.

### Therefore

`QUAN + QUAL`

does **not** automatically equal:

`MIXED METHODS`.

# 4. Basic route 1 — CONVERGENT

Canonical architecture:

`QUAL || QUAN`
→ strand-specific analysis  
→ commensurable integration target  
→ merge/compare/transform  
→ assess fit  
→ meta-inference.

### Defining features

- approximately concurrent/parallel;
- neither strand depends on completed findings from the other in the way required for sequential designs;
- merging is the primary integration mechanism.

### Not required

- exact same collection date;
- same participants;
- equal N;
- equal priority;
- identical constructs.

### Required

- meaningful conceptual bridge;
- explicit integration.

---

# 5. CONVERGENT sample rule

Same participants permit:

- case/person-level integration.

Different stakeholder groups permit:

- domain/program/system-level integration.

### Critical rule

Do not make person-level claims from different-person samples.

---

# 6. CONVERGENT fit

Possible integrated relationships:

1. confirmation/convergence;
2. complementarity;
3. expansion;
4. discordance.

### Critical rule

Discordance is not an automatic failure.

It triggers:

- construct;
- sample;
- time;
- measurement;
- analysis;
- transformation;
- context

audit before being treated as substantive contradiction.

# 7. Basic route 2 — EXPLANATORY_SEQUENTIAL

Canonical architecture:

`QUAN collection/analysis`
→ identify result requiring explanation  
→ connect/build QUAL phase  
→ `QUAL collection/analysis`
→ merge  
→ explanatory meta-inference.

### Defining feature

**Dependency.**

QUAN findings materially alter the QUAL phase.

# 9. EXPLANATORY integration

## Connecting

QUAN determines:

- who/cases to study.

## Building

QUAN determines:

- what to ask;
- what process/construct to probe.

### Strong route

Both connecting and building.

### Minimum classifier

Chronology alone is insufficient.

`QUAN then QUAL`

without material dependency is not enough.

# 10. EXPLANATORY claim boundary

QUAL can support:

- contextual explanation;
- perceived pathways;
- theory refinement;
- mechanism hypotheses.

It does not itself establish:

- causal mediation;
- effect modification;
- biological mechanism;
- causal pathway identification.

# 11. Basic route 3 — EXPLORATORY_SEQUENTIAL

Canonical architecture:

`QUAL collection/analysis`
→ derive constructs/categories/needs/components  
→ BUILD QUAN phase  
→ `QUAN collection/analysis`
→ merge/refine  
→ developmental/validation meta-inference.

### Defining feature

The QUAN phase is materially built from QUAL findings.

# 13. EXPLORATORY provenance

Expected bridge examples:

- quote/code → construct;
- construct → variable;
- theme/domain → item;
- determinant → quantitative rating;
- barrier/need → intervention component;
- user preference → digital feature.

### Critical rule

If the QUAN phase would be essentially unchanged without the QUAL phase:

the architecture is not strongly exploratory sequential.

- measurement invariance;
- responsiveness;

EFA/CFA/IRT/Rasch are quantitative measurement analyses.

# 33. Probability and purposive sampling

A mixed study can legitimately combine:

- probability/randomized QUAN sampling/allocation;
- purposive QUAL sampling.

Inferential properties do not transfer between strands.

### Therefore

Representative QUAN sample  
≠ representative QUAL themes.

Purposive QUAL sample  
≠ weak QUAN parent design.

2. sample mismatch;
3. time mismatch;
4. unit mismatch;
5. measurement limitations;
6. QUAN power/uncertainty;
7. QUAL coverage/adequacy;
8. missingness;
9. social desirability;
10. transformation loss;
11. subgroup heterogeneity;
12. contextual change;
13. implementation change;
14. analytic error.

# 45. Productive discordance

If both strands remain methodologically defensible and discrepancy survives audit:

discordance may reveal:

- construct limits;
- subgroup heterogeneity;
- measurement mismatch;
- context dependence;
- theory weakness.

### Critical rule

Do not force convergence.

# 46. Meta-inference

Final definition:

> **Meta-inference = a higher-order integrated conclusion derived from the relationship between QUAL and QUAN evidence, producing an inference or decision not reducible to separate summaries of the two strands.**

---

# 47. Meta-inference function

Store separately from fit category.

Functions may include:

- confirmation;
- explanation;
- expansion;
- theory refinement;
- development;
- measurement refinement;
- program decision;
- intervention refinement;
- implementation recommendation.

---

# 48. Meta-inference quality

A defensible meta-inference should be:

1. traceable;
2. aligned with the MMR question;
3. coherent with strand inferences;
4. compatible with sample/unit linkage;
5. compatible with uncertainty;
6. explicit about alternative explanations;
7. calibrated to design;
8. transparent about divergence;
9. not more causal/generalizable than parent designs;
10. genuinely additive.

---

# 49. Added-value test

Every mixed-method study should ideally answer:

> What did mixing allow that neither strand alone could provide?

If no meaningful answer exists:

the mixed-method classification may be nominal.

# 59. Causal parent rule

Examples:

+ mixed methods

→ randomized effect inference comes from RCT.

Cohort  
+ mixed methods

Mediation model

+ mixed methods

# 60. Prevalence/generalization rule

Representative QUAN sampling can support population estimates.

Purposive QUAL evidence can:

- explain;
- contextualize.

It does not inherit representativeness.

### Critical rule

Theme frequency is not prevalence unless sampling/inference justify it.

---

# 61. Measurement-development rule

QUAL-derived items plus later factor analysis can support:

- instrument development.

But do not collapse:

- item provenance;
- content validity;
- structural validity;
- reliability;
- responsiveness;
- cross-cultural validity.

# 62. Process-evaluation rule

Positive participant experience can coexist with:

- null RCT effect.

Correct interpretation:

- perceived benefit/acceptability/context may justify redesign or further research.

Incorrect:

- QUAL experience proves the intervention works despite the RCT.
