# 3. Canonical definition

For RES-02:

> **Explanatory sequential mixed methods = a two-phase mixed-methods architecture in which quantitative data are collected and analyzed first, the quantitative findings then materially shape a subsequent qualitative phase, and both phases are integrated to explain/elaborate/contextualize the initial quantitative results.**

Canonical representation:

`QUAN collection → QUAN analysis`  
→ identify explanatory target(s)  
→ connect/build QUAL phase  
→ `QUAL collection → QUAL analysis`  
→ merge/compare  
→ explanatory meta-inference.

### Critical rule

Chronology alone is insufficient.

`survey → interview`

is not automatically explanatory sequential.

---

# 4. Constitutive dependency

The strongest defining feature is **dependency**.

The QUAL phase exists in its actual form because the QUAN results were known.

Dependency can affect:

- who is interviewed;
- which subgroups/cases are selected;
- which variables/results are probed;
- which interview questions are asked;
- which unexpected findings receive attention;
- which comparison groups are built.

### Project rule

Extract:

> **What exactly would have been different in the QUAL phase if the QUAN results had been different?**

If the answer is:

> nothing,

then the design may be merely sequential rather than explanatory sequential.

---

# 5. Two major explanatory-sequential variants

Current methodology distinguishes at least two useful variants.

## A. Follow-up explanations variant

Primary goal:

- explain initial quantitative results.

Common pattern:

QUAN has priority  
→ QUAL probes:

- significant effects;
- null effects;
- unexpected findings;
- subgroup differences;
- outliers;
- contradictory patterns.

## B. Case-selection variant

QUAN is used mainly to identify/select cases for deeper qualitative investigation.

The qualitative phase may receive greater conceptual weight.

### Project rule

Store:

- variant;
- strand priority;
- exact connecting logic.

---

# 6. Follow-up explanations variant

Typical use cases:

1. significant association needs contextual explanation;
2. intervention effect differs across subgroups;
3. outcome is null despite strong theory;
4. unexpected adverse effect appears;
5. implementation metric conflicts with outcomes;
6. survey scale shows ceiling/floor pattern;
7. model leaves unexplained residual heterogeneity.

### Scientific contribution

QUAL can help answer:

- how participants interpret the result;
- what contextual processes may underlie it;
- which unmeasured factors matter;
- whether measurement missed relevant dimensions.

---

# 7. Case-selection variant

QUAN can classify cases before QUAL inquiry.

Examples:

- high vs low adherence;
- responder vs non-responder;
- high vs low burnout;
- high vs low self-directed talent-development scores;
- high vs low anxiety;
- high vs low physical literacy;
- expected vs unexpected model profiles.

### Critical rule

Selection criteria should be:

- explicit;
- tied to the quantitative analysis;
- justified in relation to the explanatory question.

---

# 8. Connecting

**Connecting** means:

> quantitative results inform the sampling of participants/cases for the subsequent qualitative phase.

This is one of the strongest markers of true explanatory sequential integration.

### Canonical flow

QUAN result  
→ purposeful sampling criteria  
→ QUAL participants.

### Examples

- select highest/lowest scorers;
- select outliers;
- select subgroups with divergent trajectories;
- select unexpected responders;
- select typical cases;
- select model-concordant and model-discordant profiles.

---

# 9. Building

**Building** means:

> quantitative findings shape what is asked or collected qualitatively.

Examples:

- significant association → targeted interview probe;
- null finding → ask about missing contextual factor;
- subgroup difference → ask about contrasting experiences;
- unexpected non-significant moderator → probe why measured construct may not operate as expected.

### Critical rule

Connecting and building are distinct.

A study can:

- use the same participants but generic interviews → weak building;
- use result-driven interview questions but different sample → building without person-level connecting;
- use both → strong explanatory dependency.

---

# 10. Two major integration points

Methodological literature identifies two especially important explanatory-sequential interfaces.

## Interface 1 — between phases

After QUAN analysis and before QUAL collection:

- select participants;
- define sampling strata;
- build interview guide;
- identify explanatory targets.

## Interface 2 — final integration

After QUAL analysis:

- compare QUAL explanations with QUAN findings;
- build joint display;
- produce meta-inference.

### Project rule

A study that only integrates at the final Discussion loses much of the characteristic strength of explanatory sequential design.

---

# 11. Participant-selection joint display

A participant-selection joint display can explicitly map:

- quantitative result/profile;
- sampling criterion;
- selected participant/case;
- rationale for selection;
- qualitative explanatory target.

### Value

It increases transparency of:

- connecting;
- case selection;
- sampling integration.

### Critical rule

A participant-selection display is not mandatory, but the underlying logic should be reportable.

---

# 12. Interview-question / building display

A second useful display maps:

- quantitative finding;
- unresolved question;
- qualitative interview probe;
- qualitative finding;
- final explanation.

### Value

It makes **building** visible.

### Example

QUAN:

- high adherence despite low intention.

QUAL probe:

- what sustained exercise despite low initial motivation?

QUAL finding:

- caregiver routine + automatic habit.

Meta-inference:

- adherence may become less intention-dependent once routines stabilize.

---

# 13. Typical-case sampling

A typical-case strategy selects participants whose quantitative profile approximates:

- sample mean;
- dominant pattern;
- expected model relation.

### Use

Useful for:

- understanding the ordinary pathway underlying an average group-level association.

### Limitation

Typical cases may hide:

- heterogeneity;
- minority pathways;
- failure modes.

---

# 14. Extreme-case sampling

Select:

- very high scorers;
- very low scorers;
- strongest responders;
- weakest/nonresponders.

### Use

Useful for:

- sharpening contrasts;
- identifying boundary conditions.

### Critical rule

Extreme cases are not population representatives.

Their role is explanatory, not prevalence estimation.

---

# 15. Maximum-variation sampling

Researchers can select participants spanning:

- outcome range;
- age;
- disease duration;
- adherence profiles;
- contextual characteristics.

### Goal

Capture contrasting explanatory pathways.

### Current direct example

Shao et al. 2026 selected 16 stroke participants from the 289-person quantitative sample using:

- purposive;
- maximum-variation sampling.

This is a strong connecting structure.

---

# 16. Deviant/discrepant-case sampling

Select cases that violate the dominant quantitative pattern.

Examples:

- high self-efficacy but low adherence;
- low predicted risk but poor outcome;
- strong intervention exposure but no improvement;
- weak measured motivation but high long-term exercise adherence.

### Scientific value

Can expose:

- omitted variables;
- nonlinear mechanisms;
- measurement problems;
- contextual constraints.

### Critical rule

A discrepant case is explanatory evidence, not statistical falsification of an association by itself.

---

# 17. Model-concordant vs model-discordant profiles

A systematic strategy can select:

- cases predicted well by a quantitative model;
- cases predicted poorly.

### Benefit

QUAL inquiry can compare:

- what the model captures;
- what it misses.

### Methodological precedent

Mixed-methods connecting literature has used profile-based selection to examine model-convergent and model-divergent cases.

---

# 18. Null-result follow-up

Explanatory sequential is especially useful when QUAN finds:

- no statistically significant effect;
- no subgroup difference;
- no expected association.

QUAL can investigate:

- implementation failure;
- inadequate dose;
- wrong construct;
- ceiling/floor effect;
- contextual barriers;
- heterogeneous pathways.

### Critical rule

QUAL cannot convert a null estimate into a statistically significant causal effect.

It can explain why the expected signal may not have appeared.

---

# 19. Unexpected-significant-result follow-up

If QUAN finds an unexpected association:

QUAL can probe:

- participant interpretation;
- local context;
- hidden process;
- alternative explanation.

### Critical rule

QUAL explanation should be framed as:

- contextual explanation;
- plausible pathway;
- hypothesis;

not automatically as confirmed causal mechanism.

---

# 20. Heterogeneous-effect follow-up

In trials/cohorts, QUAN may identify:

- responder heterogeneity;
- site differences;
- subgroup contrasts.

QUAL can sample across those groups.

### Potential contribution

Identify:

- implementation variation;
- context;
- acceptability;
- intervention receipt;
- behavioral pathways.

### Critical rule

Subgroup qualitative accounts do not establish statistical effect modification.

---

# 21. Individual record linkage

When QUAL participants are sampled from the QUAN cohort, their individual quantitative records can be linked to their interviews.

### Strong integration

participant ID  
→ QUAN profile  
→ QUAL account  
→ case-level interpretation.

### Project fields

- linkage possible?;
- consent covers linkage?;
- which variables linked?;
- linkage granularity?;
- missing QUAN records?;
- confidentiality risk?

---

# 22. Same-sample relationship is strong but not universally mandatory

For person-level explanation:

QUAL participants should normally come from the QUAN sample.

This permits:

- direct case linkage;
- score-informed sampling;
- person-level explanation.

### But

Explanatory sequential studies can also use different stakeholder groups.

Example:

QUAN:

- patient outcome data.

QUAL:

- clinicians/managers explaining implementation context.

### Project rule

Different samples are acceptable when the meta-inference is:

- program-level;
- site-level;
- contextual;

rather than person-level.

---

# 23. Integration granularity

E3 extends the E2 granularity rule to sequential explanation.

## Person-level

Same QUAN participant is interviewed.

Supports:

- score/profile ↔ account comparison.

## Subgroup-level

QUAL sample represents quantitative strata.

Supports:

- high vs low;
- responder vs non-responder explanation.

## Program/site-level

Different stakeholders explain aggregate/process findings.

Supports:

- implementation/contextual explanation.

## Whole-study level

Separate strands contribute to broad interpretation without direct case linkage.

### Critical rule

Claim granularity must not exceed linkage granularity.

---

# 24. Different sample ≠ automatically weak design

A current rehabilitation-student study used:

- recent graduates in the QUAN phase;
- experienced rehabilitation therapists in the QUAL phase.

This can provide:

- contextual explanation of practice environment;
- professional interpretation of quantitative patterns.

### Limitation

It cannot directly explain:

> why a specific surveyed graduate answered as they did.

### Project rule

Store:

- different-sample explanatory design;
- domain-level rather than person-level linkage.

---

# 25. Timing

Canonical timing:

1. complete enough QUAN analysis to identify explanatory targets;
2. design/select QUAL phase;
3. conduct QUAL analysis;
4. integrate.

### Critical rule

The full QUAN manuscript need not be finished before QUAL starts.

But the results needed to drive connecting/building must exist.

---

# 26. Priority / weighting

Explanatory sequential often gives:

- QUAN priority.

But this is not mandatory.

In case-selection variants, QUAL may receive:

- equal;
- greater interpretive weight.

### Current sport example

Women’s-football talent-development research used an explanatory sequential design with greater weight afforded to the qualitative phase.

### Project rule

Do not infer explanatory sequential = QUAN-dominant automatically.

Store:

- declared priority;
- enacted priority.

---

# 27. Parent quantitative design must remain explicit

Explanatory sequential can sit on:

- cross-sectional survey;
- cohort;
- RCT;
- quasi-experiment;
- SCED/randomized multiple baseline;
- prediction model;
- mediation/moderation analysis.

### Critical rule

The mixed-methods design does not replace the quantitative parent design.

---

# 28. Parent qualitative methodology must remain explicit

Possible QUAL phases include:

- Qualitative Description;
- Interpretive Description;
- RTA-based generic qualitative inquiry;
- phenomenology;
- narrative inquiry;
- ethnographic follow-up;
- focus groups;
- case-based qualitative inquiry.

### Critical rule

“Interviews” is not a qualitative methodology.

The explanatory sequential label does not excuse an under-specified QUAL strand.

---

# 29. Direct stroke-rehabilitation example — strong connecting

Shao et al. 2026:

QUAN:

- n=289 stroke patients;
- associations among temporal perspective, exercise intention, habit/self-regulation and adherence;
- mediation/moderation modeling.

QUAL:

- n=16 selected from the QUAN sample;
- purposive + maximum variation;
- semi-structured interviews.

Purpose:

- explain/supplement quantitative findings.

Integration:

- side-by-side comparison;
- convergence/divergence/expansion;
- integrated meta-inferences.

### Taxonomy classification

**strong explanatory sequential linking** because:

- phase order is explicit;
- QUAL sample comes from QUAN sample;
- QUAL purpose is result-driven;
- final integration is explicit.

---

# 30. Stroke-rehabilitation example — mechanism-language caution

The quantitative phase tested:

- mediation;
- moderation.

The qualitative phase was used to discuss:

- intention;
- habit;
- self-regulation;
- temporal perspective.

### Critical rule

QUAL findings may strengthen:

- interpretability;
- contextual plausibility;
- construct understanding.

They do **not** independently establish:

- causal mediation;
- temporal causal order;
- biological mechanism.

### Project route

Store separately:

1. statistical mediation estimate;
2. qualitative perceived/explanatory pathway;
3. integrated mechanism hypothesis.

---

# 31. Causal mediation vs explanatory meta-inference

A mixed-methods paper may produce a strong narrative:

QUAN mediator significant  
+ QUAL accounts consistent  
→ mechanism appears plausible.

### But

Causal mediation requires assumptions such as:

- temporal ordering;
- no relevant unmeasured confounding;
- correct model specification;
- appropriate intervention/exposure design.

QUAL concordance does not satisfy these assumptions.

### Critical rule

Use:

> “supports/plausibly explains/is consistent with”

rather than:

> “proves the mechanism.”

---

  - participant selection;

# 34. Direct inpatient-rehabilitation example — randomized multiple baseline

Current 2026 thermography/AI rehabilitation protocol:

quantitative parent:

- randomized multiple baseline design across participants;
- continuous activity monitoring.

QUAL:

- semi-structured interviews with:
  - patients;
  - ward sisters;
  - clinicians;
- reflexive thematic analysis.

Integration:

- joint-display framework.

### Taxonomy lesson

Mixed-method route:

`randomized multiple baseline quantitative design`  
+ `explanatory sequential mixed methods`  
+ `multi-stakeholder qualitative follow-up`.

### Claim boundary

Quantitative SCED architecture supports intervention-effect inference subject to SCED assumptions.

QUAL explains:

- usability;
- context;
- implementation;
- interpretation.

# 35. Direct physiotherapy-education example

2026 SCI physiotherapy education study:

quantitative parent:

- randomized post-test-only controlled design.

QUAL:

- open-ended responses from experimental students.

Label:

- explanatory sequential mixed methods.

### Taxonomy caution

A QUAL follow-up based only on short open-ended responses may provide:

- contextual explanation.

But the qualitative strand must still be assessed for:

- methodological depth;
- systematic analysis;
- adequacy.

### Critical rule

The explanatory-sequential label does not guarantee a strong qualitative component.

  - n=4 high;

2025 injured team-athlete study used an explanatory sequential design around:

- return-to-sport status;

This route is directly useful when rehabilitation outcomes contain:

# 39. Explanatory joint display

A canonical explanatory joint display can contain:

| QUAN finding | explanatory target | QUAL sampling/participants | QUAL finding | meta-inference |

### Purpose

Make visible:

- what needed explanation;
- how cases were selected;
- what QUAL added;
- final integrated interpretation.

---

# 40. Participant-selection display vs final explanatory display

These are different integration products.

## Participant-selection display

Used between phases.

Purpose:

- transparent connecting.

## Final explanatory display

Used after QUAL analysis.

Purpose:

- merge findings;
- generate meta-inference.

### Critical rule

Do not collapse sampling integration and final interpretation into one vague “integration occurred.”

---

# 41. Side-by-side integration

A simpler final integration can be:

1. QUAN result;
2. QUAL explanation;
3. integrated interpretation.

### Strong example

QUAN:

- no long-term association.

QUAL:

- participants describe early expectations losing relevance once exercise becomes habitual.

Integrated inference:

- outcome expectations may matter early but become less central as routines stabilize.

### Critical rule

The integrated inference should remain consistent with actual quantitative uncertainty.

---

# 42. Explaining significant findings

QUAL can unpack:

- lived meaning;
- contextual process;
- behavioral pathway;
- implementation pathway.

### Critical rule

A statistically significant association does not require a single qualitative explanation.

Multiple mechanisms may fit the same association.

---

# 43. Explaining nonsignificant findings

QUAL can reveal:

- competing mechanisms;
- heterogeneity;
- low salience;
- measurement mismatch;
- timing mismatch.

### Critical rule

A qualitative theme cannot make a nonsignificant quantitative estimate “significant.”

---

# 44. Explaining unexpected direction

Example:

QUAN:

- greater perceived behavioral advantage associated with weaker long-term intention effect.

QUAL:

- exercise may become habitual and less consciously intention-driven.

### Correct status

- plausible contextual explanation;
- hypothesis generation/refinement.

### Incorrect status

- confirmed causal moderation mechanism solely because narratives fit.

---

# 45. Post-hoc qualitative follow-up boundary

A study can conduct qualitative work after QUAN without being explanatory sequential.

### Weak/post-hoc pattern

- QUAN study completed;
- months later researchers independently decide to interview people;
- no result-driven sampling;
- no result-driven questioning;
- little/no integration.

### Classification

May be:

- follow-up qualitative study;
- multimethod program;
- secondary linked study.

Not necessarily explanatory sequential mixed methods.

---

# 46. Planned vs emergent explanatory follow-up

Explanatory sequential designs may be:

## Preplanned

Protocol specifies:

- phase 1;
- selection rules;
- phase 2;
- integration.

## Adaptively emergent

Unexpected QUAN finding creates justified QUAL follow-up.

### Project rule

Emergent mixed methods can still be legitimate if:

- rationale is transparent;
- integration is real;
- post-hoc selection risks are acknowledged.

### Critical issue

Do not disguise exploratory post-hoc decisions as prespecified.

---

# 47. Merely sequential multimethod boundary

Sequence:

survey  
→ interviews

may remain multimethod if:

- interviews were generic;
- sample unrelated to QUAN results;
- no shared meta-inference.

### Explanatory sequential requires at least one strong dependency:

1. connecting;
2. building;
3. result-specific qualitative explanation;

plus final integration.

---

# 48. Explanatory sequential vs convergent

## Explanatory sequential

QUAN results are available first and shape QUAL.

## Convergent

QUAL and QUAN strands are largely independent before merging.

### Project rule

Chronology is necessary but dependency is decisive.

---

# 49. Explanatory sequential vs embedded

A QUAL phase can be both:

- embedded in a trial/program;
- explanatory sequential relative to quantitative results.

### Example

RCT outcomes  
→ select responders/nonresponders  
→ qualitative interviews  
→ integrate.

### Project rule

Store:

- parent structural relationship;
- integration design

as separate dimensions.

---

# 50. Explanatory sequential vs process evaluation

Process evaluation is a **purpose**, not one mixed-methods design.

It can use:

- convergent;
- explanatory sequential;
- embedded;
- multistage integration.

### Critical rule

Do not code:

`process evaluation = explanatory sequential`

unless QUAN→QUAL dependency is actually present.

---

# 51. Explanatory sequential in trials

Common trial use cases:

- explain adherence;
- explain nonresponse;
- interpret adverse effects;
- understand subgroup response;
- explain fidelity variation;
- explore mechanism hypotheses;
- understand outcome relevance.

### Critical rule

The QUAL phase does not inherit:

- allocation;
- blinding;
- intention-to-treat status.

Its sampling may be purposive and selective.

---

# 52. Sampling after treatment outcome can introduce selection issues

If QUAL participants are selected based on:

- outcome;
- adherence;
- response;

the QUAL sample is intentionally conditioned on post-baseline information.

### This is appropriate for explanation.

But:

- it is not a representative sample;
- it can distort causal interpretation if treated as such.

### Project rule

Do not use respondent/nonrespondent interviews to estimate:

- average causal mechanism prevalence.

---

# 53. Extreme outcome sampling and collider-like causal interpretation risk

Selecting cases based on:

- treatment response;
- adherence;
- symptom change

can create complex selection structure.

### Project consequence

Qualitative explanation remains valuable.

But causal inference about why the outcome occurred requires caution because conditioning on outcomes can induce misleading associations.

### Critical rule

Do not promote explanatory case-selection into causal subgroup proof.

---

# 54. Priority does not determine inferential authority

Even when QUAL is weighted heavily:

- causal effect still comes from causal QUAN design;
- lived/contextual explanation comes from QUAL methodology.

### Critical rule

“QUAL dominant” does not mean qualitative explanation overrides the trial estimate.

---

# 55. Quantitative uncertainty must propagate into explanation

If QUAN estimate is:

- imprecise;
- unstable;
- exploratory;
- multiple-testing dependent;

the QUAL phase should not treat it as a fixed fact.

### Project fields

- confidence interval;
- multiplicity;
- model stability;
- exploratory vs confirmatory status;
- whether QUAL targeting was based on uncertain result.

---

# 56. Qualitative uncertainty/adequacy also matters

The QUAL phase may have limitations:

- thin interviews;
- weak methodology;
- insufficient variation;
- interviewer bias;
- social desirability;
- underdeveloped analysis.

### Critical rule

A sophisticated QUAN model does not validate a weak qualitative explanation.

---

# 57. Integration quality

For explanatory sequential studies, ask:

1. Was the quantitative result needing explanation explicit?
2. Did QUAN results materially shape QUAL?
3. Was connecting used?
4. Was building used?
5. Were sampling criteria justified?
6. Were selected cases appropriate?
7. Was sample linkage clear?
8. Was qualitative methodology coherent?
9. Was final integration explicit?
10. Was a genuine meta-inference produced?
11. Were alternative explanations retained?
12. Was causal language calibrated?

Current standards require:

- mixed-method rationale;
- mixed-method sampling rationale;
- method-specific bias consideration;
- explicit what/when/how integration;

A high-quality explanatory sequential protocol should predefine or transparently report:

# 59. Sampling bias across phases

Potential issues:

- only willing QUAN participants accept interviews;
- high/low outcome groups differ in availability;
- attrition between phases;
- most extreme cases decline;
- clinicians select “good communicators”;
- participant-selection criteria change after seeing data.

### Project rule

Store:

- eligible for QUAL;
- invited;
- accepted;
- interviewed;
- reasons for nonparticipation.

# 60. Ethical issues in result-driven sampling

Recruitment may reveal to participants that they were selected because they had:

- low adherence;
- high burnout;
- poor outcome;
- unusual profile.

### Risks

- stigma;
- defensiveness;
- perceived judgment;
- disclosure of sensitive classification.

### Project rule

Interview invitation language should not unnecessarily expose or stigmatize quantitative status.

# 61. Record linkage and privacy

Linked QUAN→QUAL datasets increase re-identification risk.

Especially with:

- rare disease;
- elite athletes;
- small teams;
- extreme cases.

### Project fields

- linkage key;
- access control;
- de-identification;
- publication masking;
- quote/context deductive-disclosure risk.

# 62. Meta-inference

A good explanatory meta-inference answers:

> What plausible explanation of the initial quantitative result becomes available because the targeted qualitative phase was conducted?

### Example

QUAN:

- low adherence in older stroke survivors.

QUAL:

- fear after falls;
- difficulty remembering exercise steps;
- caregiver dependence;
- disrupted routine.

Meta-inference:

- age-associated adherence differences may reflect interacting cognitive, safety and support barriers not captured by the original score alone.

### Critical rule

This is contextual explanation, not proof of a causal chain.

---

# 63. Meta-inference can revise the original quantitative interpretation

QUAL may show that the initial quantitative construct was:

- mislabelled;
- incomplete;
- context dependent.

### Example

A “motivation” scale predicts adherence weakly.

Interviews show:

- habit;
- caregiver scheduling;
- environmental access

dominate daily behavior.

### Value

The mixed-method conclusion may revise theory rather than simply support the model.

---

# 64. Discordant explanations

QUAL can contradict the quantitative model.

Example:

QUAN:

- self-regulation score predicts adherence.

QUAL:

- high scorers report external caregiver control as main driver.

### Response

Investigate:

- construct validity;
- confounding;
- measurement interpretation;
- subgroup differences.

### Critical rule

Do not force the QUAL phase to “explain” QUAN by agreement only.

# 65. Do-not-confuse matrix

| Do not confuse | Why |
|---|---|
| QUAN→QUAL chronology vs explanatory sequential | dependency required |
| survey→interview vs mixed methods | connecting/building/integration may be absent |
| QUAL after QUAN vs post-hoc follow-up | follow-up may be independent |
| connecting vs building | sampling linkage ≠ question construction |
| same sample vs required universal rule | different samples can support contextual explanation |
| different sample vs person-level explanation | granularity must match linkage |
| extreme-case sampling vs representativeness | explanatory contrast ≠ population estimate |
| maximum variation vs random sampling | purposes differ |
| responder interviews vs causal mechanism proof | outcome-conditioned selection |
| mediation model + interviews vs causal mediation proof | QUAL does not satisfy mediation assumptions |
| significant association + matching quote vs explanation | anecdotal illustration may not be systematic QUAL |
| null QUAN + positive QUAL theme vs significant effect | different inference |
| qualitative dominance vs causal authority | causal design remains quantitative |
| process evaluation vs explanatory sequential | purpose ≠ integration architecture |
| embedded trial qual vs explanatory sequential | nesting ≠ dependency |
| explanatory joint display vs decorative table | must trace QUAN→QUAL→meta-inference |
| meta-inference vs narrative summary | integrated explanation must add value |
| case-selection variant vs follow-up-explanation variant | priority/purpose differ |
| emergent follow-up vs prespecified follow-up | transparency required |
| participant score linkage vs safe disclosure | privacy risks increase |

# 67. Project taxonomy decision

Explanatory sequential mixed methods is confirmed as a stable core mixed-methods architecture.

Canonical project route:

**QUAN collection/analysis  
→ identify result(s) requiring explanation  
→ connect and/or build QUAL phase  
→ QUAL collection/analysis  
→ merge  
→ explanatory meta-inference.**

### Minimum classifier

For RES-02, a study should not be coded explanatory sequential solely because QUAN came first.

At least one of the following must be materially true:

1. QUAN results determine QUAL sampling/cases;
2. QUAN results determine QUAL questions/content;
3. QUAL phase is explicitly designed to explain identified QUAN findings;

and final integration must be present.
