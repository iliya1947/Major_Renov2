# Карта PR

Рабочая карта навигации по PR исследования физической подготовки.

PR: #5 — «Исследование физической подготовки: база знаний и рабочая карта»  
Ветка: `research/fitness-foundation`  
Базовая ветка: `main`

## Быстрый маршрут

Если нужно понять **что вообще происходит**:
1. `README.md` — цель, правила, архитектура исследования.
2. `WORKFLOW.md` — что уже сделано, что делается сейчас и что дальше.
3. `RAW_TOPIC_INVENTORY.md` — полный накопительный список тем до очистки.

Если нужно работать **с конкретной областью**:
- открыть соответствующий файл в `areas/`.

Если нужно будет переходить от исследования к практике:
- будущая персональная оценка → `personal_assessment/`;
- итоговые выводы → `findings/`;
- источники → `sources/`;
- программа → `program/`;
- фактические тренировки → `logs/`.

## Текущая структура

### Корень

- `README.md`  
  Главный документ исследования: цель, правила, структура, принципы работы.

- `PR_MAP.md`  
  Этот файл. Быстрая карта навигации и назначение файлов.

- `WORKFLOW.md`  
  Текущее состояние работы, завершённые этапы, очередность следующих действий и рабочие правила.

- `RAW_TOPIC_INVENTORY.md`  
  Сырой накопительный список всех найденных тем до дедупликации.  
  Ничего не удалять из него до отдельного этапа очистки.

### areas/

1. `01_medicine.md`  
   Медицина, безопасность, противопоказания, клинический скрининг, патология, фармакология, красные флаги, экстренные состояния.

2. `02_anatomy.md`  
   Анатомия верхней конечности, мышц рук, суставов, функциональных связей, индивидуальных различий и мышечной архитектуры.

3. `03_physiology.md`  
   Адаптация, гипертрофия, сила, типы мышечной работы, утомление, соединительная ткань.

4. `04_neurophysiology_motor_learning.md`  
   Нервно-мышечная физиология, моторный контроль, моторное обучение, техника как навык, обратная связь.

5. `05_bioenergetics.md`  
   Энергетические системы, ATP-PCr, гликолиз, окислительный обмен, восстановление, метаболиты, роль отдыха.

6. `06_biomechanics.md`  
   Механика движений, моменты силы, плечи рычага, профиль сопротивления, амплитуда, механика свободных весов.

7. `07_training_programming.md`  
   Цели, объём, интенсивность, частота, прогрессия, периодизация, авторегуляция, ограниченный домашний инвентарь.

8. `08_technique_and_exercise_selection.md`  
   Выбор упражнений, критерии качества, техника, разминка, мобильность, растяжка.

9. `09_testing_monitoring_measurement.md`  
   Исходное тестирование, RPE/RIR, мониторинг, измерение прогресса, валидность, надёжность, самонаблюдение.

10. `10_recovery.md`  
    Восстановление между подходами и тренировками, DOMS, сон, стресс, недовосстановление, возврат после перерыва.

11. `11_nutrition.md`  
    Энергетический баланс, белок, углеводы, жиры, микронутриенты, гидратация, добавки, состав тела.

12. `12_psychology_adhd_adherence.md`  
    Приверженность, мотивация, СДВГ, архитектура запуска тренировки, устойчивость программы.

13. `13_research_methodology.md`  
    Типы исследований, качество доказательств, статистика, перенос научных данных в практику.

14. `14_individualization_and_decision_making.md`  
    Индивидуальные факторы, вариабельность ответа, принятие тренерских решений, будущая персональная оценка Ильи.

15. `15_general_physical_preparedness.md`  
    Общая двигательная база, кардио, анаэробная подготовка, concurrent training, мобильность и баланс программы.

## Планируемые каталоги

### sources/
Ключевые источники и карта литературы по областям.

### findings/
Только проверенные и уже синтезированные выводы.  
Не складывать сюда сырые заметки.

### personal_assessment/
Фактические исходные данные Ильи перед проектированием программы.

### program/
Версии программы, причины изменений, прогрессия и логика решений.

### logs/
Фактические тренировки, результаты, симптомы, изменения производительности.

## Правило навигации

Перед любой крупной работой:
1. открыть `WORKFLOW.md`;
2. определить текущий этап;
3. открыть нужный файл области;
4. проверить `RAW_TOPIC_INVENTORY.md`, если есть риск потерять старую тему;
5. после работы обновить `WORKFLOW.md`.

Этот файл обновлять только при изменении структуры PR.
