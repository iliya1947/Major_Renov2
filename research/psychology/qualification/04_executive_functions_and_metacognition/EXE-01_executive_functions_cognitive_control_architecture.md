# EXE-01 — Executive functions and cognitive control: architecture, scope, and core distinctions

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current architecture of executive functions (EFs) and cognitive control before deeper blocks on inhibition, task switching, monitoring, and control allocation.

The block separates:

- cognitive control from the broad historical label "executive function";
- goal representation/maintenance from working memory as a whole;
- response selection from response inhibition;
- interference control from motor stopping;
- task switching from generic flexibility;
- performance monitoring from error detection alone;
- proactive from reactive control;
- control implementation from control allocation;
- cognitive control from attention, motivation, effort, metacognition, and intelligence;
- task performance from a stable executive trait.

## Core rule

**Cognitive control is a family of processes that configure, select, maintain, monitor, and adjust cognition and action in service of goals when habitual/default processing is insufficient.**

A generic control loop is:

`goal / task representation`
-> `context-sensitive control state`
-> `selection / biasing of cognition and action`
-> `behavior / outcome`
-> `performance monitoring`
-> `adjustment / learning / reconfiguration`

Control is itself subject to allocation:

`expected benefit + learned expectations + effort/cost + context`
-> `whether/how much/which control to deploy`.

## 1. Current official cognitive-control definition

NIMH RDoC currently defines Cognitive Control as a system that modulates other cognitive and emotional systems in service of goal-directed behavior when prepotent modes of responding are insufficient or when novel contexts require selection among competing alternatives.

Its current subconstructs are:

1. Goal Selection; Updating, Representation, and Maintenance;
2. Response Selection; Inhibition/Suppression;
3. Performance Monitoring.

This provides a useful functional scaffold.

It is not treated as a final ontology of all executive functions.

## 2. Executive function is an umbrella term

"Executive function" is used across psychology, neuroscience, education, development, and clinical work for partially overlapping control processes.

Bunge's 2024 review emphasizes that the field lacks consensus on the core set of EFs, with many overlapping labels and substantial task impurity.

Therefore:

`executive function = one well-defined capacity`

is false.

For this qualification system:

- **cognitive control** names the mechanistic/process family;
- **executive functions** is the broader historical/psychometric umbrella.

## 3. The classical EF trinity is useful but incomplete

A common framework emphasizes:

- inhibition;
- updating/working memory;
- shifting/flexibility.

This "trinity" has been influential, especially in developmental and latent-variable research.

But modern reviews argue it is too narrow to serve as a complete ontology.

Important control processes also include:

- goal selection;
- task-rule representation;
- context gating;
- response selection;
- monitoring;
- control adjustment;
- hierarchical control;
- control allocation.

Canonical rule:

**inhibition + updating + shifting != complete cognitive-control architecture.**

## 4. Unity and diversity

Executive tasks often correlate, motivating a common-EF factor.

At the same time, updating, shifting, inhibition, and other control operations can show separable variance.

Thus EF shows both:

- **unity** — shared control demands;
- **diversity** — operation/task-specific demands.

Recent reviews continue to support the usefulness of unity/diversity while also highlighting replication, measurement, developmental, and construct-definition problems.

Do not infer:

`correlated executive tasks -> one mechanism`

or:

`different tasks -> fully independent executive systems`.

## 5. EF structure is not guaranteed invariant across populations

Latent structures can differ with:

- age;
- development;
- task battery;
- educational experience;
- culture/context;
- measurement quality.

Recent 2026 work found correlated but separable EF factors in a diverse adult sample, but this does not establish one universal factor structure.

Canonical rule:

**latent EF structure is an empirical model, not a universal mental anatomy.**

## 6. Task impurity is fundamental

Any executive task also requires nonexecutive processes.

Examples:

### Stroop

Requires:

- reading/color perception;
- selective attention;
- semantic processing;
- response selection;
- conflict handling.

### Flanker

Requires:

- perception;
- spatial attention;
- response selection;
- distractor/interference handling.

### Stop-signal

Requires:

- go-task processing;
- stop-signal detection;
- timing;
- response preparation;
- stopping process.

### Task switching

Requires:

- cue processing;
- rule retrieval;
- task-set representation;
- stimulus/response selection;
- reconfiguration;
- interference control.

Therefore:

**task name != isolated executive process.**

## 7. Goal selection

Goal selection chooses among possible:

- outcomes;
- actions;
- task states;
- control policies.

NIMH treats goal selection as a cognitive-control component.

Goal selection is not equivalent to motivation:

- motivation determines/weights value and willingness;
- control selects/configures operations needed to pursue a chosen goal.

The systems interact strongly.

## 8. Goal representation and maintenance

Goal representations specify what currently counts as relevant behavior.

They can include:

- task rules;
- stimulus-response mappings;
- priorities;
- subgoals;
- contextual conditions.

Maintaining a goal is a major control function.

However:

**goal maintenance != working memory as a whole.**

NIMH explicitly notes overlap: working memory can maintain many kinds of information, whereas cognitive-control goal maintenance concerns representations used to regulate behavior.

## 9. Goal updating

Goals must sometimes change because of:

- new instruction;
- new context;
- feedback;
- changed environment;
- higher-level goal revision.

Updating a goal is not the same as simply replacing any WM item.

It changes the control configuration that determines subsequent selection.

## 10. Hierarchical control

Many behaviors involve nested structure:

`long-term goal -> subgoal -> task rule -> immediate response`.

Higher-order context can determine which lower-level rule applies.

Badre's 2025 review emphasizes that the content and structure of task representations are central to cognitive control.

Therefore:

**complex control failure can arise from wrong hierarchical representation, not merely weak inhibition.**

## 11. Response selection

Response selection chooses an action from competing alternatives given:

- stimulus;
- context;
- task rule;
- current goal.

It is conceptually distinct from inhibition.

A person can fail because the correct response was never selected strongly enough, even if stopping mechanisms are intact.

## 12. Inhibition/suppression

Inhibition refers broadly to reducing or stopping competing processing/action.

But several forms must be separated:

- motor response stopping;
- prepotent-response suppression;
- interference control;
- distractor suppression;
- memory retrieval suppression.

These are not automatically one process.

Canonical rule:

**"inhibition" must always specify what is being inhibited and at which processing level.**

## 13. Motor stopping and interference control are different

### Motor stopping

Cancel or withhold a prepared/initiated action.

Common paradigms:

- stop-signal;
- go/no-go.

### Interference control

Resolve competition from irrelevant/conflicting information.

Common paradigms:

- Stroop;
- Flanker;
- Simon.

These task families overlap in control requirements but should not be treated as interchangeable assays of one inhibitory trait.

## 14. Stop-signal measures are not stable trait certificates

The stop-signal reaction time (SSRT) is commonly interpreted as stopping latency under a race-model framework.

A 2024 multi-study/systematic investigation found low test-retest stability for common inhibition measures and cautioned against treating SSRT as a stable dispositional trait.

Therefore:

`one SSRT -> stable inhibition ability / impulsivity trait`

is not justified.

This does not mean stop-signal paradigms are useless.

It means their strongest use may be process/state/experimental inference rather than naïve trait ranking.

## 15. Response inhibition is not impulsivity

Impulsivity is a broad behavioral/personality/clinical construct that can involve:

- reward sensitivity;
- delay discounting;
- urgency;
- planning;
- motor disinhibition;
- attention;
- learned policy.

Response inhibition is one possible contributor.

Canonical rule:

**poor stopping-task performance != "impulsive person."**

## 16. Task switching

Task switching requires changing the currently relevant mapping/rule/task set.

Switch costs can reflect:

- task-set reconfiguration;
- residual interference from previous task;
- cue processing;
- stimulus-set change;
- response-set change;
- preparation time;
- control adjustment.

A 2026 review of task-switching paradigms shows that task design materially changes measured switch costs.

Therefore:

`switch cost = pure flexibility`

is false.

## 17. Cognitive stability and flexibility are not one simple continuum

A common intuition is:

- stability = maintain current goal;
- flexibility = switch readily.

Recent modeling supports the possibility that stability and flexibility can vary partly independently rather than being opposite ends of one scalar dimension.

This matters because a person may sometimes achieve:

- strong task focus;
- rapid switching when context demands it.

Canonical rule:

**stability and flexibility can trade off, but need not be strict opposites.**

## 18. Proactive and reactive control

### Proactive control

Control is configured in advance using:

- goals;
- cues;
- expected conflict;
- context.

It can involve sustained goal maintenance and anticipatory biasing.

### Reactive control

Control is recruited after relevant conflict/event information appears.

Examples:

- stopping after a stop signal;
- adjusting after detected conflict.

This distinction is useful but should not be treated as two isolated neural systems.

Different tasks can mix both.

## 19. Proactive control is not always better

Proactive control can improve performance when upcoming demands are predictable.

But it can also require:

- sustained maintenance;
- effort;
- opportunity cost;
- stable contextual cues.

Reactive control can be efficient when conflict is rare/unpredictable.

Therefore:

`more proactive control = globally superior executive function`

is false.

## 20. Performance monitoring

Performance monitoring evaluates ongoing behavior for signals such as:

- errors;
- conflict;
- unexpected outcomes;
- changes in reward/performance;
- need for adjustment.

Monitoring is not merely detecting that an error occurred.

It can influence:

- control intensity;
- strategy;
- speed-accuracy setting;
- task representation;
- learning.

## 21. Monitoring and adjustment are separable

An error can be detected without an effective corrective adjustment.

Conversely, behavior can adapt from statistical regularities without explicit conscious error awareness.

Canonical rule:

**error detection != successful control adaptation.**

## 22. Post-error slowing is not a pure monitoring index

Slower responding after an error can reflect:

- cautious adjustment;
- orienting/surprise;
- disrupted processing;
- strategic threshold change.

Therefore:

`post-error slowing -> better monitoring`

is not automatically valid.

## 23. Cognitive control is context-sensitive

Badre's 2025 synthesis emphasizes that control selects behaviors based on context and monitors/adjusts ongoing behavior.

The same person can show different control policies when:

- task structure changes;
- context cues change;
- reward changes;
- demands become predictable;
- errors become costly.

Control should therefore be modeled as adaptive configuration, not a fixed amount.

## 24. Control allocation

Having a control mechanism does not imply it is always deployed maximally.

Allocation concerns:

- whether to engage control;
- which control process to engage;
- how intensely;
- for how long.

Control allocation depends on expected benefits, costs, learned expectations, and opportunity structure.

## 25. Cognitive effort and cognitive control are related but distinct

Effort is the subjective/behavioral cost associated with demanding controlled processing.

Current theories disagree about why effort feels costly.

A 2026 Trends in Cognitive Sciences review compares:

- information-theoretic;
- psychological/economic;
- biological/network-control

accounts and identifies major unresolved questions.

Therefore:

**effort is not a direct meter of amount of control.**

## 26. Effortful does not mean executive

A task can feel difficult because of:

- perceptual degradation;
- unfamiliarity;
- memory load;
- low skill;
- emotional conflict.

Conversely, well-practiced control can sometimes occur with relatively little subjective effort.

Canonical rule:

**subjective effort != executive-function demand by definition.**

## 27. People can learn when control investment is worthwhile

A 2025 PNAS study showed that expectations about learning can influence willingness to allocate cognitive control/effort.

This illustrates that control allocation depends not only on immediate reward and effort but also on expected future improvement.

Therefore control allocation is partly a decision/learning problem.

Detailed motivation/economic allocation is routed to MOT/DEC.

## 28. Control adjustment itself can have costs

A 2025 Psychological Review study found costs associated with adjusting control settings to changing goals.

Thus flexibility is not free.

A rapidly changing environment can impair performance not because a person lacks control capacity but because:

- control states require reconfiguration;
- reconfiguration itself has costs.

## 29. Attention and cognitive control are distinct

Attention prioritizes/selects information.

Cognitive control configures processing according to goals/context and can modulate attention.

NIMH explicitly distinguishes cognitive control from attention while noting executive-attention overlap.

Canonical boundary:

**attention selects; cognitive control configures/maintains the goal-dependent selection policy.**

This is a functional distinction, not a claim of completely separate neural systems.

## 30. Working memory and cognitive control are distinct

Working memory maintains/updates task-relevant information.

Cognitive control uses goal/task representations to regulate cognition/action.

They overlap strongly when WM contains:

- goals;
- task rules;
- control settings.

But WM can maintain non-goal information.

Thus:

`WM deficit = cognitive-control deficit`

is not automatic.

## 31. Motivation and cognitive control are distinct

Motivation helps determine:

- goal value;
- persistence;
- willingness to invest effort.

Control determines how processing/action is configured to pursue the goal.

A person may:

- know how to exert control but choose not to;
- be highly motivated but lack an effective control policy.

Canonical rule:

**can't, won't, and didn't are different hypotheses.**

## 32. Metacognition and cognitive control are distinct

Metacognition monitors/evaluates:

- confidence;
- knowledge;
- performance;
- uncertainty.

Cognitive control implements adjustments in processing/action.

Metacognitive information can guide control allocation.

But:

`self-awareness of error -> effective executive correction`

does not automatically follow.

Detailed MET work is separate.

## 33. Executive control and emotion regulation overlap but are not identical

Cognitive control can regulate:

- attention to emotional material;
- reappraisal implementation;
- response selection.

But emotion regulation also depends on:

- appraisal;
- motivation;
- affective learning;
- social context.

Therefore "hot executive function" should not be used as a vague replacement for emotion-regulation analysis.

Detailed emotion regulation is routed to AFF.

## 34. Executive control is not intelligence

Broad cognitive ability correlates with control-demanding tasks.

But:

- intelligence is a psychometric individual-difference construct;
- cognitive control is a process family.

A high general-ability score does not identify which control process supports a particular behavior.

Likewise, one control-task score should not be interpreted as general intelligence.

## 35. Executive control is not the prefrontal cortex

Prefrontal/frontoparietal systems are important for many control functions.

But the statement:

`PFC = executive function`

is too coarse to be mechanistic.

Control depends on distributed interaction with:

- parietal systems;
- basal ganglia;
- sensory systems;
- motor systems;
- memory systems;
- affective systems.

Detailed neural architecture is routed to NEU.

## 36. Multiple-demand systems support unity without proving one executive module

Current neural accounts identify a multiple-demand (MD) system engaged across diverse difficult/control tasks.

This can help explain shared EF variance.

But diverse tasks also recruit specialized representations and adjacent/domain-specific systems.

Canonical rule:

**common control network != one all-purpose executive homunculus.**

## 37. Control operates on representations

Badre's control-systems perspective emphasizes that behavior depends strongly on what task representation is currently active.

Control can fail because:

- the wrong rule is represented;
- context is misclassified;
- subgoal hierarchy is wrong;
- required state is not maintained;
- response mapping is wrong.

This is analytically different from "control strength."

## 38. Learning can reduce control demand

With practice, behavior may become:

- faster;
- more automatic;
- less conflict-prone;
- less effortful.

Therefore improved performance can reflect:

- learning;
- automatization;
- changed representation;

rather than increased executive capacity.

Learning/control interactions are routed to LEA.

## 39. Executive failures are not one failure type

A behavioral failure can originate in:

1. wrong goal;
2. weak goal maintenance;
3. delayed/failed updating;
4. poor context representation;
5. wrong response selection;
6. stopping/suppression failure;
7. interference;
8. failure to monitor;
9. failure to adjust after monitoring;
10. low control allocation;
11. excessive control/overconstraint;
12. state/motivation/fatigue effects.

Canonical rule:

**"executive dysfunction" is a conclusion requiring localization, not an explanation.**

## 40. Control can be excessive or maladaptive

More control is not always better.

Excessive stability/control can:

- impair flexibility;
- increase perseveration;
- slow behavior;
- overconstrain exploration.

Control must be matched to context.

Thus the optimization target is:

**appropriate control**, not maximal control.

## 41. Task-based EF measures and real-world executive behavior can diverge

Laboratory tasks are intentionally constrained.

Real-world executive behavior includes:

- self-generated goals;
- long time horizons;
- interruptions;
- external tools;
- competing values;
- uncertain feedback;
- social context.

A person can perform poorly on one decontextualized task yet function effectively through:

- planning;
- environmental structuring;
- reminders;
- habits;
- externalization.

Conversely, good laboratory task performance does not guarantee real-world organization.

## 42. Self-report and behavioral EF tasks are not interchangeable

Executive-function questionnaires can capture:

- perceived everyday failures;
- contextual functioning;
- self-concept;
- distress.

Behavioral tasks capture constrained performance under experimental conditions.

Low correlations between the two do not automatically mean one is invalid.

They may measure different levels of functioning.

## 43. Trait inference requires reliability and cross-task convergence

Stable person-level EF claims require:

- reliable measurement;
- repeated occasions;
- multiple task families;
- relevant contexts;
- separation of state effects.

The 2024 stop-signal reliability evidence is a concrete warning that even widely used "inhibition" metrics may not be temporally stable enough for simple trait inference.

## 44. Executive Control Inference Gate

Before making an executive-function inference, ask:

### A. Exact target

1. Is the claim about goal selection, goal maintenance, updating, response selection, inhibition, switching, monitoring, adaptation, or control allocation?
2. Is "executive function" being used too broadly?

### B. Goal/task representation

3. What is the active goal?
4. Which task rule must be represented?
5. Is the relevant context correctly identified?
6. Is hierarchical/subgoal structure involved?
7. Could a representation error explain failure?

### C. Working-memory boundary

8. Is information merely being maintained, or is it regulating behavior?
9. Could ordinary WM capacity/interference explain the result?
10. Is goal maintenance being conflated with all of working memory?

### D. Attention boundary

11. Is input selection the main problem?
12. Is attentional capture/distractor priority sufficient to explain it?
13. Is control over attention being confused with attention itself?

### E. Response selection/inhibition

14. Is the correct response selected?
15. Is an initiated/prepotent action actually being stopped?
16. Is interference control being confused with motor stopping?
17. What exactly is being inhibited?

### F. Switching/flexibility

18. Is the task rule, stimulus set, response set, or context switching?
19. Could residual interference explain switch cost?
20. Is preparation time controlled?
21. Is "flexibility" being inferred from one switch-cost paradigm?

### G. Monitoring/adaptation

22. Is error/conflict actually detected?
23. Does detection produce adaptive adjustment?
24. Could post-error slowing reflect orienting rather than improved control?
25. Is adaptation driven by explicit awareness or learned statistics?

### H. Allocation/effort/motivation

26. Was control available but not deployed?
27. What benefit/cost structure governs allocation?
28. Is subjective effort being equated with amount of control?
29. Could motivation/value explain nondeployment?
30. Could expected learning/future benefit alter allocation?

### I. Proactive/reactive mode

31. Could control be configured before conflict?
32. Is reactive adjustment sufficient?
33. Is one mode being treated as globally superior?

### J. Measurement/task impurity

34. Which perceptual, memory, language, motor, and decision processes does the task require?
35. Is the measure reliable enough for individual differences?
36. Is one named task being treated as identical to one EF construct?
37. Is speed-accuracy tradeoff relevant?

### K. State versus trait

38. Was the effect replicated across occasions?
39. Across task families?
40. Could sleep, fatigue, stress, pharmacological state, practice, or motivation explain it?
41. Does the evidence support a process/state claim rather than a stable trait?

### L. Real-world generalization

42. Does the laboratory task resemble the real-world control demand?
43. Are external supports/offloading available in real life?
44. Is self-report being treated as equivalent to laboratory performance?

### M. Conclusion

45. What exact control component is supported?
46. Which neighboring mechanism remains viable?
47. What observation/task would discriminate the alternatives?
48. What would constitute overclaiming?

## 45. High-value failure modes

### Failure A — executive function = one capacity

Incorrect.

Correct:

EF is an umbrella over partially shared and partially distinct control processes.

### Failure B — inhibition/updating/shifting = complete EF ontology

Incorrect.

Correct:

Goal representation, response selection, monitoring, hierarchical control, and allocation also matter.

### Failure C — task = EF process

Incorrect.

Correct:

Stroop, Flanker, stop-signal, and switching tasks are process mixtures.

### Failure D — poor Stroop = weak inhibition

Incorrect.

Correct:

Perception, attention, semantic processing, response selection, conflict, and criterion can contribute.

### Failure E — stop-signal RT = stable inhibitory trait

Incorrect.

Correct:

Current evidence shows limited temporal stability for common stopping measures, requiring strong caution for trait inference.

### Failure F — poor stopping = impulsive person

Incorrect.

Correct:

Impulsivity is a broader construct with multiple mechanisms.

### Failure G — switch cost = general flexibility

Incorrect.

Correct:

Switch cost depends on cueing, preparation, residual interference, stimulus/response sets, and task design.

### Failure H — stability and flexibility are strict opposites

Incorrect.

Correct:

Recent modeling allows partly independent stability and flexibility.

### Failure I — proactive control = better control

Incorrect.

Correct:

Proactive and reactive control have different costs/benefits depending on context.

### Failure J — error detection = effective monitoring/adaptation

Incorrect.

Correct:

Detection and adaptive control adjustment are separable.

### Failure K — cognitive effort = cognitive control amount

Incorrect.

Correct:

Effort is a subjective/behavioral cost signal with multiple competing theoretical explanations.

### Failure L — effortful = executive

Incorrect.

Correct:

Difficulty can arise from perception, memory, skill, emotion, or unfamiliarity.

### Failure M — no control shown = no control capacity

Incorrect.

Correct:

Control may be available but not allocated because of motivation, cost, learned expectation, or context.

### Failure N — executive control = attention

Incorrect.

Correct:

Control configures goal-dependent priority; attention implements selection over information.

### Failure O — executive control = working memory

Incorrect.

Correct:

Goal maintenance overlaps with WM, but WM is broader and control includes selection/monitoring/adaptation.

### Failure P — executive control = intelligence

Incorrect.

Correct:

Control is a process family; intelligence is a broad psychometric individual-difference construct.

### Failure Q — PFC = executive function

Incorrect.

Correct:

Control is implemented by distributed interacting systems; PFC involvement alone is not a mechanism.

### Failure R — more control = always better

Incorrect.

Correct:

Control can be excessive, costly, slow, and maladaptive when context favors flexibility/exploration.

## Canonical working rule

**Specify the goal/control demand, localize the control operation, separate task representation from implementation, distinguish selection from inhibition and monitoring from adaptation, test allocation/state/task-impurity alternatives, then infer only the executive mechanism supported by converging evidence.**

Never:

**difficult behavior -> "executive dysfunction" -> stable person-level explanation.**

## Current-standard note

As of 2026-11-19:

- NIMH RDoC continues to define cognitive control around goal selection/maintenance/updating, response selection/inhibition, and performance monitoring;
- Badre's 2025 Annual Review frames cognitive control around context-sensitive behavior selection plus monitoring/adjustment and emphasizes the content/structure of task representations;
- current EF reviews explicitly identify unresolved ontology/terminology problems and task impurity, arguing against treating the traditional inhibition–updating–shifting trinity as a complete mechanistic taxonomy;
- current stopping-task evidence strongly cautions against interpreting a single SSRT/common inhibition measure as a stable dispositional trait;
- current task-switching evidence shows that switch costs depend materially on paradigm structure and supports separating cognitive stability from flexibility rather than forcing them onto one strict continuum;
- current control-allocation/effort work treats willingness to deploy control as dependent on learned expectations, benefits, costs, and reconfiguration demands, while the origin of subjective cognitive-effort costs remains theoretically unresolved.

## Scope note

This block establishes the executive-control architecture.

Detailed goal maintenance/proactive-reactive control, inhibition/stopping, task switching/flexibility, performance monitoring/adaptation, and control allocation can be opened as deeper EXE blocks. Detailed metacognitive confidence/self-monitoring is routed to MET, motivational valuation to MOT, emotion regulation to AFF, and neural implementation to NEU.
