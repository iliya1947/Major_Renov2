# EXE-05 — Performance monitoring, error/conflict signals, adaptation, and control adjustment

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current architecture of performance monitoring that separates:

- error detection from conflict detection;
- error processing from surprise/unexpected outcome;
- monitoring signal from conscious error awareness;
- monitoring from subsequent control adjustment;
- post-error slowing from adaptive improvement;
- post-conflict adaptation from simple sequential confounds;
- neural/ERP correlates from unique monitoring mechanisms;
- state/process-level monitoring effects from stable person-level monitoring traits.

## Core rule

**Performance monitoring evaluates ongoing behavior and outcomes for signals that current processing may need adjustment. A monitoring signal does not by itself specify what caused the problem, whether it reached awareness, or whether effective adaptation followed.**

A generic monitoring-control loop is:

`goal / task state`
-> `action / decision`
-> `outcome + internal performance evidence`
-> `monitoring signal: error / conflict / surprise / uncertainty`
-> `awareness / confidence may or may not emerge`
-> `control-policy or decision-threshold adjustment`
-> `next-trial / longer-horizon behavior`.

## 1. Current official scaffold

NIMH RDoC currently places **Performance Monitoring** inside Cognitive Control.

The current matrix links the subconstruct to:

- post-error or post-conflict behavioral adjustments;
- Flanker, Simon, and Stroop paradigms;
- physiology including ERN, N2, and N450;
- ACC/pre-SMA and insular circuits.

This is a useful organizing scaffold.

It is not proof that one task, ERP component, or brain region uniquely measures one monitoring mechanism.

## 2. Performance monitoring is broader than error detection

Monitoring can track:

- overt errors;
- response conflict;
- unexpected outcomes;
- uncertainty;
- reward/performance change;
- mismatch between intended and executed action;
- need for control adjustment.

Therefore:

`performance monitoring = noticing errors`

is too narrow.

## 3. Error detection

Error detection means registering that the selected/executed response likely violated the task goal or intended action.

Evidence can arise from:

- internal motor/action information;
- conflict after response;
- sensory feedback;
- external feedback.

Canonical rule:

**an error can be internally detected before external feedback arrives.**

## 4. Internal and external monitoring are distinct

A system can use:

- **internal monitoring** — evidence generated by its own response/action state;
- **external monitoring** — feedback supplied by the environment.

These can disagree.

False-feedback paradigms show that sensitivity to external feedback and internal self-monitoring can be dissociated.

Therefore:

**negative feedback != internally detected error.**

## 5. Error detection is not error awareness

An error-related process can occur without conscious awareness.

Conversely, conscious error awareness can occur even when a canonical early ERP signature is weak or absent.

A 2025 Psychophysiology study demonstrated error awareness in the absence of a conventional ERN in a masking paradigm.

Canonical rule:

**error signal != conscious awareness of error.**

## 6. Error awareness is not correction

A person can consciously recognize:

> "that response was wrong"

yet fail to:

- slow down;
- change strategy;
- increase control;
- improve subsequent accuracy.

Thus:

`awareness -> successful adaptation`

is not guaranteed.

## 7. Conflict detection

Conflict occurs when incompatible response/process tendencies are simultaneously active.

Examples include:

- competing response mappings;
- task-relevant versus irrelevant stimulus dimensions;
- old versus new task sets.

Conflict can be detected even when the final response is correct.

Canonical rule:

**conflict != error.**

## 8. Error and conflict can share monitoring machinery without being identical

Classic conflict-monitoring models proposed that conflict signals a need for increased control.

Errors often produce high conflict, but error processing also includes:

- violated expectation;
- negative outcome value;
- surprise;
- action-outcome mismatch.

Therefore one monitoring architecture may respond to several event types without making them psychologically identical.

## 9. Surprise/unexpectedness is another candidate signal

An event can trigger monitoring because it is:

- rare;
- unexpected;
- surprising

even if it is not an error.

This is important because neural and behavioral error markers can partly reflect orienting or surprise.

Canonical rule:

**error-related response != error-specific response by default.**

## 10. Monitoring signal versus need-for-control signal

A detected event may indicate that current control policy is inadequate.

But this inference requires an additional step:

`event detected -> evaluate relevance -> decide whether/how to adjust control`.

Monitoring and control allocation are therefore separable.

## 11. Error-related negativity (ERN/Ne)

The ERN/Ne is a response-locked negative ERP component that typically appears rapidly after erroneous responses in speeded tasks.

It is widely used as a neural correlate of error processing/performance monitoring.

However, ERN interpretation has included several partly overlapping accounts:

- error detection;
- conflict;
- reinforcement/prediction-error signaling;
- action monitoring;
- motivational significance.

Canonical rule:

**ERN = error-related neural signal, not a one-to-one readout of one settled psychological mechanism.**

## 12. ERN does not require conscious awareness in a simple way

ERN and awareness can dissociate.

The 2025 masking study found error awareness could occur without a detectable ERN under some conditions.

Therefore:

`large ERN = conscious awareness`

and

`no ERN = no awareness`

are both unsafe.

## 13. Error positivity (Pe)

Pe is a later positive ERP component following errors.

It is often associated with:

- conscious error awareness;
- accumulation of post-response evidence;
- motivational/salience processing.

But Pe should not be treated as a pure consciousness marker.

Its magnitude can depend on:

- task;
- confidence;
- salience;
- evidence strength;
- analysis choices.

Canonical rule:

**Pe is awareness-related, not an awareness meter.**

## 14. ERN and Pe are separable

ERN and Pe occur at different latencies and can show different relationships with:

- error awareness;
- task context;
- individual differences.

The distinction supports at least two stages/process families:

- early error-related monitoring;
- later evidence/awareness-related processing.

This should not be reified into one fixed serial neural model.

## 15. ERP reliability depends on task and scoring

A 2025 direct/conceptual replication across Flanker, Go/No-Go, and Stroop tasks found generally acceptable-to-high internal consistency for ERN/Pe when sufficient data were available, but reliability varied by:

- component;
- task;
- scoring method;
- trial count.

Difference scores such as ΔERN/ΔPe require separate psychometric evaluation.

Canonical rule:

**ERP reliability is measure- and task-specific.**

## 16. Internal consistency is not temporal stability or validity

A measure can be internally consistent within one session but still have:

- limited test-retest stability;
- weak construct specificity;
- task-specific variance.

Therefore good internal consistency does not prove:

- stable trait measurement;
- unique monitoring mechanism;
- diagnostic validity.

This inherits PSY-RES-03.

## 17. ERN analysis pipelines are highly heterogeneous

A 2026 systematic review of 202 adult ERN studies published 1995–2025 found:

- substantial heterogeneity in preprocessing and quantification;
- no two studies using the same complete workflow;
- persistent reporting gaps;
- large analytic flexibility.

Canonical rule:

**cross-study ERN differences may partly reflect analysis pipeline differences.**

## 18. ERN is not a direct psychopathology diagnosis

Current clinical review literature finds altered ERN associations across broad symptom/risk domains.

But:

- group associations are heterogeneous;
- direction can differ across symptom families;
- ERN is not disorder-specific;
- measurement/task/context matter.

Therefore:

`ERN abnormality -> diagnosis`

is invalid.

Clinical interpretation is routed to CLN/PSY-RES-07.

## 19. Post-error slowing (PES)

PES is the tendency for responses to become slower after an error.

Typical form:

`RT after error > RT after correct response`.

It is one of the most widely used behavioral measures of post-error adjustment.

Canonical rule:

**PES is a behavioral adjustment, not a mechanism.**

## 20. PES can be adaptive or nonadaptive

Two major explanatory families include:

### Adaptive-control account

Errors trigger increased caution/control, potentially improving later performance.

### Orienting account

Errors are rare/salient events that interrupt processing and slow the next response without necessarily improving control.

Both have empirical support under different conditions.

Therefore:

**PES alone does not prove adaptive cognitive control.**

## 21. Adaptive PES should improve an explicit performance target

If PES reflects adaptive control, one should ask whether it improves:

- accuracy;
- decision quality;
- preparation;
- later conflict resolution.

A 2026 study found that post-error slowing in **self-paced preparation time** was associated with better task performance and metacognitive/strategic knowledge.

This demonstrates that some forms of post-error slowing can be adaptive.

It does not establish all PES as adaptive.

## 22. PES is task- and context-sensitive

Recent 2026 studies show PES varies across:

- task type;
- task demand;
- age/population;
- temporal distance from the error.

A 2026 individual-differences study using several inhibitory-control tasks found both:

- domain-general;
- task-specific

components of PES.

Canonical rule:

**PES is neither purely general nor purely task-specific.**

## 23. Immediate and sustained PES may differ

Post-error effects can persist beyond the immediately following trial.

The relative contribution of domain-general versus task-specific processes may change with time from the error.

Therefore:

`PES = one fixed next-trial response`

is too narrow.

## 24. PES can reflect threshold adjustment

After an error, participants may increase decision caution by raising response threshold.

This can:

- slow RT;
- sometimes improve accuracy.

But PES can also involve:

- attention/orienting;
- nondecision time;
- preparation;
- motor changes.

Canonical rule:

**PES should be decomposed when possible rather than named "more control."**

## 25. Drift-diffusion/process models can help but remain models

Process models may separate:

- evidence accumulation;
- decision threshold;
- nondecision time;
- starting bias.

This can clarify which component changed after errors.

But model fit does not prove one unique neural mechanism.

This inherits PSY-RES-02/03.

## 26. Post-error accuracy is not guaranteed to improve

Errors can be followed by:

- higher accuracy;
- unchanged accuracy;
- another error.

Post-error slowing without accuracy benefit may reflect:

- orienting;
- overcaution;
- task interruption;
- nondecision delays.

Canonical rule:

**slowing and improvement must be measured separately.**

## 27. Emotional/affective context can modulate PES

A 2026 preregistered study plus pooled analysis found that emotional valence/arousal changed post-error slowing.

This supports interaction between:

- affective significance;
- performance monitoring;
- control adjustment.

Therefore PES is not a context-free pure executive marker.

## 28. Congruency Sequence Effect (CSE)

CSE refers to a smaller congruency effect after an incongruent trial than after a congruent trial.

It is often interpreted as conflict-triggered control adaptation.

But other mechanisms can contribute.

## 29. Feature binding and contingency learning can inflate CSE

Sequential repetitions of:

- stimulus features;
- response features;
- contingencies

can create apparent adaptation without top-down control.

The 2025 meta-analysis across 311 experiments found CSE was larger when such bottom-up confounds were present.

Canonical rule:

**raw CSE != pure conflict adaptation.**

## 30. CSE persists when major bottom-up confounds are minimized

The same 2025 meta-analysis found a robust CSE in confound-minimized studies.

Thus bottom-up mechanisms do not explain the full effect.

The evidence supports a mixed architecture involving:

- associative/binding mechanisms;
- top-down/local control;
- possibly broader control processes.

## 31. CSE is stronger within task than across tasks

The 2025 meta-analysis found:

- large within-task CSE;
- smaller but significant between-task CSE.

This suggests that much adaptation is task-local, with a smaller possible global component.

Canonical rule:

**conflict adaptation should not be assumed to generalize fully across tasks.**

## 32. Objective congruency and subjective conflict may be separable

A 2026 Cognitive Psychology study challenged the assumption that the amount of experienced conflict itself is the necessary trigger for CSE.

Its behavioral/modeling results support the possibility that objective trial congruency can trigger adaptation independently of conflict magnitude under some conditions.

Therefore:

`CSE proves conflict monitoring`

is too strong.

## 33. "Conflict adaptation" is a hypothesis, not a direct observation

Observed fact:

> current congruency effect depends on previous trial congruency.

Candidate explanations include:

- conflict-triggered control;
- congruency-triggered policy update;
- feature binding;
- contingency learning;
- expectancy;
- task-specific adaptation.

Canonical rule:

**sequence effect first, mechanism second.**

## 34. Monitoring and adaptation are separate stages

A system may correctly detect:

- error;
- conflict;
- uncertainty

yet choose not to change behavior because:

- adjustment cost is high;
- current policy remains optimal;
- evidence is weak;
- environment is unstable;
- adjustment is delayed.

Therefore:

**absence of immediate adjustment != absence of monitoring.**

## 35. Adaptation can be maladaptive

More caution/control after an error is not always better.

Over-adjustment can:

- slow performance excessively;
- impair flexibility;
- increase unnecessary control cost.

Canonical target:

**context-appropriate adjustment**, not maximal adjustment.

## 36. Monitoring can update more than response speed

Adaptive responses can include:

- threshold change;
- attentional reweighting;
- task-rule update;
- strategy change;
- increased preparation;
- confidence recalibration;
- learning.

Therefore focusing only on PES misses other adjustment forms.

## 37. Confidence and monitoring

After a response, people can estimate:

- whether it was correct;
- how confident they are.

This metacognitive evaluation overlaps with performance monitoring but is not identical.

Detailed confidence calibration belongs to MET.

Canonical boundary:

**performance-monitoring signal != explicit confidence judgment.**

## 38. Error awareness and metacognition overlap but are not identical

Error awareness concerns recognition of a specific incorrect response.

Metacognition more broadly concerns monitoring/evaluating one's cognition and uncertainty.

A person can:

- detect a specific error;
- still have poor global confidence calibration.

Or:

- have good calibration;
- miss some individual errors.

## 39. Monitoring depends on task opportunity

A task with:

- very few errors;
- ambiguous feedback;
- weak response competition

provides limited information for estimating error-monitoring behavior.

Trait claims require enough informative events.

Canonical rule:

**absence of observed error adjustment can be an opportunity/measurement problem.**

## 40. Performance-monitoring task impurity

Flanker, Stroop, Simon and related tasks also require:

- perception;
- attention;
- response selection;
- interference control;
- motor response;
- timing.

Thus a post-error or post-conflict effect inherits the task's other demands.

No monitoring metric is process-pure by default.

## 41. State factors

Performance monitoring and post-error adjustment can vary with:

- fatigue;
- arousal;
- stress;
- motivation;
- reward/penalty;
- emotional context;
- pharmacological state;
- learning.

A single session is weak evidence for a stable monitoring trait.

## 42. Monitoring can be learned/adapted

Repeated experience can alter:

- expectations about errors;
- sensitivity to conflict;
- strategy;
- adjustment size.

Thus longitudinal change can reflect learning rather than a change in a fixed monitoring capacity.

## 43. Performance Monitoring Inference Gate

Before interpreting a monitoring result, ask:

### A. Event type

1. Is the signal triggered by an overt error, conflict, surprise, uncertainty, or negative feedback?
2. Is the event objectively rare/unexpected?
3. Is error-specific processing being distinguished from orienting/surprise?

### B. Internal versus external monitoring

4. Was an internal error signal available?
5. Was external feedback provided?
6. Did internal and external evidence agree?
7. Could feedback sensitivity explain behavior rather than internal monitoring?

### C. Awareness

8. Was the error consciously reported?
9. Is awareness measured directly or inferred?
10. Is ERN being treated as equivalent to awareness?
11. Is Pe being treated as a pure awareness marker?

### D. ERP/neural measures

12. Which component is used: ERN/Ne, Pe, N2/N450, or another signal?
13. What scoring/quantification method is used?
14. Is internal consistency adequate?
15. Is temporal stability known?
16. Is preprocessing/analysis pipeline preregistered or transparent?
17. Is a component being treated as a unique mechanism/biomarker?

### E. Post-error behavior

18. Is PES present?
19. Does slowing improve accuracy or another performance target?
20. Could PES reflect orienting/surprise?
21. Could threshold change explain it?
22. Could nondecision/preparation changes explain it?
23. Does the effect persist beyond one trial?

### F. Conflict adaptation

24. Is a CSE measured?
25. Are feature repetitions controlled?
26. Are contingency-learning confounds controlled?
27. Is the effect within-task or between-task?
28. Could objective congruency rather than subjective conflict trigger adaptation?
29. Is sequence effect being labeled conflict adaptation without process discrimination?

### G. Monitoring versus adjustment

30. Is the event detected?
31. Is a control adjustment actually observed?
32. Could monitoring occur without immediate adjustment?
33. Is the adjustment adaptive for the task objective?
34. Could adjustment be excessive/maladaptive?

### H. Metacognitive interface

35. Is confidence measured?
36. Is error awareness distinguished from confidence calibration?
37. Is performance monitoring being equated with metacognition as a whole?

### I. Measurement/state

38. Are enough error/conflict trials available?
39. Is the metric reliable enough for individual differences?
40. Could fatigue/stress/motivation/emotion explain variation?
41. Is one task/session being converted into a stable monitoring trait?

### J. Individual inference

42. Does the pattern replicate across occasions?
43. Across task families?
44. Is monitoring separated from response selection/inhibition demands?
45. What rival mechanism remains?
46. What second measure/manipulation would discriminate it?
47. What is the strongest warranted conclusion?
48. What wording would overclaim awareness, adaptation, or trait status?

## 44. High-value failure modes

### Failure A — performance monitoring = error detection

Incorrect.

Correct:

Monitoring can track conflict, surprise, uncertainty, negative feedback, and need for adjustment in addition to errors.

### Failure B — error = conflict

Incorrect.

Correct:

Conflict can occur on correct trials; errors can involve additional mismatch/surprise processes.

### Failure C — ERN = conscious error awareness

Incorrect.

Correct:

ERN and awareness can dissociate.

### Failure D — Pe = awareness meter

Incorrect.

Correct:

Pe is awareness-related but can reflect broader post-response evidence/salience processes.

### Failure E — large ERN = better self-control

Incorrect.

Correct:

ERN is an error-related neural signal whose functional/clinical meaning depends on task, scoring, context, and theory.

### Failure F — ERP internal consistency = stable trait validity

Incorrect.

Correct:

Internal consistency, temporal stability, construct validity, and clinical utility are separate properties.

### Failure G — PES = adaptive control

Incorrect.

Correct:

PES can reflect adaptive caution/preparation or nonadaptive orienting/interruption.

### Failure H — slower after error = better monitoring

Incorrect.

Correct:

Slowing must be linked to an explicit performance benefit or process model.

### Failure I — no PES = no error monitoring

Incorrect.

Correct:

Monitoring can occur without immediate slowing or may produce another adjustment.

### Failure J — CSE = pure conflict adaptation

Incorrect.

Correct:

Feature binding, contingency learning, congruency-triggered policies, and top-down control can all contribute.

### Failure K — sequence effect = mechanism

Incorrect.

Correct:

The sequential behavioral pattern must be separated from its causal explanation.

### Failure L — monitoring signal = control adjustment

Incorrect.

Correct:

Detection and adjustment are distinct stages.

### Failure M — more adjustment = better control

Incorrect.

Correct:

Optimal adjustment depends on task/environment; overcorrection can be costly.

### Failure N — error awareness = metacognition as a whole

Incorrect.

Correct:

Error awareness is one specific metacognitive/performance-monitoring judgment.

### Failure O — one ERP/PES/CSE score = stable monitoring trait

Incorrect.

Correct:

Trait inference requires reliability, adequate event counts, repeated occasions, and cross-task convergence.

## Canonical working rule

**Identify what event was monitored, separate error/conflict/surprise from conscious awareness, treat ERN/Pe/PES/CSE as indicators rather than mechanisms, test whether any observed adjustment improves the relevant goal, and infer a stable monitoring tendency only from reliable repeated converging evidence.**

Never:

**error-related signal -> awareness -> adaptive control -> stable self-monitoring trait.**

## Current-standard note

As of 2026-11-19:

- NIMH RDoC continues to define Performance Monitoring as a Cognitive Control subconstruct and links it behaviorally to post-error/post-conflict adjustment and physiologically to ERN/N2/N450;
- current evidence supports separating error detection, awareness, and behavioral adjustment rather than treating them as one process;
- ERN/Pe remain useful error-related measures, but 2025–2026 work shows task/scoring-dependent psychometrics and very high preprocessing/analysis heterogeneity;
- post-error slowing is not inherently adaptive: recent work shows both task/context dependence and conditions in which preparation slowing is associated with improved performance;
- the 2025 CSE meta-analysis supports both bottom-up and top-down contributions, with substantial heterogeneity and stronger within-task than across-task adaptation;
- 2026 computational/behavioral evidence further cautions that objective congruency can trigger sequential adaptation independently of conflict magnitude under some conditions.
