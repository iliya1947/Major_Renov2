# NEU-09 — Motor control: feedforward/feedback/synergies/variability

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Motor control is task-directed regulation of movement, force and posture through interacting:

- prospective/feedforward processes;
- sensory feedback;
- state estimation/prediction;
- task-specific coordination;
- neuromechanical impedance;
- body/environment dynamics.

Canonical model:

`task goal + current state + prior experience/prediction`
→
`prospective control + coordination/impedance`
↔
`sensory feedback + state updating`
→
`movement / force / posture`
→
`task outcome + new sensory information`.

Project rule:

**motor control is closed-loop and task dependent; feedforward prediction and feedback correction are complementary rather than competing systems.**

## 1. Feedforward control

Feedforward control is prospective control generated before the relevant current sensory error can be used for correction.

It can depend on:

- prior learning;
- expected task dynamics;
- current state estimate;
- contextual cues;
- expected perturbation.

Project rule:

**feedforward ≠ fixed motor program ≠ absence of sensory information.**

## 2. Feedback control

Feedback control uses sensory consequences to modify ongoing or future output.

Relevant channels include:

- proprioceptive;
- cutaneous;
- visual;
- vestibular;
- load/force-related input.

Project rule:

**feedback can operate rapidly and automatically at multiple latencies; it is not only slow conscious correction.**

## 3. Internal models

Internal-model language is retained as a useful computational framework for:

- prediction;
- state estimation;
- sensory-consequence prediction;
- adaptation to changed dynamics.

However exact neural implementation remains open.

Project rule:

**behavior compatible with internal-model computation does not prove one literal discrete neural representation.**

## 4. Degrees of freedom / motor abundance

Human movement has redundant joint, muscle and timing solutions.

Project rule:

**redundancy can provide motor abundance: multiple solutions can preserve the same task-relevant outcome.**

The CNS does not need to eliminate all degrees of freedom for successful control.

## 5. Coordination

Coordination is:

> task-relevant organization of multiple elemental variables so that important performance variables remain acceptably controlled.

Relevant elements can include:

- joints;
- segments;
- muscles;
- force;
- timing;
- posture.

Project rule:

**coordination quality is judged against the task goal, not one fixed visual template.**

## 6. Movement synergies

Low-dimensional muscle/synergy patterns can summarize structured coordination.

But:

`EMG-derived synergy factor ≠ proven hard-wired CNS module`.

Project rule:

**synergy extraction is a descriptive/modeling tool; neural origin and exact implementation require independent evidence.**

## 7. Stability

Stability must define:

- what variable is stabilized;
- against what disturbance;
- over what time scale;
- by what return/performance criterion.

Project rule:

**low variability ≠ automatically high stability.**

Repeatability, perturbation resistance and return behavior are different constructs.

## 8. Movement variability

Movement variability is intrinsic and can arise from:

- noise;
- exploration;
- redundant solutions;
- adaptation;
- fatigue;
- changing task constraints.

Project rule:

**variability is not automatically error and is not automatically beneficial.**

## 9. Functional variability vs noise

Potentially functional variability:

- preserves the salient task outcome;
- occurs mainly in redundant dimensions;
- can support exploration/adaptation;
- can permit compensation across joints/muscles.

Potentially nonfunctional variability:

- directly destabilizes the task goal;
- increases relevant outcome error;
- reflects loss of control in the variable that matters.

Project rule:

**magnitude alone cannot classify variability; task relevance and spatial/temporal structure are required.**

## 10. Trajectory control

The nervous system need not reproduce one exact path unless the path itself is task constrained.

Project rule:

**trajectory is controlled to the degree that trajectory matters to the task.**

Different joint-level paths can preserve the same successful task outcome.

## 11. Force control

Force control includes:

- steadiness;
- tracking;
- force-matching precision;
- controlled force adjustment.

Project rule:

**maximal force capacity and force-control precision are related but distinct outcomes.**

## 12. Postural control

Postural control regulates body/segment state relative to:

- gravity;
- support;
- intended movement;
- perturbation.

It uses:

- anticipatory preparation;
- sensory feedback;
- neuromechanical regulation.

Project boundary:

**NEU-09 owns general postural-control mechanisms; NEU-10 owns balance/neuromotor-fitness evidence and transfer.**

## 13. Joint stabilization

Joint/limb stabilization can involve:

- passive tissue mechanics;
- muscle activation;
- mechanical impedance;
- co-contraction;
- feedforward preparation;
- feedback/reflex correction.

Project rule:

**joint stabilization is an adaptive neuromechanical function, not the job of one fixed set of “stabilizer muscles”.**

## 14. Co-contraction

Agonist-antagonist co-contraction can:

- increase impedance/stiffness;
- improve rapid corrective responses in some perturbation tasks;
- help under uncertainty.

It can also impose costs:

- extra activation/metabolic demand;
- reduced movement freedom;
- slower voluntary response in some contexts.

Different co-contraction indices measure different signal properties.

Project rule:

**co-contraction is one adjustable strategy; higher or lower is not universally better.**

## 15. Anticipatory postural adjustments

APAs are preparatory changes before expected movement-related or external disturbances.

Project rule:

**APA is context-dependent prospective preparation, not one invariant pre-programmed pattern.**

Its existence supports predictive control but does not uniquely prove one internal-model neural implementation.

## 16. Coordination under fatigue

Fatigue can alter:

- activation;
- timing;
- coherence;
- joint strategy;
- force steadiness;
- variability.

Project rule:

**there is no universal fatigue-related coordination signature.**

A changed strategy can be compensatory, neutral or performance limiting.

## 17. Coordination under novel/heavier load

Novel or heavier load can change:

- trajectory;
- muscle weighting/timing;
- impedance/co-contraction;
- variability;
- feedback demand;
- predictive compensation.

Direct squat evidence supports load-/training-/individual-specific reorganization while broad coordination structure can remain relatively robust.

Project rule:

**a changed motor solution under a new load is not automatically technical failure.**

## 18. Direct resistance-training interpretation

Current squat evidence supports:

1. broad common coordination structure can coexist with individual-specific patterns;
2. short-term training can increase strength while broad synergy structure remains relatively stable;
3. experienced lifters can show altered synergy timing/weighting;
4. load changes movement-variability metrics;
5. different variability metrics/devices can behave differently.

Therefore:

**resistance-exercise motor control should not be reduced to one universal “expert pattern”.**

## 19. Measurement boundaries

### EMG amplitude
Does not directly equal force, neural drive or coordination quality.

### Muscle-synergy factorization
Does not prove hard-wired neural primitives or optimality.

### UCM
Describes task-related covariance structure but does not identify the generating neural/temporal process.

### SD / CV
Describe variability magnitude, not temporal structure.

### Entropy / DFA / nonlinear measures
Capture different temporal/complexity properties and are method dependent.

### Stability metrics
Can represent distinct constructs and are not interchangeable.

### Co-contraction indices
Can emphasize amplitude, waveform similarity or temporal overlap.

Project rule:

**name the measured construct before interpreting any motor-control metric.**

## 20. Canonical project rules

1. Feedforward and feedback are coupled complementary processes.
2. Fast movement is not necessarily feedback-free.
3. Internal models are computational frameworks, not settled neural ontology.
4. Redundancy permits multiple valid motor solutions.
5. Coordination is task specific.
6. EMG-derived synergies do not prove fixed neural modules.
7. Stability is not equivalent to minimal variability.
8. Variability is not automatically error.
9. More variability is not automatically better.
10. Functional variability must be defined relative to the task goal.
11. Exact trajectory reproduction is only required when trajectory itself is constrained.
12. Force control is distinct from maximal force.
13. Postural control combines anticipatory and reactive processes.
14. Joint stabilization is neuromechanical.
15. Co-contraction is an adjustable trade-off strategy.
16. APAs are adaptable prospective responses.
17. Fatigue changes coordination without one universal direction.
18. Novel/heavier load can reorganize control without automatic technical failure.
19. Motor-control measures are construct specific and non-interchangeable.

## 21. Training-relevant implications

1. **Do not demand one visually identical repetition when multiple solutions preserve the exercise goal.**
2. **Do not interpret all movement variability as technique error.**
3. **Do not prescribe “more variability” as universally beneficial.**
4. **Define the relevant task variable before judging stability or coordination.**
5. **Do not infer neural modules from EMG factorization alone.**
6. **Do not use co-contraction as a universal good/bad marker.**
7. **Allow legitimate motor reorganization when load changes.**
8. **Distinguish compensatory fatigue-related changes from actual loss of acceptable control.**
9. **Separate maximal strength from force-control precision.**
10. **Use direct resistance-exercise evidence where available and label transfer from laboratory adaptation paradigms.**

## 23. Confidence

### HIGH
- feedforward/feedback coupling;
- task-specific coordination;
- motor abundance/redundancy;
- variability ≠ error;
- stability ≠ low variability;
- force control ≠ maximal force;
- postural control includes anticipatory/reactive components;
- joint stabilization is neuromechanical;
- APA context dependency;
- fatigue/novel-load reorganization.

### MODERATE-HIGH
- broad squat coordination structure can remain robust while timing/weighting adapts;
- direct load-dependent change in squat variability metrics;
- co-contraction can improve perturbation correction in some contexts.

### MODERATE / FRAMEWORK-DEPENDENT
- exact neural implementation of internal models;
- neural-module interpretation of extracted muscle synergies;
- exact functional-vs-noise boundary in complex free-weight lifts;
- optimal stiffness/co-contraction for a specific exercise;
- transfer from force-field paradigms to multijoint barbell tasks.

### NOT ESTABLISHED AS UNIVERSAL
- one ideal movement trajectory;
- one expert synergy pattern;
- one ideal variability magnitude;
- one stability metric;
- one fatigue coordination signature;
- one co-contraction target;
- one motor solution for all loads/people.
