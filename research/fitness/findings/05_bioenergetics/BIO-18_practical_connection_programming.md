# BIO-18 — Practical connection to programming

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-20**  
Область: 05 — Bioenergetics / Exercise Metabolism

## 0. Core decision

Bioenergetics constrains programming decisions by explaining how load, duration, recovery, density, mode and tempo change the internal energetic task.

Project rule:

**BIO explains physiological consequences; PRO selects the prescription.**

Acute metabolic difficulty is not a chronic programming score.

---

## 1. Rest and set type

Short heavy sets often emphasize:

- high force;
- high ATP-turnover rate;
- substantial phosphagen contribution;
- brief set duration.

High-repetition sets often emphasize:

- longer continuous work;
- greater cumulative metabolic disturbance;
- larger glycolytic/oxidative involvement.

But neither rep range determines a fixed rest interval.

Project rule:

**rest follows the target output/adaptation, not a rep-range energy-system label.**

High-repetition work may also need substantial rest when preserving repetitions/volume is required.

---

## 2. Rest changes the next set

Rest affects:

- PCr restoration;
- residual metabolic/ionic state;
- oxygen uptake;
- mechanical/neural recovery;
- perceived effort.

Project rule:

**same external load/reps after different recovery ≠ same internal physiological task.**

Rest is an active phase of intermittent training, not dead time.

---

## 3. Total rest vs rest placement

Equal total rest can be distributed differently.

Current evidence shows cluster/rest-redistribution structures can preserve velocity/power better than traditional set structures in selected contexts.

Project rule:

**total rest duration ≠ rest distribution.**

Acute preservation of velocity/power does not prove universal chronic superiority.

---

## 4. Repeated-set energetic shift

The source-map phrase “progressively more glycolytic/oxidative” must not be read literally.

Repeated sets change the energetic mix because:

- PCr recovery may be incomplete;
- oxidative metabolism supports repeated work and recovery;
- residual fatigue changes output;
- actual glycolytic turnover depends on work completed.

Project rules:

- **repeated sets ≠ monotonic glycolytic increase**;
- **oxidative recovery importance ≠ oxidative dominance inside every set**.

---

## 5. Pathway measurement boundary

Exact pathway contribution cannot be read directly from:

- HR;
- VO2;
- blood lactate;
- RPE;
- velocity loss.

Project rules:

- **blood lactate ≠ glycolytic ATP flux**;
- **VO2 ≠ total ATP turnover**;
- **velocity loss ≠ metabolite assay**.

Resistance exercise energy expenditure/pathway estimates remain method conditioned.

---

## 6. Circuits and density

Dense circuits can increase:

- HR;
- VO2;
- lactate;
- RPE;
- systemic cardiorespiratory strain.

They can become partly cardiorespiratory-limited.

But performance can also be limited by:

- local muscular endurance;
- grip;
- strength;
- technique;
- pacing.

Project rule:

**circuit limitation is mixed/task specific unless directly demonstrated otherwise.**

Circuit ≠ cardio-only.

---

## 7. Rep count and tempo

Rep count does not specify:

- set duration;
- TUT;
- concentric/eccentric duration;
- pauses;
- work rate;
- load.

Project rule:

**same reps ≠ same metabolic cost.**

Tempo must be interpreted together with what is matched.

---

## 8. Tempo matching constraints

Current evidence shows different outcomes when studies match:

- TUT;
- failure/effort;
- velocity loss;
- load/volume.

Different tempo conditions can produce different directions across:

- lactate;
- HR;
- TUT;
- deoxygenation;
- nVCO2;
- volume load.

Project rule:

**tempo has no context-free metabolic effect.**

Slow tempo is not universally more metabolically stressful.

Fast tempo is not universally more metabolically stressful.

---

## 9. Acute tempo ≠ chronic superiority

Current meta-analysis and ACSM 2026 synthesis show little consistent evidence that faster vs slower repetition tempo creates large chronic hypertrophy differences across typical training conditions.

Project rule:

**acute tempo physiology ≠ chronic hypertrophy/strength superiority.**

Exact tempo prescription remains PRO.

---

## 10. Energy-system training

“Train an energy system” means biasing an integrated demand profile.

Relevant variables include:

- intensity;
- work duration;
- recovery duration;
- recovery placement;
- mode;
- total bouts/work;
- frequency/total exposure;
- current state.

Project rule:

**energy-system focus ≠ pathway isolation.**

---

## 11. Work:rest ratio boundary

A ratio such as 1:4 is incomplete without absolute durations.

5:20, 10:40 and 30:120 are all 1:4 but represent different energetic tasks.

Project rule:

**same work:rest ratio ≠ same physiology.**

---

## 12. Acute strain vs chronic adaptation

Higher:

- lactate;
- VO2;
- HR;
- EPOC;
- RPE

does not automatically mean greater:

- hypertrophy;
- strength;
- power;
- VO2max;
- sport performance.

Project rule:

**acute internal load describes the session; it does not rank chronic programming value by itself.**

---

## 13. Current ACSM boundary

ACSM 2026 synthesized 137 systematic reviews and found that relatively few RT prescription variables consistently changed primary chronic outcomes.

Set structure and time under tension did not consistently alter outcomes across the evidence base.

Project rule:

**mechanistic plausibility must be checked against chronic target-outcome evidence.**

---

## 14. Mechanism→programming translation

Use this practical heuristic:

1. define target output/quality;
2. identify acute mechanical/metabolic consequence;
3. identify next-set/bout state;
4. check chronic evidence for the target outcome;
5. apply individual constraints;
6. hand exact prescription to PRO/IND.

This is a practical heuristic, not a biological law.

---

---

## 16. Trainer-level implications

1. Choose rest by the target output, not rep-zone mythology.
2. Expect later sets to begin from a changed physiological state.
3. Use rest redistribution when preserving mechanical quality is useful, without assuming universal superiority.
4. Do not assume later sets become progressively more glycolytic.
5. Treat dense circuits as mixed muscular + cardiorespiratory tasks.
6. Interpret tempo only after specifying what was matched.
7. Do not chase lactate, HR, RPE or EPOC as adaptation targets.
8. Manipulate intensity, duration, recovery, mode and total exposure together when biasing energy-system demand.
9. Exact rest/density/tempo/conditioning prescription remains PRO.

---

## 17. Confidence

### HIGH
- rest changes next-set state;
- rep range alone does not determine rest;
- same external set can create different internal demand after different recovery;
- rest placement can alter acute output;
- repeated-set energetic mix is not monotonic;
- dense circuits can impose substantial cardiorespiratory strain;
- tempo effects depend on matching constraints;
- acute metabolic response is not chronic programming superiority;
- energy-system training requires integrated variables.

### MODERATE-HIGH
- rest redistribution preserves velocity/power in selected protocols;
- RFT can create greater cardiorespiratory/metabolic strain than volume-matched EMOM;
- tempo can alter lactate/oxygenation under matched velocity-loss endpoints.

### MODERATE / CONTEXT DEPENDENT
- exact rest for a given set;
- exact pathway shift across sets;
- exact circuit limiter;
- exact tempo metabolic cost;
- exact chronic benefit of an acute metabolic manipulation.
