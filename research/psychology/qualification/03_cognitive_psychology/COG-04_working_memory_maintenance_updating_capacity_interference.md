# COG-04 — Working memory: maintenance, updating, capacity, interference, and attention/LTM interfaces

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current working model of working memory (WM) that is useful for psychological inference without prematurely selecting one theoretical architecture as final.

The block separates:

- working memory from short-term memory;
- maintenance from updating;
- item memory from binding;
- storage/representation from attention and cognitive control;
- capacity from task performance;
- interference from simple time-based decay;
- working memory from long-term memory while preserving their interaction;
- working-memory task families from one another;
- training gains from broad cognitive transfer.

## Core rule

**Working memory is a limited, interference-sensitive system for maintaining and flexibly updating information that is currently relevant to cognition and action. Its limits are not captured by one universal item count, one task, or one mechanism.**

A generic functional architecture is:

`input / retrieved information`
-> `encoding / admission`
-> `temporary maintenance + binding`
↔ `attentional prioritization`
↔ `updating / removal / replacement`
-> `readout / decision / action`

with continuous interaction with:

- long-term memory;
- cognitive control;
- attention;
- language;
- perception;
- learned structure and chunking.

## 1. Current operational definition

NIMH RDoC currently defines working memory as the active maintenance and flexible updating of goal/task-relevant information in a limited-capacity form that resists interference.

Its current subconstructs are:

1. active maintenance;
2. flexible updating;
3. limited capacity;
4. interference control.

NIMH also notes that WM representations may involve flexible binding and may be temporary partly because of ongoing interference.

This is a useful functional definition.

It is not treated as a commitment to one storage architecture.

## 2. Working memory is not identical to short-term memory

"Short-term memory" is often used for temporary retention over a short interval.

"Working memory" usually emphasizes temporary information that is actively available for ongoing cognition, including:

- maintenance;
- selection;
- updating;
- manipulation;
- binding;
- goal-directed use.

The terms overlap historically and empirically, and different theories draw the boundary differently.

Canonical rule:

**short retention interval != proof that the task measures working memory as a full construct.**

## 3. Major live model families

No single architecture currently settles all WM phenomena.

### 3.1 Multicomponent framework

The Baddeley/Hitch tradition distinguishes components such as:

- phonological loop;
- visuospatial sketchpad;
- central executive;
- episodic buffer.

Its enduring contribution is the idea that temporary memory is not one homogeneous store and that domain-specific and executive processes can interact.

Do not treat the exact historical component list as a universally established neural architecture.

### 3.2 Embedded-processes / activated-long-term-memory approaches

Cowan-type approaches treat working memory partly as temporarily activated long-term representations, with a narrower focus of attention and broader activated information.

This emphasizes continuity between working memory and long-term memory.

### 3.3 State-based / direct-access / focus-of-attention approaches

Oberauer and related frameworks distinguish states of accessibility and priority within memory, often including:

- a broad activated region;
- a direct-access region;
- a narrower focus of attention.

The exact architecture varies across models.

### 3.4 Resource / precision approaches

Especially in visual working memory, resource accounts explain capacity limits as changes in representational precision/variability as load increases rather than only as all-or-none loss of discrete slots.

Recent 2024–2026 computational work supports variable-precision/resource-like explanations for many visual-WM phenomena, while debate about implementation remains active.

### 3.5 Interference-based approaches

Interference models explain forgetting and capacity limits through competition among representations and bindings rather than assuming simple passive decay.

A 2024 formal interference model accounted for benchmark effects across both visual and verbal WM paradigms.

### Practical conclusion

These model families are best treated as competing/complementary explanatory frameworks.

Do not infer one architecture simply because one task is conventionally associated with it.

## 4. Active maintenance

Maintenance means keeping task-relevant information sufficiently available for later use despite absence or reduction of external support.

Possible maintenance operations can include:

- attentional refreshing;
- rehearsal;
- persistent activation;
- recoding/chunking;
- reinstatement from long-term memory.

The relative contribution depends on:

- material;
- task;
- delay;
- concurrent processing;
- strategy;
- interference.

Canonical rule:

**successful retention does not uniquely identify the maintenance mechanism.**

## 5. Maintenance is not necessarily continuous active firing

Neuroscience has motivated "activity-silent" and latent-state accounts in which some retained information may be temporarily recoverable without continuously elevated neural firing.

This remains an implementation-level question.

For cognitive inference, the safe statement is:

**behaviorally available information need not imply one specific neural maintenance signature.**

Detailed neural implementation is deferred to NEU.

## 6. Updating

Updating concerns changing WM contents when the current task requires:

- adding new information;
- replacing obsolete information;
- removing no-longer-relevant information;
- revising item-context relations;
- changing task-relevant bindings.

Updating is not one operation.

Recent 2025 work using reference-back paradigms suggests that:

- simple item updating can sometimes occur rapidly and relatively automatically;
- updating item-to-context bindings can require slower, effortful gating.

Therefore:

`updating = always deliberate executive replacement`

is too strong.

## 7. Gating

Gating models propose that WM needs mechanisms controlling when external/internal information is admitted or protected.

A useful generic distinction is:

- **open gate** — allow relevant updating;
- **closed gate** — protect maintained contents from unnecessary replacement/interference.

But "gate" is a computational metaphor/model component, not direct evidence of one anatomical gate.

Gating costs can depend on:

- task structure;
- current contents;
- item versus binding update;
- response-selection demands.

## 8. Removal is not simply forgetting

A no-longer-relevant representation can become less accessible through:

- intentional removal;
- attentional deprioritization;
- interference;
- replacement;
- passive loss;
- context change.

Behavioral disappearance of an item does not establish which mechanism occurred.

## 9. Binding

Working memory often requires temporary bindings between:

- item and location;
- item and temporal order;
- object and feature;
- stimulus and response;
- content and context.

Binding matters because correct elements can be present while their relations are wrong.

Examples:

- remembering two colors but swapping which object had which color;
- remembering items but confusing order;
- remembering facts but assigning them to the wrong context.

Canonical rule:

**item memory != relational/binding memory.**

## 10. Capacity is not one universal number

WM has limited capacity, but "capacity" can refer to different limits:

- number of units/items;
- representational precision;
- total information;
- attentional selection;
- binding capacity;
- interference resistance;
- control of access;
- processing-storage tradeoff.

Therefore avoid:

`working-memory capacity = exactly N items for everyone`.

Historical estimates such as a few chunks can be useful descriptive approximations in specific paradigms.

They are not universal constants.

## 11. Chunking changes effective capacity

Grouping familiar elements into higher-level units can increase effective performance.

Chunking depends on:

- prior knowledge;
- structure;
- language;
- expertise;
- learned regularities.

Recent work shows that encoding granularity can alter apparent WM capacity.

Therefore:

`more recalled elements -> larger basic storage capacity`

can be false when chunking differs.

## 12. Long-term memory can support working memory

Current research supports multiple ways LTM may aid WM:

- **boosting** — strengthening WM representations;
- **chunking** — representing several elements through a learned higher-level unit;
- **offloading/substitution** — relying more on LTM retrieval instead of continuous active maintenance;
- **semantic scaffolding** — using structured prior knowledge.

A 2026 study explicitly tests these alternatives and confirms that LTM contributions to WM performance cannot be reduced to one mechanism.

Canonical rule:

**working-memory performance is partly knowledge-dependent.**

## 13. Working memory is not a mandatory gateway to long-term memory

One traditional intuition is:

`information must fit in WM before it can enter LTM`.

Current evidence is mixed.

Recent experimental work directly testing the "gateway" hypothesis finds that WM load/capacity does not impose a simple universal bottleneck on later LTM formation.

Attention to an item in WM can sometimes improve later LTM, but a 2026 review finds the average benefit modest and inconsistent across studies.

Therefore:

**WM and LTM interact strongly, but WM is not established as a simple mandatory conveyor belt into LTM.**

## 14. Long-term memory is not merely downstream

LTM affects ongoing WM through:

- familiarity;
- semantic structure;
- chunking;
- expectations;
- retrieval;
- expertise.

This makes WM–LTM interaction bidirectional.

The information-exchange literature increasingly treats them as interacting systems rather than fully isolated stores.

## 15. Attention and working memory are deeply linked but not identical

Oberauer's conceptual analysis separates several meanings of "attention."

Useful distinctions include:

- attention as a limited resource;
- attention as selection;
- internal selection among WM representations;
- external perceptual attention guided by WM templates.

Evidence supports strong links, but not the claim:

`WM capacity = amount of attention`

as a universal equivalence.

## 16. Focus of attention inside working memory

Some WM contents receive higher priority than others.

Retro-cue and prioritization paradigms show that selectively attending to one maintained representation can improve access/performance for that representation.

This supports differentiated internal states of priority.

It does not prove one universal single-item focus architecture under all conditions.

## 17. Working memory can guide external attention

Maintained goals/templates can bias what is selected in perception.

Example:

A currently maintained target feature can increase selection of matching external stimuli.

Thus WM participates in cognitive control by holding goal/task representations.

But this role does not make WM synonymous with cognitive control.

## 18. Working memory and cognitive control overlap

NIMH defines cognitive control separately from WM.

Control includes:

- goal selection/maintenance;
- response selection and inhibition;
- performance monitoring.

WM contributes by keeping task-relevant information available.

A poor updating or complex-span score can therefore reflect control demands in addition to storage/maintenance.

## 19. Interference is central

WM performance can degrade because representations compete.

Interference can arise from:

- similarity;
- temporal proximity;
- spatial proximity;
- overlapping features;
- competing responses;
- distractors;
- context confusion;
- obsolete contents.

Interference is not one phenomenon and can act at multiple representational levels.

## 20. Decay versus interference

Some theories emphasize time-based decay; others emphasize interference and attentional refreshing.

The field does not justify treating "memory faded with time" as the default explanation.

A longer delay often also changes:

- number of interfering events;
- attentional opportunity;
- rehearsal opportunity;
- contextual drift.

Canonical rule:

**time effect != pure decay evidence.**

## 21. Visual working-memory representations are noisy and structured

Recent computational reviews emphasize that visual WM representations:

- vary in precision;
- retain uncertainty information;
- exploit environmental regularities;
- can fail through feature error, swaps, binding errors, or structured biases.

This challenges a simplistic:

`remembered vs forgotten slot`

interpretation.

## 22. Capacity and precision tradeoffs

Increasing load can reduce:

- probability of accurate access;
- representational precision;
- binding accuracy;
- response speed.

Which component changes depends on:

- task;
- model;
- stimulus set;
- strategy.

Do not infer a discrete-slot mechanism solely from a plateau in accuracy.

Do not infer a continuous-resource mechanism solely from gradual precision loss.

Model comparison must consider the full response distribution and task assumptions.

## 23. Working-memory capacity as an individual-differences construct

Working-memory-capacity (WMC) measures correlate with broad cognitive performance.

But the source of these correlations is debated.

Current 2026 review work argues that substantial predictive variance may reflect:

- attention control;
- goal maintenance;
- interference management;
- inhibition/control demands;

rather than storage capacity alone.

Therefore:

`high WMC score -> large storage system`

is too strong.

## 24. Simple span

Simple-span tasks require retaining a sequence/set with relatively little concurrent processing.

Examples:

- digit span;
- word span;
- spatial span.

Performance can depend on:

- rehearsal;
- chunking;
- language/phonology;
- serial-order memory;
- attention;
- long-term knowledge.

Simple span is not a pure count of "WM slots."

## 25. Complex span

Complex-span tasks alternate storage with processing.

Examples:

- operation span;
- reading span;
- symmetry span.

They recruit:

- temporary retention;
- processing;
- interference control;
- task switching/scheduling;
- attention control.

Their predictive power for broad cognition may therefore arise partly from control demands.

## 26. N-back

N-back requires deciding whether the current stimulus matches one presented N positions earlier.

It can recruit:

- maintenance;
- updating;
- temporal/order tracking;
- comparison;
- attention control;
- response selection;
- interference management.

A 2025 review emphasizes substantial task heterogeneity and multi-process involvement.

Canonical rule:

**n-back performance != direct measure of one generic WM capacity parameter.**

## 27. Complex span and n-back are not interchangeable

A 2025 Psychonomic Bulletin & Review analysis explicitly asks "Which working memory are we talking about?" when comparing complex span with n-back.

These paradigms differ in:

- updating demands;
- storage-processing structure;
- interference;
- response format;
- control demands.

Therefore different correlations/clinical effects across the two task families are not necessarily contradictory.

## 28. Change detection and continuous report

Visual-WM paradigms often use:

- change detection;
- delayed estimation/continuous report;
- recognition;
- recall.

These support different models of:

- precision;
- guessing;
- swaps;
- decision criteria;
- uncertainty.

Task/model choice can change the apparent capacity estimate.

## 29. Reference-back and updating tasks

Reference-back paradigms are especially useful for separating:

- updating;
- gate opening/closing;
- comparison;
- response selection.

They do not measure "working memory" in its entirety.

They target particular control/update operations.

## 30. Task impurity

All major WM tasks also require non-WM processes.

Common contributors:

- perception;
- language;
- motor response;
- attention;
- strategy;
- cognitive control;
- long-term knowledge;
- motivation;
- processing speed.

Therefore:

**one low WM task score cannot localize one WM mechanism.**

## 31. State factors

Working-memory performance can vary with:

- sleep;
- fatigue;
- stress;
- arousal;
- motivation;
- practice;
- strategy;
- pharmacological state.

Trait-level WMC inference requires repeated and validated measurement.

## 32. Training gains are not broad capacity proof

Improvement on a trained WM task can reflect:

- strategy;
- task-specific learning;
- faster responses;
- familiarity;
- learned chunking;
- improved task control.

A preregistered 2025 double-blind RCT found clear n-back training gains without reliable near/far transfer to untrained tasks.

A 2026 meta-analysis found asymmetric transfer between updating and span paradigms, with a small transfer from updating training to span and no reliable reverse transfer.

Thus the current evidence does not justify:

`trained task improved -> general WM capacity increased`.

## 33. Ecological use and cognitive offloading

In everyday cognition, people can often:

- look again;
- write information down;
- use reminders;
- manipulate external objects;
- resample the environment.

Recent ethological approaches argue that WM should be studied partly as a tradeoff between internal maintenance and external resampling/offloading.

Therefore laboratory "unaided memory capacity" is not identical to real-world cognitive effectiveness.

## 34. Working Memory Inference Gate

Before interpreting a WM result, ask:

### A. Claim

1. Is the claim about maintenance, updating, binding, interference control, capacity, or control?
2. Is the claim about a state, task performance, or stable ability?

### B. Task family

3. Is the task simple span, complex span, n-back, reference-back, change detection, continuous report, or another paradigm?
4. Which operations does that paradigm require?
5. Is the task being treated as interchangeable with another WM paradigm without evidence?

### C. Representation

6. What is maintained: verbal, visuospatial, object, feature, relation, rule, or goal information?
7. Is the task testing items or bindings?
8. Could chunking/semantic knowledge change the effective unit?

### D. Maintenance/updating

9. Is active maintenance actually required?
10. Is updating required?
11. Is removal/replacement required?
12. Could the observed cost be response selection rather than updating?

### E. Attention/control

13. What attentional selection is required?
14. Is goal maintenance important?
15. Could cognitive-control differences explain performance?
16. Is WM being equated with attention control?

### F. Capacity

17. What definition of capacity is being used?
18. Is capacity expressed as item count, information, precision, or latent ability?
19. Does the model assume slots, resources, interference, or another architecture?
20. Would a different model change the inferred capacity?

### G. Interference/time

21. What competing representations exist?
22. Could similarity/context confusion explain errors?
23. Is a delay effect being misread as pure decay?
24. Are interference and rehearsal opportunities controlled?

### H. Long-term memory

25. Could prior knowledge/chunking support performance?
26. Could LTM retrieval substitute for active maintenance?
27. Is WM being incorrectly treated as an isolated store?

### I. Measurement

28. What reliability/validity evidence exists for the task?
29. Are accuracy, RT, precision, swaps, and criterion separated where relevant?
30. Is one task score being used as a pure mechanism measure?

### J. State/trait

31. Was performance repeated?
32. Could sleep/fatigue/stress/motivation/practice explain the result?
33. Does the inference generalize across WM task families?

### K. Training

34. Is improvement task-specific or transferred to independent measures?
35. Was transfer tested with active controls and untrained tasks?
36. Is "capacity increase" being inferred from trained-task improvement alone?

### L. Conclusion

37. What exact WM component is supported?
38. Which alternative explanation remains viable?
39. What additional task/manipulation would discriminate the competing interpretations?

## 35. High-value failure modes

### Failure A — working memory = short-term memory

Incorrect.

Correct:

WM emphasizes active availability/use, updating, interference control, and often binding/control demands; terminology overlaps but is not identical.

### Failure B — working memory = one store

Incorrect.

Correct:

Current theories differ substantially and WM behavior is supported by multiple representational/control processes.

### Failure C — capacity = fixed number of items

Incorrect.

Correct:

Capacity estimates depend on representation, precision, chunking, binding, interference, and task/model assumptions.

### Failure D — more recalled elements = more basic capacity

Incorrect.

Correct:

Chunking and long-term knowledge can increase effective performance.

### Failure E — time delay = decay

Incorrect.

Correct:

Delay also changes interference, rehearsal, and contextual factors.

### Failure F — updating = always effortful executive gating

Incorrect.

Correct:

Recent work suggests simple item updating can sometimes be rapid/automatic, whereas relational updating may require gating.

### Failure G — item memory = binding memory

Incorrect.

Correct:

Correct contents can coexist with incorrect item-context relations.

### Failure H — WM = attention

Incorrect.

Correct:

Attention selects/prioritizes information and interacts deeply with WM, but the constructs are not equivalent.

### Failure I — WM = cognitive control

Incorrect.

Correct:

WM supports goal maintenance/control but cognitive control also includes response selection, inhibition, and monitoring.

### Failure J — n-back score = WM capacity

Incorrect.

Correct:

N-back is a multi-process updating/comparison/control paradigm.

### Failure K — complex span and n-back are interchangeable

Incorrect.

Correct:

They impose materially different task structures and can index different mixtures of processes.

### Failure L — training gain = general capacity increase

Incorrect.

Correct:

Transfer to independent tasks must be demonstrated.

### Failure M — WM and LTM are isolated boxes

Incorrect.

Correct:

Current evidence supports bidirectional information exchange, chunking, retrieval, and semantic scaffolding.

### Failure N — laboratory memory limit = real-world cognitive effectiveness

Incorrect.

Correct:

People use external resampling and cognitive offloading when available.

## Canonical working rule

**Identify the representation and task, separate maintenance/updating/binding, specify the capacity model, test interference and LTM support, separate attention/control demands, then infer only the WM component that survives those alternatives.**

Never:

**one memory-task score -> one working-memory capacity -> broad cognitive mechanism.**

## Current-standard note

As of 2026-11-19:

- NIMH RDoC still operationalizes WM through active maintenance, flexible updating, limited capacity, and interference control;
- contemporary visual-WM work increasingly models memory as noisy/variable-precision and structured rather than a simple set of perfectly stored versus absent items;
- current updating evidence distinguishes relatively automatic item updating from more controlled relational/binding updating in some paradigms;
- recent research treats WM and LTM as strongly interacting systems, while evidence for a simple obligatory WM-to-LTM gateway is not established;
- complex span and n-back remain distinct task families rather than interchangeable measures of one WM parameter;
- recent training studies/meta-analysis support task learning and some limited/asymmetric transfer, but not the blanket claim that WM training produces a general capacity increase.

## Scope note

This block establishes the cognitive architecture needed for reliable WM inference.

Detailed neural implementation, developmental changes, neurodevelopmental conditions, pharmacology, working-memory training interventions, and formal mathematical model adjudication are deferred to NEU, DEV, NDEV, BHC, and targeted methods work.
