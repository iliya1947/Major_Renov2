# PHY-17 — Integrated physiology

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-18**  
Область: 03 — Physiology

## 0. Core decision

Exercise physiology is a coupled multi-system control problem.

Canonical model:

`task demand`
`→ central command + motor-unit recruitment`
`→ muscle force + ATP demand + metabolite production`
`↔ sensory/afferent feedback`
`↔ cardiovascular + respiratory regulation`
`↔ substrate/endocrine/immune regulation`
`→ performance during the bout`.

Chronic adaptation emerges from repeated task-specific perturbations plus recovery and remodeling across different biological time scales.

## 1. Cross-system coupling

Exercise simultaneously involves:

- nervous system;
- skeletal muscle;
- cardiovascular system;
- respiratory system;
- substrate metabolism;
- endocrine/immune signaling.

Project rule:

**these systems interact; they should not be interpreted as independent modules.**

## 2. One-set physiology

A resistance-training set is a non-steady-state perturbation.

It combines:

- neural recruitment;
- force/intramuscular pressure;
- ATP turnover;
- local metabolites;
- transient perfusion constraints;
- cardiovascular response;
- ventilation/breathing;
- systemic signaling.

Project rule:

**external load alone does not define internal physiological load.**

## 3. Session physiology

Later sets/intervals occur after the internal state has changed.

Relevant state variables include:

- phosphocreatine recovery;
- glycogen/substrate availability;
- metabolites;
- fatigue;
- temperature;
- fluid state;
- cardiovascular/ventilatory baseline;
- signaling context.

Project rule:

**a session is history dependent, not a simple sum of identical sets.**

## 4. Acute response vs chronic adaptation

Acute signaling occurs over seconds to hours.

Structural and functional adaptation develops over sessions, weeks and months.

Project rule:

**acute response magnitude is not a direct surrogate for chronic adaptation.**

## 5. Specificity

Resistance and endurance exercise share physiological systems but weight them differently.

Resistance emphasizes:

- force/recruitment;
- mechanical loading;
- phosphagen/glycolytic demand;
- tissue remodeling.

Endurance emphasizes:

- sustained oxidative demand;
- blood flow/oxygen delivery;
- ventilation;
- mitochondrial/capillary adaptation.

Project rule:

**specificity = different weighting of shared systems, not isolated physiologies.**

## 6. Recovery context

Training adaptation depends on:

- sleep;
- energy availability;
- carbohydrate/glycogen;
- protein/amino-acid availability;
- hydration;
- non-training stress;
- illness;
- preceding/following training.

Project rule:

**training dose and recovery context jointly determine adaptation.**

## 7. Competing signals

AMPK/PGC-1α-associated and mTORC1/protein-synthesis-associated signaling can coexist and interact.

Project rule:

**“AMPK blocks mTOR” is too crude for direct concurrent-training prescription.**

Acute signaling is not a direct chronic-outcome map.

## 8. Concurrent training

Concurrent RT + endurance training can produce:

- complementary adaptation;
- neutral coexistence;
- outcome-specific interference.

Interference depends on:

- measured outcome;
- endurance modality;
- total dose;
- sequence/separation;
- training status;
- recovery.

Project rule:

**concurrent interference is context dependent, not universal.**

## 9. Inter-organ / exerkine signaling

Exercise-responsive communication can occur among:

- muscle;
- adipose tissue;
- liver;
- heart/vasculature;
- brain;
- bone;
- immune system.

Candidate mediators include peptides, metabolites, lipids and other signals.

Project rule:

**inter-organ signaling is real, but individual exerkines require causal validation.**

## 10. Network physiology

Network physiology is useful for:

- organizing measurable interactions;
- integrating time scales;
- identifying shared and mode-specific responses;
- generating testable hypotheses.

It is not valid for:

- inventing unmeasured links;
- declaring one master regulator;
- replacing direct outcome measurement.

Project rule:

**network models organize evidence; they do not create evidence.**

## 11. Evidence-status boundary

Current human MoTrPAC multi-omic papers used in this topic are indexed as preprints.

They support emerging temporal/mode-specific architecture but are not the sole basis for practical closure.

Published integrative physiology, systematic/umbrella evidence and human trial data anchor the closure-critical conclusions.

## 12. Canonical project rules

1. Exercise physiology is multi-system and coupled.
2. One set is a non-steady-state whole-system perturbation.
3. External load ≠ complete internal load.
4. Session physiology is history dependent.
5. Acute signals ≠ chronic outcomes.
6. Specificity changes weighting of shared systems.
7. Recovery context is part of the adaptation model.
8. Binary AMPK-vs-mTOR programming logic is invalid.
9. Concurrent interference is outcome/context dependent.
10. Exerkines require evidence-specific causal validation.
11. Network models do not prove every inferred link.
12. Preprints are not treated as closure-critical sole evidence.

## 13. Training-relevant implications

1. **Do not design programs from one pathway/hormone/biomarker.**
2. **Interpret each set within session history and fatigue state.**
3. **Separate acute response from longitudinal adaptation.**
4. **Treat specificity as relative systems weighting.**
5. **Include sleep, nutrition and energy availability in adaptation logic.**
6. **Do not assume concurrent training automatically impairs hypertrophy or strength.**
7. **Do not use “AMPK blocks mTOR” as a stand-alone rule.**
8. **Treat exerkine/network claims according to evidence strength.**

## 14. What PHY-17 does not prescribe

Not owned here:

- exact RT/endurance sequence;
- exact concurrent-training frequency/volume;
- individual interference risk;
- recovery scoring;
- exact nutrition dosing;
- sleep intervention;
- limiting-system diagnosis;
- fatigue testing;
- personalized conditioning.

These remain GPP, PRO, REC, NUT, TST, NEU, BIO and IND.

## 15. Confidence

### HIGH
- coupled exercise physiology;
- history dependence across a session;
- acute→chronic distinction;
- recovery-context dependence;
- non-validity of universal binary concurrent-interference models.

### MODERATE-HIGH
- broad concurrent training can support simultaneous aerobic and strength/hypertrophy development in many healthy/recreational populations;
- inter-organ exercise signaling is biologically real;
- resistance/endurance exercise show shared plus mode-specific responses.

### MODERATE / CONTEXT-DEPENDENT
- exact interference magnitude for elite populations;
- optimal sequence/separation;
- exact causal roles of many exerkines;
- human exercise network topology;
- individual limiting system in a given task.
