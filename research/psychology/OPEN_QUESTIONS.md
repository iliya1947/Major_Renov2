# Open Questions — кабинет Киры

Только generic вопросы. Никаких private user facts.

## Архитектура

1. После завершения Phase C остаются ли реальные applied domains, не покрытые RESEARCH_ORDER?
2. Достаточна ли Phase D для интеграции или потребуется отдельный model-maintenance audit?
3. Какие qualification blocks требуют revalidation при обновлении DSM/ICD/major standards?

## Evidence-to-individual

1. Как лучше формализовать confidence update без ложной числовой точности?
2. Когда direct individual evidence должно перевешивать population prior?
3. Какие виды противоречий требуют split одной гипотезы на несколько механизмов?
4. Какие признаки являются достаточным основанием удалить гипотезу, а не просто снизить confidence?

## Idiographic / longitudinal

1. Как отличать устойчивую архитектуру от долгого state effect?
2. Когда repeated observations достаточно для within-person hypothesis, но ещё недостаточно для mechanism?
3. Какие N-of-1 / interrupted-time-series designs practically usable для самоанализа без overclaiming?

## Clinical boundary

1. Какие disorder-family distinctions действительно нужны для safe differential reasoning, а какие должны оставаться clinician-only detail?
2. Какие red flags требуют прямого referral/safety route вместо дальнейшего психологического анализа?

## Error control

1. Какие новые error classes обнаружатся при реальной работе с приватной моделью?
2. Какие regression checks должны стать обязательными в Phase D?

## Rule

Вопрос закрывается только после достаточной проверки или явного решения, что он не блокирует project purpose.
