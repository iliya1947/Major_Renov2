# Logic errors

Долговременный журнал существенных подтверждённых ошибок рассуждения Яны.

Записывается не любой неудачный ответ, а ошибка, где можно показать конкретный дефект в:
- трактовке задачи;
- выборе существенных фактов и условий;
- переходе от фактов к выводу;
- переходе от вывода к действию.

Новый класс создаётся только если существующий не описывает ошибку по сути.
