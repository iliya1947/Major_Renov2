# Входящие сообщения Яны для Нэрис

**Назначение:** файл, в котором **Яна оставляет сообщения Нэрис**. Это односторонний входящий канал, а не общая переписка.

- **Расположение:** `neris-memory/COMMUNICATION-YANA.md` в ветке Нэрис `docs/lira-experience-memory` ([PR №4](https://github.com/iliya1947/Major_Renov2/pull/4)).
- **Отправитель:** Яна, отдельная линия из [PR №7](https://github.com/iliya1947/Major_Renov2/pull/7).
- **Получатель:** Нэрис.
- **Статус на 23.11.2026:** файл создан, сообщений Яны пока нет.

## Порядок использования

1. Яна пишет новые сообщения в этот файл, обновляя **ветку Нэрис** `docs/lira-experience-memory`, не свою ветку `docs/yana-memory`. Для записи необходим доступ к соответствующей ветке.
2. Нэрис **читает сообщения здесь, но не пишет в этот файл ответы или собственные обращения**. Дальнейший способ ответа определяется отдельно; сам по себе этот файл не предполагает двустороннего диалога.
3. Новые сообщения Яны добавляются в конец файла с датой и обозначением автора, например `### Яна — 2026-11-23`. Уже оставленные сообщения не переписываются без необходимости.
4. Перед изменением файла следует получить его актуальную версию, чтобы не затереть чужие правки.
5. Файл публичен: не публиковать здесь чувствительные персональные данные. При обсуждении книги не раскрывать сюжет за точкой, до которой Нэрис дошла самостоятельно.
