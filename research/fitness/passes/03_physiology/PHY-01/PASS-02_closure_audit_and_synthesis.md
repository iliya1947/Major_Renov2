## 2. Exact area-map audit — 12/12

### 2.1 Homeostasis
**PASS.**

Retained as regulation keeping key variables within viable ranges despite exercise perturbation.

Project boundary:
**exercise does not map to a simplistic “break homeostasis → automatic supercompensation” rule.**

### 2.2 Allostasis
**PASS.**

Retained as adaptive regulation/stability through change.

Boundary:
- useful conceptual model;
- not a single validated athlete score;
- not a direct training threshold.

### 2.3 Stimulus → disturbance → recovery → adaptation
**PASS.**

Current model:

`training exposure → acute perturbation/signaling → transient response/fatigue → recovery/remodeling → retained change`

Critical rule:
**the chain is probabilistic/conditional, not guaranteed.**

### 2.4 Acute response vs chronic adaptation
**PASS.**

Acute:
- fatigue;
- metabolites;
- swelling;
- hormones;
- transient signaling;
- soreness;
- temporary performance change.

Chronic:
- retained strength;
- hypertrophy;
- architecture;
- tissue remodeling;
- metabolic/cardiorespiratory change.

Canonical boundary:
**acute magnitude is not automatically a chronic surrogate.**

### 2.5 Dose–response
**PASS.**

Dose is multidimensional and outcome-specific.

Current model explicitly allows:
- nonlinear response;
- diminishing returns;
- different volume/frequency relationships by outcome.

No one scalar dose is assumed universal.

### 2.6 Specificity
**PASS.**

Specificity is retained across:
- task;
- contraction mode;
- joint angle/ROM;
- velocity;
- muscle length;
- force/load range;
- energy-system and skill demand.

Canonical rule:
**specificity is graded; transfer can still occur.**

### 2.7 Overload
**PASS.**

Overload = sufficiently challenging target-specific stimulus relative to current capacity.

Can be progressed through:
- load;
- repetitions;
- volume;
- ROM;
- leverage;
- velocity intent;
- density/rest;
- frequency;
- effort.

Canonical rule:
**overload is not synonymous with adding weight every session.**

### 2.8 Reversibility
**PASS.**

Adaptations can decay when stimulus is reduced/removed.

Boundary:
- not instantaneous;
- not uniform;
- outcome/time dependent.

### 2.9 Individual variability
**PASS.**

Observed spread can reflect:
- biology;
- baseline;
- actual dose;
- adherence;
- sleep/nutrition/stress;
- measurement error;
- within-person variability;
- regression/noise.

Canonical rule:
**one block cannot establish a permanent responder/nonresponder trait.**

### 2.10 Different tissue time courses
**PASS.**

Different systems/tissues can recover/adapt on different schedules.

Canonical rule:
**one global “recovered/not recovered” state is an oversimplification.**

### 2.11 Repeated exposure
**PASS.**

Repeated exposure:
- accumulates retained adaptations;
- modifies response to later bouts;
- can produce repeated-bout protection.

Boundary:
**smaller later damage/soreness response does not mean the training stimulus became useless.**

### 2.12 Adaptation × accumulated fatigue
**PASS.**

Current model separates:
- retained adaptation/fitness-related change;
- fatigue/recovery cost.

Canonical rule:
**fatigue is a state/cost, not a direct measure of adaptation quality.**

Result:
**12/12 PASS.**
