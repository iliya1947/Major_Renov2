# NEU-03 — Sensory feedback / proprioception

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Proprioception is a multimodal sensorimotor body-state estimate.

Canonical model:

`spindle + GTO + joint + cutaneous afferents`
`+ central prediction/efference-related signals`
`+ visual + vestibular context`
`→ task/reliability-dependent integration`
`→ position / movement / force-related estimate`
`→ motor control`.

## 1. Proprioception

Proprioception is not:
- one receptor;
- one balance test;
- one global trait.

Project rule:

**proprioception ≠ balance performance ≠ one JPS score.**

## 2. Muscle spindle

Spindles provide major muscle-length/movement information.

Ia:
- strongly dynamic/velocity sensitive;
- also contains static information.

II:
- more strongly related to maintained length/static state.

Both depend on mechanical/fusimotor context.

Project rule:

**Ia ≠ velocity-only; II ≠ position-only.**

## 3. Golgi tendon organ

GTO/Ib input provides force/tension-related information.

Project rule:

**GTO ≠ emergency shut-off switch.**

Ib effects are circuit/task dependent.

## 4. Joint receptors

Joint/capsular receptors can contribute to joint-state sensing.

Project rule:

**their contribution is supplementary/context dependent and current direct human evidence is limited.**

## 5. Cutaneous receptors

Skin stretch, pressure and deformation provide body-configuration information.

Project rule:

**cutaneous signals are part of proprioceptive state estimation, not just generic touch.**

## 6. Vision

Vision provides external spatial reference.

Project rule:

**vision is not proprioception, but visual and proprioceptive reference frames interact.**

## 7. Vestibular system

Vestibular input provides head-motion/gravity/self-motion reference.

Project rule:

**vestibular input is distinct from proprioception but integrated with it for orientation and balance.**

## 8. Sensorimotor integration

Weighting of sensory channels changes with:
- reliability;
- task;
- availability;
- conflict.

Project rule:

**sensory weighting is dynamic, not fixed.**

## 9. Position sense

Position sense estimates body-segment location.

Project rule:

**joint-reposition performance may include memory and motor-command information and is not automatically a pure peripheral proprioception test.**

## 10. Movement sense

Movement/kinesthesia concerns movement occurrence, direction and velocity.

Project rule:

**movement sense and position sense interact but are distinct constructs.**

## 11. Force sense

Force sense integrates:
- force-related afferent input;
- mechanical consequences;
- central motor command / sense of effort.

Project rule:

**force sense ≠ GTO firing alone.**

## 12. Fatigue

Fatigue can worsen proprioceptive accuracy.

But effects depend on:
- joint;
- fatigue protocol;
- local vs general fatigue;
- active vs passive task;
- error metric.

Project rule:

**fatigue does not produce one universal proprioceptive deficit.**

## 13. Measurement boundary

No single gold-standard test measures all proprioception.

Project rule:

**active reposition, passive motion detection, force reproduction and balance are not interchangeable tests.**

## 14. Canonical project rules

1. Proprioception is multimodal.
2. Proprioception ≠ balance.
3. Muscle spindles are major length/movement sensors.
4. Ia/II roles overlap and depend on context.
5. GTOs provide force/tension feedback, not a simple shut-off reflex.
6. Joint receptors contribute but exact weighting is uncertain.
7. Cutaneous deformation contributes to body-state estimation.
8. Vision is distinct from proprioception but integrated.
9. Vestibular input is distinct but integrated.
10. Sensory weighting is task/reliability dependent.
11. Position, movement and force sense are separable.
12. JPS/repositioning is not necessarily pure peripheral proprioception.
13. Fatigue effects are task/joint/metric dependent.
14. One test does not define a global proprioception trait.

## 15. Training-relevant implications

1. **Do not call every balance drill “proprioceptive training.”**
2. **Do not diagnose proprioception from one repositioning score.**
3. **Do not reduce GTO physiology to protective inhibition.**
4. **Do not ignore skin input in body-state estimation.**
5. **Do not treat eyes-closed performance as isolated proprioception.**
6. **Separate position, movement and force-sense outcomes.**
7. **Interpret fatigue-related sensory errors by task and measurement.**
8. **Keep detailed reflex implications in NEU-04 and test validity in TST.**

## 16. What NEU-03 does not prescribe

Not owned here:

- proprioceptive training plan;
- balance program;
- injury-risk prediction;
- vestibular rehabilitation;
- optimal sensory cueing;
- individualized proprioceptive deficit diagnosis.

These remain NEU-04/09/10/11, TST, TEC, PRO, MED and IND.

## 17. Confidence

### HIGH
- multimodal proprioception;
- spindle role;
- GTO force/tension feedback;
- cutaneous contribution;
- vision/vestibular distinction;
- position/movement/force distinction;
- task-dependent fatigue effects;
- measurement non-equivalence.

### MODERATE-HIGH
- dynamic sensory reweighting;
- central/memory contribution to some repositioning paradigms.

### MODERATE
- exact joint-receptor weighting in healthy humans;
- receptor-specific effects of “proprioceptive training”;
- transfer from one clinical proprioception test to complex exercise skill.
