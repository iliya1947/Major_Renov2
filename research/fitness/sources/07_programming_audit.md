# Источники аудита области 07 — программирование тренировок

Дата аудита: 2026-11-16.

1. NSCA — CSCS Exam Description / Program Design  
   https://www.nsca.com/certification/cscs/certified-strength-and-conditioning-specialist-exam-description/

   Программа design domain включает needs analysis, training methods/modes, exercise selection/order, intensities, volumes, work/rest, recovery/unloading, progression и periodization.

2. NSCA — Essentials of Strength Training and Conditioning, 5th Edition  
   https://www.nsca.com/certification/cscs/essentials-of-strength-training-and-conditioning-5th-edition/

   Resistance-training program design chapter структурирован как:
   needs analysis → exercise selection → frequency → exercise order → load/repetitions → volume → rest.

3. ACSM — 2026 Resistance Training Position Stand summary  
   https://acsm.org/resistance-training-guidelines-update-2026/

   Использовано для актуальной рамки:
   - goal-specific programming;
   - individualization;
   - consistency;
   - home-based training;
   - optional nature of many advanced methods.

4. ACSM — Certified Exercise Physiologist Content Outline  
   https://www.acsm.org/wp-content/uploads/2024/12/ACSM-Certified-Exercise-Physiologist-Exam-Content-Outline.pdf

   Использовано для проверки acute/chronic variables, total-body/split routines и modalities.

## Ограничение

Этот аудит определяет перечень programming questions. Конкретные дозы и лучшие методы будут устанавливаться только на этапе глубокого исследования, а затем персонализироваться.
