# COG-05 — Long-term memory: encoding, consolidation, retrieval, episodic/semantic structure, forgetting, and reconstruction

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a scientifically current architecture of long-term declarative memory for psychological inference.

The block separates:

- encoding from storage/consolidation;
- storage/consolidation from retrieval;
- episodic from semantic memory;
- item memory from source/context memory;
- recall from recognition;
- recollection from familiarity;
- forgetting from simple erasure;
- memory accessibility from memory availability;
- retrieval from reconstruction;
- autobiographical memory from exact historical record;
- reactivation from reconsolidation;
- memory confidence/vividness from accuracy.

## Core rule

**Long-term memory is not a static recording archive. Remembering is the result of interactions among encoded traces, consolidation/reorganization, retrieval cues, prior knowledge, context, competition, and reconstructive processes.**

Use:

`experience`
-> `encoding`
-> `stabilization / consolidation / reorganization`
↔ `long-term representation`
-> `cue-dependent retrieval`
-> `recollection / familiarity / reconstruction`
-> `report / action`

Retrieval itself can alter later accessibility or content.

## 1. Declarative memory

NIMH RDoC currently defines declarative memory as the:

- acquisition/encoding;
- storage and consolidation;
- retrieval

of representations of facts and events.

It emphasizes relational representations linking:

- spatial context;
- temporal context;
- items;
- events;
- factual knowledge.

This supports two major functional families:

- **episodic memory** — contextually situated events;
- **semantic memory** — factual/conceptual knowledge.

This distinction is useful but not an absolute anatomical separation.

## 2. Encoding

Encoding is the transformation of current processing into a form capable of supporting later memory.

Encoding quality can depend on:

- attention;
- perceptual quality;
- depth/elaboration;
- organization;
- existing knowledge;
- novelty;
- task goals;
- emotion/arousal;
- strategy;
- contextual binding.

Canonical rule:

**later memory failure can begin at encoding.**

A failed later recall does not by itself show that a previously stored memory was lost.

## 3. Encoding and attention

Information that is weakly attended may be poorly encoded.

But:

`attention present -> durable memory guaranteed`

is false.

Attention improves access to encoding opportunities but memory also depends on:

- representational structure;
- binding;
- later consolidation/reorganization;
- retrieval compatibility.

Detailed attention mechanisms remain in COG-03.

## 4. Relational/contextual binding

Episodic memory depends strongly on representing relations among:

- what;
- where;
- when;
- with whom;
- surrounding context.

An item can be remembered without its original context.

Therefore:

**item recognition != episodic source memory.**

This distinction is critical when a person remembers a statement/fact but misremembers:

- who said it;
- when it occurred;
- where it occurred;
- whether it was imagined, inferred, or directly experienced.

## 5. Episodic memory

Episodic memory supports retrieval of specific events embedded in context.

Current 2026 synthesis emphasizes two complementary properties:

1. episodic memory contains information tied to specific experiences;
2. episodic remembering is also constructive and can use prior knowledge/schema-based inference.

Ranganath and Ritchey describe:

- a **contextual mode** that anchors memory to event-specific context;
- a **generative mode** that uses prior knowledge to construct/infer event content.

These are a current theoretical synthesis, not a final universal architecture.

Canonical rule:

**episodic memory can be both trace-based and reconstructive.**

## 6. Semantic memory

Semantic memory concerns organized knowledge of:

- facts;
- concepts;
- meanings;
- categories;
- regularities.

It is less tied to a single remembered acquisition episode.

A person may know:

> a fact is true

without remembering:

> when or where they learned it.

Semantic knowledge can also be extracted gradually from repeated episodic experiences.

## 7. Episodic and semantic systems overlap

Neuropsychological evidence supports a meaningful distinction between episodic and semantic memory.

Current 2026 neuroimaging work also shows substantial overlap alongside differentiating neural representations during successful retrieval.

Therefore avoid both extremes:

`episodic = semantic`

and

`episodic and semantic are isolated systems`.

They are distinguishable but interacting.

## 8. Consolidation is not one process

"Consolidation" can refer to different timescales/processes.

### 8.1 Synaptic/cellular consolidation

Relatively local stabilization and plasticity after learning.

### 8.2 Systems-level reorganization

Changes over longer periods in how distributed brain systems support memory.

These processes should not be collapsed.

Detailed molecular/neural mechanisms are routed to NEU.

## 9. Systems consolidation remains theoretically contested

A simple traditional story is:

`new memory depends on hippocampus -> over time memory transfers to cortex -> hippocampus no longer matters`.

Current evidence does not justify using this as a universal rule.

Modern theories include:

- standard systems-consolidation accounts;
- multiple-trace approaches;
- trace-transformation accounts;
- interactive reorganization accounts.

Recent work continues to show time-dependent reorganization and changes in precision/generalization, while long-term hippocampal involvement remains important in several models and memory types.

Canonical rule:

**time-dependent memory reorganization != proof of one universal hippocampus-to-cortex transfer mechanism.**

## 10. Memory can transform with time

As memories age, they can change in:

- accessibility;
- precision;
- contextual specificity;
- gist;
- emotional tone;
- narrative organization.

Some loss of detail can support generalization.

Therefore:

`remote memory = weaker copy of recent memory`

is too simple.

Remote memory may be qualitatively reorganized.

## 11. Retrieval is cue-dependent

Remembering depends partly on how retrieval cues overlap with encoded information.

Potential cues include:

- semantic cues;
- sensory cues;
- location;
- temporal context;
- emotional state;
- social context;
- related events.

A memory that is inaccessible under one cue can become accessible under another.

Canonical rule:

**retrieval failure != proof of storage failure.**

## 12. Availability versus accessibility

Useful distinction:

- **availability** — relevant information exists in memory;
- **accessibility** — current cues/processes can retrieve it.

Behavioral tests often observe accessibility rather than storage directly.

This makes statements such as:

> "the memory is gone"

stronger than the evidence usually supports.

## 13. Recall and recognition are different tasks

### Recall

Requires generating/retrieving information with limited direct presentation of the target.

Examples:

- free recall;
- cued recall.

### Recognition

Requires judging whether presented information was encountered before.

Recognition can succeed when free recall fails.

Therefore:

`cannot recall -> does not remember`

is too strong.

## 14. Recognition can involve recollection and familiarity

Recognition judgments can draw on at least two useful process concepts:

### Recollection

Retrieval of qualitative/contextual information about a prior encounter.

### Familiarity

A sense that an item was previously encountered without recovery of rich contextual detail.

Dual-process models are influential, but the exact architecture and measurement remain debated.

Do not treat a "remember/know" response as a direct pure measure of one process without model assumptions.

## 15. Familiarity is multidimensional

Current reviews emphasize that familiarity can vary in:

- representational source;
- phenomenology;
- context;
- fluency.

Therefore:

`feels familiar -> definitely encountered before`

is invalid.

Familiarity can be generated by processing fluency or related prior exposure.

## 16. Source memory and source monitoring

Source memory concerns contextual origins of remembered information.

Source-monitoring errors can include confusing:

- perception with imagination;
- one speaker with another;
- one time/place with another;
- inference with direct observation;
- repeated retelling with original experience.

These errors matter because a person can accurately remember **content** while misattributing its **source**.

## 17. Retrieval is reconstructive

Remembering an episode is not equivalent to replaying a stored video.

Retrieval can combine:

- stored event traces;
- schemas;
- semantic knowledge;
- current goals;
- later information;
- inference;
- narrative structure.

The latest Annual Review synthesis explicitly treats episodic remembering as construction from both event-specific traces and prior-knowledge scaffolds.

Reconstruction is a normal property of memory, not evidence of dysfunction.

## 18. Reconstruction can be adaptive

Constructive memory allows:

- filling predictable gaps;
- extracting gist;
- generalizing across experiences;
- imagining future events;
- integrating new knowledge;
- updating outdated representations.

The same flexibility also creates vulnerability to distortion.

Thus:

**accuracy and adaptiveness are related but not identical goals.**

## 19. False memory and distortion

A memory report can contain:

- accurate details;
- omitted details;
- inferred details;
- source errors;
- later-added information;
- schema-consistent distortions.

Memory distortion does not imply deliberate lying.

Likewise:

**sincerity/confidence != historical accuracy.**

## 20. Confidence and vividness

People can experience memories as:

- vivid;
- emotionally intense;
- coherent;
- certain.

These phenomenological qualities can correlate with aspects of memory strength but are not perfect measures of objective accuracy.

Emotional autobiographical memories can remain especially vivid while still changing in content over time.

Canonical rule:

**vividness/confidence must not be used as an accuracy certificate.**

## 21. Emotion changes what is remembered

Emotion can affect:

- attention during encoding;
- consolidation;
- central-versus-peripheral detail;
- retrieval goals;
- rehearsal;
- narrative meaning.

Emotion can enhance memory for some information while impairing or transforming other information.

Do not use:

`emotional event -> globally more accurate memory`.

## 22. Autobiographical memory

Autobiographical memory integrates information about one's personal past.

It can include:

- episodic event details;
- semantic autobiographical facts;
- narrative organization;
- self-relevant interpretation;
- emotional meaning.

It supports:

- identity/self-continuity;
- social communication;
- planning;
- emotion regulation.

But autobiographical memory is not a direct archive of personal history.

## 23. Autobiographical memory is malleable

Current reviews show that autobiographical memories can change through:

- forgetting;
- retelling;
- narrative restructuring;
- perspective shifts;
- later knowledge;
- current goals;
- social interaction.

Emotional autobiographical memories can retain central meaning while specific details change.

Therefore autobiographical reports are strong evidence for:

- remembered experience;
- current interpretation;
- subjective meaning.

They are not automatically perfect evidence for every historical detail.

## 24. Culture shapes autobiographical memory

Current 2026 review literature shows that cultural systems can influence:

- what events are attended to;
- what is rehearsed;
- narrative organization;
- self-focus versus social-context focus;
- memory goals;
- retrieval/reporting practices.

Therefore autobiographical-memory expectations should not be universalized from one cultural population.

## 25. Memory report and event history are different evidential targets

For individualized psychological work, separate:

### A. Historical claim

> What actually occurred?

Needs corroboration when accuracy matters.

### B. Memory claim

> What does the person currently remember?

The report itself is direct evidence of current remembered content.

### C. Meaning claim

> What meaning does the remembered event currently have?

Requires interpretation of current narrative/context.

### D. Mechanism claim

> Why is this memory represented this way?

Requires additional evidence.

Canonical rule:

**a memory report can be psychologically important even when historical accuracy is uncertain.**

## 26. Repeated retelling can change memory

Repeated retrieval can strengthen access to some elements while also:

- reorganizing narrative structure;
- emphasizing some details;
- omitting others;
- integrating later information.

Therefore:

`same story repeated consistently -> independent confirmations`

is invalid.

It may be one evolving memory representation repeatedly retrieved.

## 27. Retrieval practice can strengthen later memory

Retrieving information is not merely assessment.

Retrieval practice can improve later retention relative to restudy and can modify later accessibility.

Recent meta-analytic work continues to support a retrieval-practice benefit across many conditions.

Thus the act of remembering changes the future memory system.

## 28. Retrieval can also produce forgetting of competitors

Retrieving one memory can make related competing memories less accessible under some conditions.

Retrieval-induced forgetting and retrieval-suppression paradigms show that retrieval/control processes can change later accessibility.

A 2026 meta-analysis of suppression-induced forgetting found a reliable average effect with meaningful methodological heterogeneity.

Therefore forgetting can be partly active/control-dependent rather than only passive trace decay.

## 29. Forgetting has multiple mechanisms

Observed forgetting can reflect:

- weak encoding;
- consolidation failure;
- interference;
- retrieval competition;
- cue mismatch;
- context change;
- intentional suppression;
- reduced access;
- trace alteration/decay;
- source confusion.

Do not infer mechanism from the phenomenon alone.

## 30. Forgetting can be adaptive

Forgetting can reduce:

- interference;
- obsolete information;
- irrelevant competition;
- intrusive retrieval.

Therefore:

`more forgetting = worse cognition`

is not universally true.

Adaptive memory requires both persistence and selective loss/access regulation.

## 31. Retrieval suppression

People can sometimes intentionally stop retrieval of unwanted memories.

Current neuroscience reviews distinguish retrieval stopping from action inhibition and identify control mechanisms affecting memory retrieval.

But suppression effects vary across paradigms and individuals.

Do not infer deliberate suppression merely because a memory is difficult to retrieve.

## 32. Reactivation and reconsolidation are not synonyms

Reactivation means a memory becomes active/retrieved.

Reconsolidation is the stronger hypothesis that reactivation makes a consolidated memory labile and requires restabilization, permitting modification under specific boundary conditions.

Current 2025–2026 reviews emphasize:

- boundary conditions;
- memory-system differences;
- timing;
- methodological heterogeneity.

Therefore:

**retrieved memory -> reconsolidated/rewritten**

is not a universal rule.

## 33. Human reconsolidation claims require strong controls

To infer reconsolidation rather than generic post-retrieval change, studies need to distinguish:

- reactivation;
- extinction/new learning;
- retrieval practice;
- interference;
- demand effects;
- ordinary updating.

Recent systematic review evidence on human reactivation/TMS paradigms finds some reconsolidation-compatible effects but explicitly describes the evidence as heterogeneous and strongest in controlled laboratory paradigms.

## 34. Memory modification is normal

Recent cross-species review literature treats memory as continuously modifiable.

Modification can be:

- adaptive;
- neutral;
- maladaptive.

This does not mean every retrieval changes every memory substantially.

The magnitude and mechanism depend on:

- prediction error;
- new information;
- timing;
- strength/age of memory;
- retrieval conditions;
- memory system.

## 35. Specificity versus gist

Memory can preserve:

- event-specific details;
- gist/general meaning.

With time or repeated integration, some memories can become less specific while retaining or strengthening gist.

This can support generalization but can also produce overgeneralization or source confusion.

Therefore:

`gist preserved -> event details preserved`

is invalid.

## 36. Memory and inference

Declarative memory does more than preserve past information.

Relational memory can support:

- transitive inference;
- generalization;
- prediction;
- model building.

NIMH explicitly notes that relational declarative representations facilitate flexible extraction of new information.

Thus a later conclusion may be partly **inferred from memory relations**, not literally remembered as an experienced event.

## 37. Memory and imagination/future simulation

Episodic memory contributes to construction of possible future events.

The overlap reflects reuse of:

- event components;
- relational structure;
- schemas.

Therefore similarity between remembering and imagining does not mean imagined events are stored memories.

Source monitoring remains essential.

## 38. Measuring long-term memory

Common paradigms include:

- free recall;
- cued recall;
- recognition;
- remember/know judgments;
- source memory;
- paired-associate learning;
- list/story learning;
- delayed recall;
- autobiographical interviews;
- associative inference.

Each samples different mixtures of:

- encoding;
- retention;
- retrieval;
- familiarity;
- recollection;
- source binding;
- language;
- executive control.

No one memory task is a pure assay of "memory strength."

## 39. Immediate versus delayed tests

Immediate performance can differ from delayed performance because later retention depends on:

- consolidation/reorganization;
- interference;
- retrieval practice;
- sleep/wake activity;
- contextual change.

Therefore a good immediate score does not guarantee durable long-term memory.

A delayed failure also does not reveal whether the main problem occurred at encoding, retention, or retrieval without additional design.

## 40. Recognition does not automatically diagnose encoding versus retrieval

Recognition can rescue performance when free recall fails because external cues reduce retrieval demands.

But impaired recognition can arise from several mechanisms.

Likewise, preserved recognition does not prove intact episodic recollection because familiarity may support recognition.

Interpret recall/recognition profiles through explicit models rather than simple rules.

## 41. Memory evidence in individualized analysis

When personal memory is used as psychological evidence, record separately:

1. current remembered content;
2. confidence/vividness;
3. time elapsed;
4. number of retellings;
5. possible later information;
6. source certainty;
7. corroboration;
8. stable gist;
9. disputed/uncertain details;
10. current meaning.

Do not force uncertain historical detail into the psychological model as settled fact.

## 42. Long-Term Memory Inference Gate

Before interpreting a long-term-memory result or autobiographical report, ask:

### A. Target

1. Is the claim about encoding, retention/consolidation, retrieval, recognition, source memory, or reconstruction?
2. Is it episodic, semantic, autobiographical, or another memory type?

### B. Encoding

3. Was the information attended?
4. Was it understood?
5. Was relational/contextual information encoded?
6. Could weak encoding explain later failure?

### C. Retention/consolidation

7. What delay occurred?
8. What interference occurred during the delay?
9. Is "consolidation failure" actually identified or merely assumed?
10. Is one systems-consolidation theory being treated as settled fact?

### D. Retrieval

11. What retrieval cues were available?
12. Could cue mismatch explain failure?
13. Is accessibility being confused with availability?
14. Has retrieval itself altered later accessibility?

### E. Memory type

15. Is item memory distinguished from source/context memory?
16. Is episodic content distinguished from semantic knowledge?
17. Is autobiographical episodic detail distinguished from autobiographical facts?

### F. Recognition

18. Is recognition being distinguished from recall?
19. Could familiarity support the recognition decision?
20. Is recollection actually measured or inferred loosely?
21. Could response criterion affect recognition performance?

### G. Reconstruction

22. Could schemas/prior knowledge fill missing details?
23. Could later information have been incorporated?
24. Could narrative retelling have reorganized the memory?
25. Is a source-monitoring error plausible?

### H. Emotion/autobiographical context

26. Is vividness/confidence being mistaken for accuracy?
27. Could emotion selectively preserve gist while changing detail?
28. Could current goals/identity shape retrieval/narrative?
29. Are cultural/narrative norms relevant?

### I. Forgetting/control

30. Could interference or competition explain forgetting?
31. Could retrieval suppression/control play a role?
32. Is forgetting being mistaken for erasure?

### J. Reactivation/update

33. Was the memory merely retrieved, or is reconsolidation actually demonstrated?
34. Are reconsolidation boundary conditions satisfied?
35. Could ordinary new learning or interference explain change?

### K. Measurement

36. Which memory paradigm is used?
37. What reliability/validity evidence supports the inference?
38. Does the task confound encoding, retrieval, language, attention, or control?

### L. Individual/history inference

39. What part of the report is direct evidence of current remembered experience?
40. What part is a historical claim requiring corroboration?
41. What part is current interpretation/meaning?
42. What mechanism claim is being added beyond the report?

### M. Conclusion

43. What is the strongest supported memory conclusion?
44. What remains historically uncertain?
45. What additional cue/source/corroboration would discriminate the nearest rival explanation?

## 43. High-value failure modes

### Failure A — failed recall = memory erased

Incorrect.

Correct:

Weak encoding, interference, cue mismatch, competition, or retrieval failure can all reduce recall.

### Failure B — vivid/confident memory = accurate memory

Incorrect.

Correct:

Phenomenological confidence and objective accuracy are related imperfectly.

### Failure C — episodic memory = literal replay

Incorrect.

Correct:

Episodic remembering combines event traces with contextual and generative reconstruction.

### Failure D — semantic memory = episodic memory without context

Incorrect.

Correct:

They are distinguishable memory functions that interact but have different representational properties.

### Failure E — recognition = recollection

Incorrect.

Correct:

Recognition can be supported by familiarity without rich contextual recollection.

### Failure F — content remembered = source remembered

Incorrect.

Correct:

Content and source/context memory can dissociate.

### Failure G — time passage = passive decay

Incorrect.

Correct:

Interference, reorganization, cue change, active control, and trace modification can contribute.

### Failure H — remote memory = cortical copy after hippocampal transfer

Incorrect as a universal account.

Correct:

Systems-level memory reorganization remains theoretically contested.

### Failure I — retrieval = neutral readout

Incorrect.

Correct:

Retrieval can strengthen, suppress, update, or reorganize later memory.

### Failure J — retrieval = reconsolidation

Incorrect.

Correct:

Reconsolidation requires stronger evidence and boundary conditions.

### Failure K — repeated story = independent corroboration

Incorrect.

Correct:

Repeated retelling may repeatedly sample and modify one evolving representation.

### Failure L — autobiographical report = verified history

Incorrect.

Correct:

It is direct evidence of current remembered experience; historical accuracy may require independent corroboration.

### Failure M — emotional memory = globally accurate memory

Incorrect.

Correct:

Emotion can preserve some central/gist information while other details remain malleable.

### Failure N — forgetting = cognitive failure only

Incorrect.

Correct:

Selective forgetting can reduce interference and be adaptive.

## Canonical working rule

**Separate encoding from retention from retrieval; identify memory type and source/context; treat remembering as cue-dependent reconstruction; distinguish current remembered experience from verified history; infer mechanism only after ruling out encoding, interference, cue, criterion, and source-monitoring alternatives.**

Never:

**confident memory report -> exact historical record -> psychological mechanism.**

## Current-standard note

As of 2026-11-19:

- NIMH RDoC continues to define declarative memory around encoding, storage/consolidation, retrieval, and relational representations;
- the newest Annual Review synthesis treats episodic memory as both trace-constrained and reconstructive rather than as a static readout;
- current evidence supports a meaningful episodic/semantic distinction alongside substantial overlap;
- systems consolidation remains an active theoretical debate rather than a settled one-way hippocampus-to-cortex transfer account;
- autobiographical memory is strongly supported as malleable and reconstructive, with culture, emotion, retelling, and current context affecting content and organization;
- human reconsolidation research supports memory modification under some reactivation conditions, but reactivation alone does not establish reconsolidation.

## Scope note

This block covers long-term declarative memory and autobiographical-memory inference.

Procedural learning, conditioning, habits, extinction, and detailed reconsolidation intervention science are routed to LEA/BHC. Detailed neural mechanisms are routed to NEU. Clinical amnesia/dementia and trauma-memory assessment are routed to CLN/NDEV/appropriate clinical domains.
