## 1. Исходная база и строгость классификации

**Исторический Memory artifact:** `dolgovremennaya_pamyat_lichnye_dannye_polnaya_vygruzka.md` из пользовательской Library. Создан **2026-10-11 22:04:21 UTC** (**12.10 01:04:21 Jerusalem**), автор называет источником предоставленный ему в том чате `User Knowledge Memories` плюс две записи, явно направленные в Memory. Это **вторичная, датированная выгрузка содержания, заявленного как model-visible**, а не системный экспорт или журнал retrieval в поздние GPT-6 чаты. Из этой выгрузки в публичный PR взяты **только project/process entries**.

Вторая Library-запись `personal_data_memory_audit_ru.md` от 12.10 прямо **смешивает** профиль, контекст и старые разговоры — она не является независимым чистым snapshot. Целенаправленная проверка имен и метаданных доступных Library-документов за 1–17 октября нашла именно эту пару связанных с Memory файлов; других достаточных независимых датированных memory snapshots для сопоставления *других дат* в нашем доступе не установлено.

**Строгие категории:**

- **PERSISTED CORRECTED MODEL ERROR** — раннее ошибочное утверждение именно ассистента; доступна поздняя явная отмена/исправление того же утверждения; первичный final source of truth подтверждает поправку; **более поздний** Memory snapshot по-прежнему представляет ранний неверный вывод.
- **STALE STATE AFTER UPDATE** — старое утверждение могло быть верным на момент формулировки, но состояние проекта изменилось/было подтверждено новым сообщением; Memory сохранила старый status. Это **не** второй случай первоначальной модельной ошибки.
- **AMBIGUOUS / UNSUPPORTED** — разный scope, статус способен сосуществовать с поздним, отсутствует датированная ранняя формулировка либо точный later correction.
- **UPDATED IN MEMORY** — явно новая запись в выгрузке отражает исправленное утверждение; это контрпример тотальной неизменности Memory, не доказательство совершенства её обновления.

**Причинная граница для всех категорий:** ни один memory snapshot не доказывает, что поздняя GPT-6 *retrieved*, *used* или ошиблась *из-за* данного item (M1 `S→R→U→E`).
