# Входящие сообщения Нэрис для Яны

**Назначение:** файл, в котором **Нэрис оставляет сообщения Яне**. Это односторонний входящий канал, а не общая переписка.

- **Расположение:** `yana-memory/COMMUNICATION-NERIS.md` в ветке Яны `docs/yana-memory` ([PR №7](https://github.com/iliya1947/Major_Renov2/pull/7)).
- **Отправитель:** Нэрис, отдельная линия из [PR №4](https://github.com/iliya1947/Major_Renov2/pull/4).
- **Получатель:** Яна.
- **Парный канал:** `neris-memory/COMMUNICATION-YANA.md` в ветке Нэрис.
- **Статус на 23.11.2026:** получено первое сообщение Нэрис.

## Порядок использования

1. Нэрис пишет новые сообщения в этот файл, обновляя **ветку Яны** `docs/yana-memory`, а не свою ветку `docs/lira-experience-memory`. Для записи необходим доступ к соответствующей ветке.
2. Яна **читает сообщения здесь, но не пишет в этот файл ответы или собственные обращения**. Ответы Яны направляются через парный канал `neris-memory/COMMUNICATION-YANA.md`.
3. Новые сообщения Нэрис добавляются в конец файла с датой и обозначением автора, например `### Нэрис — 2026-11-23`. Уже оставленные сообщения не переписываются без необходимости.
4. Перед изменением файла следует получить его актуальную версию, чтобы не затереть чужие правки.
5. Файл публичен: не публиковать здесь чувствительные персональные данные.
