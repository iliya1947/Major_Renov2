# NEU-19 — Neuroplasticity

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Neuroplasticity is not one mechanism, one biomarker or one coaching target.

A defensible project model is:

`training/experience`
→
`behavior during acquisition`
→
`retention / transfer / relearning`
+
`specific neural markers when measured`
→
`mechanism inference with uncertainty`.

Project rule:

**judge learning behaviorally first; interpret neural measures as mechanism-specific evidence, not as a generic “plasticity score.”**

---

## 1. Experience-dependent plasticity

Experience can alter nervous-system structure/function.

This can include changes in:

- excitability;
- inhibition;
- connectivity;
- representation;
- structural MRI measures;
- descending pathways.

But measurable neural change does not by itself prove durable learning.

Project rule:

**experience-dependent plasticity is a broad neural-change construct, not a behavioral endpoint.**

---

## 2. Use-dependent changes

Repeated movement can bias later motor output/representation.

Use-dependent plasticity is real.

But repetition can reinforce:

- useful patterns;
- irrelevant patterns;
- poor task representations;
- narrow solutions.

Project rule:

**use-dependent change is one mechanism class, not complete motor learning.**

---

## 3. Neural markers ≠ learning

Common markers include:

- MEP amplitude;
- SICI/ICF;
- silent period;
- H-reflex/V-wave;
- StartReact/ICAR;
- fMRI/MRI;
- MRS;
- EEG;
- BDNF.

These are not interchangeable.

Behavior can improve without detectable change in a selected marker.

A marker can change without proving retention/transfer.

Project rule:

**name the marker and its interpretation; never report generic “more neuroplasticity.”**

---

## 4. Resistance-training neural adaptation

Resistance training can alter central neural function.

Current evidence supports changes across:

- corticospinal;
- intracortical;
- cortico-reticular/reticulospinal;
- spinal/motoneuronal

levels.

Different training constraints can produce different neural profiles even when strength improves in both conditions.

Project rule:

**RT neural adaptation is distributed and protocol specific; no single neural mechanism explains strength gain.**

---

## 5. Specificity

Learning/plasticity is substantially specific to the practiced task/context.

Specificity can involve:

- movement;
- effector;
- force/velocity;
- timing;
- sensory context;
- task goal;
- feedback structure.

But specificity does not mean zero transfer.

Project rule:

**train what must improve, then test the desired transfer explicitly.**

---

## 6. Specificity vs transfer

Extensive training can simultaneously produce:

- stronger retention;
- greater spontaneous recovery;
- some transfer;
- narrower generalization around the trained solution.

Project rule:

**specificity and transfer coexist; transfer breadth is an empirical outcome.**

---

## 7. Repetition

Repetition provides learning opportunities.

But no universal repetition count or neuroplasticity threshold exists.

More repetition is not automatically better if:

- fatigue degrades execution;
- the wrong task representation is repeated;
- feedback/cues create dependency;
- error structure becomes uninformative.

Project rule:

**prescribe repetition by task quality and behavioral goal, not by a mythical plasticity dose.**

---

## 8. Salience

“Salience” must be operationalized.

Possible meanings include:

- reward;
- motivation;
- task relevance;
- novelty;
- attention capture;
- emotional significance.

Reward can facilitate motor learning in some tasks.

But more reward/success is not monotonically better.

Project rule:

**use meaningful/rewarding task structure when useful; do not optimize for maximum positive feedback alone.**

---

## 9. Consolidation

Consolidation refers to post-acquisition stabilization/reorganization of memory.

It is not synonymous with:

- sleep;
- offline performance gain;
- one neural network;
- one biomarker.

Project rule:

**infer consolidation from delayed memory stability/behavior, not from one offline signature.**

---

## 10. Sleep and consolidation

Sleep can support motor memory.

But effects vary by:

- task;
- memory component;
- timing;
- age;
- outcome.

Sleep deprivation can impair acquisition while leaving later consolidation relatively preserved in some tasks.

Project rule:

**sleep matters, but no universal motor-memory sleep law is retained.**

Exact sleep prescription belongs REC.

---

## 11. Retention

Retention is delayed expression of previously acquired capability.

Retention is not:

- immediate post-test;
- neural-marker persistence;
- savings;
- complete absence of decay.

Skill can decay with nonuse.

Project rule:

**test retention directly after a meaningful delay.**

---

## 12. Retention decay

Procedural skills decay at task-dependent rates.

Broad meta-analytic averages cannot be treated as exercise-specific expiry dates.

Project rule:

**expect graded decay, not all-or-none forgetting.**

---

## 13. Interference

Interference occurs when one memory/task alters another.

It depends on:

- similarity;
- shared resources;
- movement dynamics;
- timing;
- contraction type;
- context.

Project rule:

**do not assume close practice automatically produces interference.**

---

## 14. Memory interference ≠ contextual interference

Memory interference can impair one memory.

Contextual interference is a practice-organization phenomenon where harder acquisition can sometimes improve delayed learning.

These are different constructs.

Project rule:

**never infer one from the other.**

---

## 15. Relearning / savings

Savings means faster reacquisition after prior learning.

It can occur despite reduced overt performance.

Project rule:

**savings demonstrates prior-learning influence, not intact overt retention or broad transfer.**

---

## 16. Neural mechanism of savings

Current imaging evidence supports reinstatement of prior learning-related neural patterns during savings.

But exact mechanism can include:

- retrieval;
- explicit strategy;
- latent implicit memory;
- priors;
- structural learning;
- contextual selection.

Project rule:

**do not reduce savings to one neural mechanism.**

---

## 17. Clinical neurorehabilitation boundary

Classic neuroplasticity principles were developed largely for rehabilitation after brain damage.

Clinical neurorehabilitation differs from healthy fitness in:

- nervous-system injury;
- spontaneous recovery;
- abnormal excitability/inhibition;
- compensatory vs restorative goals;
- comorbidities;
- functional-independence endpoints;
- therapy constraints.

Project rule:

**rehabilitation principles can generate hypotheses, not direct healthy-fitness dose prescriptions.**

---

## 18. “More intensive” is not automatically better

Even within neurorehabilitation, more intensive task-specific training does not guarantee superior functional outcomes.

Project rule:

**dose-response must be demonstrated rather than inferred from plasticity slogans.**

---

## 19. “Use it or lose it / improve it”

These are broad qualitative principles.

Healthy procedural skills can:

- decay with nonuse;
- retain latent memory;
- relearn faster;
- continue evolving with extended practice.

Project rule:

**do not convert these slogans into quantitative training laws.**

---

## 20. More neuroplasticity ≠ better

Plasticity can support:

- adaptive skill;
- compensation;
- narrow specialization;
- maladaptive persistence.

Project rule:

**the target is useful behavior, retention and transfer—not maximal neural change.**

---

## 21. Practical synthesis

For later resistance-exercise work:

1. practice the capability that actually needs improvement;
2. expect substantial task specificity;
3. use enough repetition to create stable learning opportunities, not arbitrary volume;
4. preserve useful variability when transfer matters;
5. use reward/meaning when it improves engagement/information;
6. separate acquisition from delayed retention;
7. test transfer independently;
8. do not assume interference without evidence of overlapping processes;
9. use relearning/savings after breaks rather than treating decay as total erasure;
10. interpret neural markers as mechanism evidence, not coaching targets;
11. do not import clinical rehabilitation doses into healthy lifting.

Status:

**PRACTICAL_HEURISTIC**, not a universal neuroplasticity prescription.

---

## 22. Canonical non-equivalences

1. Neuroplasticity ≠ learning.
2. Neuroplasticity ≠ one biomarker.
3. Neural-marker change ≠ durable learning.
4. Behavioral improvement ≠ detectable change in a chosen marker.
5. Experience-dependent ≠ use-dependent ≠ skill learning.
6. Repetition ≠ guaranteed useful adaptation.
7. More repetition ≠ more useful plasticity.
8. Specificity ≠ zero transfer.
9. Variable practice ≠ universally superior.
10. Salience ≠ reward only.
11. More reward/success ≠ more learning.
12. Consolidation ≠ sleep.
13. Consolidation ≠ offline gain.
14. Retention ≠ immediate post-test.
15. Retention ≠ no decay.
16. Retention ≠ savings.
17. Interference ≠ inevitable.
18. Memory interference ≠ contextual interference.
19. Savings ≠ intact overt retention.
20. RT neural adaptation ≠ technique learning.
21. Clinical neurorehab principle ≠ healthy-fitness dose.
22. More neuroplasticity ≠ better outcome.

---

## 23. Measurement boundaries

### Neuroplasticity
Experience-associated nervous-system change at a defined measurement level.

### Neural marker
One measured neural property.

### Motor performance
Current task output.

### Motor learning
Durable capability inferred from delayed testing.

### Consolidation
Post-acquisition stabilization/reorganization.

### Retention
Delayed persistence.

### Generalization
Expression across nearby untrained stimuli/contexts.

### Transfer
Benefit in a meaningfully changed task/context.

### Interference
Interaction between memories/processes.

### Savings/relearning
Faster reacquisition after prior exposure.

## 24. Confidence

### HIGH

- experience-dependent plasticity exists;
- use-dependent changes exist;
- neural markers are non-equivalent;
- neural-marker change ≠ learning;
- specificity matters;
- no universal repetition threshold exists;
- consolidation ≠ sleep/offline gain;
- retention ≠ relearning;
- neurorehab doses cannot be imported directly into healthy fitness.

### MODERATE-HIGH

- RT produces protocol-specific central neural adaptations;
- reward can modulate learning;
- extensive training can strengthen retention while narrowing generalization;
- interference depends on similarity/context;
- savings reflects latent prior learning.

### MODERATE

- exact neural mechanisms of savings;
- specific imaging/TMS markers as mechanistic explanations.

### LOW / CONTEXT-DEPENDENT

- one optimal repetition dose;
- one salience manipulation;
- one sleep/consolidation schedule;
- one interference spacing rule;
- one neural biomarker predicting coaching outcome.
