## A2 — уточнения, полученные из совокупности источников

1. **Episode is constructed before it is remembered.** Continuous experience segmentation и representation задают, что позже может выступать единицей episodic memory. Следовательно, raw event in world ≠ memory episode.

2. **Episode → reusable knowledge is not one mechanism.** Generalization может использовать similarity to instances, explicit rules, latent structure, schema or hybrid routes. Semantic knowledge не обязано быть simple compressed copy of episodes.

3. **Compression always implies selection.** Любая abstraction/gist/schema теряет detail; важный A2-вопрос — какие conditions/exceptions должны сохраняться, чтобы later understanding не стало rigid overgeneralization.

4. **Surprise/prediction error is a candidate prioritization signal, not a universal definition of significance.** Это пересекается с learning №3 и motivation №4; область №2 должна исследовать, как unusual events affect memory representation/retrieval, но не превращать surprise в готовое правило «что важно».

5. **Retrieval is potentially an intervention.** Вспоминание может улучшать target retention, ослаблять/усиливать related information и менять subsequent encoding. Поэтому retrieval policy later cannot be treated as neutral access mechanism.

6. **Stored, accessible, retrieved, reported and influential are different states.** A record can exist but not be accessible; can be accessible but not retrieved; can be retrieved but not control behavior. Это central distinction для будущего synthesis.

7. **Forgetting is not equivalent to erasure.** Inaccessibility, active suppression, interference, updating/competition and loss of explicit recall need separate treatment.

8. **External memory changes the cognitive system without becoming internal memory.** Offloading can improve task performance and change what needs to be maintained internally, while reliance creates vulnerability to loss of access. This is the appropriate human analogue boundary for future files, not evidence that a project file is “episodic memory”.

9. **Choice of internal vs external memory can itself be metacognitively controlled.** This matters for future cross-area work on memory use, but exact engineered write/retrieval policy belongs to №9.

10. **Memory can guide future behavior without explicit autobiographical recall.** Therefore future claims about “experience influencing choice” cannot require conscious-like explicit recollection as the only possible signature — but human evidence cannot be directly transferred to GPT.

# Phase B — B2: from episode to reusable, revisable acquired experience

**Статус 16.10.2026:** B2 начата и НЕ завершена. Первый глубокий проход по gaps 5, 13, 15. Цель этого прохода — определить, что именно human memory literature позволяет считать episode/representation/generalization/revision, не превращая её в готовую архитектуру для LLM.

## Реально просмотренные источники B2

### Bailey & Smith (2024) — Event perception and event memory in real-world experience
Nature Reviews Psychology 3:754–766
https://www.nature.com/articles/s44159-024-00367-0

**Фактически просмотрено:** abstract и доступный preview/reference structure статьи, включая sections/references по event segmentation, event models, temporal/causal organization и memory updating. Review, не LLM research.

**Результат:** continuous experience не хранится естественно как один недифференцированный поток. Люди сегментируют его на events; event representation организует действия во времени, causal relations и context. Event boundaries одновременно помогают организовать memory и могут нарушать temporal continuity across boundaries.

### Nolden et al. (2024) — Prediction error and event segmentation in episodic memory
Neuroscience & Biobehavioral Reviews 157:105533
https://doi.org/10.1016/j.neubiorev.2024.105533

**Фактически просмотрено:** abstract и доступные section snippets/summary.

**Результат:** prediction error и event segmentation участвуют в формировании episodic representations, но через partly overlapping mechanisms involving attention/working memory. Для B2 важно: boundary возникновения episode не обязана совпадать с later lesson/generalization.

### Li, Johansson & Nikolaev (2025) — Hierarchical event segmentation of episodic memory in virtual reality
npj Science of Learning 10:25
https://www.nature.com/articles/s41539-025-00321-6

**Фактически просмотрено:** abstract/available online sections.

**Результат:** event structure может быть hierarchical: perceptual/spatial и conceptual boundaries по-разному структурируют sequence memory. Следовательно, «один episode» не имеет универсального фиксированного масштаба.

### Zaki & Cai (2025) — Memory engram stability and flexibility
Neuropsychopharmacology 50:285–293

## Первый вывод B2 по human memory

Human literature не поддерживает идею, что experience unit — это:
- raw message/event;
- готовый lesson;
- неизменяемый summary;
- обязательно один фиксированный temporal chunk.

Лучше различить **как минимум три разных объекта исследования**:

1. **Episode/event representation** — ограниченный фрагмент происходившего, организованный context/time/action relations.
2. **Interpretive relation** — что participant/system считает этот episode означающим, включая causal attribution/expectation; это уже не сам episode.
3. **Reusable generalized understanding** — relation/pattern, который переносится за пределы исходного episode и поэтому должен иметь scope/conditions/exceptions.

Это conceptual distinction, НЕ финальная memory schema.

## Критический результат: abstraction ≠ compression

Memory research показывает, что generalization полезна именно потому, что выделяет structure across experiences. Но schema/gist influence способен:
- стирать детали;
- заполнять пробелы prior knowledge;
- создавать distortions;
- overgeneralize beyond supporting episodes.

Следовательно, B2 не может принять «summary = acquired experience». Lossy summary без связи с episode делает позднюю проверку условий/исключений принципиально слабее.

## Revision lifecycle — пока только conceptual space

Zaki & Cai и broader reconsolidation/extinction literature дают сильную причину отказаться от overwrite-only view.

New evidence может:
- укрепить прежнее understanding;
- изменить его;
- сузить scope;
- создать exception/context-specific alternative;
- оставить competing representations;
- сделать старое знание inactive/obsolete, не уничтожая historical fact that it once guided behavior.

B2 должна ещё исследовать precise lifecycle terminology и provenance before declaring a final principle.

## Edge-case results

1. **Single decisive episode:** candidate relation survives. One episode may support broad revision if it is diagnostic against an already structured set of alternatives. Episode count is not the unit criterion.
2. **Conflicting episodes:** candidate relation survives only if multiple condition-specific interpretations can coexist. Conflict does not force global overwrite.
3. **Exception to a useful generalization:** exception can narrow scope, create a conditional branch, or remain separately represented. A reusable rule must preserve boundary cases.
4. **Later-disproved causal attribution:** original episode remains historical evidence; the attribution can become contradicted. Past causal influence of the attribution is a different fact from present truth of the attribution.
5. **Historically important but currently false understanding:** current action-guidance must be separable from historical existence/influence.
6. **Many-to-one abstraction:** a generalized relation may be supported by multiple episodes with no single privileged source, while specific episodes remain independently accessible.

## Lifecycle insight: labels are not enough

A2 listed useful labels: provisional, validated, contradicted, narrowed, stale/obsolete, historical-only, reactivated. B2 shows these should **not** be treated as a mandatory linear state machine. They project several partially independent dimensions:

- **evidential warrant:** how strongly current evidence supports the interpretation/generalization;
- **scope/conditions:** where it applies and what exceptions/context boundaries exist;
- **current action-guidance eligibility:** whether it should currently influence choices;
- **temporal validity:** whether the represented situation is still current;
- **historical causal status:** whether this understanding actually influenced past choices, even if it is now false;
- **accessibility/retention:** whether supporting episode evidence remains available enough for revision.

This multidimensional view explains why `narrowed` is not the same as `contradicted`, `obsolete` is not the same as `false`, and `historical-only` is not the same as accidental loss.

## Functional forgetting vs accidental loss

**Functional forgetting/obsolescence** reduces ordinary action-guidance or retrieval of currently irrelevant/invalid material while preserving enough historical/provenance structure to revise, audit, or understand prior trajectory when needed.

**Accidental loss** removes still-relevant evidence or breaks its relation to a derived understanding, making later checking/revision impossible. The two can look behaviorally similar in the moment but are conceptually opposite.

# Phase B — B6 support pass 1: compression, exceptions and functional forgetting

B6 uses the B2 human-memory synthesis as a constraint on retrieval/compression.

Adaptive compression can be useful, but a derived semantic/generalized representation should not erase the episodic evidence needed to:
- recover conditions;
- inspect exceptions;
- revise a false attribution;
- distinguish current truth from historical influence.

For B6, **compression is a derived view over evidence**, not an authority upgrade.

A summary such as “X works” is invalidly stronger than the underlying conditional relation “X worked under C; exception E remains unresolved”.

Functional forgetting/obsolescence also becomes a retrieval rule:
- reduce ordinary retrieval/action-guidance of stale or irrelevant material;
- preserve enough provenance/history for audit and later reactivation when needed.

This differs from accidental deletion/loss.
