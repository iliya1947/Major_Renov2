# NEU-18 — Errors and correction

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

A visible movement deviation is not a diagnosis.

A defensible project workflow is:

`define task criterion`
→
`separate outcome vs movement error`
→
`check recurrence under comparable conditions`
→
`separate solution variability from actual error`
→
`generate candidate constraints`
→
`measure / perturb one plausible driver`
→
`observe response`
→
`select correction`
→
`verify retention/transfer when learning is claimed`.

Project rule:

**correct what is causally relevant to the task, not merely what looks different from a preferred template.**

---

## 1. Outcome error

Outcome error means failure to satisfy the task-success criterion.

Examples:

- failed repetition;
- missed target;
- insufficient prescribed ROM;
- failure to satisfy competition/task requirement.

Outcome error does not prove bad technique.

---

## 2. Movement error

Movement error means violation of a justified execution criterion.

It is not:

- any visible variation;
- difference from an expert;
- difference from the previous repetition.

Project rule:

**a movement criterion must be justified by task, safety, competition or transfer requirements.**

---

## 3. Sensory prediction error

Sensory prediction error is a different construct from coaching outcome/movement error.

Current experimental evidence shows sensory-prediction-error-driven adaptation can be dissociated from task-performance error.

Project rule:

**do not collapse outcome error, movement criterion and sensory prediction error.**

---

## 4. Stable vs random error

Operationally:

### Stable/systematic
A similar task-relevant deviation recurs across comparable attempts.

### Random/variable
Direction or magnitude fluctuates substantially across comparable attempts.

Project rule:

**recurrence tells us the phenomenon is repeatable; it does not identify the cause.**

No universal minimum repetition count is established.

---

## 5. Variability ≠ error

Human movement naturally varies.

Some variability represents:

- exploration;
- alternative task-successful solutions;
- adaptable coordination.

Some variability represents:

- task error;
- instability that degrades outcome.

Project rule:

**separate solution variability from error variability before correcting movement.**

---

## 6. Task misunderstanding

An error can arise because the learner has the wrong or imprecise task representation.

Possible signs:

- unclear success criterion;
- confusion between outcome and stylistic detail;
- immediate improvement after clarifying the task.

Project rule:

**clarify the task goal before adding technical corrections when misunderstanding is plausible.**

---

## 7. Strength / force capacity

Strength can constrain which movement solutions are available.

But visible movement does not identify one weak muscle.

Project rule:

**treat strength deficit as a candidate cause that requires actual demand/capacity evidence.**

---

## 8. Mobility

Mobility can constrain movement geometry.

Limited ankle dorsiflexion, for example, can be associated with altered squat pelvis/hip/lumbar/trunk kinematics.

But:

**forward lean ≠ ankle restriction by default.**

Project rule:

**measure the relevant mobility and test whether modifying the constraint changes the pattern.**

---

## 9. Excessive load

Load changes the motor problem.

Higher load can change:

- velocity;
- joint moments;
- segment coordination;
- sticking-region mechanics;
- relative joint contribution.

Project rule:

**a pattern appearing only under high load may be a demand-dependent strategy/capacity problem rather than misunderstanding.**

---

## 10. Fatigue

Fatigue/proximity to failure can change:

- velocity;
- power;
- movement mechanics;
- variability.

Project rule:

**state-dependent technique change is not automatically loss of learned skill.**

Compare early vs late set/session and post-recovery execution.

---

## 11. Bad cue

Instructions can themselves create a poor or different movement solution.

Project rule:

**if a deviation appears after a cue, remove or rephrase the cue before stacking more instructions.**

---

## 12. Inappropriate movement solution

A movement solution is inappropriate only relative to a justified criterion.

It is not inappropriate merely because it differs from a model.

Project rule:

**correct task-relevant failure, not harmless individuality.**

---

## 13. Correct the cause, not the symptom

This is a diagnostic heuristic, not a one-to-one causal law.

Candidate drivers include:

- task understanding;
- load;
- fatigue;
- mobility;
- force capacity;
- cue/instruction;
- equipment/setup/environment;
- movement-solution choice.

Project rule:

**test plausible causes rather than asserting them from appearance.**

---

## 14. One-constraint perturbation

A practical N-of-1 workflow:

1. identify a plausible driver;
2. change one main constraint while holding others stable;
3. observe whether the target pattern changes as predicted;
4. update the hypothesis.

Examples:

- lower load;
- retest after recovery;
- change heel elevation/stance/ROM;
- clarify task criterion;
- remove/rephrase cue.

This is not a medical diagnostic protocol.

---

## 15. Task/environment manipulation

Changing task/environment can directly change the available movement solution.

Examples:

- load;
- stance;
- heel elevation;
- ROM target;
- equipment/setup;
- external target.

Project rule:

**use constraint manipulation when it directly addresses the relevant problem; do not treat it as universally superior to verbal instruction.**

---

## 16. Errorless learning

Errorless learning deliberately constrains practice to reduce errors early.

Current meta-analytic evidence does not show a consistent universal advantage over errorful learning.

Project rule:

**errorless practice is one tool, not the default learning law.**

---

## 17. Informative error

The goal is not zero error.

Useful learning can include:

- manageable task error;
- solution exploration;
- comparison between success and failure.

Project rule:

**seek informative, tolerable error rather than zero error or uncontrolled failure.**

---

## 18. Heel elevation example

Heel elevation can change squat ankle and knee ROM and alter proximal kinematics.

This demonstrates:

**changing an environmental constraint changes the movement solution.**

It does not prove:

- better technique;
- motor learning;
- ankle restriction as the cause in every person.

---

## 19. Load and fatigue can mimic “technique errors”

Changes under high load/fatigue can include:

- greater trunk inclination;
- altered bar path;
- different joint contribution;
- slower sticking-region mechanics.

Project rule:

**first test demand/state effects before assuming the athlete forgot the technique.**

---

## 20. “Bad technique” is not a diagnosis

The same visible feature can arise from:

- misunderstanding;
- load;
- fatigue;
- mobility;
- capacity;
- cue;
- setup;
- harmless variability;
- measurement/viewpoint artifact.

Project rule:

**observed movement → hypothesis generation, not instant causal labeling.**

---

## 21. Medical boundary

Movement deviation does not diagnose pathology.

Pain, neurological symptoms, injury and medical restrictions belong MED.

Project rule:

**movement deviation ≠ pathology.**

---

## 22. Practical correction synthesis

For later resistance-exercise coaching:

1. define what criterion is actually failing;
2. confirm the pattern across comparable attempts;
3. distinguish functional variability from true task error;
4. identify several plausible causes;
5. test the most likely low-cost candidate first;
6. change one major constraint at a time;
7. verify whether the target variable changes;
8. avoid stacking cues when the cue itself may be the cause;
9. reduce load/retest after recovery before labeling demand-related change a learning problem;
10. verify delayed independent execution when claiming correction/learning.

Status:

**PRACTICAL_HEURISTIC**, not a universal diagnostic algorithm.

---

## 23. Canonical non-equivalences

1. Outcome error ≠ movement error.
2. Movement error ≠ sensory prediction error.
3. Failed repetition ≠ technique failure.
4. Movement deviation ≠ task failure.
5. Variability ≠ error.
6. Stable deviation ≠ known cause.
7. Random variability ≠ meaningless noise.
8. Different-from-model ≠ error.
9. High-load change ≠ lost technique.
10. Fatigue-related change ≠ lost learning.
11. Forward lean ≠ ankle restriction.
12. Visible compensation ≠ weak muscle.
13. Cue-induced change ≠ improvement.
14. Successful outcome ≠ optimal solution.
15. Errorless practice ≠ universally superior.
16. Constraints ≠ universally superior to verbal instruction.
17. Kinematic change ≠ durable learning.
18. Movement deviation ≠ pathology.
19. “Bad technique” ≠ causal diagnosis.

---

## 24. Measurement boundaries

### Outcome error
Failure of task outcome.

### Movement error
Violation of justified execution criterion.

### Stable/systematic pattern
Repeated similar deviation under comparable conditions.

### Random/variable pattern
Fluctuating deviation under comparable conditions.

### Solution variability
Different movements preserving task success.

### Error variability
Variation degrading task outcome/constraint.

### Candidate cause
Hypothesis requiring measurement or perturbation.

### Correction
Intervention aimed at a relevant driver/criterion.

### Compensation
Alternative strategy, not automatically wrong.

### Technical failure
Loss of a predefined acceptable task/movement criterion.

---

## 25. Confidence

### HIGH

- outcome/movement/SPE distinction;
- variability ≠ error;
- load and fatigue alter lifting mechanics;
- cues can reorganize movement;
- visual deviation does not reveal one cause;
- errorless learning is not universally superior;
- movement deviation ≠ pathology.

### MODERATE-HIGH

- mobility and capacity can constrain movement;
- task representation matters;
- solution variability can support transfer;
- constraint manipulation can help test causes.

### MODERATE

- cause-first correction workflow;
- one-constraint perturbation as coaching diagnostic method.

### LOW / CONTEXT-DEPENDENT

- exact cause of a specific technique deviation;
- muscle-specific diagnosis from appearance;
- exact load threshold for unacceptable technique;
- exact mobility threshold;
- lift-specific technical-failure geometry.
