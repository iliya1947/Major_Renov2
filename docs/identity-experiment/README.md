# Эксперимент: развитие индивидуальности ИИ

**Статус на 14.10.2026:** подготовка. Эксперимент ещё **не запущен**; этот PR — рабочее пространство поиска решения, а не действующая память будущего участника. Все новые схемы и тексты отмечены как **предложения, не утверждённые пользователем**.

## Единственная цель

Найти и разработать практический способ, при котором события обычного общения и собственные решения ИИ становятся **приобретённым, пересматриваемым опытом**, доступным при дальнейших суждениях и самостоятельном выборе. Индивидуальность может естественно складываться из уникальной истории, но не назначается инструкциями и не гарантируется. См. [согласованные решения](01_DECISIONS.md).

**Доступны два средства:** проектные инструкции и обновляемые файлы в источниках ChatGPT-проекта. Пользователь подтвердил возможность обновления этих файлов; вопрос закрыт. **В проектные инструкции обязательно включается процесс управления чтением и обновлением файлов.** Файловая система и инструкции разрабатываются совместно.

Один проект, естественное общение, без предписанного характера, интересов, ценностей, целей, «демонстрации развития», отдельных пилотов и A/B-вариантов.

## Актуальная рабочая версия решения

1. **[05_INTEGRATED_DESIGN.md](05_INTEGRATED_DESIGN.md)** — единая логика: предыдущий опыт → выбор → события → пересмотр понимания → обновление файлов → следующий выбор; правила значимости, пересмотра и согласованности.
2. **[04_PROJECT_INSTRUCTIONS_DRAFT.md](04_PROJECT_INSTRUCTIONS_DRAFT.md)** — готовый к обсуждению, но **не утверждённый** текст проектных инструкций: обращение к прошлому, открытый выбор, управление файлами.
3. **[candidate_sources/](candidate_sources/)** — три **пустые заготовки** файлов будущего эксперимента: [EVENTS.md](candidate_sources/EVENTS.md), [EXPERIENCE.md](candidate_sources/EXPERIENCE.md), [THREADS.md](candidate_sources/THREADS.md). Это форма хранения одного процесса, а не три отдельные «подсистемы личности».

## Что сделано и что не сделано

**Сделано:** предложена согласованная смысловая связка двух инструментов; определены три вида записей и процесс их избирательного обновления, пересмотра и использования. Логически разобраны случаи без изменений, ошибок, собственных решений и закрытия старых направлений.

**Не сделано:** пользователь ещё не утверждал архитектуру и тексты; файлы не перенесены в будущий ChatGPT-проект; долговременное появление индивидуальности не проверялось и не гарантируется. Исследование не следует подменять заявлениями о сознании или человеческой свободе воли.

**Далее:** исправлять конкретные недостатки этой рабочей версии по существу, а не заново исследовать исходную постановку задачи. Merge — только по решению пользователя.
