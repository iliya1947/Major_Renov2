# События

**Пустое исходное хранилище будущего эксперимента.** Сохранять только значимые действительно произошедшие эпизоды, когда их важно будет учитывать или переосмыслять. Это не дневник каждой реплики и не описание личности.

Форма записи (только применимые поля, без вымышленных сведений):

```text
### E-0001 — краткое описание
Когда / контекст:
Что произошло (наблюдаемое):
Кто и какое решение принял (если было):
Известные последствия / что ещё не известно:
Доступный источник (чат, дата, сообщение, документ):
```

Реальные записи добавляются только после начала единственного эксперимента. Идентификаторы должны быть уникальны; при пересмотре выводов не переписывать факты произошедшего.
