# GFT-19 — Методология психологического анализа

Статус: IN_PROGRESS. GFT-19.1–19.2 COMPLETE_FOR_SPECIFIED_SCOPE — общая методология, не специфическая эмпирика экстремального IQ.

**Ответственная сессия: Кира-4 — ASSIGNED, 27.11.2026, прямое назначение пользователя.** Канонический реестр: [PARALLEL_WORK.md](../PARALLEL_WORK.md).

**Локальное следующее действие:** GFT-19.3 — интеграция минимально достаточного индивидуального анализа, зависимость доказательств, пересмотр и сквозная проверка. Независимая методология; итоговое закрытие только после проверки GFT-16/17/18.

## Программа
Индивидуальные конфигурации, конкурирующие гипотезы, многоуровневые объяснения, контроль упрощения; практическая методология сложных индивидуальных конфигураций, предотвращение редукционизма, необоснованного упрощения, фрагментарности и искусственного усложнения.

## Исследовательская задача
Разработать проверяемые правила анализа, выбирать достаточную сложность модели, оценивать применимость и пересмотр при новых данных.

## Зависимости
Локальные GFT: 02, 16, 17, 18. Переиспользуемые области кабинета: INT-02, INT-03, INT-04, ETH; фактическую готовность проверить до исследования.

## Порядок внутри области
1. Уточнить определения, популяцию, измерения и типы утверждений.
2. Выделить ограниченные исследовательские вопросы, искать прямые и противоречащие результаты.
3. Отдельно проверять применимость к взрослым и верхнему хвосту; зафиксировать отсутствие данных без экстраполяции.
4. Синтезировать практические правила, границы и контрпримеры; проверить на новых синтетических задачах.
5. Сохранить блоки в этом каталоге и обновить локальные реестры; закрытие по [ASSESSMENT_PROTOCOL](../ASSESSMENT_PROTOCOL.md).

Навигация: [план](../CURRICULUM.md) · [карта](../RESEARCH_MAP.md) · [очередь](../RESEARCH_QUEUE.md) · [шаблон](../RESEARCH_TEMPLATE.md).

## Уточнение после аудита программы
Сохранять контекст и зависимости; выявлять собственные предпосылки, сравнивать минимально достаточные и более сложные модели, перестраивать архитектуру при опровержении; проверять пользу для самопонимания.
Эти процессы — вопросы исследования, не обязательные признаки высокого IQ. Для выводов о взрослых с IQ 150–160+ нужны данные соответствующей популяции и проверяемых измерений; альтернативные объяснения и непрямой перенос маркировать отдельно.
