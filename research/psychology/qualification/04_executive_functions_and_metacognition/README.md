# Executive functions and metacognition

## Purpose

This directory stores topic-level qualification material for **Executive functions and metacognition**.

## Completed blocks

1. `EXE-01_executive_functions_cognitive_control_architecture.md` — executive-function/cognitive-control architecture, unity/diversity, task impurity, goal representation, response selection/inhibition, switching, monitoring, proactive/reactive control, effort/allocation, and a reusable Executive Control Inference Gate.
2. `EXE-02_goal_representation_proactive_reactive_hierarchical_control.md` — goal/task representations, maintenance/shielding/updating, hierarchical control, proactive/reactive modes, context processing, control-state reconfiguration, and a reusable Goal-Control Inference Gate.
3. `EXE-03_response_selection_inhibition_stopping_interference_control.md` — response selection, restraint/cancellation, Stop-Signal modeling, trigger failures, interference control, distractor/memory suppression, trait limits, and a reusable Inhibition Inference Gate.
4. `EXE-04_task_switching_cognitive_flexibility_reconfiguration.md` — local switch versus mixing costs, reconfiguration versus residual interference, cue/stimulus/response-set switching, stability/flexibility, voluntary switch readiness, measurement limits, and a reusable Task Switching / Flexibility Inference Gate.
5. `EXE-05_performance_monitoring_error_conflict_adaptation_control_adjustment.md` — error/conflict/surprise monitoring, ERN/Pe limits, post-error slowing, congruency-sequence effects, adaptation versus awareness, measurement limits, and a reusable Performance Monitoring Inference Gate.
6. `EXE-06_control_allocation_cognitive_effort_demand_avoidance_expected_value.md` — capacity versus allocation, objective demand versus subjective effort, EVC, demand avoidance/discounting, effort-cost theories, learning value, measurement limits, and a reusable Control Allocation / Effort Inference Gate.
7. `MET-01_metacognition_monitoring_confidence_calibration_control.md` — first-order/second-order boundaries, confidence bias, calibration, metacognitive sensitivity/efficiency, local/global self-evaluation, prospective/retrospective judgments, task/self-report limits, and a reusable Metacognitive Inference Gate.
8. `MET-02_metacognitive_control_information_revision_abstention_stopping.md` — information seeking, revision, abstention, help/social information use, strategy selection, study allocation, stopping rules, measurement reactivity, and a reusable Metacognitive Control Inference Gate.
