# Behavior change and intervention science

## Purpose

This directory is the canonical storage location for the **BHC** Phase C qualification domain.

BHC covers generic behavior-change and intervention science, including intervention efficacy, mechanisms of change, adherence/engagement, behavior-maintenance/relapse, implementation/context, treatment heterogeneity, mediation/moderation, and the boundary between package efficacy and active mechanism.
