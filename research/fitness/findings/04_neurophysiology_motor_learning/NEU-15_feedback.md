# NEU-15 — Feedback

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Feedback is not one variable.

A defensible project model is:

`source`
+
`content`
+
`modality`
+
`timing`
+
`frequency/schedule`
+
`learner self-evaluation`
+
`task/goal`
→
`practice performance + retention + transfer`.

Project rule:

**use feedback to add task-relevant information and calibrate learner self-evaluation; do not apply one universal timing/frequency schedule.**

---

## 1. Intrinsic feedback

Intrinsic feedback is naturally available task-generated sensory information.

It can include:

- proprioception;
- vision;
- audition;
- tactile input;
- vestibular input;
- force/effort sensation.

It does not mean only “internal bodily sensation.”

Project rule:

**intrinsic feedback is information available from performing the task without an added external information channel.**

---

## 2. Augmented / extrinsic feedback

Augmented feedback is externally supplied information that supplements intrinsic feedback.

Examples:

- coach statement;
- video replay;
- force/velocity display;
- auditory signal;
- haptic guidance;
- software/AI.

Project rule:

**augmented feedback is an information source, not a single intervention.**

---

## 3. KR

Knowledge of results provides information about task outcome relative to the goal.

Examples:

- velocity;
- accuracy;
- target miss distance;
- time;
- success/failure against a criterion.

Question answered:

> What happened?

KR does not necessarily specify how to change movement.

---

## 4. KP

Knowledge of performance provides information about movement execution.

Examples:

- trunk angle;
- bar path;
- segment timing;
- knee displacement.

KP can be:

- descriptive;
- prescriptive.

Project rule:

**descriptive and prescriptive KP must be separated.**

---

## 5. KR vs KP

No universal hierarchy is established.

### KR is useful when

- outcome error is informative;
- learner can search for a movement solution;
- one exact movement geometry is not required.

### KP is useful when

- learner cannot identify why the outcome occurred;
- a specific movement feature matters;
- novice lacks task-relevant movement information.

Current novice-dominant evidence suggests:

- KR + prescriptive KP can outperform KR alone;
- prescriptive KP can be more useful than descriptive KP.

Project rule:

**select KR or KP according to the missing information, not by a universal content hierarchy.**

---

## 6. Immediate vs delayed feedback

Immediate post-response feedback can improve acquisition.

Delayed feedback can sometimes improve retention by allowing:

- intrinsic processing;
- self-estimation;
- error comparison.

No universal optimal delay duration is established.

Project rule:

**delay is useful only if it preserves or improves task-relevant processing; immediate feedback is not automatically superior.**

---

## 7. Concurrent vs terminal feedback

Concurrent feedback occurs during execution.

Terminal feedback occurs after movement completion.

Concurrent feedback can:

- improve online correction;
- reduce practice error;
- support difficult task execution.

But it can also create withdrawal cost in some tasks.

Terminal feedback may preserve more learner-generated control.

Project rule:

**better guided practice performance under concurrent feedback does not prove better learning.**

---

## 8. Feedback frequency

Feedback frequency can be reported as:

- absolute number of feedback events;
- relative percentage of trials.

The classical guidance hypothesis predicts a general reduced-frequency advantage for retention.

Current meta-analytic evidence does **not** support that as a robust universal law.

Project rule:

**do not prescribe one feedback percentage across tasks.**

---

## 9. Guidance hypothesis

Guidance/dependency effects can occur.

But:

- high frequency is not automatically harmful;
- reduced frequency is not automatically superior;
- frequency alone does not determine learning.

Project rule:

**treat guidance as a possible task-specific mechanism, not a universal feedback law.**

---

## 10. Faded feedback

Faded feedback gradually reduces support.

It has positive retention/transfer evidence in some tasks.

A recent walking RCT found better 24/48-h retention and transfer with 50% faded KR than constant KR.

But no universal:

- fade rate;
- starting frequency;
- final frequency

is established.

Project rule:

**fade feedback when learner-generated control is becoming reliable, then verify retention/transfer.**

---

## 11. Bandwidth feedback

Bandwidth feedback is delivered when performance error exceeds a predefined tolerance.

It simultaneously changes:

- feedback frequency;
- information meaning.

No feedback inside the band itself communicates that performance is acceptable.

Project rule:

**use a task-relevant tolerance, not a universal percentage band.**

---

## 12. Summary feedback

Summary feedback batches information after several attempts.

Potential functions:

- less trial-by-trial guidance;
- more intrinsic processing;
- pattern recognition across attempts.

No universal summary length exists.

Project rule:

**summary feedback is an option for batching information, not a fixed “every N reps” law.**

---

## 13. Self-controlled feedback

Self-controlled feedback lets the learner choose whether/when feedback is provided.

The 2025 meta-analysis found:

- no significant acquisition advantage;
- positive retention effect;
- positive transfer effect.

But:

- heterogeneity was substantial;
- retention/transfer comparisons showed publication-bias signals;
- many studies were small.

Project rule:

**self-controlled feedback is a promising option, not a universal superiority rule.**

---

## 14. Feedback dependency

Feedback dependency means:

> independent performance deteriorates when augmented feedback is removed.

It cannot be inferred solely from:

- 100% frequency;
- concurrent presentation;
- frequent coaching.

Project rule:

**demonstrate dependency using no-feedback retention/transfer.**

---

## 15. Learner error detection

Learner error detection is the ability to estimate/evaluate one's own performance using intrinsic information.

Evidence shows that requiring self-estimation can materially alter feedback effects.

In one KR-frequency experiment:

- 100% KR + learner error estimation produced strong retention;
- 100% KR without estimation produced poor retention.

Project rule:

**feedback should calibrate learner error detection rather than permanently substitute for it.**

---

## 16. Feedback dimensions must remain separate

### Source
Intrinsic vs augmented.

### Content
KR vs KP; descriptive vs prescriptive.

### Modality
Visual, verbal, auditory, haptic, multimodal.

### Timing
Concurrent vs terminal; immediate vs delayed.

### Schedule
Constant, reduced-frequency, faded, bandwidth, summary, self-controlled.

These dimensions can be combined independently.

Example:

- terminal visual KP;
- concurrent auditory KR;
- faded verbal prescriptive KP;
- self-controlled video feedback.

---

## 17. Resistance-training feedback

Resistance-training feedback evidence supports acute performance benefits.

Meta-analytic evidence shows:

- higher barbell velocity on average;
- positive acute performance effects;
- possible chronic benefits.

But most outcomes are not delayed technique-learning tests.

Project rule:

**acute strength/velocity gain from feedback ≠ durable motor learning.**

---

## 18. Squat feedback

Direct squat evidence exists.

A randomized trial in novices found:

- visual/video feedback improved multiple squat variables;
- selected changes persisted 3 days to 1 week;
- tactile feedback did not show comparable retention.

This is direct acquisition/retention evidence.

But:

- sample was small;
- one exercise;
- no factorial comparison of feedback schedules.

Project rule:

**visual feedback can help novice squat learning under some protocols, but no universal squat feedback architecture is established.**

---

## 19. Technology vs trainer feedback

Technology is not inherently superior.

A five-week study in untrained women found no significant between-group advantage of technological over traditional trainer feedback.

Project rule:

**choose feedback modality by information quality, usability, access and task relevance.**

---

## 20. Real-time / AI feedback

Current AI real-time feedback evidence can show large post-intervention performance effects.

But the 2026 meta-analysis had:

- extreme heterogeneity;
- prediction interval crossing zero;
- very low certainty;
- no pooled delayed retention/transfer outcomes.

Project rule:

**real-time performance improvement is not durable motor learning unless retention/transfer is tested.**

---

## 21. Practical coaching synthesis

For later resistance-exercise technique work:

1. let the learner experience the attempt and intrinsic information;
2. when feasible, ask for a brief self-estimate of outcome/error;
3. give KR when the outcome is unclear;
4. give targeted/prescriptive KP when movement information is missing;
5. use concurrent feedback when online guidance is needed;
6. verify independent execution without concurrent feedback;
7. use terminal/delayed feedback when preserving self-processing matters;
8. fade/reduce feedback only when it remains informative and independence is improving;
9. use self-controlled feedback when learner autonomy is useful;
10. verify learning through no-feedback retention/transfer.

Status:

**PRACTICAL_HEURISTIC**, not a universal feedback algorithm.

---

## 22. Canonical non-equivalences

1. Intrinsic feedback ≠ only internal bodily sensation.
2. Augmented feedback ≠ KR only.
3. KR ≠ KP.
4. Descriptive KP ≠ prescriptive KP.
5. KP ≠ universally superior to KR.
6. KR ≠ universally superior to KP.
7. Immediate ≠ universally better.
8. Delayed ≠ universally better.
9. Concurrent ≠ terminal.
10. Better guided practice ≠ better learning.
11. High feedback frequency ≠ automatically harmful.
12. Reduced frequency ≠ universally superior.
13. Fading ≠ universal optimum.
14. Bandwidth ≠ one fixed error percentage.
15. Summary feedback ≠ one fixed summary length.
16. Self-controlled feedback ≠ universally superior.
17. Frequent feedback ≠ proven dependency.
18. Acute RT feedback benefit ≠ technique learning.
19. Visual feedback ≠ universally best.
20. Feedback after every error ≠ best error detection.

## 23. Measurement boundaries

### Acquisition
Performance during feedback-supported practice.

### Retention
Delayed performance, ideally without the augmented feedback being tested.

### Transfer
Performance in a changed/untrained condition.

### Dependency
Withdrawal-related loss of independent performance.

### Error detection
Accuracy of learner's own estimate.

### Technical competency
Defined movement-quality/functional criterion.

### Acute RT output
Velocity/force/repetition output; not equivalent to learning.

---

## 24. Confidence

### HIGH

- intrinsic vs augmented distinction;
- KR vs KP distinction;
- descriptive vs prescriptive KP distinction;
- acquisition ≠ retention/transfer;
- reduced-frequency superiority is not a universal law;
- dependency must be demonstrated after withdrawal;
- acute RT output ≠ motor learning.

### MODERATE-HIGH

- prescriptive KP can benefit novices;
- concurrent feedback can create withdrawal cost in some tasks;
- learner error estimation can improve retention;
- visual feedback can improve novice squat retention;
- self-controlled feedback can support retention/transfer.

### MODERATE

- faded feedback as adaptive strategy;
- delayed feedback to support self-processing;
- bandwidth feedback;
- summary feedback.

### LOW / CONTEXT-DEPENDENT

- exact feedback percentage;
- exact delay;
- exact fade rate;
- exact bandwidth;
- exact summary length;
- exact compound-lift feedback architecture;
- technology/AI superiority.

### NOT ESTABLISHED AS UNIVERSAL

- KP > KR;
- KR > KP;
- immediate > delayed;
- terminal > concurrent;
- reduced frequency > high frequency;
- faded > constant;
- self-controlled > coach-controlled;
- frequent feedback = dependency.
