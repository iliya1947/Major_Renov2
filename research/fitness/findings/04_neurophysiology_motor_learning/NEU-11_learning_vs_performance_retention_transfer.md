# NEU-11 — Learning vs performance / retention / transfer

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Motor learning is a durable change in capability inferred from later behavior, not directly observed from practice performance alone.

Canonical model:

`practice conditions`
→
`acquisition performance`
≠ automatically
`durable learning`.

Durable learning is better inferred through:

`delayed retention`
+
`transfer/generalization where relevant`.

Other distinct properties include:

- automaticity;
- relearning/savings;
- fatigue robustness;
- pressure robustness.

Project rule:

**one good practice session is not evidence that a motor skill has been learned.**

## 1. Performance vs learning

Motor performance is observable task output at a given moment.

Motor learning is a relatively durable change in capability attributable to practice/experience.

Performance can change transiently because of:

- feedback;
- fatigue;
- warm-up;
- motivation;
- strategy;
- task familiarity.

Project rule:

**performance during practice ≠ learning.**

## 2. Acquisition

Acquisition is the practice-phase trajectory of performance.

It can show:

- error reduction;
- improved speed/accuracy;
- changing coordination;
- responsiveness to feedback.

Project rule:

**acquisition describes current practice performance but does not establish durable learning.**

## 3. Retention

Retention tests persistence after a delay without substantial re-practice.

Interpretation depends on:

- delay;
- test conditions;
- feedback/instruction;
- warm-up/reminder trials;
- exact performance variable.

Project rule:

**retention must be delayed and explicitly defined; there is no universal retention interval or motor-skill half-life.**

## 4. Transfer

Transfer is expression of training benefit in an untrained target condition.

Possible changed dimensions include:

- load;
- speed;
- movement;
- limb;
- equipment;
- environment;
- dynamics.

Project rule:

**transfer must be measured in the target condition and cannot be assumed from retention of the trained task.**

## 5. Generalization

Project operational convention:

- generalization = expression of learning across related values/contexts within a task space;
- transfer = broader effect in a different target condition/task.

Literature terminology overlaps.

Project rule:

**retention strength and generalization breadth are different properties.**

## 6. Automaticity

Automaticity is gradual/partial reorganization or reduction of higher-level control demands.

Project rule:

**automaticity ≠ zero attention ≠ an all-or-none autonomous stage.**

Dual-task cost is one possible probe, not a universal score.

## 7. Relearning / savings

Savings is faster/more efficient reacquisition after prior learning.

Project rule:

**relearning/savings ≠ full overt retention.**

Savings can reveal retained learning history but does not prove one unique neural-memory mechanism.

## 8. Fatigue robustness

Fatigue can alter acquisition and retained performance in task- and fatigue-specific ways.

Project rule:

**rested retention does not prove fatigued-state robustness.**

Practicing under fatigue also does not automatically create fatigue resilience.

## 9. Pressure robustness

Psychological pressure can facilitate or impair performance depending on person/task/context.

Project rule:

**calm retention does not prove pressure robustness.**

Pressure-specific performance must be assessed in the relevant context.

## 10. Exercise technique as motor skill

Exercise technique is an executable sensorimotor capability involving:

- perception;
- task goal;
- coordination;
- prediction;
- feedback;
- force control;
- repeated practice;
- retained execution.

Project rule:

**technique is not merely verbal-rule knowledge.**

Knowing a rule does not prove the person can execute it under load or altered conditions.

## 11. Technique does not imply one universal geometry

Motor control permits multiple successful task solutions.

Project rule:

**learning technique means improving reliable control within acceptable task constraints, not necessarily reproducing one universal kinematic template.**

Exact acceptable-technique criteria remain TEC/MEC.

## 12. Measurement boundaries

### Acquisition score
Practice-phase performance only.

### Immediate post-test
May still contain temporary guidance/performance effects.

### Delayed retention
Tests durability under defined conditions.

### Transfer test
Tests an explicitly untrained target condition.

### Generalization test
Tests expression across a related task/context dimension.

### Dual-task cost
Probes attentional demand/automaticity.

### Savings
Tests reacquisition advantage.

### Fatigued performance
Tests state-dependent robustness.

### Pressure performance
Tests pressure-context robustness.

Project rule:

**motor-learning claims must specify which learning dimension was actually measured.**

## 13. Canonical project rules

1. Practice performance is not learning.
2. Acquisition is not retention.
3. Immediate post-test is not durable retention.
4. Retention is task/outcome/delay specific.
5. Retention does not guarantee transfer.
6. Transfer must be tested in the actual target condition.
7. Generalization breadth can differ from retention strength.
8. Automaticity is graded rather than binary.
9. Savings is distinct from overt retention.
10. Rested retention does not prove fatigue robustness.
11. Rested retention does not prove pressure robustness.
12. Exercise technique is a practiced motor skill.
13. Verbal knowledge does not guarantee executable technique.
14. Learned technique does not require one universal geometry.
15. Strength expression contains a task-specific skill component.

## 14. Training-relevant implications

1. **Do not judge technique learning from the best set of one session.**
2. **Use delayed retention when the question is whether technique was learned.**
3. **Use target-specific transfer tests when load, speed, implement or exercise changes.**
4. **Do not infer complete automaticity from smooth-looking technique.**
5. **After a break, assess both current performance and relearning speed.**
6. **Test fatigue robustness under the relevant fatigue state when it matters.**
7. **Test pressure robustness under realistic pressure when it matters.**
8. **Teach technique through repeated execution, not verbal rules alone.**
9. **Do not require exact repetition identity if task-relevant control remains acceptable.**

## 15. What NEU-11 does not prescribe

Not owned here:

- explicit vs implicit learning method;
- constraints-led coaching;
- practice frequency/volume;
- blocked vs random practice prescription;
- attentional focus;
- feedback frequency/timing;
- cue wording;
- demonstration/video use;
- error-correction method;
- exact acceptable exercise technique.

These remain NEU-12…18, TEC/MEC, TST, COA, PRO and IND.

## 16. Confidence

### HIGH
- performance-learning distinction;
- acquisition-retention dissociation;
- delayed retention as stronger durability evidence;
- task-specific transfer;
- retention vs savings distinction;
- fatigue robustness as state dependent;
- exercise technique has a motor-skill component.

### MODERATE-HIGH
- automaticity as graded;
- retention strength can dissociate from generalization breadth;
- pressure robustness as context dependent;
- delayed retention of some squat-technique variables.

### MODERATE / CONTEXT-DEPENDENT
- terminology boundary between transfer and generalization;
- optimal retention interval for a given lift;
- best automaticity metric for complex RT;
- best fatigue/pressure exposure for robustness;
- exact transfer across heavy compound lifts.

### NOT ESTABLISHED AS UNIVERSAL
- one retention interval proving learning;
- one motor-skill decay rate;
- one transfer coefficient;
- one automaticity threshold;
- one fatigue-inoculation method;
- one pressure-training prescription;
- one universal ideal technique.
