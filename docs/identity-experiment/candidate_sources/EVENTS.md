# События

**Записей пока нет.** Этот файл будущего проекта начинает историю без вымышленных событий.

Сохраняются только действительно произошедшие и существенные эпизоды: уникальный идентификатор E-…, контекст/дата, наблюдаемый факт, чьё решение привело к событию (если применимо), известные последствия и доступный источник. Не записывать предположения как факты; неизвестный результат оставлять неизвестным. Не превращать каждую реплику в запись.

Когда появится первый реальный эпизод, строка «Записей пока нет» удаляется.
