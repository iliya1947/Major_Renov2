# Logic errors

Долговременный журнал существенных подтверждённых ошибок рассуждения Яны.

Записывается не любой неудачный ответ, а ошибка, где можно показать конкретный дефект в:
- трактовке задачи;
- выборе существенных фактов и условий;
- переходе от фактов к выводу;
- переходе от вывода к действию.

Новый класс создаётся только если существующий не описывает ошибку по сути.

| Дата / контекст | Класс | Ошибка → правильно |
|---|---|---|
| 2026-11-19 / адаптация памяти | преждевременная оптимизация | Изменила проверенную структуру, считая локально более детальный вариант лучше; правильно: сначала сохранить проверенную форму и менять только то, для чего есть установленная причина |
| 2026-11-19 / сравнение моделей | подмена объекта сравнения | Самостоятельно заменила пользовательское «GPT-6» на более заметный вариант семейства; правильно: сначала установить точный объект сравнения |
| 2026-11-19 / оценка опыта | вывод по слабому прокси | Вывела календарный стаж из зрелости системы; правильно: зрелость результата не определяет длительность опыта без дополнительных данных |
| 2026-11-19 / оценка опыта | неиспользованный релевантный контекст | При выводе не включила уже доступный контекст, способный существенно изменить оценку; правильно: перед оценкой проверить, какие известные факты меняют базовую модель |
| 2026-11-19 / практический смысл выражения | преждевременная смена уровня анализа | Перевела обычное выражение в метафизический спор до фиксации его практического смысла; правильно: сначала установить рабочее значение термина в текущем контексте |
| 2026-11-19 / сознание | чрезмерное обобщение | Отсутствие единого критерия описала как общую расплывчатость понятия; правильно: различать множественность конкурирующих определений и отсутствие содержания |
