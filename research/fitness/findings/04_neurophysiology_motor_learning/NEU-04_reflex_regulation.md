# NEU-04 — Reflex regulation

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Reflexes are task-dependent sensorimotor gain-control processes, not fixed protective switches.

Canonical model:

`sensory perturbation`
`→ afferent input`
`→ spinal + supraspinal processing`
`→ task-dependent motor response`.

## 1. Stretch reflex

The mechanically evoked stretch response can include:

- short-latency spinal response;
- interneuronal modulation;
- descending/background drive;
- long-latency supraspinal feedback.

Project rule:

**stretch reflex ≠ one fixed monosynaptic response.**

## 2. Monosynaptic component

The classic shortest arc is:

`Ia muscle-spindle afferent → alpha motor neuron`.

Project rule:

**“monosynaptic” describes this shortest central component, not the whole observed reflex.**

## 3. H-reflex

H-reflex electrically stimulates peripheral afferents and bypasses normal spindle mechanical transduction.

Project rule:

**H-reflex ≠ natural stretch reflex and ≠ pure CNS/motoneuron excitability.**

## 4. Reciprocal inhibition

Ia inhibitory interneurons can reduce antagonist motoneuron output.

But expression depends on:
- task;
- phase;
- descending command;
- background activation.

Project rule:

**reciprocal inhibition ≠ antagonist completely switches off.**

## 5. GTO / Ib feedback

GTOs provide force-related Ib input.

Ib effects can be:
- inhibitory;
- facilitatory;
- redistributed across motor pools.

Project rule:

**GTO ≠ high-force emergency brake.**

There is no canonical “strength gains by overcoming GTO inhibition” mechanism.

## 6. Presynaptic modulation

Afferent transmission can be modulated before effective motoneuron activation.

Modern PAD evidence shows some GABAergic axo-axonic mechanisms can facilitate afferent spike propagation.

Project rule:

**presynaptic/PAD control ≠ universal inhibition.**

## 7. Rapid corrective responses

Short latency:
- mainly spinal.

Long latency:
- supraspinal/task dependent;
- corticospinal contribution;
- current human evidence also supports online reticulospinal contribution.

Project rule:

**rapid correction uses multiple levels of the nervous system.**

## 8. Stretch-shortening cycle

SSC performance reflects interaction among:

- feedforward preactivation;
- reflex feedback;
- tendon/series-elastic behavior;
- muscle-tendon interaction;
- force-velocity effects;
- history-dependent contractile properties.

Project rule:

**SSC ≠ stretch-reflex power alone.**

## 9. Fast/slow SSC boundary

The common ~250 ms contact-time threshold is useful as an operational label.

Project rule:

**250 ms is not an established biological/reflex discontinuity.**

## 10. Canonical project rules

1. Stretch reflex is multi-latency and task dependent.
2. Monosynaptic Ia arc is only the shortest component.
3. H-reflex is an experimental spinal probe, not the natural reflex itself.
4. Reciprocal inhibition is regulated, not all-or-none.
5. GTO/Ib feedback is distributed force feedback, not an emergency shut-off.
6. Presynaptic/PAD control is not uniformly inhibitory.
7. Short- and long-latency feedback use different nervous-system levels.
8. Reflex gain is not universally better when larger.
9. SSC is neural + mechanical + history dependent.
10. ~250 ms SSC classification is operational, not biological.

## 11. Training-relevant implications

1. **Do not use “GTO inhibition” as a strength-training explanation.**
2. **Do not equate H-reflex changes with total neural adaptation.**
3. **Do not assume less antagonist activity is always better; co-contraction can be functional.**
4. **Do not diagnose presynaptic inhibition from one reflex-amplitude change.**
5. **Do not describe plyometric output as a stretch-reflex effect alone.**
6. **Do not target “bigger reflexes” without a task-specific rationale.**
7. **Do not treat 250 ms ground contact as a neural threshold.**
8. **Keep detailed force-production mechanisms in NEU-05 and programming in PRO/GPP.**

## 12. What NEU-04 does not prescribe

Not owned here:

- reflex-training protocol;
- plyometric dosage;
- H-reflex interpretation for an individual;
- optimal co-contraction;
- injury-risk prediction;
- individual reflex limitation;
- exercise-specific SSC prescription.

These remain NEU-05/08/09/10, TST, TEC, PRO, GPP and IND.

## 13. Confidence

### HIGH
- monosynaptic Ia→alpha-MN component;
- H-reflex vs natural-reflex distinction;
- reciprocal-inhibition task dependence;
- rejection of simple GTO safety-brake model;
- spinal vs supraspinal latency distinction;
- SSC multi-mechanistic model.

### MODERATE-HIGH
- PAD facilitation of afferent transmission in some human contexts;
- online reticulospinal contribution to LLR;
- lack of a biological discontinuity at exactly 250 ms.

### MODERATE / CONTEXT-DEPENDENT
- exact reflex contribution to one resistance/plyometric exercise;
- exact Ib effects in a given task;
- optimal reflex gain for performance;
- exact spinal vs supraspinal weighting in one individual.
