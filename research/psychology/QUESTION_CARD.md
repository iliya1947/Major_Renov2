# Question Card — обязательный pre-search gate

Заполнять до нового substantive qualification search.

## 1. Concrete dependency

Какой reasoning failure / knowledge gap / downstream judgment требует работы?

## 2. Question type

- [ ] description
- [ ] prevalence/frequency
- [ ] association
- [ ] prognosis/prediction
- [ ] causal effect
- [ ] mechanism
- [ ] measurement
- [ ] diagnosis/classification
- [ ] intervention
- [ ] qualitative/process
- [ ] guideline/policy

## 3. Target construct

Что именно измеряется/объясняется?

## 4. Population / context

К какой scientific population/context относится вопрос?

## 5. Exposure / intervention / phenomenon

Что является X?

## 6. Comparator / alternative explanation

Что сравнивается или какая competing explanation должна быть отличена?

## 7. Outcome / target phenomenon

Что именно должно быть установлено?

## 8. Time / course

Какая временная шкала релевантна?

## 9. Eligible evidence

Какие designs реально способны ответить на claim?

## 10. Applicability boundary

Что evidence не сможет установить даже при положительном результате?

## 11. Privacy transform

Если вопрос возник из private material:

- [ ] personal context полностью удалён;
- [ ] вопрос сформулирован generic;
- [ ] из записи нельзя вывести private fact.

Если нет — repo write запрещён.

## 12. Closure criterion

Что должно быть установлено, чтобы блок можно было закрыть?

## 13. Scope-change log

Если scope меняется после просмотра evidence — записать что, почему и как это меняет interpretation.
