# NEU-02 — Motor units: recruitment/rate coding

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Motor force is controlled through interacting recruitment and discharge-rate mechanisms.

Canonical model:

`shared + task-specific synaptic input`
`→ orderly motor-unit recruitment`
`+ rate coding`
`→ muscle twitch summation / force`.

Observed behavior depends on:
- muscle;
- task;
- contraction speed;
- force profile;
- muscle length;
- fatigue;
- sensory input;
- neuromodulation.

## 1. Motor unit

A motor unit is:

`one alpha motor neuron + its axon/branches + all muscle fibers it innervates`.

Project rule:

**motor unit ≠ motor neuron alone.**

## 2. Motor-unit size

Size can refer to:
- motoneuron size/excitability;
- innervation ratio;
- motor-unit territory;
- twitch/tetanic force;
- MUAP-related features.

Project rule:

**one EMG amplitude is not a universal motor-unit-size measure.**

## 3. Recruitment threshold

Recruitment threshold is the task level at which a unit begins to discharge.

It can change with:
- muscle length/joint angle;
- force trajectory;
- contraction speed;
- fatigue/training;
- MVC normalization.

Project rule:

**recruitment threshold is context dependent, not a fixed unit identity.**

## 4. Size principle

Default architecture:

`smaller / more excitable motoneurons`
are generally recruited before
`larger / less excitable motoneurons`.

Project rule:

**size principle constrains recruitment order but does not impose one fixed %MVC threshold across tasks.**

## 5. Derecruitment

Units can stop firing at a different threshold from recruitment.

Contributors include:
- PICs;
- neuromodulation;
- inhibition/excitation balance;
- task history.

Project rule:

**derecruitment ≠ recruitment reversed.**

## 6. Recruitment and rate coding

Force rises through:
1. recruiting additional units;
2. increasing discharge rate of active units.

Project rule:

**neither mechanism alone explains force control across all muscles/force ranges.**

## 7. Temporal summation

Rate coding:
- neural discharge-frequency control.

Temporal summation:
- mechanical overlap/fusion of successive twitches.

Project rule:

**rate coding and temporal summation are linked but not synonymous.**

## 8. Common synaptic input

Motor-neuron pools receive substantial shared input.

This supports coordinated low-dimensional control.

Common-input composition can change with:
- force profile;
- muscle length;
- task.

Project rule:

**common input is fundamental but task modulated.**

## 9. Synchronization

Synchronization is correlated timing of motor-unit discharges.

Project rule:

**synchronization ≠ common-input strength and “more synchronization” ≠ automatically more strength/RFD.**

## 10. Effort level

As effort rises, neural output generally scales through recruitment + rate coding.

But:
- absolute firing rates differ among muscles;
- force–discharge slopes differ;
- fast and slow contractions can use different discharge/recruitment strategies.

Project rule:

**there is no universal firing-rate curve based only on %MVC.**

## 11. Fatigue

Fatigue can alter:
- firing rate;
- recruitment;
- common input;
- afferent regulation.

But patterns depend on task.

Project rule:

**firing-rate decline is not a universal cause or biomarker of fatigue.**

## 12. Slow / fast motor units

Useful archetypes:
- S;
- FR;
- FI;
- FF.

Project rule:

**retain physiological archetypes, but treat properties as overlapping/continuous and do not assign full human motor-unit phenotype from HD-sEMG alone.**

## 13. HD-sEMG limits

HD-sEMG decomposition provides high-resolution motor-unit samples.

Limits include:
- high force;
- dynamic tasks;
- high-threshold units;
- longitudinal tracking;
- algorithm validation;
- sample-size dependence.

Project rule:

**sampled motor units are not the complete active pool.**

## 14. Canonical project rules

1. Motor unit = alpha motor neuron + innervated fibers.
2. Motor-unit size is multidimensional.
3. Recruitment threshold is context dependent.
4. Size principle is the default recruitment architecture.
5. Size principle does not imply rigid task-independent thresholds.
6. Derecruitment is history dependent.
7. Recruitment and rate coding jointly control force.
8. Rate coding ≠ temporal summation.
9. Common input ≠ synchronization.
10. More synchronization is not a generic strength target.
11. Firing-rate patterns differ across muscles/tasks.
12. Fatigue-related firing-rate changes are task dependent.
13. Slow/fast motor-unit types are useful archetypes, not perfectly discrete human HD-sEMG labels.
14. HD-sEMG samples the pool rather than fully enumerating it.

## 15. Training-relevant implications

1. **Do not reduce motor-unit recruitment to external load alone.**
2. **Do not claim a fixed %MVC recruitment threshold across exercises.**
3. **Do not infer “all high-threshold units require heavy loads” from size principle alone.**
4. **Do not compare absolute firing rates across muscles without context.**
5. **Do not use synchronization as a generic neural-quality target.**
6. **Do not diagnose fatigue from firing-rate decline alone.**
7. **Do not infer full fast/slow phenotype from surface EMG alone.**
8. **Treat dynamic-exercise transfer from isometric MU studies cautiously.**

## 16. What NEU-02 does not prescribe

Not owned here:

- optimal training load;
- high-threshold-unit recruitment prescription;
- voluntary activation testing;
- RFD programming;
- fatigue-management rules;
- exercise-specific motor-unit strategy;
- individualized neural limitation.
