## 1. Purpose / Question Card

### Decision

Build a defensible error-diagnosis/correction framework for resistance-exercise coaching without:

- treating every task failure as a technique error;
- treating every movement deviation as an outcome failure;
- treating trial-to-trial variability as error;
- assuming a repeated visible deviation proves one cause;
- assuming mobility, strength, load or fatigue from appearance alone;
- correcting load/fatigue-driven mechanics with more verbal cueing;
- assuming a “bad-looking” but task-successful solution is wrong;
- assuming cue-induced changes are automatically improvements;
- using one expert geometry as the error reference;
- treating errorless practice as universally superior;
- turning constraints/task manipulation into a universal replacement for instruction;
- making medical/pathology diagnoses inside NEU-18.

### Primary downstream context

Healthy adult novice/intermediate resistance trainees learning or refining squat/hinge/press and related exercise technique.

### Critical outcomes

- task success;
- movement-quality criterion;
- consistency/reliability;
- independent retention;
- transfer across load/fatigue/context;
- safety/task constraints;
- correct identification of the limiting information/capacity when possible.

## 2. “Error” is not one construct

Motor-learning literature uses several distinct error concepts.

For this project, Section 18 uses a coaching taxonomy:

### Outcome error

Failure to meet the task criterion.

Examples:

- missed target;
- failed repetition;
- bar/path endpoint outside a defined criterion;
- insufficient depth if depth is a task requirement;
- failure to complete prescribed ROM.

### Movement error

Deviation from a **justified movement criterion** during execution.

Examples:

- loss of a defined positional constraint;
- movement feature known to interfere with the current task goal;
- violation of competition/safety/technical criterion.

Important:

**movement error is not synonymous with sensory prediction error.**

The 2026 J Neurosci study PMID 42680590 directly dissociated:

- sensory prediction error (SPE);
- task performance error (TPE).

SPE-driven adaptation was insensitive to TPE magnitude in that paradigm.

Canonical boundary:

**different error signals can coexist and drive different processes; a missed task outcome, a movement-criterion deviation and a sensory prediction error must not be collapsed.**

Confidence: **HIGH**.

## 3. Outcome error vs movement error

This distinction parallels the KR/KP distinction from NEU-15 but is not identical.

### Outcome error
Answers:

> Did the attempt satisfy the task goal?

### Movement error
Answers:

> Did execution violate a movement criterion that actually matters for this task?

Possible combinations:

1. good outcome + acceptable movement;
2. good outcome + movement criterion violation;
3. poor outcome + acceptable movement;
4. poor outcome + movement criterion violation.

Therefore:

**outcome failure does not prove bad technique, and visible movement deviation does not automatically explain the outcome failure.**

This is especially important in redundant multi-joint tasks.

Confidence: **HIGH for conceptual boundary**.

## 4. Stable vs random error — operational project distinction

“Stable vs random error” is not treated here as one universal formal taxonomy.

Operationally:

### Stable/systematic error pattern
A similar task-relevant deviation recurs across repeated comparable attempts.

### Random/variable error pattern
Direction/magnitude changes substantially trial to trial under comparable conditions.

This resembles classical:

- constant/directional error;
- variable error;

but the project does not assume classical one-dimensional scores map cleanly onto complex lifting.

Older motor-learning measurement literature already distinguishes bias from variability (e.g. PMID 3217208), while modern variability research shows that variability itself is multidimensional.

Canonical rule:

**identify whether the problem is recurrent/systematic or fluctuating, but do not infer cause from stability alone.**

Confidence: **HIGH for distinction / MODERATE for applied complex-lift labeling**.

## 5. Variability ≠ error

This is closure-critical.

The 2025 systematic review PMID 39547333:

- included 18 studies;
- found that greater initial motor variability was associated with better learning/adaptation in many studies;
- effects depended on task type and how variability was quantified.

The 2026 kettlebell-swing study PMID 42617501 is directly relevant:

- 12 young adults practiced kettlebell swing for one week;
- uncontrolled-manifold analysis separated **solution variability** from **error variability**;
- high early solution variability was associated with better transfer to a water-filled kettlebell;
- this benefit occurred when error variability was low.

Thus:

**different movement solutions can vary while preserving the task goal.**

Project rule:

`movement variability`
≠
`movement error`.

A coach should distinguish:

- variability within task-successful solution space;
- variability that actually degrades task outcome/constraint.

Confidence: **HIGH**.

---

## 6. Stable error ≠ same cause every time

A repeated visible deviation may be produced by different constraints.

For example, increased trunk inclination in squat could plausibly reflect:

- load-dependent strategy;
- ankle mobility restriction;
- hip/knee extensor capacity distribution;
- intended powerlifting technique;
- fatigue;
- cue-induced strategy;
- anthropometry.

Therefore:

**consistency increases confidence that a phenomenon is real; it does not identify its mechanism.**

Causal attribution requires an intervention/perturbation or converging evidence.

Status: **CORE DIAGNOSTIC PRINCIPLE**.

---

## 7. Error due to misunderstanding the task

Task representation can itself be wrong or imprecise.

PMID 32997556:

- different chunk instructions changed initial performance;
- misaligned instruction caused an initial deficit;
- instruction-dependent temporal pattern persisted after 10 days;
- learners eventually developed idiosyncratic stable execution strategies.

PMID 41309101 (2025/2026):

- n = 180 visuomotor participants;
- increasing uncertainty about the intended goal attenuated implicit adaptation even when later visual input was controlled.

These findings support:

**if the learner's task goal/reference is unclear or incorrectly represented, more repetition of the same instruction may reinforce the wrong search space.**

Practical diagnostic questions:

- Does the learner know the actual task goal?
- Can they describe/identify success?
- Do they distinguish outcome criterion from optional stylistic details?
- Does clarification of the task change performance immediately?

Status: **PRACTICAL_HEURISTIC grounded in instruction/goal-representation evidence**.

## 8. Error due to insufficient strength / force capacity

Strength can constrain movement strategy.

PMID 34712337:

- 53 participants squatted at 75% 1RM;
- relative muscular strength was associated with hip net joint torque and knee flexion angle;
- squat biomechanics related more strongly to relative strength and flexibility than to leg-length ratio in that sample.

Recent elite-powerlifting evidence further shows load-dependent redistribution of joint demand.

PMID 41826687:

- 29 elite powerlifters;
- 70–90% 1RM;
- increasing intensity increased hip moments;
- relative joint contribution shifted toward the hip;
- kinematics changed with intensity.

PMID 42342242:

- 8 elite powerlifters;
- 90, 95 and 100% 1RM;
- heavier load increased presticking knee torque, forward lean near end of sticking region, and reduced velocity;
- hip-to-knee torque ratio exceeded 3:1 in the sticking region.

These studies support **capacity-related constraints and strategy changes**.

They do not prove that a visible deviation in one individual is caused by “weak glutes,” “weak quads,” etc.

Canonical rule:

**insufficient force capacity is a candidate cause when the required task demand exceeds available capacity, but muscle-specific diagnosis cannot be made from appearance alone.**

Confidence: **MODERATE-HIGH for strength/capacity constraint / LOW for appearance-based muscle diagnosis**.

---

## 9. Error due to mobility limitation

Mobility can constrain available movement solutions.

PMID 41196246:

- 44 physically active adults;
- limited ankle dorsiflexion group had greater pelvis ROM, hip/lumbar flexion and forward trunk lean during squat;
- ankle dorsiflexion correlated with trunk lean in the limited group.

PMID 34712337 also linked flexibility measures with squat biomechanics.

Important boundary:

**association does not mean every trunk lean or knee pattern is caused by mobility restriction.**

A mobility hypothesis is stronger if:

1. a relevant mobility restriction is actually measured;
2. the task requires that ROM;
3. changing the mobility/environmental constraint changes the movement pattern in the predicted direction.

Confidence: **MODERATE-HIGH**.

---

## 10. Environment manipulation as a diagnostic test for mobility/geometry

Heel elevation provides a useful example.

2026 systematic review/meta-analysis PMID 41612762:

- 14 studies;
- n = 177;
- heel elevation increased ankle ROM by about 4.33° and knee ROM by about 4.94° on average;
- higher heel elevation showed a larger ankle effect;
- meta-regression suggested greater heel height was associated with reduced hip/trunk ROM.

This does not prove heel elevation “fixes technique.”

It shows:

**altering the task/environment constraint can change the solution directly.**

Diagnostic use:

- if a relevant movement limitation changes predictably when heel support changes, that strengthens a constraint-based hypothesis;
- if it does not, repeatedly cueing “stay upright” may be targeting the symptom rather than the driver.

Status: **PRACTICAL_DIAGNOSTIC_HEURISTIC**.

---

## 11. Error due to excessive load

Load changes the motor problem.

The 2025 systematic review PMID 41085612:

- 22 studies;
- 293 experienced lifters;
- higher intensity consistently reduced bar velocity/power;
- increased concentric duration;
- increased variability in joint mechanics, particularly around acceleration/sticking regions;
- different lifters adopted different mechanical strategies as intensity increased.

2026 elite data strengthen this:

- PMID 41826687: increasing 70→90% 1RM shifted relative support toward the hip;
- PMID 42342242: 90→100% 1RM altered torque, forward lean and velocity.

Therefore:

**a movement pattern that appears only at high load may be a load-specific motor solution, capacity limit or impending failure—not necessarily a failure of conceptual understanding.**

Practical discriminator:

`same instruction + lower load`
vs
`same instruction + problematic load`.

If the movement criterion returns immediately at lower load, more verbal correction at the heavier load may be the wrong first intervention.

Confidence: **HIGH that load alters mechanics / MODERATE for causal diagnosis in an individual**.

---

## 12. Error due to fatigue

Fatigue changes performance capacity and mechanics.

PMID 41085612:

- fatigue/proximity-to-failure reduced velocity/power;
- joint mechanics became more variable;
- effects differed across individuals/studies.

The review explicitly notes that many included studies inferred fatigue from proximity to failure/performance decline rather than directly measuring neuromuscular fatigue.

Therefore:

**fatigue is a state-dependent candidate cause, not a visual label.**

A technique deviation that:

- appears late in a set/session;
- co-occurs with velocity decline;
- disappears after recovery;

is more consistent with a fatigue-related hypothesis than the same deviation present from the first unloaded rehearsal.

But this remains inference unless the relevant state is measured/manipulated.

Confidence: **HIGH that fatigue affects mechanics / MODERATE for individual diagnosis**.

---

## 13. Load and fatigue effects can resemble “technical error”

This is a critical coaching trap.

Examples from the powerlifting review include load/fatigue-associated changes in:

- forward lean;
- spinal/trunk mechanics;
- bar path;
- sticking-region coordination;
- joint contribution;
- velocity.

Thus:

**a changing movement pattern under higher demand is not automatically evidence that the athlete “forgot technique.”**

It may represent:

- an adaptive redistribution;
- a compensatory solution;
- a capacity-limited solution;
- an actual criterion violation.

The distinction depends on the task goal and criterion.

## 14. Error due to a bad cue / instruction

Instructions can create or reinforce an undesirable movement solution.

PMID 32997556:

- misaligned instruction produced an initial performance deficit;
- instructional structure continued to shape temporal execution after prolonged practice.

Direct RT evidence also shows cueing can reorganize movement immediately.

PMID 42190132:

- generic “activate your core” did not change the intended trunk coordination;
- detailed coaching did;
- both cue conditions reduced maximal force.

PMID 33170116:

- internal vs external back-squat instructions redistributed muscle excitation.

Therefore:

**when a deviation appears after a cue, the cue itself becomes a candidate cause.**

Project rule:

**do not respond to a cue-induced problem by automatically adding more cues.**

Confidence: **HIGH for cue-induced reorganization / MODERATE for exact lifting correction**.

---

## 15. Error due to an inappropriate movement solution

A movement solution is “inappropriate” only relative to:

- task goal;
- load;
- safety/competition constraint;
- available capacities;
- transfer requirement.

It is not inappropriate merely because it differs from a model.

PMID 42617501 directly illustrates:

- high solution variability can support transfer;
- error variability can be harmful;
- solution and error variability must be separated.

NEU-09 motor abundance remains binding.

Canonical rule:

**first ask whether the solution fails a task-relevant criterion; do not correct harmless individual variation.**

Confidence: **HIGH**.

---

## 16. Outcome success does not prove an optimal movement solution

The reverse error also matters.

A successful repetition can still:

- violate a competition rule;
- exceed an agreed safety/comfort constraint;
- create unnecessary energy cost;
- be non-transferable to the intended load/context;
- rely on a transient compensation.

Therefore:

**outcome success is necessary for many tasks but may not be sufficient for coaching acceptance.**

Any additional movement criterion must be explicitly justified.

Status: **PRACTICAL_HEURISTIC**.

---

## 17. Correct the cause, not only the visible symptom

This is a **diagnostic heuristic**, not a claim that one can always identify a single biological cause.

The defensible formulation is:

> before repeatedly correcting a visible movement feature, test which modifiable constraint/information source is plausibly generating it.

Candidate domains:

1. task understanding;
2. load;
3. fatigue;
4. mobility;
5. force capacity;
6. cue/instruction;
7. equipment/setup/environment;
8. movement-solution selection.

A visible symptom may have multiple simultaneous causes.

Canonical rule:

**prefer the simplest intervention that changes the relevant driver while preserving the task goal.**

Confidence: **MODERATE-HIGH as coaching logic / LOW for one-to-one symptom→cause mapping**.

---

## 18. Differential perturbation as a correction workflow

A practical correction approach is to change **one plausible constraint at a time**.

Examples:

### Hypothesis: load
Reduce load while holding setup/cue constant.

### Hypothesis: fatigue
Retest after recovery or early in the set.

### Hypothesis: mobility/environment
Change heel elevation, stance or ROM demand when justified.

### Hypothesis: misunderstanding
Clarify the task outcome/criterion without adding biomechanical detail.

### Hypothesis: cue
Remove/rephrase the cue.

### Hypothesis: capacity
Compare task at demand levels within vs near current capacity; long-term strength testing belongs TST/PRO.

This is not a clinical diagnostic protocol.

It is an **N-of-1 coaching hypothesis test**.

Status: **PRACTICAL_HEURISTIC**.

## 19. Manipulating task/environment instead of endless verbal correction

This principle has direct evidence support but not universal superiority.

The 2026 errorless-learning meta-analysis PMID 41953321:

- 29 studies / 31 experiments;
- 1,509 participants;
- errorless practice commonly manipulated/constrained the environment to promote early success;
- no significant overall advantage for movement performance under random-effects synthesis;
- movement accuracy showed benefit, but heterogeneity and bias were substantial;
- GRADE certainty ranged very low to low;
- benefits were clearer in children and impaired populations than healthy young adults.

Therefore:

**task/environment manipulation is a legitimate way to shape errors and search space, but errorless practice is not universally superior to errorful learning.**

This prevents the false rule:

`constraints > verbal instruction`.

Correct rule:

**use the intervention that changes the relevant information/constraint with least unnecessary cognitive burden.**

Confidence: **HIGH for legitimacy of constraint manipulation / HIGH against universal superiority**.

## 20. Resistance-exercise task/environment manipulation

Examples include:

- load reduction;
- stance adjustment;
- heel elevation;
- ROM target;
- bar/equipment setup;
- external target/reference.

The 2026 heel-elevation meta-analysis shows that changing the support geometry changes squat kinematics.

The 2026 squat-variation systematic review PMID 43028583 found that:

- depth;
- stance;
- bar placement;
- stability;
- fatigue

alter squat mechanics in different ways, but certainty was **very low** across domains.

Therefore:

**task manipulation can be more direct than verbal correction, but the exact manipulation must match the intended task goal and evidence certainty.**

## 21. Errorless ≠ no useful errors

Errors can provide information.

The 2026 errorless meta-analysis does not support eliminating errors universally.

The 2026 kettlebell study also shows that solution exploration can support transfer when error variability remains controlled.

Therefore:

**the goal is not zero error; it is informative error at a tolerable level.**

Too much error can make solution-vs-error discrimination difficult.

Too little variation can reduce exploration/transfer in some tasks.

Status: **PRACTICAL_SYNTHESIS**.

---

## 22. Stable vs random errors need repeated comparable observations

A single repetition is insufficient to classify an error as stable or random.

At minimum, compare attempts under similar:

- load;
- fatigue state;
- setup;
- cue;
- ROM;
- tempo/intention.

Otherwise apparent “randomness” may simply reflect changed constraints.

Project rule:

**classify recurrence only after controlling the most obvious context variables.**

Exact reliability/measurement thresholds belong TST.

---

## 23. “Bad technique” is not a diagnosis

This phrase can conceal different phenomena:

- task misunderstanding;
- movement criterion violation;
- capacity limitation;
- fatigue;
- load-specific strategy;
- mobility constraint;
- cue-induced strategy;
- normal solution variability;
- measurement/camera error.

Therefore NEU-18 rejects:

> “I see X, therefore cause Y.”

Canonical diagnostic chain:

`observed phenomenon`
→
`task relevance`
→
`recurrence/context`
→
`candidate causes`
→
`single-constraint perturbation`
→
`response`
→
`correction decision`.

## 24. Safety / pathology boundary

NEU-18 does not diagnose injury/pathology from movement appearance.

Pain, neurological symptoms, acute injury, medical restriction or pathological ROM limitation belong MED.

Project rule:

**movement deviation ≠ pathology.**

No “screening” movement pattern is treated as a medical diagnosis inside this topic.

## 26. Measurement boundaries

### Outcome error
Deviation from task success criterion.

### Movement error
Deviation from a justified execution criterion.

### Stable/systematic pattern
Repeated similar task-relevant deviation across comparable attempts.

### Random/variable pattern
Substantial trial-to-trial fluctuation across comparable attempts.

### Solution variability
Movement variation that preserves task success.

### Error variability
Variation that degrades task outcome/constraint.

### Cause hypothesis
Proposed driver requiring converging evidence/perturbation.

### Correction
Intervention intended to change the relevant driver or task relation.

### Compensation
Alternative movement strategy; neither automatically good nor bad.

### Technical failure
Loss of a predefined acceptable task/movement criterion—not merely visible change.

## 27. Direct resistance-exercise evidence boundary

Direct evidence strongly supports that:

- load changes mechanics;
- fatigue/proximity to failure changes mechanics;
- mobility can relate to squat geometry;
- cueing can reorganize muscle/movement output;
- task/environment changes can alter kinematics.

Direct evidence is much weaker for universal mappings such as:

- “knee cave = weak glute”;
- “forward lean = ankle immobility”;
- “bar drift = poor cue comprehension”;
- one visual error → one muscle weakness;
- one correction drill → one causal mechanism.

Therefore:

**exercise-specific causal error maps must be developed later in MEC/TEC and tested individually rather than imported as folklore.**
