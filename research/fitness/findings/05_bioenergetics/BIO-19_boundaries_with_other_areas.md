# BIO-19 — Boundaries with other areas

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-20**  
Область: 05 — Bioenergetics / Exercise Metabolism

## 0. Core decision

Bioenergetics owns the **energetic mechanism/state layer**.

It does not automatically own:
- whole-system physiology;
- training prescription;
- nutrition intervention;
- measurement validity;
- clinical diagnosis;
- practical recovery/readiness decisions;
- person-specific adaptive decisions.

Canonical project rule:

**ownership follows the level of claim and downstream decision, not the keyword.**

The same variable can appear in several domains without being duplicate content.

---

## 1. Why boundaries are necessary

A single term can answer different questions.

Example: `lactate`.

BIO question:
- what does blood lactate mean metabolically?

TST question:
- how reliable/valid is the measurement protocol?

PRO question:
- should training density be changed because of the target outcome?

MED question:
- does the measurement indicate disease or clinical risk?

These are not the same evidence problem.

Therefore:

**mechanism ≠ measurement ≠ prescription ≠ pathology.**

---

## 2. Muscle contraction and fatigue

BIO retains:
- PCr;
- glycogen;
- Pi/pH/metabolite state;
- oxidative limitation;
- energetic contributors to fatigability.

PHY owns:
- excitation–contraction coupling;
- Ca2+ handling;
- membrane excitability;
- cross-bridge/contractile integration;
- central/peripheral fatigue architecture.

Canonical rule:

**BIO owns metabolic contributors; PHY owns integrated contraction/fatigue mechanism.**

Do not diagnose complete fatigue mechanism from:
- PCr depletion;
- blood lactate;
- pH;
- glycogen;
- one energy-system estimate.

---

## 3. Cardiovascular / respiratory delivery

BIO retains:
- O2 as terminal electron acceptor;
- oxidative ATP-resynthesis dependence on oxygen availability;
- VO2 as integrated oxygen-consumption flux;
- delivery-vs-extraction-vs-utilization constraints.

PHY owns:
- ventilation;
- gas exchange;
- cardiac output;
- blood pressure/hemodynamics;
- O2 transport/diffusion;
- integrated cardiopulmonary response.

Canonical rule:

**BIO owns energetic use/constraint; PHY owns detailed cardiopulmonary delivery physiology.**

Do not infer:
- mitochondrial limitation from VO2 alone;
- cardiac limitation from HR alone;
- pulmonary limitation from ventilation alone;
- universal O2-delivery limitation from one population.

---

## 4. Work:rest programming

BIO retains:
- PCr restoration;
- metabolite/pH recovery;
- O2 state;
- changed energetic starting state of later bouts;
- acute effect of recovery placement/duration.

PRO owns:
- exact rest interval;
- density;
- cluster/rest-redistribution choice;
- progression;
- chronic goal-specific program design.

Canonical rule:

**BIO explains what rest changes physiologically; PRO selects the prescription.**

No universal:
- heavy-rest time;
- high-rep rest time;
- fixed PCr→rest mapping;
- work:rest ratio;
- short-rest superiority;
- long-rest superiority

is derived from BIO alone.

---

## 5. Nutrition and substrate repletion

BIO retains:
- muscle/liver glycogen state;
- PCr state;
- IMTG;
- blood-glucose flux/state;
- depletion/repletion physiology.

NUT owns:
- carbohydrate intake;
- meal timing;
- creatine use;
- hydration/electrolyte strategy;
- supplement dose/safety;
- practical nutrition plan.

Canonical rule:

**BIO owns substrate physiology; NUT owns nutritional manipulation of that state.**

Substrate restoration also does not certify:
- complete performance recovery;
- global readiness.

---

## 6. Testing VO2 / lactate / anaerobic capacity

BIO retains:
- construct meaning;
- physiological interpretation;
- known non-equivalences.

TST owns:
- test selection;
- protocol;
- standardization/familiarization;
- validity;
- reliability;
- error/MDC;
- reference values;
- longitudinal monitoring decisions.

Canonical rule:

**BIO defines what a metric can mean; TST determines whether a specific measurement is good enough for a decision.**

Current ERS 2026 CPET work reinforces this boundary because VO2peak/Wpeak values can vary with:
- site;
- metabolic cart;
- protocol/analysis choices.

---

## 7. Medical metabolic disease

BIO retains:
- normal/performance exercise metabolism;
- physiological metabolic adaptation;
- non-diagnostic variation.

MED owns:
- diabetes;
- endocrine/metabolic disease;
- hypoglycemia risk;
- medication effects;
- contraindications;
- clinical management;
- referral.

Canonical rule:

**BIO owns normal/performance metabolism; MED owns pathology and clinical risk.**

Do not infer disease from:
- low aerobic performance;
- unusual substrate use;
- poor training response;
- one glucose/lactate result;
- one mitochondrial marker.

---

## 8. Recovery secondary boundary

Exact Section 19 does not require a separate REC item.

Project ownership already defines:

- BIO → substrate/PCr/metabolic restoration;
- PHY → physiological restoration;
- REC → practical recovery domain;
- TST → readiness measurement;
- COA → session action;
- PRO → load/deload management.

Canonical rule:

**a metabolic recovery marker is not a global readiness score.**

---

## 9. Individualization secondary boundary

BIO can establish:
- group-average effects;
- plausible moderators;
- state variables;
- individual-response uncertainty.

IND owns:
- practical adaptive decision-making;
- dose titration;
- change rules;
- personal evidence loop.

Canonical rule:

**BIO explains why people may differ; IND decides what to change for the person after repeated individual evidence.**

## 10. Professional-architecture consistency

Current NSCA CSCS architecture separates:
- bioenergetics/metabolism;
- nutrition;
- program design;
- testing/program implementation.

Current NSCA Essentials 5th Edition similarly separates:
- Bioenergetics (Chapter 3);
- Nutrition (Chapters 10–11);
- Testing (Chapters 13–14);
- Resistance Program Design/rest periods (Chapter 18);
- Rehabilitation/Medical Issues (Chapter 23).

Current ACSM EP/CEP requirements separate:
- exercise physiology;
- exercise testing/prescription;
- pathophysiology/special populations;
- health-risk appraisal.

ACSM CEP content explicitly distinguishes:
- advanced exercise physiology/bioenergetics;
- clinical exercise testing/prescription;
- clinical pathophysiology/metabolic disease/drugs.

These professional structures are external consistency checks.

They are **not** treated as biological proof of the repository taxonomy.

## 12. Anti-category-error rules

1. Energetic contributor ≠ complete fatigue mechanism.
2. VO2 ≠ local mitochondrial ATP flux.
3. HR ≠ O2-delivery diagnosis.
4. Rest physiology ≠ rest prescription.
5. Substrate state ≠ nutrition prescription.
6. Glycogen repletion ≠ complete readiness.
7. Blood lactate ≠ glycolytic ATP flux.
8. Threshold construct ≠ one universally valid test protocol.
9. Test score ≠ true adaptation without measurement-error analysis.
10. Metabolic variation ≠ metabolic disease.
11. Group moderator ≠ individual prescription.
12. Mechanistic plausibility ≠ chronic programming superiority.

---

## 13. Trainer-level routing workflow

Before using a BIO fact:

1. Define the energetic mechanism/state.
2. Ask whether the next claim is still metabolic.
3. If whole-system physiological → PHY.
4. If training prescription → PRO.
5. If nutrition intervention → NUT.
6. If measurement/test interpretation → TST.
7. If disease/medication/referral → MED.
8. If practical readiness/recovery → REC/TST/COA.
9. If person-specific change → IND.
10. Use the destination domain's evidence before making that decision.

This is a routing rule, not a shortcut around downstream evidence.
