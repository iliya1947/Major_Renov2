# PHY-03 — Fiber types / phenotype

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-18**  
Область: 03 — Physiology

## 0. Decision

Создать человеческую physiological model of skeletal-muscle fiber phenotype, достаточную для ответа на вопрос:

> **что в fiber phenotype реально меняется от training?**

и для downstream hypertrophy, strength, power, fatigue, programming and individualization без:

- human IIb error;
- fiber-type determinism;
- MyHC = complete phenotype error;
- athlete cross-sectional causality;
- sex/age stereotyping;
- guessed fiber-type-based prescription.

## 1. Adult human fiber types

Primary adult human limb/torso MyHC classes:

1. **Type I** → MyHC I → **MYH7**.
2. **Type IIA** → MyHC IIa → **MYH2**.
3. **Type IIX** → MyHC IIx → **MYH1**.

Project rule:

**normal adult human fast-fiber nomenclature is IIA / IIX; do not create a true human IIB/MYH4 prescription category from rodent terminology.**

Historical human “IIb” labels should generally be interpreted in context as older nomenclature for what modern human work calls IIx.

## 2. Type I

Broad phenotype:

- slower contractile kinetics;
- more oxidative specialization on average;
- relatively high fatigue resistance.

Project rule:

**Type I does not mean weak or irrelevant to hypertrophy/strength.**

Force still depends on fiber size, activation, length, velocity and context.

## 3. Type IIA

Broad phenotype:

- faster than Type I;
- mixed oxidative-glycolytic capacity;
- intermediate fatigue resistance;
- substantial force/power potential.

Project rule:

**IIA is a major adaptable fast-fiber phenotype, not merely an arbitrary midpoint.**

## 4. Type IIX

Broad phenotype:

- fastest major adult human limb-fiber class;
- more glycolytic bias;
- lower fatigue resistance on average;
- high shortening-rate/power potential.

Project rule:

**IIX = very-fast human phenotype; do not call it true human IIB.**

## 5. MyHC is not the whole phenotype

MyHC is a central contractile classifier.

But full phenotype also includes:

- hybrid MyHC expression;
- metabolic machinery;
- mitochondria;
- Ca²⁺ handling;
- fiber size;
- capillary environment;
- regulatory proteins;
- proteomic/transcriptional state;
- activity/innervation history.

Project rule:

**MyHC identity is a contractile anchor, not a complete metabolic/functional diagnosis.**

## 6. Slow-to-fast continuum

Useful simplified continuum:

`I → I/IIA → IIA → IIA/IIX → IIX`

This represents broad changes in:

- contractile speed;
- oxidative/glycolytic bias;
- fatigue behavior.

Project rule:

**fiber phenotype is continuous and multidimensional rather than three perfectly isolated boxes.**

## 7. Hybrid fibers

Human fibers can co-express multiple MyHC isoforms.

Common examples:

- I/IIA;
- IIA/IIX.

Hybrid fibers may represent:

- stable intermediate phenotypes;
- transition/remodeling states.

Single-fiber methods are particularly important for identifying them.

Project rule:

**hybrid fibers are biologically meaningful, not automatically assay noise.**

## 8. Contractile speed

Broad ordering:

`I < IIA < IIX`

for contractile speed.

MyHC motor properties contribute directly.

But whole-muscle movement speed also depends on:

- architecture;
- tendon mechanics;
- neural activation;
- task mechanics.

Project rule:

**fiber type contributes to speed; it does not uniquely determine movement velocity.**

## 9. Metabolic profile

Broad tendency:

- I → more oxidative;
- IIA → mixed oxidative-glycolytic;
- IIX → more glycolytic.

Project rule:

**MyHC type and metabolic phenotype are correlated but separable.**

A fiber can become more oxidative without changing its major MyHC class.

## 10. Fatigability

Broad tendency:

`I = more fatigue resistant → IIA = intermediate → IIX = less fatigue resistant`

Observed fatigue also depends on:

- activation frequency;
- contraction mode;
- duty cycle;
- Ca²⁺ handling;
- energy/substrate status;
- temperature;
- prior fatigue;
- measurement endpoint.

Project rule:

**fiber type biases fatigability; task/state determines the observed fatigue response.**

Detailed mechanisms → PHY-10.

## 11. Recruitment boundary

Fiber recruitment belongs to motor-unit/neural physiology.

Detailed:

- size principle;
- recruitment threshold;
- rate coding;
- fatigue-related recruitment;
- load–recruitment relationship

remain NEU.

Project rule:

**PHY-03 does not authorize a fixed %1RM threshold for “turning on Type II fibers.”**

## 12. What training can change

Training can modify:

1. MyHC isoform distribution;
2. hybrid ↔ pure-fiber state;
3. oxidative/glycolytic machinery;
4. mitochondrial phenotype;
5. Ca²⁺-handling machinery;
6. fiber size;
7. fiber-specific proteome.

These features do not need to change together.

## 13. Common IIx → IIA direction

A common repeated-training pattern is:

`IIX / IIA-IIX → more IIA-dominant phenotype`

across several exercise modalities depending on baseline and program.

Project rule:

**IIx → IIA does not mean the muscle became “slow”; IIA is still a fast phenotype.**

## 14. Type I ↔ Type II conversion

Slow-fast phenotype transitions can occur.

But:

- magnitude;
- direction;
- reproducibility

depend on training modality, duration, baseline, muscle sampled, measurement method and hybrid detection.

Project rule:

**do not promise large predictable I ↔ II conversion from ordinary resistance training.**

## 15. Resistance training

Resistance training can produce:

- Type I hypertrophy;
- Type II hypertrophy;
- fiber-specific molecular/proteomic remodeling;
- reduced IIx representation / greater IIA representation in many contexts;
- metabolic changes without full MyHC-class conversion.

Project rule:

**both slow and fast fibers are trainable.**

## 16. Load-specific fiber hypertrophy

Current 2026 synthesis does not establish a robust selective hypertrophy rule by load.

Eight studies / 195 participants were included; pairwise Type I vs Type II load-specific contrasts had wide uncertainty and 95% confidence intervals crossing zero.

Project rule:

**do not choose high- vs low-load training solely to target a presumed fiber type.**

Load may matter for other outcomes; those questions belong elsewhere.

## 17. Training status

Endurance and power athletes can show different fiber distributions.

But cross-sectional athlete phenotype combines:

- training;
- genetics;
- self-selection;
- sport history;
- muscle sampled;
- sex;
- age.

Project rule:

**athlete group differences are not pure causal estimates of training-induced conversion.**

Longitudinal training evidence receives more weight for causality.

## 18. Age

Current synthesis supports:

- vulnerability/atrophy of fast Type II/IIA fibers with aging;
- shifts in relative MyHC expression;
- no simple universal conversion of the entire distribution from II to I.

Project rule:

**aging affects fast-fiber size/phenotype, but “older = Type I muscle” is too crude.**

## 19. Sex

Healthy adults show group-average sex differences in:

- Type I/II CSA;
- Type I/II distribution;
- proportional area.

But distributions overlap and effects vary by age/muscle/context.

Project rule:

**sex is a group-level modifier, not an individual fiber-type diagnosis.**

## 20. Measurement

Fiber composition may be measured as:

- fiber-count distribution;
- proportional CSA;
- MyHC protein abundance;
- single-fiber phenotype;
- IHC/histochemical categories.

These are not interchangeable.

Biopsy limitations include:

- small sampled region;
- muscle/region heterogeneity;
- hybrid-detection sensitivity;
- loss of single-fiber information in bulk assays.

Project rule:

**always interpret “fiber-type percentage” relative to method and denominator.**

## 21. Noninvasive estimation boundary

Performance tests and visual/subjective impressions are not biopsy-equivalent fiber typing.

Project rule:

**do not infer Ilya's fiber composition from jump tests, repetition endurance, explosiveness or anecdotal sport history and then prescribe training from that label.**

If fiber typing ever becomes decision-critical → TST/IND must assess validity and utility.

## 22. Integrated phenotype model

Current project model:

`MyHC identity + hybrid state + contractile kinetics + metabolic machinery + Ca²⁺ handling + fiber size + proteomic state + activity history`

This model allows:

- contractile phenotype change;
- metabolic change without MyHC conversion;
- hypertrophy without fiber-type conversion;
- hybrid transitions;
- training-specific remodeling.

## 23. Training-relevant implications

1. **Type I and Type II fibers are both trainable.**
2. **IIx → IIA is a common exercise-associated transition.**
3. **MyHC type does not fully define metabolism or fatigue.**
4. **Fiber type does not uniquely determine whole-muscle force/power.**
5. **Cross-sectional athlete data cannot isolate training causality.**
6. **Age/sex modify group averages, not individual identity.**
7. **No validated fiber-type-based load algorithm exists for this project.**
8. **Recruitment belongs to NEU.**
9. **Guessed noninvasive fiber typing is not a sufficient basis for personal prescription.**

## 24. What PHY-03 can establish

PHY-03 establishes:

1. human I / IIA / IIX nomenclature;
2. hybrid-fiber continuum;
3. broad contractile/metabolic/fatigue tendencies;
4. phenotype plasticity;
5. common IIx → IIA training shift;
6. uncertainty of broad slow↔fast conversion magnitude;
7. correct interpretation of training status;
8. age/sex group-level modifiers;
9. measurement limits;
10. boundaries against fiber-type determinism.

## 25. What PHY-03 cannot prescribe

Not owned here:

- exact load/repetition range;
- fixed %1RM recruitment threshold;
- contraction-mode selection;
- strength/hypertrophy dose;
- individual “fast-twitch dominance” without direct valid measurement;
- exercise selection from fiber type alone.

These remain PHY-04/07/08/10, NEU, PRO, TST and IND.

## 26. Current non-blocking uncertainties

1. Exact I ↔ II conversion magnitude for a given program.
2. Exact load × fiber-type hypertrophy interaction.
3. Genetics vs training contribution in elite athlete distributions.
4. Sex-specific molecular response differences.
5. Decision utility of direct fiber typing for programming.
6. Whole-muscle inference from local biopsy.

Project rule:

**uncertainty is preserved rather than filled with unsupported fiber-type heuristics.**

## 27. Canonical project rules

1. Human adult major fiber types = I / IIA / IIX.
2. Do not create a true human IIb/MYH4 category for ordinary limb muscle.
3. MyHC ≠ complete phenotype.
4. Fiber phenotype forms a continuum and includes hybrids.
5. Type I is slower/more oxidative/more fatigue resistant on average.
6. IIA is fast and metabolically mixed.
7. IIX is fastest/more glycolytic/less fatigue resistant on average.
8. Fiber type biases function; task/state still matter.
9. Recruitment is neural and belongs to NEU.
10. Training can change phenotype without all dimensions changing together.
11. IIx → IIA is common with repeated training.
12. Large predictable I ↔ II conversion should not be assumed.
13. Athlete cross-sectional differences do not prove training causality.
14. Age/sex group averages do not classify an individual.
15. Fiber-type-based load prescription is not currently justified.
16. Indirect performance anecdotes are not valid personal fiber typing.

## 28. Evidence / confidence

### HIGH
- human I / IIA / IIX classification;
- MYH7 / MYH2 / MYH1 mapping;
- hybrid fibers and phenotype continuum;
- broad contractile/metabolic/fatigue tendencies;
- phenotype plasticity;
- common IIx → IIA direction;
- age-related fast-fiber atrophy;
- population-level sex differences;
- measurement-method dependence.

### MODERATE / CONTEXT-DEPENDENT
- exact I ↔ II conversion magnitude;
- exact load-specific fiber hypertrophy;
- athlete training-causality attribution;
- sex-specific molecular adaptation differences;
- personal utility of fiber typing.
