# NEU-12 — Explicit / implicit / constraints-based learning

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Motor-skill acquisition should not be reduced to one exclusive coaching ideology.

A defensible project model is:

`learner capability/state`
+
`task constraints`
+
`environment/context`
→
`functional learning problem`.

Learning can involve parallel contributions from:

- deliberate reasoning / explicit strategy;
- sensorimotor refinement;
- retrieval;
- exploration;
- less consciously accessible practice-dependent learning.

Coaching can modify the learning problem through:

- concise direct instruction;
- analogy;
- task/environment constraints;
- guided exploration;
- progression/regression;
- target-specific practice.

Project rule:

**instructional method, internal learning process and durable learning outcome are different levels and must not be conflated.**

---

## 1. Cognitive / associative / autonomous stages

The Fitts–Posner three-stage model is retained as a useful descriptive heuristic:

### Cognitive
High deliberate problem solving and task understanding.

### Associative
More stable task relations, refinement and reduced error.

### Autonomous
Lower higher-level control demand for well-practiced execution.

But it is not treated as:

- three discrete neural states;
- a universal fixed-duration sequence;
- one-way irreversible stages;
- one learning process active at a time;
- proof of zero attentional demand in the autonomous stage.

Modern process frameworks support multiple parallel learning processes.

Project rule:

**Fitts–Posner is descriptive scaffolding, not a literal three-state biological law.**

---

## 2. Explicit learning

Explicit learning involves task-relevant:

- knowledge;
- rules;
- hypotheses;
- action–outcome reasoning;
- deliberate strategies

that are sufficiently accessible to intentional use.

Possible benefits:

- rapid use of understandable information;
- strategy change;
- deliberate error correction;
- communication of safety-critical constraints;
- early solution of a novel task problem.

Important boundaries:

- explicit learning ≠ verbal instruction alone;
- explicit learning ≠ internal attentional focus;
- explicit learning ≠ large rule checklist;
- explicit contribution is not inherently harmful.

Project rule:

**explicit strategy is one legitimate contributor to motor learning, not an inferior mode by definition.**

---

## 3. Implicit learning

Implicit learning is operationally treated as skill change with relatively reduced dependence on:

- accessible verbal rules;
- deliberate strategy;
- consciously reportable task knowledge.

It is not defined as:

- total unconsciousness;
- absence of attention;
- absence of error perception;
- absence of any strategy;
- a process automatically produced by a named coaching method.

Project rule:

**implicit learning is a learner-process construct, not a synonym for “implicit instruction.”**

---

## 4. Explicit and implicit contributions can coexist

Explicit and implicit components should not be treated as perfectly pure, independent and linearly additive.

Common measurement approaches in visuomotor adaptation have shown that:

- measured explicit and implicit contributions may interact;
- simple addition can fail;
- process decomposition depends on method/assumptions.

This does not negate the distinction.

It means the project must avoid:

`total learning = explicit score + implicit score`

as a universal identity.

Project rule:

**when mechanism matters, measure the relevant processes directly and preserve the assumptions of the measurement method.**

---

## 5. Adaptation evidence is not complex-skill evidence

Much of the strongest explicit/implicit mechanism evidence comes from:

- visuomotor rotations;
- reaching;
- force-field adaptation.

These paradigms are useful for construct and mechanism boundaries.

They do not directly provide:

- the percentage of explicit learning in a squat;
- the percentage of implicit learning in a power clean;
- the optimal explicit/implicit mix for a compound lift.

Project rule:

**adaptation studies constrain theory but do not numerically define complex resistance-exercise learning.**

---

## 6. Instructional label ≠ internal process

A study can label an intervention:

- analogy;
- errorless;
- external focus;
- nonlinear pedagogy;
- constraints-led;
- dual task;
- explicit instruction.

But the label does not prove which internal process dominated.

A learner in an “implicit” condition can still develop explicit knowledge.

A learner given explicit instruction can still undergo implicit refinement.

Project rule:

**separate intervention, learning mechanism and measured outcome.**

---

## 7. No universal implicit-over-explicit hierarchy

Current evidence does not justify:

`implicit > explicit`

or

`explicit > implicit`

as a universal rule.

Systematic-review evidence suggests:

- some implicit-classified methods can improve outcomes;
- analogy can be useful;
- effects are heterogeneous;
- methodological quality and risk of bias vary;
- most automaticity comparisons have not shown a clean universal advantage.

Project rule:

**judge a method by delayed task-relevant outcomes, not by ideological label.**

---

## 8. Analogy instruction

Analogy instruction can compress a movement idea into a meaningful image/metaphor.

It may:

- reduce rule load;
- change movement organization;
- support some learners/tasks.

But current evidence does not establish universal superiority.

Project rule:

**analogy is a coaching tool, not a universally superior learning mechanism.**

Exact analogy wording remains NEU-16/COA.

---

## 9. Errorless learning

Errorless learning reduces early errors by manipulating practice conditions.

Current meta-analytic evidence does not show a consistent overall movement-performance advantage over errorful learning.

Benefits may exist in specific subgroups or outcomes.

Project rule:

**minimum error is not a universal learning objective.**

Neither:

- zero error;
- maximum error

is treated as a universal optimum.

---

## 10. Discovery / exploration

Exploration is:

> search across candidate movement solutions to discover actions that satisfy the task goal.

Exploration is not identical to movement variability.

Observed variability can reflect:

- useful solution search;
- redundant task-successful solutions;
- noise;
- fatigue;
- unstable control;
- changing constraints.

Project rule:

**more variability ≠ more learning.**

Useful exploration should distinguish:

- solution variability;
- error variability;
- task-relevant outcome.

---

## 11. Kettlebell exploration evidence

A 2026 kettlebell-swing study found that participants with higher early solution variability and low error variability later showed fewer errors with a water-filled kettlebell.

This supports the plausibility that:

- exploring multiple successful solutions can aid transfer.

But:

- N=12;
- participants were not randomized to exploration levels;
- grouping was observational/post hoc.

Project rule:

**the study supports an exploration hypothesis, not a prescription to deliberately maximize variability.**

---

## 12. Constraints-led learning

Constraints-led learning changes the task/action environment so that useful solutions become more likely to emerge.

Core constraint families:

1. individual / organism;
2. task;
3. environment.

The framework is compatible with:

- motor abundance;
- task-specific coordination;
- exploration;
- individual solutions.

Project rule:

**constraints-led learning is a valid practice-design strategy, not a universal replacement for instruction.**

---

## 13. Task constraints

Task constraints can include:

- goal;
- target;
- success criterion;
- load;
- implement;
- ROM;
- timing;
- allowed actions;
- support;
- rules.

Project rule:

**a task constraint changes the motor problem; a cue provides information about the problem.**

They can be combined but should not be confused.

---

## 14. Organism / individual constraints

Relevant learner constraints include:

- anthropometry;
- morphology;
- strength;
- mobility;
- previous skill;
- sensory capacity;
- fatigue;
- attention/working memory;
- pain/discomfort;
- arousal.

The same nominal exercise can therefore create different functional difficulty across learners/states.

Project rule:

**individual constraints change available solutions but do not justify deterministic learner types or one mandatory technique.**

---

## 15. Environmental constraints

Environmental constraints can include:

- surface;
- space;
- lighting;
- obstacles;
- noise;
- equipment arrangement;
- social context;
- contextual pressure.

Some variables can be classified differently depending on framework.

Project rule:

**the causal practice manipulation matters more than rigid classification of every variable.**

---

## 16. Constraint interaction

Task, learner and environment constraints interact.

Therefore:

`same external task`
does not mean
`same functional challenge`.

Example:

the same external load can differ in functional difficulty because of:

- strength;
- fatigue;
- prior skill;
- ROM target;
- support;
- surface;
- speed;
- feedback.

Project rule:

**functional learning difficulty is relational, not contained in the exercise label alone.**

---

## 17. Constraints-led vs linear pedagogy

Current comparative evidence does not show universal superiority of nonlinear/constraints-led pedagogy for technical skills.

Team-sport systematic review:

- most technical outcomes showed no clear difference;
- nonlinear pedagogy sometimes favored tactical outcomes;
- evidence base is limited.

Transfer to closed resistance exercise must be cautious.

Project rule:

**choose coaching principles by the learner/task problem, not by allegiance to linear or nonlinear pedagogy.**

---

## 18. Direct power-clean evidence

A small randomized study of 16 power-clean beginners compared:

- linear pedagogy with explicit movement-form instruction;
- nonlinear pedagogy using analogy + task constraints.

Across seven lessons over four weeks:

- both groups improved movement-form performance;
- exploration quantity did not clearly differ;
- barbell-trajectory distribution did not clearly differ.

The accessible report does not establish a separate delayed-retention test.

Project rule:

**both approaches can support training-period improvement; neither universal nor retention superiority is established.**

---

## 19. Challenge Point Framework

The Challenge Point Framework distinguishes:

### Nominal difficulty
Task difficulty as specified externally.

### Functional difficulty
Difficulty experienced by a particular learner under current conditions.

This is useful because learning challenge depends on:

- learner skill;
- task demand;
- practice information.

Project rule:

**Challenge Point is a reasoning framework, not a numeric prescription.**

---

## 20. No universal optimal difficulty

Current evidence does not establish one universal:

- success percentage;
- error rate;
- difficulty zone

that maximizes motor learning.

A 2026 RCT in golf putting compared:

- 60–70% success;
- 20–30% success;
- <10% success.

No significant group difference appeared in the pattern or magnitude of learning after a 24-h retention test.

Project rule:

**no universal motor-learning “sweet spot” percentage is retained.**

This does not prove optimal challenge never exists for any task.

It rejects a universal numerical law.

---

## 21. Progression

Progression can increase:

- load;
- range;
- speed;
- complexity;
- precision;
- uncertainty;
- target specificity;
- independence from support.

Project rule:

**progression is a task-design tool, not a mandatory fixed ladder.**

---

## 22. Regression

Regression temporarily reduces one or more demands to make practice:

- safer;
- more interpretable;
- more successful/informative;
- easier to perceive/control.

A regression can be useful when:

- learning a new movement;
- returning after a break;
- correcting a coordination problem;
- practicing under fatigue;
- changing implement/load.

Project rule:

**regression is not failure; it is temporary scaffolding.**

---

## 23. No universal easy→hard sequence

Gradual progression is not universally superior.

A gait-learning study found that direct criterion-task practice outperformed sequential progression under that protocol.

Thus progression can trade off against specificity.

Project rule:

**easy→hard is not a universal law; enough practice in the actual target task remains necessary.**

---

## 24. Regression success ≠ target-task learning

A learner can become good at:

- a lighter version;
- supported version;
- partial-ROM drill;
- constrained variation

without automatically transferring the improvement to the target condition.

Project rule:

**a regression is useful only insofar as it improves eventual target-task execution.**

Target-condition retention/transfer must ultimately be checked.

---

## 25. Acute lifting instruction effects

A 2026 novice-lifting study found acute changes in:

- EMG;
- RFD;
- force output

with analogy/explicit instruction.

These are legitimate performance/control findings.

But without delayed retention/transfer they are not evidence of durable learning superiority.

Project rule:

**acute instruction effect ≠ durable motor learning.**

---

## 26. Practical coaching synthesis

Current evidence supports a flexible hybrid practice heuristic.

A coach may combine as needed:

- concise explicit explanation;
- safety-critical direct instruction;
- analogy;
- repeated execution;
- task constraints;
- guided exploration;
- progression/regression;
- removal of support;
- target-condition practice.

Selection should depend on:

- current error/problem;
- learner understanding;
- functional difficulty;
- cognitive load;
- task complexity;
- retention;
- transfer.

Status:

**PRACTICAL_HEURISTIC**, not proof that “hybrid coaching” is universally superior.

---

## 27. Canonical non-equivalences

1. Explicit instruction ≠ process-pure explicit learning.
2. Implicit-labeled method ≠ proof of implicit learning.
3. Analogy ≠ guaranteed implicit learning.
4. External focus ≠ implicit learning by definition.
5. Errorless learning ≠ universal superiority.
6. Variability ≠ exploration.
7. Exploration ≠ random movement.
8. Constraints-led ≠ no instruction.
9. Nonlinear pedagogy ≠ universal superiority.
10. Challenge Point ≠ fixed success percentage.
11. Functional difficulty ≠ nominal task difficulty.
12. Progression ≠ always easy→hard.
13. Regression success ≠ target-task learning.
14. Autonomous stage ≠ zero attention.
15. Acute performance change ≠ durable learning.
16. Adaptation-process percentages ≠ complex-lift process percentages.

---

## 28. Measurement boundaries

### Instructional condition
What the study/coach provided.

### Declarative knowledge
One probe of accessible explicit knowledge.

### Adaptation explicit/implicit measures
Mechanistic probes with assumptions; not universal complex-skill decomposition.

### Dual-task cost
Probe of attentional demand, not pure implicit learning.

### Variability
Requires distinction among solution/error/temporal/task-relevant structure.

### Success rate
One possible difficulty metric, not universal functional challenge.

### Immediate technique score
Current performance.

### Delayed retention
Durability.

### Transfer
Performance in a changed/untrained target condition.

Project rule:

**method, mechanism and outcome must be reported separately.**

---

## 29. Training-relevant implications

1. Use direct explanation when it communicates a necessary task/safety rule cheaply.
2. Do not overload a novice with a long technical checklist by default.
3. Use analogy when it improves understanding/execution; do not assume it is automatically superior.
4. Use constraints to shape the problem when verbal correction is inefficient.
5. Allow exploration when multiple task-successful solutions are possible.
6. Do not maximize variability for its own sake.
7. Adjust task difficulty to the learner rather than using a fixed success-rate rule.
8. Regress when the target task becomes noninformative or unsafe.
9. Return to the target condition soon enough to preserve specificity.
10. Judge learning by retention/transfer, not the best immediate repetition.

## 31. Confidence

### HIGH
- instructional label ≠ internal learning process;
- explicit and implicit contributions can coexist;
- simple additive decomposition is unsafe;
- variability ≠ exploration;
- acute performance ≠ durable learning;
- no universal fixed success-rate optimum is established;
- target specificity remains necessary.

### MODERATE-HIGH
- Fitts–Posner as a useful descriptive heuristic;
- constraints-led learning as a legitimate framework;
- task/individual/environment interaction;
- progression/regression as adaptive task manipulation.

### MODERATE
- analogy average benefit in some tasks/populations;
- constraints-led comparative benefit;
- structured exploration benefit;
- power-clean applicability.

### LOW / CONTEXT-DEPENDENT
- exact optimal explicit/implicit mix in compound lifts;
- exact exploration dose;
- best constraint manipulation;
- best success range for a given lift;
- best progression sequence for an individual.

### NOT ESTABLISHED AS UNIVERSAL
- implicit > explicit;
- explicit > implicit;
- analogy > explicit;
- errorless > errorful;
- constraints-led > linear;
- more variability > less variability;
- one optimal success percentage;
- one easy→hard progression law;
- one coaching method for every learner.
