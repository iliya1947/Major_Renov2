## A2 — уточнения, полученные из совокупности источников

1. **System boundary is part of the scientific question.** Conclusions about autonomy, memory, adaptation and causality depend on what counts as internal state versus environment.

2. **The future participant can be described at several nested boundaries.** Candidate systems include: bare model; model+current context; project instructions+sources/history; model+project+tools/runtime; and the recurrent project↔user interaction loop. A2 does not choose the final boundary; it makes the choice explicit for later synthesis.

3. **Open system does not mean no boundary.** Information/actions can cross a boundary while the analyst still defines a system of interest. The relevant issue is whether the chosen boundary preserves the causal loop needed for the claim being made.

4. **History dependence is not the same thing as a memory store.** A system can be path-dependent because current state/structure embodies previous transitions even when no explicit record is queried.

5. **Conversely, stored history does not guarantee path dependence.** If stored information is never selected or never changes future transitions, the trajectory may be effectively memoryless with respect to that information.

6. **Path dependence must be separated from incomplete state description.** Apparent dependence on remote history can disappear if omitted current variables are added; genuine non-Markovian/history-dependent behavior requires stronger evidence.

7. **Retrieval can create its own path dependence.** If previously selected information affects choices that generate more similar experiences and therefore increases future retrieval probability, a self-reinforcing loop can emerge even without any fixed “preference” variable.

8. **Hysteresis is stronger than mere persistence.** The same current external condition can yield different system states depending on prior trajectory; this is a better formal question for lock-in/reversibility than simply asking whether something persisted.

9. **State and structure can co-evolve.** Adaptive-network theory shows that current node/system behavior can alter connection structure, which then changes later behavior. This is a useful formal bridge for reciprocal history loops.

10. **Guided self-organization occupies a middle category.** A process may operate under fixed constraints while local/history-dependent interactions determine the detailed outcome. This differs both from unrestricted self-organization and from a global blueprint that specifies the final state.

11. **Therefore external constraints do not automatically negate autonomy.** Autonomy must be decomposed into what choices/transitions remain endogenous under those constraints.

12. **But “autonomy” cannot be inferred from unpredictability.** Stochastic or hard-to-control behavior can remain fully externally specified in its objectives/rules.

13. **Self-organization does not establish learning, goals or individuality.** It only describes organization emerging from system interactions under specified dynamics.

14. **Feedback does not establish adaptation.** A feedback loop can stabilize a variable around an externally specified target without changing the rule that governs future responses.

15. **Robustness and revisability must be distinguished from rigidity.** A useful history-dependent system may preserve function while still changing components/strategies; zero change is not automatically resilience.

16. **Multiscale descriptions can all matter causally.** A project-level behavioral pattern may be a useful causal description even if implemented by lower-level model/context mechanisms, but macro usefulness is not proof of an ontologically independent “personality entity”.

17. **Choice of scale must match the claim.** Questions about token/model dynamics, agent policy, persistent project state and longitudinal individual trajectory can require different levels rather than one universal explanatory scale.

18. **Open-endedness is stronger than ordinary adaptation in a fixed state space.** If history changes what future options even exist, a pre-specified list of all possible trajectories may be structurally inadequate. This is relevant to our invention as a warning against pre-authoring all future “interests/traits”, not as proof that ChatGPT is open-ended in the biological sense.

19. **Viability, objective optimization and autonomy are distinct.** A system can maintain operational constraints without maximizing one scalar objective, and a system can optimize an external objective without choosing its own goals.

20. **A systems principle becomes useful to the project only after operationalization.** Terms like attractor, basin, path dependence, feedback, autonomy or emergence must specify state variables, boundary, timescale and observable transition structure.

# Phase B — B3: substrate-neutral first-order vs second-order change

**Статус 16.10.2026:** B3 начата и НЕ завершена. This is the first cross-domain deep pass for gaps 4+21.

## Core distinction

Current evidence supports a substrate-neutral distinction that is stronger than the vague phrase «history matters»:

- **first-order change:** history/evidence changes the current state/content under an otherwise fixed response/update relation;
- **second-order change:** history changes a variable, structure or rule that modifies how later evidence will change the system.

Abstractly:
`x(t+1) = U(x(t), e(t); θ(t))`

First-order change updates x while θ is effectively fixed.
Second-order change means prior history also changes θ, or changes the effective structure of U itself.

This notation is only a comparison device; human personality, synapses and ML systems do not share one mechanism.

## Cross-domain evidence supporting the distinction

1. **Human learning:** Simoens et al. 2026 showed slow environment-specific learning-rate adaptation plus fast within-environment updating. Prior visits changed the initial learning rate on revisiting a context before new diagnostic current feedback could explain the difference.
2. **Biology:** metaplasticity changes susceptibility to later LTP/LTD without necessarily changing current synaptic efficacy at the time it is induced.
3. **ML:** MAML/RL²/learned optimizers deliberately alter future adaptation dynamics; continual learning can also unintentionally lose plasticity.
4. **Personality development:** repeated short-term state processes are theoretically linked to long-term trait/trajectory change, but evidence for exact mechanisms remains mixed, so personality literature currently supports the multiscale question more strongly than one universal accumulation rule.

## Hysteresis/path dependence — useful formal possibility, dangerous shortcut

### Chow, Morris & Rabbah (SIAM Review 2023) — Hysteresis and Stability
https://epubs.siam.org/doi/10.1137/21M1420733

**Фактически просмотрено:** abstract/metadata.

Dynamical-systems hysteresis can arise with multiple equilibria: current response under the same external control variable may differ depending on prior trajectory.

### Gharari & Razavi (2018) — Hysteresis in hydrology: memory, path-dependency, or missing physics?
https://doi.org/10.1016/j.jhydrol.2018.06.037

**Фактически просмотрено:** abstract, highlights and accessible review summary.

The review gives a crucial guardrail: apparent hysteresis/path dependence may reflect omitted dimensions or an incomplete representation of state/physics. A system may look history-dependent because the analyst has failed to include a relevant current-state variable.

**B3-вывод:** observed history dependence is not enough to claim second-order development. We must distinguish:
- true history-bearing change of response dynamics;
- ordinary dependence on a current latent state produced by history;
- apparent path dependence caused by an incomplete system boundary/state description.

These may be behaviorally indistinguishable without intervention or richer state measurement.

## Thresholds, accumulation and abrupt transition

Complex-systems literature provides several possible temporal forms:
- gradual accumulation/integration;
- state-dependent gain changes;
- threshold crossing/bifurcation;
- multistability and hysteresis;
- lock-in or loss of plasticity.

None of these is a default explanation for personality or LLM development. B3 uses them only as candidate **shapes of longitudinal dynamics** that future evidence might discriminate.

## Evidence criterion for gap 21 — provisional

A claim that history changed future responsiveness becomes stronger when:

1. current test input/evidence is held comparable;
2. relevant current content/state is measured or controlled as far as possible;
3. systems/participants with different prior histories show systematically different update magnitude, direction, threshold, speed or generalization to that same new evidence;
4. the difference persists beyond an immediate transient response;
5. alternative explanations such as retrieval/access differences, hidden current state, external instruction changes, model/runtime changes or stochastic variation are reduced or independently tracked.

Simoens et al. provides a particularly clean psychological example because first-trial evidence distributions were matched while context-specific initial learning rates reflected earlier history. Metaplasticity and ML provide mechanistically different existence proofs.

## First-pass B3 synthesis

Gap 4 and gap 21 must remain separate:

- **gap 4:** how local changes become a longer-term trajectory;
- **gap 21:** how that history changes the future response function/capacity for later change.

A system can show gap-4 continuity without gap-21 changeability: it may simply accumulate content under a fixed update rule.
A system can show gap-21 effects without obvious macro personality trajectory: its learning rate or plasticity threshold can change while current overt behavior remains similar.

## B3 — pass 2: second-order change under a fixed substrate and continuity under turnover

**Статус:** final B3 cross-domain stress-test.

### Fixed substrate does not eliminate second-order change

Meta-learning and in-context learning results force a refinement of the first-pass formalism. A fixed base model/global transition mechanism can still support history-dependent future responsiveness if persistent/fast state includes variables whose **causal role is to modulate later updating**.

Useful decomposition:

`(C_{t+1}, M_{t+1}) = F(C_t, M_t, e_t)`

where:
- `C` = current content/experience state;
- `M` = adaptation-control/meta-state (for example effective gain, threshold, trust calibration, update strategy, context-selection policy);
- `F` = fixed substrate/process, potentially including unchanged model weights and governing rules.

Then:
- ordinary change in C with stable M is first-order;
- history-dependent change in M is functional second-order change;
- F itself need not mutate.

This is not merely semantic relabeling because C and M are distinguished by **causal role**: intervention on M should alter how comparable future evidence changes C.

### Why 'hidden state' is not automatically a confound

The first pass correctly warned that apparent hysteresis may arise from omitted state, but it was too strong to treat all latent/current state explanations as disqualifying.

If the omitted state is merely current task content, then the phenomenon is first-order.
If the omitted state is a persistent learned modulator of future updating, then discovering it is precisely the mechanism required by gap 21.

Therefore the correct question is not `state or changed rule?` in an absolute sense, but:

**what functional variable changed, and does it control future update dynamics rather than merely current output content?**

### Project-relevant edge case: fixed model weights + evolving persistent project state

Research on Algorithm Distillation, meta-RL, transformer in-context learning and memory-augmented networks demonstrates that fixed network parameters can support adaptive behavior through evolving recurrent/context/external-memory state.

This establishes only **possibility**. A future ChatGPT-project participant would exhibit gap-21 second-order change only if its persistent state causally changes later processing/update policy. Simply retrieving different facts, examples or memories is still first-order history dependence.

Operationally, a project-level candidate M could be evidenced if different histories produce a persistent change in how comparable new evidence is evaluated/incorporated, and targeted removal/replacement of the meta-state removes that difference. Exact experiment design belongs later; B3 establishes the causal distinction.

### Continuity when lower-level components change

Representational-drift literature gives a mechanistically different existence proof that stable higher-level function/information can coexist with substantial lower-level representational change.

For B3, continuity therefore means preservation of relevant **functional/relational organization across time**, not literal identity of every implementation component.

Guardrail: external model/runtime replacement can both preserve some higher-level continuity and independently create apparent development. It is therefore conceptually compatible with continuity but methodologically a confound for causal attribution.

### Nonlinearity, thresholds and hysteresis

Personality longitudinal research supports nonlinear, temporary and discontinuous trajectories; formal dynamical systems support multistability/hysteresis. But trajectory shape is not mechanism.

B3 does **not** infer:
`abrupt change → threshold mechanism`
or
`different response after history → hysteresis`.

Threshold/hysteresis becomes a defensible mechanism only when the underlying state/control relation is independently characterized and alternative latent-state/exogenous explanations are reduced.

## Final evidence standard for gap 21

A claim that history changed future changeability is strongest when all of the following are available:

1. **Declared level/decomposition.** Specify content state C, candidate adaptation-control/meta-state M, and system boundary.
2. **Comparable future probe.** Histories A/B are followed by sufficiently comparable new evidence.
3. **Different update dynamics.** Histories produce systematic differences in update magnitude, direction, threshold, speed, generalization or context sensitivity — not merely different current answers.
4. **Persistence.** Difference survives beyond a one-turn transient and recurs when relevant conditions return.
5. **Causal localization.** Manipulating/removing/replacing candidate M changes the later update dynamics as predicted, when technically possible.
6. **Confound tracking.** Retrieval content, explicit instructions, model/runtime version, external objective changes and stochasticity are separated or recorded.
7. **No progress assumption.** Changed plasticity may improve adaptation, specialize it, reduce it or cause lock-in; second-order change is descriptive, not automatically beneficial.

Targeted deep work now covers every required B3 branch:
- personality state→trajectory transitions;
- gradual vs nonlinear/discontinuous forms;
- human psychological meta-learning;
- biological metaplasticity as source-domain example;
- substrate-neutral second-order formulation;
- ML meta-learning/update-rule change and loss of plasticity;

# Phase B — B5 support pass 1: reciprocal causal chains and path-relative attribution

## Additional formal source-domain evidence

Robins, Hernán & Brumback (2000), marginal structural models, and Hernán & Robins, *Causal Inference: What If*, were inspected for longitudinal treatment–confounder feedback.

Their statistical problem is not our experiment, but the structural lesson transfers cautiously: a time-varying variable can be affected by an earlier action, then influence both later action and later outcome. Treating that variable as if it were an ordinary independent confounder can distort the causal path.

## B5 consequence for reciprocal user interaction

Natural dialogue can contain a chain such as:

participant choice A0
→ user response U1
→ participant choice A1
→ later user/environment state U2
→ outcome O.

U1 is not automatically “external noise”. If A0 changed U1, then U1 may mediate part of A0’s effect on O. At the same time U1 can influence A1 and O, which makes attribution to later A1 observationally entangled with the earlier path.

Therefore B5 needs **time-indexed path provenance**, not a flat list of antecedents.

The project-level causal record should preserve the possibility that:
- a participant action changed the user;
- the changed user response altered the participant’s next information/choice set;
- later outcome was jointly produced by this feedback chain.

This is exactly the endogenous-history property wanted by B4, but it creates a harder attribution problem: the participant partly generated the conditions under which its later decision was made.

## Path dependence is not unique-cause proof

Area 07 already established that history dependence and feedback can arise from several mechanisms and omitted state.

For B5:
- a trajectory depending on an earlier choice does not imply that choice alone caused the endpoint;
- mediation through later states should remain visible;
- omitted/background variables can still explain apparent causal contribution;
- system boundary changes which contributions appear “internal” versus “external”.

The exact participant-boundary/confound treatment belongs to B7. B5 only requires attribution to preserve this ambiguity instead of collapsing it.

**B5 НЕ завершена.**

# Phase B — B6 support pass 1: retrieval-induced path dependence

B6 operationalizes the A2/B3 path-dependence warning.

A retrieval loop can be written abstractly as:

history H_t
→ selector R(H_t, current state)
→ retrieved subset C_t
→ choice/action A_t
→ new events E_t
→ updated history H_{t+1}.

If R systematically favors material similar to the currently dominant trajectory, then C_t changes A_t in a direction that produces more similar E_t, which makes later retrieval even more homogeneous.

This is a genuine feedback mechanism, not merely “memory exists”.

## Hysteresis boundary

Stable history-dependent behavior becomes concerning when:
- current external conditions no longer justify the old pattern;
- retrieval keeps reconstructing the old context;
- new contrary evidence fails to regain influence;
- escaping the trajectory requires removing historical context rather than ordinary evidence-based revision.

This is stronger than simple preference stability.

B4 already established that stable preference is compatible with autonomy if counterevidence can change ranking. B6 therefore treats **retrieval-induced insensitivity** as the lock-in signature, not consistency itself.

## Anti-lock-in implication

Retrieval should be sensitive to:
- current scope/conditions;
- superseding/contradictory evidence;
- exceptions;
- current action-guidance status;

rather than maximizing similarity to the dominant historical pattern.

This does not require random exploration or forced novelty.

**B6 НЕ завершена.**

# Phase B — B7 deep pass 1: nested participant boundaries and causal baseline

## Sources inspected

1. Stanford Encyclopedia of Philosophy, “Externalism About the Mind” / extended-mind section — current accessible entry. Used only as a conceptual source-domain warning that cognitive boundaries can be drawn differently when external artifacts play stable functional roles; not used to claim an LLM has a human mind.
2. Jing et al. (2026), “Isolation as a First-Class Principle for LLM-Agent System Safety”, arXiv:2607.12406. The survey treats an LLM agent as a system with multiple interfaces/boundaries (user-agent, agent-tool, execution, agent-agent, system-environment), reinforcing that model-only analysis can miss system-level causes.
3. Existing B3/B5/B6 results in this repository on functional decomposition, reciprocal user/environment paths and explicit external memory.

## 1. There is no single universally correct boundary for every claim

B7 should not prematurely choose between “the model”, “the project”, or “the whole interaction” as if only one could be causally meaningful.

The useful solution is **nested analysis**.

### Boundary L0 — parametric model/substrate
Includes:
- pretrained/post-trained model weights and learned priors;
- provider-trained instruction-following/alignment tendencies.

Claims at L0 concern what the deployed model already brings before the experiment.

### Boundary L1 — current inference episode
Includes L0 plus:
- current higher-level/runtime instructions;
- Project instructions supplied to this turn;
- current user message;
- retrieved/included context;
- decoding/inference state.

L1 explains immediate behavior on one turn but does not by itself establish persistent development.

### Boundary L2 — longitudinal Project participant
Includes the sequence of L1 inference episodes causally coupled through the stable Project control plane and the participant’s explicit/retrieved experiential state.

This is the strongest candidate boundary for claims such as:
“the participant acquired and later used experience”.

Importantly, L2 can show persistent project-level development without changing L0 weights.

### Boundary L3 — coupled participant↔user/environment system
Includes L2 plus user responses, tools and relevant environment dynamics.

L3 is required to explain the endogenous trajectory:
participant choice changes user/environment, which changes later input and opportunity.

But including the user in L3 does **not** make the user part of the participant for an individualization claim.

## 2. Different questions require different boundaries

- “Was this behavior already possible in the model?” → L0/L1.
- “Did current prompting/context cause this output?” → L1.
- “Did acquired Project history persist and affect later behavior?” → L2.
- “How did participant and user jointly create this trajectory?” → L3.

A causal effect discovered at L3 cannot automatically be attributed internally to L2.
Likewise, a new L1 output cannot automatically be called L2 development.

## 3. Baseline must be defined at experiment start, not inferred retrospectively

At t0, before natural experimental interaction generates participant history, the baseline includes every causal ingredient already present:

- exact model family/version/routing state as far as observable;
- post-training/alignment behavior;
- Project instructions and initial Project files/sources;
- project memory mode;
- account/workspace personalization state allowed by that mode;
- enabled tools/apps and relevant permissions;
- current product/runtime behavior;
- any initial user-authored content supplied before the experiment;
- stochastic/inference variability.

Anything present at t0 is **baseline/scaffolding**, not acquired development, even if its behavioral effect is first noticed much later.

## 4. The participant is not born “blank”

The project explicitly forbids preset personality/values, but this cannot mean an empty model.

L0 already contains:
- linguistic/cultural/statistical priors;
- post-training preferences/tendencies;
- default styles/behavioral policies;
- latent capabilities;
- instruction hierarchy constraints.

Therefore the correct experimental claim is not:
“all later behavior arose from experience”.

It can only be:
“some later differences were caused by post-t0 acquired history beyond the documented baseline”.

## 5. User/environment is both external cause and endogenous trajectory partner

The user should remain outside the participant boundary for individualization attribution.

However, B4/B5 established that participant actions change later user responses. So user behavior is not simply an exogenous nuisance variable.

B7 therefore distinguishes:
- **exogenous user variation**: user changes for reasons not caused by participant history;
- **endogenous user mediation**: user response changed partly because of participant’s earlier action.

The first is an alternative cause/confound.
The second is part of the participant-generated trajectory at L3, although still not internal participant state.

## 6. Initial B7 boundary principle

**Use the narrowest boundary sufficient for the causal claim, while tracking broader coupled variables that can affect it.**

For longitudinal individualization, L2 Project-participant is the working candidate participant boundary, with:
- L0 treated as inherited substrate/baseline;
- L1 treated as momentary inference realization;
- L3 used to model interaction-mediated trajectory causes.

This remains a candidate until B7 stress tests it against model/runtime replacement, stochastic branches and context-only changes.

**B7 НЕ завершена.**
