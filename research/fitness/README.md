# Исследование физической подготовки

Рабочее пространство Ники для системного исследования силовых тренировок, набора мышечной массы, развития силы и устойчивой тренировочной системы под Илью.

## Статус

Этап: **2 — системное глубокое исследование после Stage 2 restart**.

Stage 0A, Stage 0B и Stage 1 normalization v1.0 завершены. Текущая задача — построить достаточно полную и проверенную научную базу по физической подготовке, необходимую для последующей персональной оценки и проектирования программы. Методология исследований — обслуживающий инструмент этой цели, а не самостоятельная энциклопедическая конечная цель.

## Правила работы

1. Не удалять тему только потому, что она похожа на другую.
2. До отдельного этапа очистки сохранять дубли и пересечения.
3. Новые темы сначала добавлять в соответствующий файл области и при необходимости в `RAW_TOPIC_INVENTORY.md`.
4. Для каждой темы различать:
   - установленный факт;
   - рабочую гипотезу;
   - практический вывод;
   - персональное предположение.
5. Изменяемые рекомендации проверять по актуальным первичным источникам и нужной версии.
6. Не переносить общие рекомендации на Илью до оценки его исходного состояния.
7. Отдельно учитывать ограниченный домашний инвентарь и СДВГ, но не подменять ими базовую физиологию и методику.
8. Исследование темы не ограничено одним сообщением или одним проходом.

## Структура

- `RAW_TOPIC_INVENTORY.md` — накопительный список до очистки.
- `ARCHITECTURE_AUDIT.md` — Stage 0B проверка структуры.
- `TOPIC_OWNERSHIP.md` — границы и канонические владельцы пересекающихся тем.
- `areas/` — рабочие файлы по областям.
- Позже:
  - `sources/` — карта ключевых источников;
  - `findings/` — подтверждённые выводы;
  - `personal_assessment/` — исходная оценка Ильи;
  - `program/` — итоговая программа и её версии;
  - `logs/` — данные тренировок и изменения программы.
