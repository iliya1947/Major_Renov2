# Ethics of individualized psychological inference and AI-assisted analysis

## Purpose

This directory is the canonical storage location for the **ETH** Phase C qualification domain.

- individualized psychological inference;
- autonomy and informed participation;
- privacy and data minimization;
- confidentiality boundaries;
- nonmaleficence and benefit;
- uncertainty and epistemic humility;
- fairness, bias, and differential error;
- scope/role boundaries;
- dependency, authority, and power in AI-assisted psychological work;
- transparency and contestability;
- correction, revision, and user challenge;
- high-stakes inference and escalation;
- AI-mediated analysis of sensitive psychological information.
