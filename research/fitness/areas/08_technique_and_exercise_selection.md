# 08. Техника и выбор упражнений

Статус: **MAP_READY после отдельного аудита полноты 2026-11-16**.

## 3. Критерии приемлемого повторения

1. Целевая задача выполняется.
2. Нагрузка остаётся контролируемой.
3. Суставы движутся в допустимом диапазоне.
4. Нет резкой/необычной боли.
5. Компенсации не меняют цель упражнения сверх допустимого.
6. Темп/скорость соответствуют задаче.
7. Начало и конец повтора контролируются.
8. Повтор можно воспроизвести.

## 25. Technique evaluation workflow

For each exercise:
1. State goal.
2. Define acceptable rep.
3. Identify major joints/muscles.
4. Define start/end.
5. Define ROM.
6. Define key constraints.
7. Define stop criteria.
8. Observe first set.
9. Identify one highest-priority error.
10. Cue or regress.
11. Reassess.
12. Document persistent limitations.
