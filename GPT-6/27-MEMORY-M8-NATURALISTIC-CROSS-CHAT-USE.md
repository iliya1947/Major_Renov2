- Поиск истории выдаёт выбранные сообщения и summaries, **не полный byte-exact user/system/project/tool prefix** каждого разговора и **не внутренний trace automatic Memory retrieval**. Отсутствие tool-call в найденном фрагменте не эквивалентно доказанному отсутствию всех внешних источников.
- **Строго различаются**: (S) пункт известен из прежней Memory; (R) пункт реально доставлен модели в целевом ответе; (U) модель использовала пункт; (E) наблюдаемый эффект. Упоминание конкретного PR в ответе поддерживает U на уровне *какой-то информации*, но не идентифицирует R как Memory.
