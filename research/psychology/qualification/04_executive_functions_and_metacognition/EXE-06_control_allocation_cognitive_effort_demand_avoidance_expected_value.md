# EXE-06 — Control allocation, cognitive effort, demand avoidance, and expected value of control

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current architecture of cognitive-control allocation and mental effort that prevents failures to engage effort from being confused with lack of cognitive capacity.

The block separates:

- control capacity from control allocation;
- control allocation from successful control implementation;
- objective task demand from control actually exerted;
- control exertion from subjective effort;
- subjective effort from aversiveness;
- effort aversion from demand avoidance;
- cognitive demand from time/delay and error risk;
- immediate reward from future learning value;
- effort cost from opportunity cost;
- ability from willingness;
- laboratory effort choice from stable motivation/personality.

## Core rule

**Whether a person can exert cognitive control, whether control is worth deploying, how much control is actually deployed, how effortful that deployment feels, and whether the person chooses to repeat the task are distinct inferential targets.**

A generic control-allocation architecture is:

`goal / candidate task`
-> `expected payoff + probability of success + future value`
minus
`anticipated effort / time / opportunity / error / switching costs`
-> `control policy selection`
-> `control intensity / duration`
-> `performance + experienced effort`
-> `learning / value update`
-> `future allocation choice`

## 1. Control capacity is not control allocation

**Capacity** concerns whether a control operation can be implemented under suitable conditions.

**Allocation** concerns whether, where, when, and how strongly that control is deployed.

A person can possess sufficient capacity yet deploy little control because:

- expected payoff is low;
- effort cost is high;
- another activity has greater value;
- success seems unlikely;
- future learning seems negligible;
- time is limited.

Canonical rule:

**did not exert control != could not exert control.**

## 2. Allocation is not implementation

A system may decide to invest control yet still perform poorly because:

- the wrong control policy was selected;
- task representation was wrong;
- implementation failed;
- demand exceeded available capacity.

Conversely, low effort expenditure can still produce excellent performance when skill or automatization is high.

Therefore:

**allocation decision != control efficacy.**

## 3. Objective demand, exerted control, and subjective effort are distinct

### Objective demand

Experimenter-defined task properties such as:

- working-memory load;
- task switching;
- conflict;
- uncertainty;
- number of alternatives.

### Control exertion

The degree to which control parameters are actually adjusted.

### Subjective effort

The experienced sense that processing is effortful/costly.

These measures can covary but need not.

The 2026 Trends in Cognitive Sciences review explicitly distinguishes effort perception from effort exertion.

## 4. Difficulty is not effort

A task can be difficult because:

- perceptual signal is poor;
- knowledge is absent;
- motor requirements are demanding;
- task rule is ambiguous.

Such difficulty need not imply high controlled processing.

Likewise, an easy-looking task can require substantial sustained control.

Canonical rule:

**task difficulty != cognitive effort by definition.**

## 5. Subjective effort is not a direct control meter

People can report strong effort while exerting relatively little useful control.

They can also deploy effective practiced control with modest subjective effort.

Subjective effort can depend on:

- demand;
- skill;
- errors;
- uncertainty;
- frustration;
- boredom;
- arousal;
- task meaning;
- expectations.

Therefore:

**felt effort cannot identify control intensity without converging evidence.**

## 6. Why cognitive effort feels costly remains unresolved

A major 2026 review compares several live accounts, including:

- architectural/bottleneck and opportunity-cost accounts;
- information-theoretic accounts;
- psychological/economic valuation accounts;
- biological/network-control accounts.

No single account currently explains all cognitive-effort phenomena.

Canonical rule:

**effort cost is an active theoretical problem, not a solved resource-depletion fact.**

## 7. Expected Value of Control (EVC)

The Expected Value of Control framework proposes that control allocation weighs:

- expected payoff from a controlled process;
- the identity/type of control signal;
- control intensity;
- expected efficacy;
- cognitive-control cost.

It provides a useful normative/computational framework for asking:

> Which control signal is worth deploying, and how strongly?

EVC is influential but should not be treated as a literal complete brain mechanism.

## 8. Expected benefit matters

People can rationally expend more control when greater control is expected to improve:

- accuracy;
- reward;
- goal progress;
- avoidance of loss;
- future performance.

Thus:

`high effort -> irrational overexertion`

is not valid without evaluating expected benefit.

## 9. Expected efficacy matters

A high-value outcome may not justify effort if additional control is unlikely to improve success.

Effort allocation depends partly on beliefs about:

- skill;
- controllability;
- learnability;
- task structure.

Canonical rule:

**reward magnitude alone does not determine effort investment.**

## 10. Future learning value changes allocation

Masís Obando, Musslick, and Cohen (2025) showed that prior estimates of skill and learning rate predicted later willingness to deliberate.

Their extended EVC account includes the discounted future value of learning.

This solves an important limitation of purely immediate-reward accounts:

people may rationally invest more effort now because doing so improves future proficiency.

Canonical rule:

**short-term effort cost can be outweighed by long-term learning value.**

## 11. Learning investment breaks a simple "least effort" rule

A person can choose a more difficult strategy because it:

- teaches a skill;
- increases future efficiency;
- expands future options.

Therefore the psychological system cannot be modeled as simply minimizing immediate effort.

## 12. The "law of least effort" is not universal

A 2024 review argues that people can sometimes seek effort even without direct immediate extrinsic payoff.

Potential drivers include:

- learning/development;
- meaning;
- learned industriousness;
- beliefs about effort;
- intrinsic challenge.

Canonical rule:

**effort avoidance is common, not universal.**

## 13. Doing nothing can itself be costly

Experimental evidence shows that when the alternative is literally doing nothing, participants often do not strongly prefer the no-effort option and can sometimes choose effort.

This means choice reflects the relative value of available alternatives, not an unconditional aversion to exertion.

## 14. Cognitive conflict can sometimes be intrinsically attractive

A 2026 study found participants voluntarily chose higher cognitive conflict in Simon/Stroop tasks without external reward and reported it as both effortful and enjoyable.

This does not imply conflict is generally rewarding.

It demonstrates that:

**effortfulness and negative hedonic value are not identical.**

## 15. Demand avoidance

Demand avoidance is a behavioral tendency to choose lower-demand options when other factors are held reasonably constant.

A classic method is the Demand Selection Task (DST), in which alternatives differ in task-switch frequency.

But demand-avoidant choice can reflect more than effort cost.

## 16. Demand avoidance is not a pure effort measure

Potential contributors include:

- task-switch costs;
- error frequency;
- side/color preference;
- awareness of task contingencies;
- skill;
- reward structure;
- boredom;
- strategy.

Therefore:

**choosing the easier deck != direct measure of subjective effort cost.**

## 17. Demand avoidance can depend on decision context

A 2026 risky-choice study found that participants avoided decision pairs with less discriminable expected-value differences.

However, pupillary responses did not simply map onto the high-demand choices as expected.

This illustrates that:

- subjective demand;
- choice;
- physiological effort markers

can dissociate.

## 18. Demand Selection Task has limited trait reliability

A multi-study psychometric investigation found poor test-retest reliability for DST demand avoidance.

It also found that DST, cognitive-effort discounting, and reasoning-based measures were not strongly correlated.

Canonical rule:

**one DST score should not be treated as a stable "effort aversion" trait.**

## 19. Cognitive Effort Discounting (COG-ED)

COG-ED asks how much reward is required for a person to choose a more demanding cognitive task.

It estimates subjective value/cost by finding indifference points between:

- lower effort / lower reward;
- higher effort / higher reward.

This is closer to an explicit economic effort-cost measure than implicit demand selection.

## 20. Effort-discounting measures still mix ability and valuation

Performance/experience at high load depends on:

- working-memory ability;
- error rate;
- perceived competence;
- task familiarity.

Thus a person may discount a task heavily because that task is genuinely harder for them.

Canonical rule:

**high effort discounting != low motivation alone.**

## 21. COG-ED and DST are not interchangeable

The 2023 multi-study comparison found:

- poor DST test-retest reliability;
- good COG-ED test-retest reliability in their sample;
- little correlation between the paradigms.

Thus these tasks do not appear to be interchangeable readouts of one latent cognitive-effort trait.

## 22. Effort-discounting tasks can contain delay confounds

A 2024 validation study showed that when greater effort also took more time, measured effort discounting increased.

Therefore:

**effort cost and delay cost must be experimentally separated.**

This is especially important in real-world tasks where harder tasks often also take longer.

## 23. Effort cost has multiple components

A 2024 computational study decomposed the wage participants demanded for cognitive tasks and showed that "effort cost" can arise from multiple task components.

Potential cost sources include:

- time;
- errors;
- working-memory load;
- switching;
- conflict;
- subjective unpleasantness.

Canonical rule:

**mental effort cost is not one homogeneous price.**

## 24. Opportunity-cost accounts are plausible but not sufficient

Opportunity-cost theories propose that effort signals the value lost by not pursuing alternative activities.

This yields a strong prediction:

more valuable alternatives should increase effort/boredom/disengagement on the current task.

A 2025 experimental series found little support for this prediction in on-task performance and stronger evidence that on-task errors predicted effort avoidance.

Canonical rule:

**opportunity cost is one candidate mechanism, not a universal explanation.**

## 25. Error aversion can contribute to demand avoidance

If high-demand tasks produce more errors, people may avoid them partly because errors are:

- aversive;
- frustrating;
- threatening to reward;
- informative of low efficacy.

Therefore experiments must separate:

`demand`
from
`error probability`.

## 26. Control-state switching itself can carry a subjective cost

A 2026 study found people avoided internally switching between relaxed and focused control states within one task.

This suggests that effort cost may arise not only from high control intensity but also from:

- reconfiguration;
- instability;
- switching between control states.

Canonical rule:

**control intensity and control-state transition costs are distinct.**

## 27. Effort after-effects on reward are not necessarily monotonic

Recent 2026 evidence suggests that the relation between prior cognitive effort and subsequent reward valuation can be nonlinear.

High effort can sometimes increase rather than simply discount later reward value.

Therefore:

**more effort -> less value**

is not a universal law.

## 28. Deadlines change the value of effort

A 2026 Nature Communications study argues that progress toward a temporally constrained long-term goal can justify high effort despite weak immediate reward.

Thus control allocation can depend on:

- remaining time;
- goal distance;
- required progress rate.

Canonical rule:

**effort allocation is horizon-sensitive.**

## 29. Effort and arousal are related but not identical

Physiological arousal can increase with demand and effort.

However, current theories disagree on whether arousal:

- causes effort;
- implements effort;
- tracks demand;
- reflects salience.

A recent 2026 review proposes an arousal-focused synthesis, but this remains a model rather than settled fact.

## 30. Pupillometry is not a pure effort meter

Task-evoked pupil responses are often used as indicators of arousal/effort.

But pupil size also depends on:

- luminance;
- surprise;
- uncertainty;
- emotional arousal;
- autonomic state;
- decision processes.

The 2026 risky-choice study found a pattern opposite a simple "more demand -> larger pupil response" prediction.

Canonical rule:

**pupil response != cognitive effort directly.**

## 31. Boredom and effort are distinct

High demand can feel effortful.

Very low demand can feel boring.

Both can motivate disengagement.

Therefore a U-shaped relation between engagement and demand is plausible in some contexts.

Canonical rule:

**disengagement does not uniquely identify excessive cognitive demand.**

## 32. Effort and fatigue are distinct

### Effort

Current experienced/invested cost of controlled processing.

### Fatigue

State developing over time that can change:

- motivation;
- perceived effort;
- performance;
- willingness to continue.

A fatigued person may experience the same objective task as more costly.

Do not infer fixed capacity from fatigue-induced effort avoidance.

## 33. Skill changes effort

With learning/automatization, the same objective task can require less controlled processing.

Therefore:

`task demand fixed -> effort fixed`

is false across people or time.

This is why control allocation must incorporate skill/learning history.

## 34. Low subjective effort can reflect expertise

Experts can solve difficult domain tasks with:

- efficient representations;
- chunking;
- automatic retrieval.

Low effort therefore does not imply low engagement.

Likewise, high effort can sometimes signal inefficient strategy rather than superior persistence.

## 35. Reward can increase control allocation but is not the only incentive

External reward can justify additional control.

But control allocation can also be driven by:

- intrinsic interest;
- curiosity;
- mastery;
- identity/meaning;
- learning value;
- avoidance of loss;
- deadline progress.

Canonical rule:

**motivation for cognitive effort is multidimensional.**

## 36. Effort beliefs can change choices

People differ in what effort means to them.

Effort can be interpreted as:

- evidence of progress;
- challenge;
- lack of ability;
- task importance;
- wasted time.

These interpretations can influence willingness to persist independent of capacity.

Thus self-report statements like "this is hard" require contextual interpretation.

## 37. Demand reduction does not guarantee better performance

A 2026 study of choice overload found that reducing decision demand sped choices but did not improve choice quality; participants appeared to conserve rather than redeploy effort.

Canonical rule:

**making a task easier can reduce effort investment instead of freeing effort for better performance.**

## 38. Allocation is adaptive to learned environment

People can learn:

- which tasks are worth effort;
- which tasks are learnable;
- which control states are costly;
- how likely success is.

Control allocation therefore reflects history.

A one-session choice can encode prior learning rather than stable personality.

## 39. Digital environments may recalibrate effort valuation — theoretical status

A 2026 Nature Human Behaviour perspective proposes that low-friction/high-reward digital environments can recalibrate how cognitive effort is valued and allocated.

This is a theoretically important hypothesis.

It is **not** established as a universal causal effect of digital media on individual cognition.

Canonical rule:

**perspective/framework != confirmed person-level mechanism.**

## 40. Need for Cognition is not effort capacity

Need for Cognition (NFC) indexes self-reported tendency/enjoyment of effortful thought.

It is not equivalent to:

- cognitive capacity;
- control strength;
- actual effort exertion.

The 2023 multi-study comparison found only modest relations between NFC and some effort measures, and no reliable association with DST demand avoidance.

Canonical rule:

**liking effort != being able to exert more control.**

## 41. Effort choice and real-world engagement are not identical

Laboratory effort discounting can correlate with daily engagement under some conditions, but effects depend on framing.

A study combining COG-ED with seven-day EMA found associations between laboratory effort cost and daily mentally demanding activity that changed between gain/loss frames.

Therefore:

**ecological generalization requires direct measurement.**

## 42. Person-level inference requires context and psychometrics

Stable claims such as:

- "effort-averse";
- "lazy";
- "low executive motivation";
- "high control capacity"

require more than one task.

Prefer:

- repeated choices;
- multiple task families;
- manipulation of reward/demand;
- ability measurement;
- subjective-effort ratings;
- real-world sampling.

## 43. Capacity, allocation, and performance must be triangulated

A useful individual-difference design separately measures:

1. **ability/capacity** under strong incentive/support;
2. **allocation/choice** when effort is optional;
3. **subjective effort** at matched demand;
4. **performance** after allocation;
5. **ecological engagement**.

This allows distinctions such as:

- can but usually does not;
- tries but cannot;
- performs efficiently with little effort;
- perceives high cost but still invests effort.

## 44. Control Allocation / Effort Inference Gate

Before interpreting cognitive effort or control allocation, ask:

### A. Construct

1. Is the claim about task demand, control exertion, subjective effort, aversiveness, or choice?
2. Is control capacity being separated from willingness to deploy control?
3. Is control allocation separated from implementation success?

### B. Demand

4. What objectively makes the task demanding?
5. Is demand perceptual, mnemonic, switching, conflict, reasoning, or uncertainty-related?
6. Is difficulty being confused with controlled processing?
7. Does the participant have the skill/knowledge required?

### C. Subjective effort

8. Is effort self-reported or inferred?
9. Could boredom, frustration, errors, or uncertainty explain the rating?
10. Could expertise lower experienced effort?
11. Is perceived effort being treated as control intensity?

### D. Choice/allocation

12. What alternatives are available?
13. What rewards/payoffs differ?
14. What probability of success is expected?
15. Is future learning/progress valuable?
16. Is control-state switching itself costly?

### E. Cost decomposition

17. Is time/delay controlled?
18. Is error probability controlled?
19. Is opportunity cost manipulated?
20. Is switching/reconfiguration cost controlled?
21. Could subjective unpleasantness be independent of objective demand?

### F. Competing theories

22. Does the evidence distinguish EVC/economic, opportunity-cost, information-theoretic, bottleneck, network-control, or other accounts?
23. Is one framework being treated as settled fact?
24. Does the proposed account make discriminating predictions?

### G. Demand avoidance

25. Is the measure DST, COG-ED, or another paradigm?
26. Is the measure reliable enough for individual differences?
27. Could side/color/contingency learning explain DST choices?
28. Could ability/performance explain effort discounting?
29. Are DST and COG-ED being treated as interchangeable?

### H. Physiology

30. Is pupil/arousal being used?
31. Are luminance, surprise, uncertainty, emotion, and autonomic factors controlled?
32. Is physiology being treated as a direct effort meter?

### I. Motivation/value

33. Is reward immediate or delayed?
34. Is intrinsic interest/meaning/mastery relevant?
35. Could effort itself be rewarding in this context?
36. Do effort beliefs alter interpretation?

### J. State/context

37. Could fatigue, stress, sleep, boredom, or recent learning alter effort cost?
38. Has task skill changed with practice?
39. Is the environment stable/volatile?
40. Are deadlines or time horizon changing allocation?

### K. Individual inference

41. Is the pattern repeated across occasions?
42. Across different demand types?
43. Is capacity directly measured?
44. Is subjective effort directly measured?
45. Is real-world engagement measured?
46. What rival explanation remains?
47. What manipulation would distinguish low capacity from low allocation?
48. What is the strongest warranted conclusion?
49. What wording would overclaim motivation/personality?
50. Is a moral label being substituted for a mechanism?

## 45. High-value failure modes

### Failure A — did not exert control = lacks control capacity

Incorrect.

Correct:

Capacity and allocation are separate.

### Failure B — objective demand = subjective effort

Incorrect.

Correct:

Demand, exertion, perceived effort, and choice can dissociate.

### Failure C — effort = difficulty

Incorrect.

Correct:

Difficulty can arise without high cognitive-control investment.

### Failure D — high effort = strong control

Incorrect.

Correct:

High subjective effort may accompany inefficient processing, uncertainty, errors, or low skill.

### Failure E — low effort = disengagement

Incorrect.

Correct:

Skill/automatization can reduce effort while preserving high performance.

### Failure F — effort is inherently aversive

Incorrect as a universal claim.

Correct:

Effort avoidance is common, but effort can also be intrinsically valued or preferred over inactivity.

### Failure G — people minimize effort

Incorrect as a universal law.

Correct:

Allocation depends on reward, learning, progress, meaning, alternatives, and horizon.

### Failure H — EVC is established literal brain mechanism

Incorrect.

Correct:

EVC is an influential normative/computational framework.

### Failure I — opportunity cost explains all mental effort

Incorrect.

Correct:

Recent experiments provide limited support for its strongest behavioral predictions.

### Failure J — DST score = stable effort-aversion trait

Incorrect.

Correct:

DST has shown poor test-retest reliability and task-specific confounds.

### Failure K — COG-ED = motivation only

Incorrect.

Correct:

Effort discounting is influenced by ability, task performance, reward, and potentially delay.

### Failure L — DST and COG-ED measure the same latent trait

Incorrect.

Correct:

Empirical work finds weak cross-paradigm convergence.

### Failure M — pupil dilation = effort

Incorrect.

Correct:

Pupil responses are multiply determined.

### Failure N — chooses easy option = lazy

Incorrect.

Correct:

Choice can reflect low payoff, poor efficacy, error cost, opportunity cost, skill, fatigue, or rational policy.

### Failure O — reduced demand frees resources for better performance

Incorrect as a universal rule.

Correct:

People may conserve effort instead of reallocating it.

### Failure P — effort preference = cognitive ability

Incorrect.

Correct:

Preference/enjoyment, capacity, allocation, and performance are separate constructs.

## Canonical working rule

**Separate capacity, task demand, control allocation, actual exertion, subjective effort, and choice; model expected payoff, efficacy, learning value, time and alternative costs; validate the effort measure; then infer only the motivational/control mechanism supported by repeated converging evidence.**

Never:

**did not choose the harder option -> low effort tolerance / weak will / low executive capacity.**

## Current-standard note

As of 2026-11-19:

- current control research supports treating allocation as a value-sensitive decision about what/how much control to deploy rather than a direct readout of capacity;
- the 2026 effort-cost review concludes that the source of subjective cognitive-effort costs remains unresolved across information-theoretic, psychological/economic, bottleneck/opportunity, and network-control accounts;
- 2025 experimental work extends allocation models by showing that expected future learning value can justify greater current deliberation/control;
- demand avoidance is context-sensitive and cannot be reduced to a stable least-effort law;
- current measurement work shows limited convergence across effort paradigms, poor DST test-retest reliability in direct testing, and potentially better reliability for COG-ED-style discounting while retaining ability/reward/delay confounds;
- recent 2026 evidence further shows that control-state switching, deadlines, intrinsic enjoyment, and nonlinear effort–reward relations can all alter the apparent cost/value of cognitive effort.

## Scope note

This block establishes control-allocation and cognitive-effort architecture.

Detailed motivational valuation and goal pursuit are routed to MOT. Reward learning and effort learning are routed to LEA/MOT. Metacognitive estimates of effort/confidence are routed to MET. Fatigue/stress physiology is routed to STR/NEU. Clinical apathy/avolition/amotivation are routed to CLN.
