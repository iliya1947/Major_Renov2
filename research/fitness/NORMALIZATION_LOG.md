# Журнал нормализации

Дата начала: 2026-11-16.

## Правила

1. `RAW_TOPIC_INVENTORY.md` не сокращается.
2. Нормализация означает назначить canonical home, а не потерять тему.
3. Mechanism/application/measurement may remain separate.
4. Cross-domain references replace duplicated full explanations only later.
5. IDs in `NORMALIZED_KNOWLEDGE_TREE.md` become stable research identifiers.

1. «Физиология роста мышц» + hypertrophy mechanisms + acute/chronic muscle adaptation → PHY-05/06/07.
2. «Физиология развития силы» + neural contribution + specificity → PHY-08 + NEU-05/06 + PRO prescription.
3. «Анатомия рук» absorbed into full anatomy → ANA-04/05/06.
4. «Биомеханика упражнений на руки» absorbed into MEC with arm-specific application in TEC-14.
5. «Выбор упражнений» split:
   - exercise properties → TEC;
   - placement in program → PRO;
   - personal fit → IND.
6. «Техника» split:
   - motor learning → NEU;
   - movement execution → TEC;
   - real-time coaching → COA.
7. «Нагрузка/рабочий вес» split:
   - prescription → PRO-06;
   - RPE/RIR measurement → TST-13;
   - personal adjustment → IND.
8. «Прогрессивная перегрузка» → PRO-14/15, mechanics under fixed load → MEC-20.
9. «СДВГ и приверженность» → PSY canonical; medical medication issues → MED; coaching delivery → COA.
10. «Измерение прогресса» → TST canonical; statistical interpretation → RES.
11. «Восстановление» → REC canonical; mechanisms remain PHY/BIO.
12. «Питание» → NUT canonical; clinical risks remain MED.
13. «Индивидуальная вариабельность» → RES for proof, IND for decisions.
14. «Общая физподготовка» → GPP; physiology/programming remain in their canonical domains.
15. «Implementation/communication/professional practice» → new COA domain.
