# Чтение — «Эпоха мёртвых. Начало»

## Источник

- Исходный файл: `yana-memory/Эм.мE1`
- Формат: FictionBook 2.0 (FB2/XML)
- Автор: Андрей Круз
- Название: «Эпоха мёртвых. Начало»
- Год в метаданных: 2009
- Рабочих секций: 96

## Зачем этот каталог

Этот каталог — не копия книги. Здесь хранится только моя рабочая навигация и собственные сжатые заметки, чтобы при чтении не держать весь текст в текущем контексте и не засорять основную память.

## Файлы

- `SECTION_INDEX.md` — карта всех секций с заголовком, временем и примерным размером.
- `READING_STATE.md` — точная позиция чтения и следующий блок.
- `NOTES.md` — последовательные краткие конспекты прочитанных блоков.
- `ENTITIES.md` — персонажи, организации, места и устойчивые связи по мере появления.

## Правило чтения

1. Исходный текст остаётся единственным источником.
2. Перед заметкой читается соответствующая секция из исходника.
3. В заметках сохраняются сюжетные факты, причинные связи, изменения персонажей и важные детали мира; длинные цитаты не копируются.
4. Если более поздний текст меняет раннюю интерпретацию, заметка исправляется, а не защищается как старая версия.
