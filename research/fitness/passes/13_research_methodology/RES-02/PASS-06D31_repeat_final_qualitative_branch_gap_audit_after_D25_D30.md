# 4. Audit criterion

A candidate is elevated to a new methodology-level blocker when most/all are true:

1. it has a recognizable research lineage;
2. it changes the scientific object/question;
3. it has distinct epistemic/ontological commitments;
4. it has characteristic participant/data/researcher architecture;
5. it has distinctive analysis/integration/representation logic;
6. merging it into an existing family would erase a claim-relevant distinction;
7. there is credible current methodological or applied use;
8. direct fitness/sport/health relevance materially raises classification importance.

This criterion is stricter than:

> “someone calls it a methodology.”

# 5. NEW BLOCKER 1 — Self-Study of Practice / S-STEP

## Audit finding

**BLOCKING — dedicated pass required.**

Self-study is explicitly described in current methodology literature as a qualitative, practitioner-centred methodology.

Signature architecture includes:

- practitioner researches their own practice;
- self-in-practice is the scientific object;
- inquiry is self-initiated;
- professional/practice improvement is central;
- critical friends / collaboration challenge self-interpretation;
- multiple data sources commonly support scrutiny;
- public contribution beyond private reflection is expected.

### Why D17 is insufficient

D17 explicitly states:

> self-study / reflective practice ≠ autoethnography automatically.

But D17 did not build:

- self-study quality criteria;
- critical-friend architecture;
- self-in-practice object;
- improvement/public-knowledge boundary.

### Direct sport relevance

Current Physical Education/PETE literature actively uses S-STEP.

A 2025 coach-developer study used:

> Self-Study of Teaching Practice as overarching methodology + Heuristic Inquiry as guiding method.

Therefore omission would create direct sport/education classification error.

### Needed pass

**PASS-06D32 — Self-Study of Practice / S-STEP structures.**

# 6. NEW BLOCKER 2 — Duoethnography

## Audit finding

**BLOCKING — dedicated pass required.**

Duoethnography is described in peer-reviewed methodological literature as a distinct collaborative research methodology.

Characteristic architecture:

- two or more researchers are simultaneously participants/sites of inquiry;
- autobiographical histories are deliberately juxtaposed rather than merged;
- dialogue/polyvocality is constitutive;
- difference is treated as analytic resource;
- change/reconceptualization of perspective is central;
- universal truths are explicitly not the goal;
- ethical trust/safe dialogical space is methodology-level.

### Why collaborative autoethnography is insufficient

D17 already owns collaborative autoethnography.

But duoethnography has a more specific architecture:

self A
↔
self B
→
juxtaposition
→
dialogic disruption/reconceptualization.

Collapsing it into generic collaborative AE would erase:

- deliberate juxtaposition;
- difference as method;
- polyvocal dialogic structure;
- researcher-as-site relation.

### Direct physical-activity relevance

A 2025 study used a six-week duoethnography to investigate:

- chronic health;
- Garmin self-tracking;
- running/cycling/swimming/strength training;
- what activity data capture or omit.

### Needed pass

**PASS-06D33 — Duoethnography study structures.**

# 7. NEW BLOCKER 3 — Collective Memory Work (CMW)

## Audit finding

**BLOCKING — dedicated pass required.**

Current sport/PA methodology literature explicitly describes Collective Memory Work as a feminist-rooted participatory/praxis-oriented methodology.

Characteristic architecture includes:

- small researcher/participant group;
- shared topic;
- written personal memories;
- collective textual scrutiny;
- recursive group discussion;
- interrogation of taken-for-granted socialization;
- analysis of power embedded in memory/self/relationships;
- researcher–participant boundary deliberately blurred.

### Why narrative/participatory routes are insufficient

Narrative inquiry can analyze memory stories.

D8 can represent participation.

But CMW combines:

memory writing
+
collective analysis
+
feminist power/socialization inquiry
+
researcher/participant co-analysis

in a recognizable methodology-specific process.

### Direct sport relevance

A 2024 dedicated methodological chapter is:

> Collective Memory Work in Sport and Physical Activity.

Current 2025 work also connects CMW with Post-Qualitative Inquiry using sporting memories of young women.

### Needed pass

**PASS-06D34 — Collective Memory Work structures.**

# 8. NEW BLOCKER 4 — Indigenous / decolonizing research methodology routing

## Audit finding

**BLOCKING AT ROUTING/ARCHITECTURE LEVEL — but must not be collapsed into one universal “Indigenous method.”**

Current evidence shows that Indigenous methodologies can change:

- ontology;
- epistemology;
- axiology;
- who owns/governs research;
- what counts as knowledge;
- relationships to community/land/kin;
- data sovereignty/stewardship;
- culturally legitimate methods.

### Verified sport/PA examples

1. **Kaupapa Māori methodology** in Indigenous Māori rugby.
2. Kaupapa Māori sport/identity research.
3. Aboriginal physical-activity research using an **Indigenous methodology + yarning**.
4. Current Indigenous health methodology literature explicitly extends Indigenous research methodology even into quantitative research.

### Why generic PAR / “cultural adaptation” is insufficient

Kaupapa Māori is not merely:

> PAR with Māori participants.

It includes explicit Māori:

- epistemological;
- ontological;
- axiological;
- methodological;

commitments and principles such as:

- tino rangatiratanga;
- taonga tuku iho;
- whānau;
- kaupapa.

Likewise:

- yarning;
- Dadirri;
- Talking Circles;
- relational Indigenous methodologies;

cannot be treated as interchangeable universal methods.

### Critical taxonomy rule

The needed pass must **not** invent one pan-Indigenous methodology.

It should establish:

- Indigenous/decolonizing methodology as a routing family;
- community/nation-specific methodology identity;
- Indigenous method vs full methodology distinction;
- relational accountability;
- sovereignty/governance/data-rights fields;
- Kaupapa Māori and Aboriginal yarning examples.

### Needed pass

**PASS-06D35 — Indigenous/decolonizing research-methodology routing and sport/PA structures.**

# 11. NEW BLOCKER 7 — Post-Qualitative Inquiry (PQI)

## Audit finding

**BLOCKING — dedicated orientation/taxonomy pass required before conventional qualitative synthesis.**

PQI is not a conventional method family.

That is precisely why it cannot be silently routed under generic qualitative analysis.

Current sport/exercise literature identifies characteristic commitments including:

- posthumanist ontology;
- poststructuralism;
- often new materialism;
- decentering autonomous human subject;
- human/nonhuman/material co-constitution;
- “thinking with concepts”;
- questioning fixed separation of:
  - theory/method;
  - data/analysis;
  - human/material;
  - researcher/researched;
- possible use of “un-methods”;
- diffractive/posthuman analytic practices.

### Direct physical-activity relevance

A published physical-activity intervention study explicitly used:

> post-qualitative “(un)methodology” + diffractive analysis

to rethink an intergenerational physical-activity intervention.

The 2025 book **Post-Qualitative Inquiry in Sport, Health and Physical Education** and current field activity confirm PQI is not a historical curiosity.

### Why existing branches are insufficient

D19 Situational Analysis and D23 ethnomethodology can include material/nonhuman elements but retain different epistemic lineages.

D9 discourse work remains language/discourse-centered.

Generic new-materialist theory metadata would not capture PQI's challenge to conventional:

- data;
- method;
- subject;
- causality;
- representation.

### Needed pass

**PASS-06D38 — Post-Qualitative Inquiry / posthuman-new-materialist inquiry routing.**

### Important classification rule

PQI may ultimately be stored as:

> paradigm/orientation-level inquiry architecture

rather than an atomic “design.”

But that routing decision requires its own pass.
