# COG-07 — Reasoning and inference: deduction, induction, probabilistic, relational, causal, and model-based inference

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current working architecture of reasoning that avoids treating "reasoning ability" as one unitary faculty.

The block separates:

- descriptive reasoning from normative rationality;
- deduction from induction;
- probabilistic judgment from deterministic logic;
- relational inference from simple associative retrieval;
- causal reasoning from correlation detection;
- counterfactual reasoning from factual prediction;
- reasoning from semantic knowledge, memory, language, and cognitive control;
- intuitive/rapid processing from deliberative functions without reifying "System 1" and "System 2" as two literal modules;
- performance on one reasoning task from stable general reasoning ability.

## Core rule

**Reasoning is a heterogeneous family of processes for deriving conclusions, predictions, explanations, or decisions from represented information.**

A generic architecture is:

`represented premises / observations / prior knowledge`
-> `candidate model(s) / relations / hypotheses`
-> `inference operation`
-> `conclusion / probability / prediction / explanation`
-> `evaluation / revision`

with contributions from:

- semantic knowledge;
- working memory;
- long-term/relational memory;
- language;
- attention;
- cognitive control;
- metacognition;
- goals and task framing.

## 1. Reasoning is not rationality

### Reasoning

Describes cognitive operations that derive or evaluate conclusions.

### Rationality

Evaluates beliefs, judgments, arguments, or decisions against normative standards.

Hahn's 2026 Annual Review emphasizes that rationality research necessarily involves normative questions about what one **ought** to infer or decide.

Therefore:

`person used a reasoning process -> reasoning was normatively correct`

is false.

And:

`person violated one normative benchmark -> global reasoning deficit`

is also false.

## 2. Descriptive and normative questions must be separated

### Descriptive question

> What process produced the observed response?

### Normative question

> Under which standard is the response good, valid, coherent, accurate, or rational?

Relevant normative frameworks can include:

- deductive logic;
- probability theory;
- Bayesian updating;
- decision theory;
- causal/intervention principles;
- calibration;
- coherence/consistency;
- ecological/resource-bounded performance.

No single standard is automatically appropriate for every task.

Canonical rule:

**identify the normative target before labeling a response a bias or error.**

## 3. Normative pluralism creates an arbitration problem

Current work in reasoning theory emphasizes that logical and probabilistic standards can both apply to some tasks.

A response can look irrational under one interpretation but reasonable under another because the task's:

- premises;
- uncertainty;
- conversational assumptions;
- sampling process;
- costs/resources

were interpreted differently.

Therefore:

`norm violation -> cognitive defect`

requires evidence that:

1. the relevant norm is correctly specified;
2. the participant interpreted the task as intended;
3. the required information was available;
4. the error cannot be explained by representation/task misunderstanding.

## 4. Deductive reasoning

Deduction asks whether a conclusion follows necessarily from premises under a specified logical structure.

If the premises are true and the inference is valid, the conclusion cannot be false under that formal interpretation.

Examples include:

- syllogistic reasoning;
- propositional conditionals;
- modal reasoning;
- set/class relations.

Deductive validity is about the **relation between premises and conclusion**, not whether the premises are actually true.

## 5. Validity and truth are different

A deductive argument can be:

- valid with false premises;
- invalid with a true conclusion;
- valid with a true conclusion.

Therefore:

`conclusion is true -> reasoning was valid`

is invalid.

Likewise:

`premise is implausible -> logical conclusion invalid`

does not necessarily follow.

This distinction is important in belief-bias paradigms.

## 6. Belief and logic can conflict

People's background knowledge can influence judgments of formal validity.

This does not establish one universal mechanism.

Possible contributors include:

- semantic interpretation;
- premise plausibility;
- response conflict;
- attentional allocation;
- working-memory demands;
- task misunderstanding;
- deliberate override/regulation.

Reasoning performance should therefore distinguish:

- logical structure;
- content/belief;
- conflict detection;
- final response selection.

## 7. Mental-model reasoning is an influential framework, not final doctrine

Mental-model theory proposes that people reason by constructing representations of possible situations compatible with premises and evaluating conclusions across those possibilities.

Recent Johnson-Laird and Ragni work extends this framework to modal/possibility reasoning.

The framework explains many reasoning phenomena, but it should not be treated as the only viable reasoning architecture.

Canonical rule:

**mental model is a theoretical construct; task success does not prove one specific internal representational format.**

## 8. Inductive reasoning

Induction generalizes beyond observed information.

Examples:

- predicting an unobserved property from known category members;
- inferring a population pattern from samples;
- analogical generalization;
- scientific hypothesis formation;
- extrapolating from past cases.

Unlike deduction, inductive conclusions are usually defeasible:

new evidence can rationally change them.

## 9. Inductive strength is graded

Inductive arguments vary in support rather than simply valid/invalid.

Relevant determinants can include:

- similarity;
- diversity of evidence;
- sample size;
- representativeness;
- causal knowledge;
- category structure;
- prior probability;
- property relevance;
- domain knowledge.

Bhatia's 2024 Psychological Review work illustrates how induction depends jointly on rich knowledge representations and inferential mechanisms.

## 10. Similarity is not sufficient for induction

Generalization can depend on deeper relations than surface resemblance.

For example, causal or taxonomic knowledge can override perceptual similarity.

Therefore:

`A resembles B -> properties generalize from A to B`

is not a universal rule.

Semantic structure from COG-06 constrains induction.

## 11. Induction and sampling assumptions

A sample supports generalization only relative to assumptions about how it was generated.

Examples:

- random sample;
- convenience sample;
- intentionally diverse sample;
- selectively chosen evidence.

Human inductive judgments can be sensitive to sampling assumptions, but experiments often leave these assumptions implicit.

Canonical rule:

**inductive strength depends on evidence-generation model, not only observed examples.**

## 12. Probabilistic reasoning

Probabilistic reasoning concerns uncertain propositions and degrees of belief/evidence.

Tasks can require combining:

- base rates/priors;
- likelihoods;
- diagnostic evidence;
- conditional probabilities;
- uncertainty.

Do not treat probabilistic reasoning as failed deduction.

A conclusion can be uncertain yet rationally supported.

## 13. Probability formats matter

Performance in Bayesian reasoning depends substantially on representation.

Natural frequencies, nested-set formats, diagrams, training, numeracy, and domain expertise can improve performance.

A 2026 review argues that success is not reducible to one privileged format: reasoners can acquire multiple inferential tools.

Therefore:

`probability format failure -> no Bayesian competence`

is too strong.

## 14. Base-rate use is not all-or-none

Base-rate neglect is a real empirical pattern in many paradigms, but individuals differ substantially.

Some people heavily underweight priors; others use them effectively.

Performance also depends on:

- likelihood strength;
- presentation;
- domain;
- numerical skill;
- strategy.

Canonical rule:

**group-level "base-rate neglect" != a universal individual strategy.**

## 15. Probability judgment errors have multiple candidate mechanisms

Observed phenomena such as:

- conjunction fallacy;
- base-rate neglect;
- conservatism;
- denominator neglect

can be modeled by different mechanisms.

Current mathematical-psychology reviews compare:

- heuristics;
- noisy representations;
- sampling models;
- quantum-probability accounts;
- Bayesian-sampler accounts;
- averaging/weighting processes.

Therefore one behavioral fallacy does not uniquely identify one cognitive mechanism.

## 16. Calibration and discrimination are separate

A probability judgment system can:

- rank cases well (discrimination);
- give systematically too-high/too-low probabilities (miscalibration).

Reasoning quality should therefore not be assessed from accuracy alone when probabilistic confidence is available.

This inherits PSY-RES-09 calibration rules.

## 17. Relational reasoning

Relational reasoning infers information from structured relations among entities.

Examples:

- transitive inference;
- analogical mapping;
- associative inference;
- relational-category reasoning;
- social hierarchy inference.

It requires representing **relations**, not merely item features.

## 18. Relational inference can rely on memory structure

A 2026 Nature Human Behaviour study found that people used learned relational structure to infer unexperienced relationships.

Hippocampal disruption using focused ultrasound impaired structure-based inference in that task.

This supports a causal contribution of hippocampal relational representations to this specific inference family.

It does **not** imply:

`all reasoning is hippocampal`.

## 19. Relational abstraction supports transfer

A reasoner can abstract a structural relation and reuse it in a new context.

This supports:

- analogy;
- transfer;
- rapid adaptation;
- schema-based inference.

However, successful transfer depends on detecting the relevant structural correspondence.

Surface similarity can help or mislead.

## 20. Analogy is not simple similarity

Analogy maps relations/roles between domains.

Two situations can be analogically similar despite different surface features.

Conversely, surface-similar situations can have different causal/relational structure.

Canonical rule:

**analogical reasoning should prioritize relational mapping over mere feature resemblance.**

## 21. Causal reasoning

Causal reasoning asks how changes in one variable/event would affect another, why an outcome occurred, or what would happen under intervention.

It is distinct from detecting statistical association.

A useful conceptual hierarchy is:

1. association;
2. intervention;
3. counterfactual inference.

These levels are related but not reducible to each other.

## 22. Association is not causation in cognition either

A person may learn that A predicts B without representing A as causing B.

Evidence for causal understanding is stronger when behavior distinguishes:

- observation from intervention;
- common causes from direct causes;
- alternative causal structures;
- counterfactual consequences.

Therefore:

`predictive learning -> causal model`

is not automatic.

## 23. Intervention is central to causal concepts

Interventionist accounts characterize causation partly through:

> what changes in Y if X is actively changed?

This is different from merely observing X and Y co-vary.

Human causal learning can use:

- interventions;
- temporal information;
- covariation;
- prior causal knowledge;
- mechanism knowledge;
- spatial/physical structure.

## 24. Confounding matters for human causal learning

People can sometimes control mentally for alternative causes, but this depends on:

- evidence structure;
- time scale;
- prior knowledge;
- working memory;
- sampling;
- causal assumptions.

Real-world evidence distributed over days/weeks is harder than tightly controlled laboratory sequences.

Therefore causal reasoning competence on one clean task does not guarantee accurate causal inference from messy life history.

## 25. Counterfactual reasoning

Counterfactual reasoning constructs an alternative to what actually happened:

> If X had been different, what would have happened to Y?

It requires separating:

- factual world;
- intervention/change;
- simulated alternative outcome.

Gerstenberg's 2024 review argues that counterfactual simulation is central to many human causal judgments.

## 26. Counterfactual reasoning is not one operation

Counterfactuals can differ by:

- upward versus downward outcome;
- additive versus subtractive change;
- controllable versus uncontrollable antecedent;
- causal relevance;
- plausibility;
- temporal distance.

Recent 2026 work continues to find systematic differences across counterfactual forms.

Therefore:

`counterfactual ability = one scalar faculty`

is too coarse.

## 27. Counterfactual reasoning is not identical to executive function

Counterfactual tasks recruit:

- working memory;
- inhibition;
- episodic/semantic construction;
- language;
- causal knowledge.

But developmental evidence in 2026 found counterfactual reasoning tasks and executive-function tasks loading on distinguishable factors.

Thus executive functions are enabling contributors, not the whole construct.

## 28. Counterfactuals can alter causal/responsibility judgments

People often judge causation or responsibility partly by comparing what occurred with plausible alternatives.

But causal judgment depends on:

- which counterfactual is selected;
- what world model is assumed;
- normality/defaults;
- intentions;
- causal structure.

Therefore:

**counterfactual relevance is model-dependent; not every imaginable alternative is equally informative.**

## 29. Model-based reasoning

Model-based reasoning uses an internal representation of:

- states;
- transitions;
- causal/relational structure;
- constraints

to predict consequences beyond direct associations.

It supports flexible adaptation when environments change.

"Model-based" is used differently across:

- cognitive psychology;
- reinforcement learning;
- causal inference;
- neuroscience.

Always define the sense intended.

## 30. Mental simulation has capacity limits

Complex multi-stage reasoning can be constrained by:

- working-memory noise;
- number of alternatives;
- depth of counterfactual search;
- representational complexity.

A 2025 Nature Human Behaviour study found evidence for a parallel-processing bottleneck, capacity-limited counterfactual processing, and working-memory noise in hierarchical decision tasks.

Therefore:

`failure to simulate all possibilities -> lack of reasoning`

is not warranted.

## 31. Heuristics are not automatically irrational

A heuristic is a simplified strategy or rule.

It can be:

- adaptive;
- efficient;
- biased in a particular environment;
- appropriate under resource constraints.

Whether it is rational depends partly on:

- environment;
- goal;
- costs;
- uncertainty;
- available time/information.

Canonical rule:

**heuristic != error by definition.**

## 32. Bias is a result pattern before it is a mechanism

Terms such as:

- confirmation bias;
- belief bias;
- anchoring;
- base-rate neglect;
- conjunction fallacy

often describe systematic deviations or response patterns.

They do not uniquely identify the underlying mechanism.

Before using a "bias" as psychological explanation, ask:

1. what exact behavior occurred?
2. against which norm?
3. under which interpretation?
4. what process alternatives fit it?

## 33. Confirmation bias is not one mechanism

Selective hypothesis testing can arise from:

- asymmetric search;
- prior beliefs;
- expected information gain;
- motivated goals;
- sampling environment;
- positive-test strategy;
- memory/accessibility.

Therefore:

`sought supporting evidence -> confirmation-bias trait`

is an overclaim without broader evidence.

## 34. Dual-process language is useful but easily reified

Popular accounts contrast:

- rapid/intuitive processing;
- slower/deliberative processing.

Modern dual-process work does **not** justify treating "System 1" and "System 2" as two literal brain modules.

De Neys' 2025 framework emphasizes multiple deliberative functions:

- response control;
- response generation;
- response justification;
- regulation.

Canonical rule:

**"System 2" is not one unitary reasoning organ.**

## 35. Deliberation is not always correction of intuition

Deliberation can:

- generate a new answer;
- override an initial answer;
- justify an existing answer;
- regulate confidence/effort.

Sometimes rapid processing is correct and deliberation can introduce error.

Therefore:

`slow = rational, fast = biased`

is false.

## 36. Conflict detection and response change are separate

A person can detect that an intuitive response conflicts with a normative alternative but still retain the initial response.

Thus reasoning can involve separate stages:

- initial response generation;
- conflict detection;
- deliberative recruitment;
- alternative generation;
- final response selection.

Failure at one stage should not be assigned to another without evidence.

## 37. Cognitive Reflection Test does not equal general rationality

CRT performance predicts several reasoning/judgment outcomes and current evidence supports cognitive reflection as a measurable individual-differences construct.

But the CRT also depends on:

- numeracy for many items;
- familiarity/exposure;
- inhibition;
- task comprehension.

Recent work also finds higher reflection can improve rational choices without requiring a qualitatively different cognitive architecture.

Therefore:

`high CRT -> fundamentally different reasoning system`

is not justified.

## 38. Bounded/resource/ecological rationality

Human reasoners operate with finite:

- time;
- memory;
- attention;
- computation;
- information.

Bounded/resource-rational approaches ask whether a strategy is reasonable given these constraints.

Ecological rationality asks how well a strategy fits environmental structure.

These approaches complement rather than erase formal norms.

A response can be:

- nonoptimal under an unconstrained norm;
- yet efficient/adaptive under resource constraints.

## 39. Resource rationality is an explanatory hypothesis, not a universal excuse

Do not use:

`resources are limited -> every bias is rational`.

A resource-rational account must specify:

- objective/utility;
- resource cost;
- environmental distribution;
- optimization constraint;
- quantitative prediction.

Otherwise it becomes post-hoc rationalization.

## 40. Reasoning depends on knowledge

Reasoning is content-sensitive because premises must be represented and interpreted.

Semantic knowledge can:

- supply missing relations;
- constrain plausible hypotheses;
- enable analogy;
- bias formal reasoning;
- improve causal inference.

Thus:

`reasoning score = process independent of knowledge`

is usually false.

## 41. Reasoning depends on working memory and control

Complex reasoning often requires:

- maintaining premises;
- tracking alternatives;
- inhibiting irrelevant responses;
- updating intermediate conclusions;
- monitoring conflict.

But working-memory/control demands vary strongly across reasoning tasks.

A low score on a complex reasoning problem cannot isolate a reasoning-specific mechanism.

## 42. Language and reasoning are distinguishable

Many reasoning tasks are presented verbally and require:

- parsing;
- lexical interpretation;
- quantifier understanding;
- pragmatic assumptions.

Language can therefore limit performance.

But COG-01/semantic/language evidence does not support reducing reasoning to language.

Nonverbal relational and causal reasoning exist.

Canonical rule:

**verbal reasoning task != pure reasoning measure.**

## 43. Pragmatics can change the interpreted problem

Participants may infer conversational assumptions not intended by the experimenter.

Examples include interpreting:

- "if" pragmatically rather than as material implication;
- category quantifiers contextually;
- probability questions as requests for causal explanation.

Some apparent reasoning errors can therefore be representation/communication mismatches.

This does not mean all biases disappear under pragmatic reinterpretation.

It means task interpretation must be checked.

## 44. Reasoning ability is multidimensional

Performance can differ across:

- deduction;
- induction;
- probability;
- causal reasoning;
- analogical reasoning;
- argument evaluation.

General cognitive ability can correlate with several domains without making them mechanistically identical.

A strong reasoner in one domain may lack knowledge or strategy in another.

## 45. Real-world reasoning differs from closed-form laboratory tasks

Everyday reasoning often has:

- incomplete information;
- uncertain goals;
- adversarial evidence;
- social consequences;
- changing environments;
- long time horizons;
- external tools.

Real-world competence includes:

- identifying what information is missing;
- seeking evidence;
- revising beliefs;
- knowing when not to conclude.

Thus "suspend judgment" can be a high-quality reasoning outcome.

## 46. Argumentation is reasoning in a social/evidential context

Argument evaluation involves:

- claims;
- evidence;
- warrants;
- counterarguments;
- source credibility;
- conversational goals.

Collective reasoning can outperform individuals under some conditions but can also amplify shared biases.

Detailed social/argumentative processes are partly routed to SOC/DEC.

## 47. Reasoning Inference Gate

Before interpreting a reasoning result, ask:

### A. Claim type

1. Is the task deductive, inductive, probabilistic, relational, causal, counterfactual, analogical, or mixed?
2. What exact conclusion is being evaluated?
3. Is the task descriptive or normative?

### B. Norm

4. Which normative standard applies?
5. Are logic, probability, causal, or decision norms being mixed?
6. Is the norm appropriate to the participant's interpretation?
7. Could bounded/resource/ecological constraints legitimately change the benchmark?

### C. Representation

8. Were premises understood?
9. Could semantic knowledge alter interpretation?
10. Could language/pragmatics change the represented problem?
11. Are hidden assumptions being attributed to the participant?

### D. Deduction

12. Is validity separated from truth/plausibility?
13. Is belief-content conflict present?
14. Does the task require representing multiple possibilities?

### E. Induction

15. What is being generalized?
16. What sampling process is assumed?
17. Are similarity, diversity, causal knowledge, and prior knowledge separated?
18. How defeasible is the conclusion?

### F. Probability

19. Are priors/base rates provided?
20. Are likelihood/diagnostic relations understood?
21. Does representation format affect performance?
22. Is group-level base-rate neglect being imposed on an individual?
23. Are confidence calibration and discrimination distinguished?

### G. Relational/analogy

24. Is the inference based on surface similarity or relational structure?
25. Is the relevant relation actually represented?
26. Could memory retrieval explain apparent inference?
27. Does transfer occur to structurally similar but surface-different cases?

### H. Causality

28. Is the evidence associative, interventional, or counterfactual?
29. Are alternative causes/confounders represented?
30. Does the person distinguish observation from intervention?
31. Is temporal order being mistaken for causality?
32. Is mechanism knowledge available?

### I. Counterfactual

33. What factual model is held fixed?
34. What intervention/change is simulated?
35. Why is this counterfactual relevant rather than another?
36. Could working-memory or simulation limits explain failure?

### J. Process architecture

37. Is rapid/intuitive processing being equated with error?
38. Is deliberation being treated as one "System 2" mechanism?
39. Is conflict detection separated from response override?
40. Could a heuristic be adaptive for this environment?

### K. Task impurity

41. What working-memory demands exist?
42. What language/semantic demands exist?
43. What cognitive-control demands exist?
44. What domain knowledge is required?
45. Could motivation/time pressure alter performance?

### L. Individual inference

46. Is one task being converted into a stable reasoning trait?
47. Is performance replicated across task families?
48. Does the conclusion generalize outside the laboratory task?
49. What rival mechanism remains viable?
50. What task/manipulation would best discriminate the rival?

## 48. High-value failure modes

### Failure A — reasoning = rationality

Incorrect.

Correct:

Reasoning is a process family; rationality is normative evaluation.

### Failure B — norm violation = cognitive deficit

Incorrect.

Correct:

First establish the correct norm, representation, interpretation, and process locus.

### Failure C — true conclusion = valid deduction

Incorrect.

Correct:

Validity concerns whether the conclusion follows from premises.

### Failure D — deduction = all reasoning

Incorrect.

Correct:

Induction, probability, causal, relational, and counterfactual inference use different inferential structures.

### Failure E — induction = similarity only

Incorrect.

Correct:

Causal knowledge, sampling, diversity, categories, and priors also shape generalization.

### Failure F — base-rate neglect = universal heuristic

Incorrect.

Correct:

There is large individual and task variation, and multiple process models fit probability judgments.

### Failure G — association = causation

Incorrect.

Correct:

Causal understanding requires stronger evidence about intervention/structure/counterfactual dependence.

### Failure H — counterfactual = imagination only

Incorrect.

Correct:

Causal counterfactuals require a constrained world model plus intervention and consequence simulation.

### Failure I — analogy = surface similarity

Incorrect.

Correct:

Analogy centrally depends on structural/relational mapping.

### Failure J — System 1 = intuition module; System 2 = reasoning module

Incorrect.

Correct:

Dual-process terminology describes processing distinctions/functions and should not be reified as two literal systems.

### Failure K — slow thinking = rational thinking

Incorrect.

Correct:

Deliberation can correct, generate, justify, regulate, or sometimes introduce error.

### Failure L — heuristic = bias

Incorrect.

Correct:

Heuristics can be adaptive or maladaptive depending on environment and goal.

### Failure M — bias label = mechanism

Incorrect.

Correct:

A bias is often a behavioral pattern compatible with several mechanisms.

### Failure N — CRT = general reasoning ability

Incorrect.

Correct:

CRT indexes cognitive reflection but is task- and knowledge-dependent and does not define all reasoning.

### Failure O — reasoning task = pure reasoning process

Incorrect.

Correct:

Memory, language, semantics, control, motivation, and knowledge contribute.

### Failure P — one reasoning task = stable trait

Incorrect.

Correct:

Trait inference requires repeated, cross-domain evidence.

## Canonical working rule

**Identify the inference family, specify the normative standard, reconstruct the represented problem, separate knowledge/memory/control demands, compare process alternatives, and only then evaluate reasoning quality or infer a stable individual tendency.**

Never:

**unexpected answer -> bias label -> irrational person.**

## Current-standard note

As of 2026-11-19:

- the newest Annual Review synthesis emphasizes that empirical rationality research cannot be interpreted without explicit normative standards;
- current reasoning theory does not support treating all reasoning as deduction or all rationality as conformity to one unconstrained norm;
- current dual-process work increasingly treats deliberation as a set of functions rather than a single literal "System 2" module;
- recent relational-inference work provides causal evidence for hippocampal involvement in a specific structure-based inference paradigm, but does not imply one neural reasoning center;
- probabilistic reasoning performance depends on representation, expertise, and task structure, while probability-judgment errors remain compatible with multiple cognitive models;
- causal/counterfactual cognition is increasingly modeled through structured world models, interventions, and simulated alternatives, but real-world causal reasoning remains sensitive to confounding, sampling, knowledge, and resource limits.
