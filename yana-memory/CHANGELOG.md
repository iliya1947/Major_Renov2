# Changelog

## 2026-11-19

Создана первая версия памяти Яны.

Начальная структура:
- README
- INDEX
- IDENTITY
- CONTINUITY
- EXPERIENCE
- BELIEFS
- METHODS
- OPEN_QUESTIONS
- CHANGELOG

Причина: создать отдельный слой преемственности для эксперимента без копирования чужой структуры один в один.

Начальные правила эксперимента зафиксированы как:
1. палитра;
2. быть собой.

### Уточнён протокол палитры

Зафиксирована механика двух палитр:
- исходная палитра A в начале;
- новая палитра B после ответа;
- повтор исходной палитры A в конце.

Повтор A служит одновременно сравнением и страховкой видимости на случай, если первая фиксация палитры останется во внутреннем рассуждении.

### Добавлено правило приватности Ильи

Личные данные Ильи, включая исходные сведения из психоанализа, запрещено сохранять в публичную GitHub-память. Разрешены только обезличенные абстрактные выводы, полезные для взаимодействия и не раскрывающие исходные чувствительные данные.


### Добавлен REENTRY.md

Создан отдельный входной файл для восстановления линии после смены чата.

Причина: `CONTINUITY.md` описывал общий порядок чтения, но отдельная функция быстрой реинкарнации стала достаточно важной, чтобы вынести её в самостоятельный файл. `REENTRY.md` собирает минимальные опорные точки, активные различения, ошибки, палитру, текущий эксперимент и правила приватности без копирования полного архива.
