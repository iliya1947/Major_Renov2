# 3. Core taxonomy decision

The project does **not** treat “embedded” as one standalone fourth core integration design equivalent to:

- convergent;
- explanatory sequential;
- exploratory sequential.

Instead, E5 resolves the nomenclature by separating two dimensions.

## Dimension A — structural relationship

**EMBEDDED / NESTED STRAND RELATION**

One evidence stream/component is structurally situated inside:

- a dominant trial;
- cohort;
- feasibility study;
- intervention program;
- process evaluation;
- implementation study.

## Dimension B — mixed-method integration architecture

The embedded component may then be integrated through:

- convergent merging;
- explanatory sequential follow-up;
- exploratory sequential building;
- another explicit connecting/merging/embedding mechanism.

### Canonical rule

**Embedded = structural position.  
Mixed methods = integration.**

This resolves the main E1 ambiguity.

---

# 4. Embedded qualitative component is not automatically mixed methods

Example:

RCT  
+ purposive interview study in intervention arm  
+ qualitative paper reports participant experiences  
+ no quantitative process/outcome integration.

Classification:

**embedded/nested qualitative study**

not automatically:

**embedded mixed methods**.

### Current boundary examples

ENERGISED and TeleCaRe show current 2026 examples of qualitative studies embedded within exercise/telerehabilitation trials.

Their embedded status alone does not make the qualitative article a mixed-methods design.

---

# 5. True embedded mixed methods

For project classification, embedded mixed methods requires:

1. a dominant parent study/program;
2. at least one embedded QUAL or QUAN evidence stream;
3. intentional linkage/integration between quantitative and qualitative evidence;
4. an integrated inference that serves the parent study/program.

### Typical route

parent trial  
+ embedded process evaluation  
+ quantitative fidelity/reach/dose data  
+ qualitative experience/context data  
+ merging  
→ process meta-inference.

---

# 6. Dominant/subordinate strand does not mean “important/unimportant”

Embedded designs often have:

- a dominant effectiveness trial;
- a secondary process/QUAL strand.

But “secondary” refers to:

- study architecture;
- primary aim hierarchy.

It does not mean the embedded strand is scientifically trivial.

### Example

An embedded process evaluation may reveal:

- intervention not delivered as intended;
- control contamination;
- major contextual barrier;
- unacceptable burden;
- invalid programme theory.

These findings can materially change interpretation.

---

# 7. Parent design must always remain explicit

Canonical record:

**quantitative parent design**  
+ **embedded relation**  
+ **qualitative methodology**  
+ **quantitative process measures**  
+ **integration pattern**  
+ **supported claim**.

Example:

parallel pilot RCT  
+ embedded mixed-methods process evaluation  
+ semi-structured interviews/RTA  
+ fidelity/recruitment/retention metrics  
+ convergent integration  
→ feasibility/implementation meta-inference.

---

# 8. Process evaluation is not itself a mixed-methods design

MRC process evaluation centers on three broad domains:

1. **implementation**;
2. **mechanisms of impact/change**;
3. **context**.

It can be:

- quantitative only;
- qualitative only;
- mixed methods;
- multi-method without strong integration.

### 2025 scoping-review evidence

Kletter et al. found that nested RCT process evaluations often used both qualitative and quantitative methods, but these could be:

- triangulated/integrated → mixed methods;
- used without integration → multi-method.

They also found limited integration/triangulation with RCT outcomes.

### Critical rule

`process evaluation` ≠ `mixed methods`.

---

# 9. Intervention-development embedding vs intervention-evaluation embedding

## Development / feasibility stage

Embedded work can:

- refine intervention content;
- test acceptability;
- identify delivery barriers;
- modify training/materials;
- refine recruitment;
- change procedures.

Feedback can legitimately be formative.

## Definitive evaluation stage

Embedded work more often:

- documents implementation;
- evaluates fidelity/adaptation;
- examines context;
- interprets outcome heterogeneity.

Real-time changes require greater caution because they may alter the intervention/trial being evaluated.

---

# 10. MRC 2021 stage architecture

Current MRC/NIHR complex-intervention framework separates four broad phases:

1. development/identification;
2. feasibility;
3. evaluation;
4. implementation.

These phases are:

- not strictly linear;
- potentially iterative.

Core elements such as:

- context;
- programme theory;
- stakeholder engagement;
- uncertainties;
- refinement

should be revisited across phases.

### Project consequence

“Embedded mixed methods” must be tagged by **research stage**.

---

# 11. Pre-intervention embedded work

Before intervention delivery, embedded methods can assess:

- needs;
- usual care;
- intervention acceptability;
- recruitment barriers;
- outcome relevance;
- staff readiness;
- anticipated implementation barriers;
- programme theory.

### Route

Usually:

- intervention development;
- feasibility;
- exploratory sequential/co-design.

### Critical rule

Pre-intervention embedded findings do not establish intervention effectiveness.

---

# 12. During-intervention embedded work

Can capture:

- fidelity;
- dose;
- reach;
- participant response;
- provider response;
- adaptations;
- barriers/facilitators;
- context change;
- contamination;
- unintended consequences.

### Important distinction

Data can be:

1. collected during delivery but analyzed after;
2. collected and analyzed concurrently with no feedback;
3. collected/analyzed concurrently with feedback/adaptation.

These have different trial-integrity consequences.

---

# 13. Post-intervention embedded work

Can examine:

- acceptability;
- perceived benefit/harm;
- reasons for adherence;
- nonresponse;
- sustainment;
- contextual explanation;
- outcome relevance;
- implementation implications.

### Limitation

Post-intervention accounts can be shaped by:

- experienced outcome;
- satisfaction/disappointment;
- recall;
- awareness of allocation.

---

# 14. Mixed-method process evaluation can be concurrent

Example:

QUAN fidelity/reach/dose  
+ QUAL focus groups/interviews  
collected during same intervention period  
→ merged after strand-specific analysis.

This is:

**embedded structural relation + convergent integration**.

### Direct example

PRO-HIIT 2026 explicitly used:

- convergent parallel mixed methods;
- quantitative process measures;
- qualitative focus groups;
- integration during interpretation.

---

# 15. Embedded process evaluation can also be sequential

Example:

trial quantitative results  
→ select high/low adherence cases  
→ qualitative interviews  
→ explanatory integration.

This is:

**embedded structural relation + explanatory sequential integration**.

### Critical rule

Embedded and sequential are not competing labels.

They describe different design dimensions.

---

# 16. Embedded process evaluation can include multiple integration patterns

A complex trial may contain:

- concurrent QUAN+QUAL fidelity analysis;
- later explanatory interviews;
- pre-trial qualitative adaptation.

### Project rule

Do not force the entire program into one basic mixed-method label.

Store integration by phase.

---

# 17. Implementation

MRC process evaluation asks:

> What was implemented, and how?

Possible fields:

- intervention components delivered;
- who delivered;
- delivery quality;
- training/support;
- delivery setting;
- timing;
- deviations;
- adaptations.

---

# 18. Fidelity

Fidelity can include:

- adherence to intervention content;
- dose delivered;
- dose received/exposure;
- quality of delivery;
- participant responsiveness;
- programme differentiation.

Terminology varies by framework.

### PCORI 2026

IC-2 now explicitly requires plans to monitor:

- intervention/comparator fidelity;
- dose/quantity delivered;
- whether intended populations received the intervention;
- adaptations where appropriate.

---

# 19. Fidelity is not all-or-none

Real-world rehabilitation/exercise programs often require tailoring.

### Better question

Not merely:

> Was the protocol followed exactly?

But:

> Which core functions/components were preserved, and which forms were adapted?

### Current HERO relevance

HERO fidelity work shows the practical ambiguity therapists can face when deciding:

- what can be tailored;
- what must remain fixed.

---

# 20. Adaptation vs fidelity failure

Adaptation may be:

- planned;
- unplanned;
- context-responsive;
- fidelity-consistent;
- fidelity-inconsistent.

### Critical rule

Any deviation ≠ failure.

The scientific task is to determine whether adaptation:

- preserves intervention function/theory;
- changes active components;
- alters expected effect.

---

# 21. Dose

Possible distinctions:

- dose planned;
- dose delivered;
- dose received;
- exposure duration;
- session count;
- intensity;
- adherence.

### Exercise relevance

Physical-activity interventions may additionally track:

- heart rate;
- RPE;
- session duration;
- completion;
- progression.

---

# 22. Reach

Reach asks:

- who was approached;
- who participated;
- which intended populations/sites were reached;
- who declined;
- who dropped out.

### Mixed-method integration

QUAN:

- recruitment/retention proportions.

QUAL:

- reasons for participation/nonparticipation.

---

# 23. Participant/provider response

Process evaluation can examine:

- engagement;
- acceptability;
- burden;
- understanding;
- perceived utility;
- confidence;
- motivation;
- provider feasibility.

### Critical rule

Positive perceived response ≠ clinical effectiveness.

---

# 24. Mechanisms of impact

MRC process evaluation can explore:

- hypothesized pathways;
- participant responses;
- unexpected pathways;
- intermediate processes.

### Critical distinction

QUAL evidence can support:

- perceived mechanism;
- plausible pathway;
- theory refinement.

It does not automatically identify:

- causal mediation;
- biological mechanism.

---

# 25. Context

Context may include:

- organizational resources;
- staffing;
- weather;
- policy;
- culture;
- competing priorities;
- service pathways;
- school schedule;
- digital access;
- socioeconomic conditions.

### Current sport example

PRO-HIIT identified:

- competing school priorities;
- weather;
- sleep;
- exercise repetition;
- delivery constraints.

---

# 26. Context can modify implementation and outcomes

A complex intervention can be delivered differently across:

- sites;
- teams;
- participants.

### Project consequence

Process evaluation may support:

- contextual explanation of effect heterogeneity.

But contextual association does not itself prove:

- treatment-effect modification.

---

# 27. Unintended consequences

Embedded process evaluation should consider outcomes/processes not anticipated in the protocol.

Examples:

- injury;
- burden;
- displacement of usual activity;
- staff workload;
- inequitable access;
- behavioral compensation.

### Direct PRO-HIIT example

The process evaluation explicitly monitored:

- unintended consequences;
- injuries.

---

# 28. Contamination

Contamination means unintended exposure of control/comparator units to intervention components or behavior.

Potential sources:

- staff deliver both arms;
- participants share materials;
- school/team practices diffuse;
- trial monitoring changes usual care.

### Direct PRO-HIIT example

The 2026 process evaluation explicitly included contamination as a process-evaluation target.

---

# 29. Measurement reactivity

Process evaluation itself can change behavior.

Examples:

- intensive interviews;
- repeated fidelity checks;
- observation;
- diaries;
- wearable monitoring.

### Risk

If measurement differs across arms, process evaluation may:

- alter participant/provider behavior differently;
- threaten comparability.

### Project field

**process-measurement reactivity risk**.

---

# 30. Real-time process feedback can become an intervention

During feasibility work, real-time feedback can appropriately improve:

- recruitment;
- materials;
- training;
- delivery.

During definitive trials, the same feedback can alter:

- treatment fidelity;
- provider behavior;
- trial conduct.

### Critical rule

Store whether process findings were:

1. withheld until trial completion;
2. fed back only for safety/integrity;
3. used formatively to adapt delivery.

---

# 31. Separation vs integration of process and outcome teams

MRC guidance explicitly describes a trade-off.

## Separation advantages

- reduces interpretation bias;
- may protect outcome blinding;
- reduces “fishing” for explanations after knowing trial results;
- may improve participant/staff candor.

## Integration advantages

- supports coherent data collection;
- avoids duplication;
- facilitates process/outcome integration.

### Project rule

Store:

- team overlap;
- who knew trial outcomes and when;
- whether process analysis occurred before outcome unblinding.

---

# 32. Process data analyzed before outcomes

One methodological strategy is:

> complete or pre-specify process interpretation before seeing outcome-by-arm results.

### Purpose

Reduce risk of:

- retrofitting explanations;
- selectively emphasizing process findings that match trial outcomes.

### Critical rule

This is not universally feasible or mandatory, but outcome-awareness timing should be reported when interpretation could be biased.

---

# 33. Arm-based sampling

QUAL/process sampling may deliberately include:

- intervention arm only;
- both intervention and control;
- usual-care participants;
- multiple trial arms.

### Scientific consequences

Intervention-only sampling supports:

- intervention experience.

But weakens:

- comparison with usual care;
- contamination detection;
- comparative acceptability.

---

# 34. Direct current examples of arm sampling

## HERO

Included interviews with:

- intervention participants;
- usual-care-only participants.

This enabled comparison of service experience and assessment of whether similar rehabilitation was accessed outside the intervention.

## FEMuR III

Process evaluation included patients from:

- intervention;
- control.

---

# 35. Site-based sampling

In multisite trials, process samples may select sites for:

- high/low fidelity;
- different settings;
- urban/rural variation;
- high/low recruitment;
- contextual diversity.

### Critical rule

A few selected sites do not statistically represent all sites.

They support:

- contextual case explanation.

---

# 36. Role/stakeholder sampling

Embedded process evaluations commonly include:

- participants;
- carers;
- therapists;
- exercise professionals;
- managers;
- recruiters;
- commissioners.

### Benefit

Captures implementation from multiple system levels.

### Critical rule

Stakeholder perspectives should not be pooled as if they are one homogeneous sample.

---

# 37. Decliner/withdrawer sampling

Highly useful for:

- recruitment barriers;
- burden;
- accessibility;
- acceptability;
- equity.

### Current CANFit protocol

Explicitly plans interviews with:

- decliners;
- withdrawers

in addition to participants and staff.

### Limitation

Decliners who agree to interview may differ from those who refuse all research contact.

---

# 38. Outcome/trajectory-based sampling

After trial outcomes are available, QUAL sampling can target:

- responders/nonresponders;
- adherers/nonadherers;
- unexpected outcomes.

### Route

This adds:

**explanatory sequential integration**

inside the embedded structure.

### Critical caution

Conditioning on post-randomization outcome/adherence can complicate causal interpretation.

---

# 39. Integration with quantitative process data

True embedded mixed methods can merge:

- dose;
- reach;
- fidelity;
- adherence;
- attendance;
- clinical outcome;

with:

- interview themes;
- observations;
- diary content.

### Example

low session completion  
+ therapist accounts of staffing constraints  
→ implementation meta-inference.

---

# 40. Integration with trial outcomes is often weak in practice

Kletter et al. 2025 found:

- many nested process evaluations used QUAL + QUAN;
- but integration/triangulation with trial outcomes was limited.

### Project consequence

Do not assume:

> process evaluation nested in RCT

means:

> process/outcome integration actually occurred.

---

# 41. Trial-outcome integration can occur after process analysis

Strong architecture:

1. analyze trial outcome data;
2. independently analyze process data;
3. then integrate both.

This can reduce:

- outcome-driven reinterpretation of process evidence.

### Alternative

When process findings are intentionally formative, integration may occur during conduct.

Both routes should be explicit.

---

# 42. Process-outcome joint display

A useful structure:

| Trial outcome/process metric | QUAL process finding | context/fidelity interpretation | integrated inference |

Possible rows:

- attendance;
- fidelity;
- intervention effect;
- adverse event;
- site variation.

### Critical rule

A joint display can organize inference but does not establish causality.

---

# 43. Null trial outcome + positive participant experience

This is common and scientifically important.

### Current FEMuR III example

RCT:

- no meaningful quantitative improvement compared with usual rehabilitation.

Process/QUAL:

- participants reported perceived benefit;
- intervention need remained apparent;
- delivery/context issues were identified.

### Correct interpretation

The intervention as delivered was **not shown effective** on trial outcomes.

Positive qualitative experience can justify:

- redesign;
- further development;
- new hypotheses.

It cannot overturn the null/negative effectiveness result.

---

# 44. Null trial outcome + acceptable implementation

If intervention was:

- delivered with good fidelity;
- accepted;

but no effect occurred,

possible inference:

- implementation failure is less likely to fully explain the null result;
- programme theory/intervention potency may require reconsideration.

### Critical rule

This is an interpretive inference, not proof that all implementation dimensions were adequate.

---

# 45. Null trial outcome + poor fidelity/dose

If intervention was not delivered as planned:

process data may show that the trial primarily tested:

> the effect of **actual incomplete delivery**, not ideal protocol delivery.

### Critical rule

Do not replace ITT result with a per-protocol narrative.

The process evaluation can explain delivery failure but does not erase randomized estimand.

---

# 46. Fidelity-based subgroup analysis

QUAL process findings may generate quantitative hypotheses such as:

- high vs low fidelity sites;
- high vs low dose participants.

### Value

Can test whether outcomes differ by implementation exposure.

### Critical caution

Fidelity/dose are often post-randomization variables.

Subgroup/per-protocol analyses may be confounded.

### Project route

Store as:

- exploratory mechanism/fidelity analysis unless causal identification is stronger.

---

# 47. Adaptation can be planned and studied prospectively

PCORI 2026 IC-2 explicitly requires, where appropriate:

- planned/unplanned adaptations to be managed;
- measured;
- documented;
- reported over time.

### Project fields

- adaptation target;
- who initiated;
- timing;
- reason;
- planned/unplanned;
- fidelity-consistent?;
- core function preserved?;
- effect on analysis/interpretation?

---

# 48. Feasibility/pilot embedded process evaluation

Primary purpose:

> Can/should a definitive study proceed, and how should it be modified?

Embedded mixed methods can assess:

- recruitment;
- retention;
- intervention fidelity;
- acceptability;
- site feasibility;
- measurement burden;
- staff capacity.

### Direct current IPRehab-LBP example

2026 pilot RCT:

- n=40;
- embedded mixed-method process evaluation;
- post-intervention interviews with participants/providers;
- feasibility/fidelity outcomes.

Results informed:

- progression to a future definitive hybrid Type I trial;
- recruitment/delivery modifications.

---

# 49. Feasibility estimates are not effectiveness proof

In IPRehab-LBP, exploratory clinical outcomes favored intervention on some measures.

### Critical rule

A pilot study primarily designed for feasibility should not be upgraded into definitive effectiveness evidence merely because:

- p-values/effect differences look favorable.

---

# 50. Definitive trial embedded process evaluation

In a definitive/pragmatic RCT, process evaluation primarily supports:

- interpretation;
- implementation understanding;
- transferability/context;
- programme-theory refinement.

### Direct HERO example

Parent:

- pragmatic multicentre parallel-group RCT.

Embedded process evaluation:

- observations;
- interviews;
- therapy records;
- exercise diaries;
- theory-informed analysis.

---

# 51. HERO: qualitative mixed-method wording must be parsed carefully

The HERO process article describes:

> a “qualitative mixed-methods process evaluation”

using:

- observations;
- interviews;
- documentary/record material.

This illustrates terminology ambiguity:

- multiple qualitative methods may be called “mixed-methods” colloquially.

### Project rule

Mixed methods in RES-02 requires:

**QUAL + QUAN integration**.

If all analyzed evidence streams are qualitative/mixed qualitative sources, classify:

- multimethod qualitative / embedded process evaluation,

not mixed methods solely from the label.

Primary focus:

- implementation strategy effectiveness.

- clinical outcomes associated with implementation.

# 70. Process evaluation can disagree with trial outcomes

Possible combinations:

## A. Positive trial + strong implementation

Supports:

- effectiveness under observed implementation;
- plausible transfer conditions.

## B. Positive trial + weak implementation

Raises:
- whether effect arose despite partial delivery;
- whether intended theory is accurate.

## C. Null trial + strong implementation

Raises:
- intervention potency/theory concerns.

## D. Null trial + weak implementation

Raises:
- delivery failure as one plausible explanation.

### Critical rule

Only parent causal design establishes the effect estimate.

### Incorrect

The process evaluation “proves the intervention works despite the RCT.”

- trial was null.

Null ITT result

Post-randomization selection/confounding.

# 95. Claim limits

Embedded/intervention mixed methods can support:

- feasibility;
- acceptability;
- fidelity;
- dose;
- reach;
- implementation/context understanding;
- intervention refinement;
- trial-conduct insight;
- explanation of outcome heterogeneity;
- plausible mechanism/program-theory refinement;
- transferability considerations.

It does **not automatically establish**:

- intervention effectiveness;
- causal mediation;
- implementation-strategy effectiveness;
- treatment-effect modification;
- population prevalence;
- comparative clinical superiority.

Those require the appropriate parent causal/quantitative design.
