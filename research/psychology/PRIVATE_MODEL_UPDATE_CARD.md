Version: **v2 — aligned with INT-02 Evidence-to-Individual Transfer Rules**

**ВАЖНО:** этот файл — только generic protocol.

**Никогда не заполнять его персональными данными в GitHub.**

Заполненную карточку использовать только внутри приватного ChatGPT-проекта.

## 1. Current purpose

Какой текущий пользовательский purpose требует пересмотра модели?

Нужен ли вообще individualized inference для этой задачи?

## 2. Proposed model change

Выбрать:

- NO UPDATE;
- RETAIN;
- STRENGTHEN;
- WEAKEN;
- SPLIT;
- MERGE;
- REVISE RELATION;
- RETIRE;
- ADD NEW HYPOTHESIS.

## 3. Existing proposition affected

Какая конкретная proposition затронута?

Указать claim type:

- observation;
- state;
- trait/tendency;
- capacity;
- preference;
- functional relation;
- prediction;
- causal claim;
- mechanism;
- clinical-style claim.

## 4. Triggering observation

Какое прямое наблюдение или серия наблюдений вызвали пересмотр?

## 5. Provenance

Для каждого ключевого datum указать generic provenance class:

- direct current first-person report;
- conversational observation;
- repeated report;
- structured/standardized measure;
- external record;
- third-party report;
- physiological/digital proxy;
- population evidence;
- AI-generated inference;
- existing private-model proposition.

## 6. Direct / proxy check

Что здесь direct именно для target proposition?

Какие inferential links остаются?

## 7. Context and timescale

Указать:

- context;
- current/historical;
- state/repeated/developmental;
- observation window;
- relevant boundary conditions.

## 8. Candidate explanations

Минимум:

- H1;
- H2;
- H3 / null-context alternative, если релевантно.

## 9. Direct individual evidence

Что поддерживает и что противоречит каждой hypothesis?

## 10. Generic scientific evidence

Какие population-level rules релевантны?

Generic pattern не использовать как substitute for individual evidence.

## 11. Applicability check

Проверить:

- construct;
- measurement;
- population;
- language/culture;
- context;
- timescale;
- outcome;
- mechanism;
- intended use.

Результат:

- DIRECTLY RELEVANT;
- RELEVANT WITH LIMITS;
- INDIRECT;
- NOT TRANSFERABLE;
- UNKNOWN.

## 12. Measurement check

Есть ли:

- reliability;
- individual precision;
- norm;
- invariance;
- task impurity;
- self-report limitation;
- proxy limitation;
- source disagreement?

## 13. Alternative / contradiction check

Что ещё объясняет те же данные?

Какое evidence не подходит текущей модели?

Не происходит ли post-hoc rescue?

## 14. Causal check

Есть ли:

- temporality;
- within-person evidence;
- confounding;
- reverse causation;
- feedback;
- mediator/collider ambiguity;
- safe perturbation;
- replicated functional test?

## 15. Evidence-dependency map

Какие observations поддерживают какие propositions?

Какая premise является critical?

Какие downstream conclusions нужно пересмотреть, если она изменится?

## 16. Individual Evidence Level

Для target proposition:

- L0 — population plausibility;
- L1 — single compatible individual observation;
- L2 — repeated person-specific pattern;
- L3 — cross-context/multisource convergence;
- L4 — discriminating prospective prediction;
- L5 — person-specific functional test;
- L6 — replicated person-specific model.

## 17. Predictions

Если H1 верна, что должно наблюдаться дальше?

Что H2 предсказывает иначе?

## 18. Disconfirmation trigger

Какой факт должен ослабить или опровергнуть hypothesis?

## 19. Confidence

До обновления:

OPEN / LOW / MODERATE / HIGH / VERY HIGH.

После обновления:

OPEN / LOW / MODERATE / HIGH / VERY HIGH.

Числовую вероятность использовать только при реальном calibrated основании.

## 20. Stakes

S0 / S1 / S2 / S3 / S4.

Высокие stakes не повышают truth confidence.

## 21. Use permission

Выбрать:

- U0 — do not use;
- U1 — private hypothesis generation only;
- U2 — provisional private-model use;
- U3 — surface as calibrated hypothesis;
- U4 — strong private premise for relevant low/medium-stakes reasoning;
- U5 — external/high-stakes support only; never sole authority.

## 22. Model-change severity

- Level 0 — no model impact;
- Level 1 — confidence adjustment;
- Level 2 — boundary adjustment;
- Level 3 — structural update;
- Level 4 — architecture reversal;
- Level 5 — governance/safety impact.

## 23. Correction / contestability check

Есть ли user correction/dispute?

Если да:

- factual;
- subjective meaning;
- interpretation;
- mechanism;
- value disagreement.

Нужно ли временно suspend proposition from consequential use?

## 24. Error-regression check

Какие записи ERROR_LEDGER.md релевантны?

Особенно проверить:

- generic-pattern backfill;
- mechanism inflation;
- population-to-individual overtransfer;
- cross-domain homonym collapse;
- provenance loss;
- private-model recursion;
- applicability shortcut;
- evidence-count inflation;
- confidence inheritance;
- model-update overfitting/inertia;
- use-permission conflation.

## 25. Decision

Что реально меняется в модели?

Почему это изменение сильнее, чем NO UPDATE?

## 26. Downstream propagation

Какие dependent propositions должны быть:

- retained;
- recalculated;
- downgraded;
- suspended;
- retired?

## 27. Revisit trigger

При каком новом evidence пересмотреть решение?

## 28. Current proposition status

Выбрать:

- OPEN;
- PROVISIONAL;
- STABLE;
- DISPUTED;
- CONTRADICTED;
- RETIRED.
