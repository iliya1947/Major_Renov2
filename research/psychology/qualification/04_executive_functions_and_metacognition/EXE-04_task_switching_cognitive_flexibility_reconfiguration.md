# EXE-04 — Task switching, cognitive flexibility, set shifting, and reconfiguration

Status: **CLOSED_FOR_PRACTICE v1.0**

## Purpose

Establish a current architecture of task switching and cognitive flexibility that prevents one switch-cost measure from being treated as a direct measure of a stable, unitary "flexibility capacity."

The block separates:

- task switching from cognitive flexibility as a broader construct;
- rule retrieval from rule discovery;
- local switch cost from mixing/global cost;
- task-set reconfiguration from residual interference/task-set inertia;
- cue processing from target processing;
- task switching from response switching and stimulus-set switching;
- preparation effects from residual switch cost;
- forced switching from voluntary switch readiness;
- cognitive stability from cognitive flexibility;
- transient switching performance from stable person-level flexibility;
- laboratory switching from real-world adaptation.

## Core rule

**Task-switching performance reflects the interaction of task representations, preparation, residual activation/interference, cue and target processing, stimulus/response mappings, learned expectations, and control policy. A switch cost is therefore a behavioral phenomenon, not a pure process or stable trait.**

A generic switching architecture is:

`current task set`
-> `switch/repeat cue or environmental change`
-> `retrieve/update task representation`
-> `prepare relevant stimulus/response set`
-> `resolve residual old-task interference`
-> `select/execute response`
-> `update switch readiness / task history`

## 1. Cognitive flexibility is broader than task switching

Cognitive flexibility broadly concerns adapting cognition/behavior when goals, rules, task states, or environmental demands change.

Task switching is one laboratory family for studying this.

Other flexibility demands can involve:

- discovering a new rule;
- changing strategy;
- abandoning a goal;
- updating causal beliefs;
- switching attention;
- changing response policy;
- selecting among competing tasks.

Canonical rule:

**task switching != cognitive flexibility in full.**

## 2. Task set

A task set is a representation/configuration that specifies how to behave in a task context.

It can include:

- relevant stimulus features;
- task rule;
- stimulus-response mappings;
- response set;
- attentional settings;
- decision criteria;
- contextual information.

Modern reviews emphasize that task representations can bind abstract task information with specific cue/stimulus/response features.

Therefore:

`task = one abstract rule only`

is too simple.

## 3. What counts as a "task switch" is itself method-dependent

Task-switching paradigms vary in whether a switch changes:

- perceptual dimension;
- classification rule;
- operation;
- stimulus set;
- response set;
- cue;
- modality;
- language;
- hierarchical context.

Hazeltine's 2024 review emphasizes wide procedural variation and lack of one universally agreed definition of the core process measured by switch costs.

Canonical rule:

**name what changes, not merely that "the task switched."**

## 4. Cued task switching

In cued task switching, an explicit cue tells the participant which known rule/task to perform.

A typical sequence is:

`cue -> prepare/retrieve task set -> target -> response`.

This primarily tests **rule retrieval and implementation**.

It should not be equated with discovering an unknown rule.

## 5. Rule retrieval versus rule discovery

Classic task-switching paradigms typically provide known rules and require retrieving the appropriate rule from a cue.

The Wisconsin Card Sorting Test (WCST) often requires discovering the currently valid rule from feedback.

Recent meta-analytic work explicitly distinguishes:

- **Task-Switching Paradigm (TSP)** — rule retrieval;
- **WCST** — rule discovery.

These share flexibility demands but differ substantially in:

- uncertainty;
- hypothesis testing;
- feedback learning;
- working memory;
- planning.

Canonical rule:

**WCST/set-shifting and cued task-switching are not interchangeable flexibility measures.**

## 6. Local switch cost

A local switch cost typically compares performance in a mixed block:

`switch trial - repeat trial`.

It can be expressed in:

- RT;
- accuracy;
- sometimes model-derived parameters.

The local cost captures a transient cost associated with changing task state relative to repeating it.

It does not isolate one mechanism.

## 7. Mixing/global cost

A mixing cost typically compares:

`repeat trial in a mixed block - same task in a pure/single-task block`.

It reflects the extra cost of maintaining/operating in a multi-task context even when the current trial repeats the task.

Potential contributors include:

- keeping multiple task sets available;
- monitoring cues;
- increased uncertainty;
- interference;
- control-state maintenance.

Canonical rule:

**mixing cost != switch cost.**

## 8. Switch and mixing costs can dissociate

A 2026 four-experiment study found that increasing similarity between tasks increased **mixing costs** but not **switch costs** under a controlled paradigm.

This supports the interpretation that:

- transient task switching;
- maintaining multiple competing task sets

can be separable processes.

Therefore:

`large mixing cost -> poor switching`

is invalid.

## 9. Switch cost is multiply determined

Modern task-switching theory attributes switch costs to combinations of:

- task-set reconfiguration;
- residual activation/inertia;
- interference from previous task;
- cue encoding;
- task identification;
- stimulus-response binding/history;
- response selection;
- inhibition;
- feature/event-file effects.

No single explanation accounts for every paradigm.

Canonical rule:

**switch cost is a composite behavioral effect.**

## 10. Task-set reconfiguration

Reconfiguration accounts propose that switching requires loading/configuring a new task set.

Potential reconfiguration processes include:

- activating the new task rule;
- changing attentional weights;
- selecting new response mappings;
- updating thresholds/control settings.

Longer preparation often reduces switch costs, supporting a preparatory reconfiguration component.

But preparation usually does not remove all switch cost.

## 11. Preparation is important but not sufficient

The 2026 systematic review of 73 publications/85 studies in healthy older adults found that longer preparation-related intervals were generally associated with smaller switch costs.

However, residual costs commonly remain.

Therefore:

**switch cost contains both preparatory and post-target contributors.**

## 12. Cue-only evidence supports multiple cost sources

Yamaguchi and Swainson (2025) tested switches following cue-only versus completed task trials.

Their results support at least two broad sources:

1. cue/preparation-related cost;
2. target/task-performance-related cost.

Switch cost after cue-only preparation was more fragile and short-lived than after completed task performance.

Canonical rule:

**task preparation and task execution leave different switch-history effects.**

## 13. Residual switch cost

Even with substantial preparation time, switch costs can remain.

Possible contributors include:

- processes triggered only after target onset;
- residual old-task interference;
- stimulus/task binding;
- response conflict;
- incomplete reconfiguration.

Residual cost should not automatically be interpreted as a hard "central bottleneck."

## 14. Task-set inertia

Task-set inertia refers to persistence of previously relevant task-state information after a switch.

It can help repeat performance but impair switching.

A 2026 study shows that both local and broader task context can shape task-set inertia in dual-task settings.

Canonical rule:

**old-task persistence is context-sensitive, not one fixed decay process.**

## 15. Residual activation and active inhibition are different hypotheses

Poor switching after Task A can arise because:

- Task A remains activated;
- Task A was actively inhibited and must be reactivated later;
- new Task B is insufficiently activated;
- stimulus/response bindings retrieve the wrong task.

Behavioral switch cost alone does not discriminate these.

## 16. N-2 repetition cost

In three-task sequences, performance can be slower for:

`A-B-A`

than:

`C-B-A`.

This is called an N-2 repetition cost and is often interpreted as an after-effect of inhibiting the previously abandoned task.

It is useful evidence for backward-inhibition-like mechanisms.

But it is not a pure inhibition measure.

## 17. N-2 costs require task-processing context

A 2026 experiment found N-2 repetition costs even when stimuli were unique rather than repeatedly associated with tasks.

This weakens the claim that N-2 costs require repeated cue-stimulus-response bindings.

However, mere preparation of the intervening task without actual task execution was not sufficient to reliably produce the effect.

Canonical rule:

**N-2 cost supports reactive task-set inhibition under some conditions, but remains paradigm-dependent.**

## 18. Task-set inhibition and task-set inertia can coexist

The field should not be forced into:

`switch cost = inertia`

versus

`switch cost = inhibition`.

Different temporal and sequence effects can reflect:

- lingering activation;
- suppression of prior sets;
- episodic bindings;
- reconfiguration.

Multiple mechanisms can operate in one experiment.

## 19. Cue processing matters

Task cues can themselves differ in:

- visual complexity;
- semantic transparency;
- familiarity;
- cue-task mapping;
- repetition.

Switch costs can therefore include:

- cue-switch costs;
- task-switch costs.

A cue change is not necessarily the same as a task change.

Canonical rule:

**cue switch != task switch.**

## 20. Cue informativeness matters

The 2026 systematic review found larger switch costs in task environments with less informative cues.

A poorly informative cue increases demands on:

- retrieval;
- uncertainty resolution;
- preparation.

Therefore a large switch cost may partly reflect cue quality, not intrinsic flexibility.

## 21. Stimulus-set switching

Grange (2026) distinguishes control of:

- which stimulus/object is relevant;
- which response rule applies.

Switching relevant stimulus set can add a separate control demand beyond response-rule switching.

Canonical rule:

**switching what to process != switching how to respond.**

## 22. Response-set switching

Changing response mappings or response set can add cost independently of changing task rule.

The 2026 systematic review notes additive effects when both task and response mappings switch.

Thus:

`task switch cost = response-remapping cost`

is not valid, but response changes can contribute.

## 23. Task-rule similarity/dissimilarity changes cost

A 2024 study found switch costs scaled with dissimilarity between task rules.

This illustrates that the distance between representations matters.

However, a separate 2026 study found task similarity increased mixing/maintenance cost without increasing switch cost under a different design.

These findings are not necessarily contradictory because:

- "similarity" can be defined differently;
- paradigms isolate different stages;
- switch and mixing costs are distinct.

Canonical rule:

**representational similarity effects are task/model specific.**

## 24. Cognitive stability and cognitive flexibility

### Stability

Maintain the current task/goal despite distraction.

### Flexibility

Change task/goal when the environment requires it.

A simple one-dimensional theory predicts:

`more stability -> less flexibility`.

Current evidence does not require this strict tradeoff.

## 25. Stability and flexibility can be two-dimensional

Geddert et al. (2025) modeled switching and cross-task interference and found evidence more consistent with partly independent stability and flexibility dimensions.

This means a control system can sometimes show:

- high stability;
- high flexibility

under the same broad task context.

Canonical rule:

**flexibility is not simply the absence of stability.**

## 26. Flexibility is adaptive and context-sensitive

Egner and Siqi-Liu's 2024 review emphasizes that switch readiness changes with:

- switch probability;
- reward prospect;
- context/history.

Thus flexibility is dynamically regulated rather than fixed.

A person may rationally adopt:

- stable control in predictable environments;
- higher switch readiness in volatile environments.

## 27. Repeated switching can increase switch readiness

Mendl, Bratzke, and Dreisbach (2026) found that a prior task switch reduced subsequent switch costs and increased voluntary switching rates.

Some of this effect transferred to new task pairs.

This supports a more abstract, learned **switch-readiness** state in addition to task-specific activation.

Canonical rule:

**recent switching history can alter flexibility independently of stable trait.**

## 28. Forced and voluntary task switching are different

### Forced switching

The paradigm determines which task is required.

### Voluntary switching

The participant chooses which task to perform.

Voluntary switch rate can index willingness/readiness to change tasks, but also depends on:

- reward;
- difficulty;
- preference;
- effort;
- strategy.

Canonical rule:

**ability to switch and willingness to switch are different.**

## 29. Low voluntary switching is not necessarily rigidity

A person may rationally repeat a task because:

- switching is costly;
- current task is rewarded;
- current task is easier;
- current goal prioritizes stability.

Thus:

`low voluntary switch rate -> inflexible person`

is invalid.

## 30. Mixing cost can reflect task maintenance competition

The 2026 Poncet study suggests that when two tasks rely on highly similar processing, maintaining both in the mixed environment can be harder even if actual switching is not harder.

Thus global/mixing costs may capture:

- multi-task-set maintenance;
- cross-task competition;

more than transient reconfiguration.

## 31. Task similarity is not a unitary variable

Similarity can involve:

- stimulus features;
- response rules;
- operations;
- semantic content;
- neural/process overlap.

Effects depend on which similarity dimension is manipulated.

Canonical rule:

**"similar tasks" must be operationalized.**

## 32. Task switching is not dual-tasking

Task switching typically concerns sequential changes in task set.

Dual-task paradigms often require tasks to overlap in time.

Dual-task cost can arise from:

- concurrent bottlenecks;
- shared resources;
- response-selection overlap.

Switch cost can occur even without temporal overlap.

Canonical rule:

**switching cost != dual-task cost.**

## 33. Task switching is not distraction

Being pulled away from a task by an irrelevant stimulus is not the same as intentionally switching to a new relevant task.

Distractibility belongs primarily to attention/control interfaces.

Flexibility concerns adaptive change when the new task is relevant.

## 34. Flexibility is not distractibility

High flexibility means changing behavior when the change is warranted.

High distractibility means irrelevant events too easily disrupt current processing.

A person can be:

- highly stable against irrelevant distraction;
- highly flexible when a relevant switch cue appears.

This is exactly why stability/flexibility should not be forced onto one axis.

## 35. Flexibility is not absence of persistence

Persistence can be adaptive when the task remains relevant.

Flexibility becomes adaptive when task relevance changes.

Canonical target:

**context-appropriate switching**, not maximal switching frequency.

## 36. Preparation interval changes measured switch cost

The 2026 systematic review found generally smaller switch costs with longer preparation time.

Thus comparisons across studies/people require matched:

- cue-stimulus interval;
- response-cue interval;
- response-stimulus interval;
- inter-stimulus interval.

A "switch cost" without timing details is underspecified.

## 37. Paradigm architecture changes measured switch cost

The same systematic review found cost differences associated with:

- base task;
- switch rule/cue type;
- stimulus complexity;
- cue informativeness;
- preparation time.

The range of reported RT effect sizes was very large.

Canonical rule:

**switch cost magnitude is partly a property of the paradigm.**

## 38. Speed and accuracy must be evaluated together

A small RT switch cost can be obtained by:

- accepting more errors;
- slowing repeat trials;
- changing response criterion.

Likewise, a larger RT cost can accompany higher accuracy.

Therefore:

**RT switch cost alone is not complete switching performance.**

## 39. Difference scores create reliability problems

Switch cost is a difference between two performance conditions.

Difference scores can have limited reliability even when underlying RTs are reliable.

A 2024 Category Switch Task pilot found:

- good/high reliability for single-task RT;
- only marginal/moderate reliability for switch- and mixing-cost RT;
- poor/low reliability for switch/mixing accuracy costs.

Therefore trait inference requires exact measure-level reliability.

## 40. Practice effects matter

The same 2024 study found practice effects in several task outcomes, including mixing-cost RT.

Repeated testing can therefore change performance because participants learn:

- task structure;
- cue mappings;
- switching expectations;
- strategy.

Longitudinal change cannot be interpreted without practice controls.

## 41. Group-sensitive does not mean person-reliable

A switch cost can be highly replicable as a group-average phenomenon while being unreliable for ranking individuals.

Canonical rule:

**robust experimental effect != valid individual-difference metric.**

This is the same reliability paradox already established in PSY-RES-03/EXE-03.

## 42. Age effects depend on paradigm design

The systematic review published 12 November 2026 found that many studies report slower/less accurate switching in older adults.

But it also found substantial heterogeneity in:

- paradigm manipulations;
- outcome definitions;
- effect reporting;
- under-reporting of nonsignificant results.

Therefore:

**age group difference != one universal decline in a single flexibility mechanism.**

## 43. Rule-discovery and rule-retrieval can age differently

Recent neuroimaging meta-analyses distinguish age trajectories for:

- WCST-like rule discovery;
- TSP-like rule retrieval.

This reinforces that "cognitive flexibility" aggregates multiple operations.

Population-level age findings must not be applied directly to one person.

## 44. Real-world switching is richer than laboratory switching

Everyday task transitions often involve:

- self-generated goals;
- interruptions;
- unfinished-task memory;
- task resumption;
- social demands;
- variable importance;
- external tools;
- longer time horizons.

Laboratory task-switching controls many of these factors by design.

Therefore:

`large lab switch cost -> poor everyday adaptability`

requires independent ecological evidence.

## 45. Real-world switching can be strategic

People can manage switching costs through:

- batching similar tasks;
- external reminders;
- environmental cues;
- completing subgoals before switching;
- reducing interruptions;
- planning resumption points.

Real-world executive effectiveness is not equivalent to zero switch cost.

## 46. Task Switching / Flexibility Inference Gate

Before interpreting a switching result, ask:

### A. Construct

1. Is the claim about task switching, set shifting, rule discovery, strategy switching, or broad cognitive flexibility?
2. What exact task representation must change?
3. Is the change externally cued, internally chosen, or discovered from feedback?

### B. Task type

4. Is this cued task switching, alternating-runs, voluntary switching, WCST, or another paradigm?
5. Does it require rule retrieval or rule discovery?
6. Are the tasks known in advance?

### C. Cost type

7. Is the measure local switch cost or mixing/global cost?
8. What is the exact comparison condition?
9. Is RT, accuracy, or both used?
10. Are mixing and switching being treated as interchangeable?

### D. Representation

11. What task-set components change: stimulus set, rule, operation, response set, context, or modality?
12. How similar/dissimilar are the task representations?
13. Could event-file/stimulus-response bindings explain part of the effect?

### E. Reconfiguration

14. Is a new task set actively reconfigured?
15. Is enough preparation time available?
16. Does longer preparation reduce the cost?
17. What residual cost remains after preparation?

### F. Residual interference

18. Could previous task-set activation/inertia explain the cost?
19. Could backward inhibition explain sequential costs?
20. Is N-2 repetition cost measured?
21. Could episodic bindings mimic an inhibition effect?

### G. Cue processing

22. Does the cue itself change?
23. Is cue-task mapping transparent/learned?
24. Is cue informativeness matched?
25. Could cue encoding explain apparent task-switch cost?

### H. Target/response processing

26. Does the response mapping switch?
27. Does the relevant stimulus set switch?
28. Could target-triggered response conflict explain residual cost?
29. Is action reprogramming involved?

### I. Stability/flexibility

30. Is stability against distraction measured separately?
31. Is flexibility being forced onto the opposite end of a stability axis?
32. Could both stability and flexibility be high?
33. Is the environment stable or volatile enough to justify the current switch policy?

### J. Voluntary control

34. Is task choice forced or voluntary?
35. Is switch rate being interpreted as ability rather than willingness/policy?
36. Could reward/difficulty/effort explain voluntary switch rate?
37. Could recent switching history alter switch readiness?

### K. Measurement

38. Is the switch/mixing cost reliable enough for individual differences?
39. Could difference-score reliability be low?
40. Are practice effects modeled?
41. Are timing parameters matched?
42. Does the paradigm itself inflate/reduce the cost?

### L. Individual inference

43. Is the pattern replicated across task families?
44. Across occasions?
45. Does it generalize from rule retrieval to rule discovery?
46. Does it generalize to real-world task transitions?
47. Could state factors explain the session result?
48. What rival mechanism remains viable?
49. What second paradigm/manipulation would discriminate it?
50. What is the strongest warranted conclusion?

## 47. High-value failure modes

### Failure A — switch cost = cognitive flexibility

Incorrect.

Correct:

Switch cost is one context- and paradigm-dependent behavioral signature of switching.

### Failure B — task switching = all flexibility

Incorrect.

Correct:

Rule discovery, strategy change, goal updating, and other adaptive changes can require different mechanisms.

### Failure C — WCST = cued task switching

Incorrect.

Correct:

WCST prominently includes rule discovery from feedback; typical TSP mainly requires retrieval of known rules.

### Failure D — local switch cost = mixing cost

Incorrect.

Correct:

Local cost reflects transient switch-vs-repeat difference; mixing cost reflects operating within a mixed-task context.

### Failure E — large mixing cost = poor switching

Incorrect.

Correct:

Mixing costs can index maintenance/competition among multiple task sets separately from transient switching.

### Failure F — switch cost = reconfiguration time

Incorrect.

Correct:

Residual interference, cue processing, bindings, response selection, and target-triggered processes also contribute.

### Failure G — preparation removes switch cost

Incorrect.

Correct:

Preparation often reduces costs but residual costs can remain.

### Failure H — residual switch cost = one central bottleneck

Incorrect.

Correct:

Multiple target-triggered and interference mechanisms can produce residual cost.

### Failure I — N-2 repetition cost = pure inhibition

Incorrect.

Correct:

It supports backward-inhibition-like dynamics but remains sequence/task/model dependent.

### Failure J — cue switch = task switch

Incorrect.

Correct:

Cue changes can generate independent encoding/retrieval costs.

### Failure K — response switch = task switch

Incorrect.

Correct:

Response-set changes add distinct control demands.

### Failure L — flexibility = opposite of stability

Incorrect.

Correct:

Current modeling supports partly independent stability and flexibility dimensions.

### Failure M — low voluntary switch rate = rigidity

Incorrect.

Correct:

Switch willingness depends on reward, effort, task value, difficulty, and policy.

### Failure N — frequent switching = high flexibility

Incorrect.

Correct:

Adaptive flexibility means switching when warranted, not maximizing switch frequency.

### Failure O — robust group switch cost = reliable individual flexibility score

Incorrect.

Correct:

Difference-score reliability can be only moderate or poor.

### Failure P — laboratory switch cost = everyday adaptability

Incorrect.

Correct:

Real-world switching includes self-generated goals, interruption management, resumption, priorities, and external supports.

## Canonical working rule

**Specify what changes, distinguish rule retrieval from rule discovery and local switch cost from mixing cost, separate reconfiguration from residual interference/cue/response effects, model preparation and switch history, verify reliability, then infer only the flexibility mechanism supported across paradigms and contexts.**

Never:

**one switch-cost score -> cognitive flexibility -> stable person-level adaptability.**

## Current-standard note

As of 2026-11-19:

- current reviews emphasize that task-switching paradigms vary widely and switch costs do not isolate one core switching process;
- the systematic review published 2026-11-12 documents substantial heterogeneity in task designs, cueing, preparation intervals, base tasks, outcome reporting, and effect sizes;
- current evidence distinguishes local switch costs from mixing/global costs and includes direct 2026 evidence that they can dissociate;
- current models support partly independent cognitive stability and flexibility rather than requiring a single strict tradeoff axis;
- flexibility/readiness to switch is context- and history-sensitive and can change after recent switching experience;
- individual-difference inference is constrained because switch/mixing difference scores can show only modest or poor test-retest reliability even when the group-level switch phenomenon is robust;
- WCST-like rule discovery and cued task-switch rule retrieval should not be treated as interchangeable measures of one flexibility mechanism.
