# 02 — Когнитивная психология и память: накопленное понимание A1

**Здесь фиксируется только понимание структуры поля, не ответы на механизмы.**

## После первого прохода

1. **Для нашей задачи недостаточно спрашивать «как работает память».** Есть минимум четыре принципиально разных перехода:
   - experience → memory representation;
   - multiple memories → generalized knowledge;
   - old memory + new experience → updated/reconstructed memory;
   - available memory → actual future judgment/action.

2. **Главный будущий вопрос «как воспоминания становятся опытом» на самом деле распадается на несколько научных проблем.** Generalization, schema formation, semanticization, retrieval, consolidation и memory-based decision making — разные ветви. Если их слить, можно получить красивую, но фиктивную цепочку.

3. **Память не следует трактовать как неизменный архив.** Современная карта поля включает reconstruction, retrieval-induced changes, updating, forgetting, distortion и selective consolidation. Но A1 пока не устанавливает, какой механизм из них «правильный».

4. **Сохранённая информация и используемая информация — разные проблемы.** Working memory/attention, retrieval cues, current goals и metacognitive control определяют, что из долговременной памяти вообще попадает в текущую работу.

5. **Конкретность и обобщение находятся в напряжении.** Episodic detail позволяет гибко использовать неожиданные детали позднее; abstraction/generalization позволяет переносить закономерность. Поэтому будущая фаза B должна исследовать не только «как обобщить опыт», но и **что теряется при обобщении и когда нужна исходная конкретика**.

6. **Забывание потенциально является частью адаптивной памяти**, а не только её отказом. Это означает, что будущий вопрос о долговременном опыте должен включать не только накопление, но и suppression/interference/pruning — без преждевременного вывода, как это должно работать у ИИ.

7. **Autobiographical memory и external/offloaded memory — два разных пересечения с нашим экспериментом.** Первая связывает память с self-continuity/directive use; вторая — с внешними носителями. Ни одна аналогия пока не является моделью ChatGPT.

8. **Методологический риск высокий:** многие области memory science сами предупреждают о разрыве лабораторных задач и everyday memory. Поэтому при A2 нужно отдельно смотреть, какие вопросы основаны на реальных ситуациях, а какие только на удобных experimental paradigms.

## Состояние

Рабочая карта: M1–M16. Она **ещё не считается достаточной для A1**, пока не проверены шесть возможных пропусков из RESEARCH.

## Следующий шаг

Провести короткий второй проход A1 именно по возможным пропускам: source/reality monitoring, episodic future simulation, social/transactive memory, procedural/implicit memory, development и memory control. После этого либо скорректировать M1–M16, либо признать карту достаточно зрелой для первого глобального прохода и перейти к области №3.


## После второго прохода A1

1. **Source monitoring и metamemory не требуют отдельных новых направлений**, но делают карту точнее: недостаточно иметь содержание памяти — нужно ещё различать происхождение содержания и оценивать надёжность собственного recollection.

2. **Future-oriented cognition нужно разделять внутри одного блока.** Episodic future thinking конструирует возможные будущие события; prospective memory удерживает намерение и запускает действие позже. Их нельзя смешивать под общей фразой «память о будущем».

3. **Implicit/procedural memory важна именно как контрпример архивной модели памяти.** Опыт может менять performance без доступного сознательного эпизода. Но объяснять обучение навыкам должна область №3.

4. **Социально распределённая память показывает, что граница памяти не всегда совпадает с одним человеком.** Для нашей карты достаточно отметить это пересечение; механизмы conversational/social memory уйдут в №5, техническая external memory — в №9/№11.

5. **Memory control — не только retrieval, но и deliberate/non-deliberate non-retrieval.** Это усиливает M8: долговременная память формируется и тем, что систематически не допускается к повторному извлечению.

## Статус A1

Рабочая карта M1–M16 признана **достаточной для первого глобального прохода A1**. Она не финализирована: на A2 потребуется пересмотр после областей №3–№12, прежде всего границ memory↔learning, memory↔motivation, human memory↔external/agent memory.
