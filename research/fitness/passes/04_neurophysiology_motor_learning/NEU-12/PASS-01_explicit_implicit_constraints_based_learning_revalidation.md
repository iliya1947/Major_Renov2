## 1. Purpose / Question Card

### Decision

Build a defensible framework for how a coach can structure skill acquisition before later deciding exact cue, feedback and exercise-progression methods.

The downstream decisions are:

- whether early skill learning should be treated as a fixed three-stage sequence;
- when deliberate/verbal strategy is useful versus when it can create unnecessary cognitive load;
- what “implicit learning” actually means and what common coaching methods can or cannot establish;
- whether exploration should be encouraged and how to distinguish useful search from uncontrolled error/noise;
- whether manipulating task/person/environment constraints is a valid route to skill acquisition;
- whether constraints-led/nonlinear pedagogy is demonstrably superior to explicit/linear teaching;
- whether there is a validated universal “optimal difficulty” or success-rate target;
- how to interpret progression/regression without assuming a universal easy-to-hard law;
- how much of these findings can be transferred to resistance-exercise technique.

Motor-learning construct + instructional intervention + practice-design framework + direct resistance-exercise applicability.

## 3. Cognitive / associative / autonomous stages

The classical Fitts–Posner model is useful as a coarse descriptive heuristic:

- **cognitive**: the learner is solving what the task requires and often depends more on deliberate attention, instructions and detectable errors;
- **associative**: movement-task relationships become more stable and errors are progressively refined;
- **autonomous**: execution is more efficient and less dependent on high-level deliberate control.

For project use, this model must not be treated as:

- three discrete neural states;
- three mandatory periods of fixed duration;
- a universal sequence in which the learner permanently leaves one state;
- proof that an “autonomous” skill requires zero attention;
- a rule that explicit instruction belongs only to the beginning.

Modern motor-learning evidence supports multiple time scales and changing neural/behavioral processes across practice (PMID 16385137, 22078504), but this does not validate hard boundaries corresponding one-to-one with the classic labels.

Upstream NEU-11 also established that automaticity is graded and task/context specific. A skilled lifter can execute one component with low deliberate control while another component, a new load, a new implement or an error correction again requires deliberate attention.

### Canonical rule

**Cognitive → associative → autonomous is a useful descriptive teaching model, not a literal universal three-state biological law.**

Confidence: **MODERATE-HIGH for broad progression / LOW for hard stage boundaries.**

## 4. Explicit motor learning

For this project, explicit learning is operationally treated as motor-skill acquisition in which task-relevant knowledge, rules, hypotheses or strategies are sufficiently accessible to deliberate awareness that the learner can intentionally use and often verbalize them.

Examples can include:

- deliberately aiming to a particular location;
- consciously applying a technical rule;
- testing a stated strategy;
- using a verbal cue as a rule for execution.

Important boundaries:

1. explicit learning is **not identical** to verbal instruction;
2. verbal instruction can be brief and outcome-oriented without generating a large declarative rule set;
3. explicit learning is **not identical** to internal attentional focus;
4. explicit strategy can coexist with implicit adaptation/refinement;
5. the amount of reported declarative knowledge is an imperfect proxy for the complete explicit contribution.

In sensorimotor adaptation, explicit strategy can contribute substantially to early compensation, but the exact decomposition depends on measurement assumptions. Maresch et al. (PMID 34214514) and 't Hart et al. (PMID 39191485) show why explicit/implicit components cannot safely be inferred as two perfectly measured additive quantities.

### What explicit learning can plausibly provide

- rapid use of understandable task information;
- deliberate correction when a known error cause is identified;
- flexible strategy change;
- efficient communication of safety-critical or task-goal constraints;
- a way to solve a novel problem before repeated sensorimotor refinement has occurred.

### What is not established

It is not established that:

- more explicit rules always improve skill;
- explicit instruction is universally inferior;
- explicit knowledge necessarily prevents automaticity;
- every novice should receive a large checklist;
- reducing all explicit knowledge is a goal in itself.

### Canonical rule

**Explicit learning is deliberate, accessible strategy/knowledge contributing to skill acquisition; it is a tool, not an intrinsically superior or inferior learning mode.**

Confidence: **HIGH for construct distinction / MODERATE for exact optimal amount in complex resistance exercise.**

## 5. Implicit motor learning

A defensible operational definition is learning expressed with relatively little accessible/verbalizable task knowledge or deliberate rule use.

This does **not** mean:

- absolutely unconscious learning in every sense;
- absence of attention;
- absence of perception of success/error;
- absence of all strategy;
- that the learner cannot describe anything about the task;
- that one specific coaching method proves the resulting learning process was implicit.

The Delphi study (PMID 24968228) reached consensus on broad definitions but did **not** reach consensus that common intervention strategies reliably produce implicit versus explicit learning.

This is an important project boundary:

> **instructional method ≠ process-pure learning mechanism.**

A learner receiving:

- analogy instruction;
- external-focus instruction;
- errorless practice;
- dual-task practice;
- nonlinear/constraints-led practice

may still develop explicit knowledge.

Conversely, a learner receiving explicit instructions can still undergo implicit sensorimotor refinement.

### Sensorimotor-adaptation boundary

Much of the cleanest explicit/implicit decomposition literature uses visuomotor rotation or similar adaptation paradigms.

Those paradigms are highly useful for mechanism identification, but:

- adaptation to a perturbation is not identical to acquiring a complex strength skill;
- simple reported aiming strategies do not map one-to-one onto all declarative knowledge in a multi-joint exercise;
- implicit recalibration in reaching should not be treated as a complete model of “implicit coaching” in sport.

### Canonical rule

**Implicit learning means relatively reduced conscious/declarative rule dependence, not a process-pure “unconscious mode”; explicit and implicit contributions can coexist.**

Confidence: **HIGH for coexistence/measurement caution / MODERATE for direct mapping to resistance-exercise coaching.**

## 6. Explicit and implicit are not a clean binary treatment comparison

The project should distinguish three levels:

### Level 1 — instructional manipulation

What the coach/researcher provides:

- explicit rules;
- analogy;
- errorless task design;
- constraint manipulation;
- external focus;
- reduced feedback;
- dual task.

### Level 2 — internal learning process

What the learner actually does:

- deliberate strategy;
- hypothesis testing;
- perceptual attunement;
- implicit recalibration/refinement;
- exploration;
- retrieval of previously learned solutions.

### Level 3 — observable outcome

What changes:

- acquisition;
- retention;
- transfer;
- movement pattern;
- performance;
- declared knowledge;
- dual-task cost.

These levels cannot be collapsed.

The 2025 sport-biomechanics systematic review (PMID 40209584) found a small aggregate advantage for interventions classified as implicit versus controls, while direct implicit-versus-explicit results and study quality were heterogeneous. The paper explicitly cautions against assuming that an “implicit” intervention necessarily produced implicit learning.

The 2025 analogy meta-analysis (PMID 39419241) reported favorable average effects for analogy instruction, including some retention outcomes, but also high heterogeneity and high risk of bias.

The 2026 errorless-learning systematic review/meta-analysis (PMID 41953321) found no consistent overall movement-performance advantage over errorful learning and rated certainty low/very low across much of the evidence.

Therefore there is no defensible universal hierarchy:

`implicit > explicit`

or

`explicit > implicit`.

### Canonical rule

**Compare instructional methods by delayed task-relevant outcomes, not by assuming that their labels reveal a pure internal learning mechanism.**

Confidence: **HIGH**.

## 7. Discovery and exploration

For project purposes:

> **Exploration** = search across candidate movement solutions to discover actions that better satisfy the task goal under current constraints.

Exploration can involve variability, but variability is not synonymous with exploration.

Observed movement variability can arise from:

- deliberate search;
- reinforcement-driven search;
- motor noise;
- unstable control;
- fatigue;
- changing constraints;
- redundant solutions that preserve the same outcome.

Therefore:

`more variability`
does not automatically mean
`more useful exploration`.

The 2025 systematic review on initial motor variability (PMID 39547333) found associations with later learning/adaptation in many but not all studies, with results depending on task class and how variability was measured. Initial-performance bias and measurement choices limit simple prescriptions.

The exploration-methodology literature (PMID 34341885) further warns that trial-to-trial variability can be misclassified as exploration.

### Exploration/exploitation trade-off

Early in learning, broad search can help identify effective solutions.

As a task becomes better solved, excessive continued search can:

- destabilize a useful solution;
- increase error;
- reduce task-specific practice;
- obscure which changes caused success.

Thus useful learning may alternate between:

- **exploration** — search;
- **exploitation/refinement** — repeat and tune a useful solution.

This is compatible with NEU-09:

- variability can be functional;
- but variability magnitude alone is not a quality metric.

### Direct kettlebell evidence

PMID **42617501** studied 12 young adults practicing the kettlebell swing for one week.

Participants with higher early **solution variability**, when **error variability remained low**, later made fewer errors with a water-filled kettlebell.

This is directly relevant because it distinguishes:

- solution exploration;
- task error.

But it is:

- very small;
- observational with post-hoc high/low variability grouping;
- not evidence that deliberately forcing more variability will cause better transfer.

### Canonical rule

**Useful exploration is structured search among task-successful or informative solutions; random error/noise and larger variability are not automatically beneficial.**

Confidence: **MODERATE-HIGH for principle / LOW-MODERATE for dose prescription in resistance training.**

## 8. Discovery learning is not “no guidance”

“Discovery” can range from relatively unguided trial-and-error to strongly guided search.

For motor coaching, the useful distinction is not:

`instruction` versus `no instruction`.

A coach can guide discovery by manipulating:

- goal;
- target;
- implement;
- range;
- support;
- external reference;
- environment;
- feedback availability.

This can make some solutions easier to discover without specifying every joint angle.

However, pure unguided discovery should not be assumed superior:

- some learners may not detect the relevant error;
- the task may contain safety-critical constraints;
- repeated noninformative failure can consume practice time;
- a missing concept can sometimes be communicated directly and cheaply.

### Canonical rule

**Discovery is a search process; guidance can shape the search without dictating one movement solution.**

Confidence: **MODERATE-HIGH**.

## 9. Constraints-based / constraints-led learning

The constraints-led perspective treats movement as emerging from the interaction of:

1. performer/organism constraints;
2. task constraints;
3. environmental constraints.

In coaching, the practical mechanism is:

> change a constraint so that the learner is more likely to perceive and stabilize movement solutions that satisfy the task goal.

Examples:

- change target or implement;
- change available space;
- change load or support;
- alter rules or success criterion;
- change stance options or reach target;
- create an environment that makes the desired task information easier to detect.

This can reduce reliance on continuous verbal correction.

### What the evidence supports

The framework is conceptually compatible with:

- motor abundance;
- task-specific coordination;
- exploration;
- individual movement solutions.

It is also directly relevant to strength training through the dynamical-systems framing of resistance exercise (PMID 37270792).

### What the evidence does not support

Current evidence does not establish that constraints-led/nonlinear pedagogy:

- is universally superior to explicit/linear teaching;
- should eliminate all direct instruction;
- produces better technique in every closed strength task;
- guarantees more individualized or safer technique;
- should maximize variability.

The 2025 systematic review in team-invasion sports (PMID 40759833) found that both linear and nonlinear approaches supported skill development. Tactical outcomes sometimes favored nonlinear pedagogy, whereas most technical outcomes did not show clear differences. Transfer from team-sport tactical learning to closed resistance exercise is limited.

### Direct power-clean evidence

PMID **35499570** randomized 16 beginners learning the power clean to:

- linear pedagogy with explicit movement-form instruction;
- nonlinear pedagogy using analogy instruction plus two task constraints.

Across seven lessons over four weeks:

- both groups improved performance accuracy;
- no significant between-group difference appeared in exploration quantity;
- no significant difference appeared in bar-trajectory distribution.

This is one of the most directly relevant studies for resistance-exercise technique.

Its implication is narrow but useful:

**both explicit/linear and nonlinear/constraints-led approaches can produce skill improvement; this study does not support universal superiority of either.**

Limitations:

- N=16;
- one exercise;
- short intervention;
- outcome set does not settle long-term transfer/generalization or injury risk.

### Canonical rule

**Constraints-led learning is a valid practice-design strategy, not a universal replacement for instruction.**

Confidence: **HIGH for framework legitimacy / MODERATE for applied benefit / LOW for universal superiority.**

## 10. Task constraints

Task constraints are features that define what must be accomplished and the rules/conditions under which the action is performed.

Relevant examples can include:

- task goal;
- target location;
- accuracy tolerance;
- external load;
- implement characteristics;
- required range of motion;
- tempo or timing requirement;
- base-of-support rule;
- allowed/forbidden movement options;
- repetition success criterion.

In resistance training, changing load itself can alter the available motor solution, as already established upstream in NEU-09.

A task constraint is not automatically a “cue.”

A cue is information directed at the learner; a task constraint changes the problem the learner must solve. In practice they can interact.

### Project rule

When using task constraints for learning:

1. define the actual target outcome;
2. change as few variables as necessary to make the relevant task information learnable;
3. assess delayed execution, not only immediate compliance;
4. remove or alter the constraint later when testing transfer to the target exercise condition.

### Canonical rule

**Task constraints shape the motor problem; they should be manipulated to improve task-relevant information and solution search, not merely to force a cosmetic movement shape.**

Confidence: **HIGH for construct / MODERATE for exercise-specific implementation.**

## 11. Organism / individual constraints

Organism constraints are properties/states of the learner that affect which movement solutions are available or economical.

Relevant examples:

- anthropometry;
- joint morphology;
- strength/capacity;
- mobility;
- prior skill;
- sensory capability;
- fatigue state;
- pain/discomfort state;
- attention/working-memory capacity;
- current arousal;
- previous motor experience.

These constraints can change:

- slowly, such as strength/training age;
- rapidly, such as fatigue or attention.

This matters because the same externally specified task can have different **functional difficulty** for different people.

It also means a movement pattern that is easy and stable for one learner may be difficult or inefficient for another.

However, organism constraints must not become deterministic labels:

- anthropometry does not dictate one inevitable technique;
- ADHD does not define one fixed coaching method;
- “learning style” typologies are not inferred from this framework.

### Canonical rule

**The learner is part of the task system: identical instructions and external loads do not create identical learning problems across individuals or states.**

Confidence: **HIGH for principle**.

## 12. Environmental constraints

Environmental constraints are features of the surrounding physical/social context that affect available information or action.

Examples can include:

- surface;
- space;
- lighting/visibility;
- ambient noise;
- temperature;
- surrounding obstacles;
- equipment arrangement;
- social/coaching context;
- time pressure or contextual pressure where relevant.

Classification boundaries vary across ecological/dynamical literature.

For example, an implement can be treated as part of:

- task definition;
- environmental affordance/context,

depending on the analytic framework.

Therefore the three constraint categories should be treated as **useful analytic bins**, not rigid ontological compartments.

What matters downstream is:

> which variable changed, how it changed the information/action problem, and whether learning transfers when that variable is restored to the target condition.

### Canonical rule

**Environmental constraints alter the information/action context; category labels are secondary to the causal practice manipulation and transfer test.**

Confidence: **HIGH for principle**.

## 13. Constraints interact

Task, organism and environment constraints do not act independently.

Example:

A 40-kg barbell is a nominal external task feature, but its functional difficulty depends on:

- the trainee's strength;
- prior barbell experience;
- fatigue;
- range target;
- available rack/setup;
- footwear/surface;
- pace and feedback context.

Thus:

`same task`
does not mean
`same challenge`.

This interaction is central both to:

- constraints-led learning;
- challenge-point reasoning.

### Practical implication

A coach should not prescribe progression solely by the external task label.

Instead, progression should consider the learner's current ability to:

- understand the goal;
- produce enough successful/informative attempts;
- detect relevant error;
- retain the solution;
- transfer it to the target condition.

Confidence: **HIGH for interaction principle / PRACTICAL_HEURISTIC for exact progression thresholds.**

## 14. Challenge Point Framework

The Challenge Point Framework (CPF; PMID 15130871) proposes that learning depends on the interaction between:

- learner skill level;
- task difficulty;
- informational challenge created by practice conditions.

A useful distinction is:

### Nominal task difficulty

Difficulty inherent to the task specification.

### Functional task difficulty

Difficulty experienced by a particular learner under a particular set of conditions.

This is highly useful for coaching because a fixed task is not equally difficult for every learner.

### What CPF contributes

It warns against two simplistic assumptions:

1. harder is always better;
2. easier/more successful is always better.

A task can be:

- too easy to provide much new information;
- sufficiently challenging to generate useful error/information;
- too difficult to produce interpretable or controllable practice.

### Evidence status

The 2025 systematic scoping review (PMID **40568842**) identified 100 papers applying or discussing CPF. Use of the framework was generally favorable, but the review explicitly noted limitations, including limited practical-application research.

This is not equivalent to validation of one universal optimum.

### Canonical rule

**Challenge point is a useful framework for matching functional difficulty to learner ability, not a validated universal difficulty prescription.**

Confidence: **MODERATE-HIGH for framework / LOW-MODERATE for quantitative optimum.**

## 15. There is no established universal “optimal difficulty” or success-rate sweet spot

A common overextension of challenge-point reasoning is:

> “Motor learning is best at X% success.”

Current evidence does not justify a universal number.

The 2026 golf-putting RCT (PMID **41400972**) randomized 150 participants to three practice-success ranges:

- high success: 60–70%;
- medium: 20–30%;
- low: <10%.

After 50 practice trials and a 24-hour retention test, the study found no significant difference in the pattern or magnitude of learning among the groups under that design.

The authors highlighted unresolved problems:

- no standard metric for task difficulty;
- no standard dependent variable across difficulty levels;
- no single agreed definition of “optimal difficulty.”

Other task-difficulty/progression studies are mixed.

Therefore the project must reject:

- fixed universal success-rate targets;
- one “desirable difficulty” percentage;
- the assumption that more errors are automatically more informative;
- the assumption that high practice success automatically maximizes learning.

### Canonical rule

**Functional difficulty should be adapted to the learner and target skill, but no universal optimal success rate is established.**

Confidence: **HIGH against a universal numeric sweet spot / MODERATE for adaptive-difficulty principle.**

## 16. Progression and regression

### Progression

Progression is a change in task/practice constraints toward:

- greater target-task demand;
- greater complexity;
- reduced external support;
- higher load/speed/precision;
- more target-specific context.

### Regression

Regression is a temporary change that reduces one or more demands so that the learner can:

- produce safe/interpretable attempts;
- perceive the relevant task information;
- isolate a coordination problem;
- re-establish a useful solution;
- continue practice when fatigue or novelty makes the target task noninformative.

Regression is not failure.

A skilled trainee can appropriately regress when:

- learning a new variation;
- returning after a break;
- practicing under fatigue;
- correcting a newly identified error;
- changing implement or load.

### No universal easy-to-hard law

Sequential progression is plausible and useful in many contexts, but it is not universally superior.

PMID **30905405** compared:

- criterion-task-specific practice;
- sequential progression from easier to harder;
- random progression.

For the novel gait task used, criterion-task-specific practice produced lower tracking error, while sequential and random progression did not differ. The authors concluded that target-task practice amount was more important than progression of difficulty in that protocol.

Other motor-learning studies show benefits of progressive difficulty in some tasks, so the correct conclusion is **task dependence**, not “progression never works.”

### Canonical rule

**Progression/regression is adaptive manipulation of task demands; it should serve target-task learning and sufficient specific practice, not obey a universal easy→hard sequence.**

Confidence: **HIGH for task dependence / MODERATE for best sequencing.**

## 17. Specificity can compete with progression

A practical learning design has two competing needs:

1. make the task solvable/informative enough to learn;
2. spend enough practice time in the actual target condition.

Too much regression can create a different skill problem.

Examples:

- permanently practicing only a very light load may not prepare coordination for working load;
- using a support forever may prevent learning unsupported control;
- narrowing range indefinitely may not transfer to target ROM;
- endlessly simplifying a movement can reduce exposure to the exact perceptual-motor demands that need to be learned.

This is consistent with NEU-11:

**retention of the regression does not prove transfer to the target task.**

Therefore every progression/regression scheme ultimately requires:

- target-condition practice;
- target-condition retention/transfer testing.

### Canonical rule

**A regression is useful only if it improves learning of the eventual target task; successful performance of the regression is not itself the goal.**

Confidence: **HIGH for specificity boundary**.

## 18. Direct resistance-exercise evidence

### 18.1 Power clean — linear vs nonlinear pedagogy

PMID **35499570** provides the strongest direct study in this PASS for learning a resistance-exercise movement form.

What it supports:

- beginners can improve a technical lifting skill under both linear/explicit and nonlinear/constraints-based instruction;
- deviations from one prescribed trajectory do not automatically prevent improvement;
- one cannot infer universal superiority of constraints-led or explicit instruction.

What it does not establish:

- long-term superiority;
- injury effects;
- generalization to squat/deadlift/press;
- optimal mix of instruction and constraints.

Confidence: **MODERATE** because direct but small.

### 18.2 Acute lifting — analogy vs explicit instruction

PMID **41558250** compared analogy and explicit instruction in lifting and observed changes in EMG/motor control and acute force/RFD outcomes.

It is relevant to immediate performance and control strategy.

But it does **not** establish durable motor learning unless delayed retention/transfer are demonstrated.

Therefore this study cannot be used as proof that:

- analogy produces superior learning;
- explicit instruction permanently impairs force production.

Confidence: **MODERATE for acute performance / LOW for durable learning inference.**

### 18.3 Kettlebell swing — solution variability and transfer

PMID **42617501** is directly relevant to exploration and transfer.

It suggests that early variability in successful movement solutions may be associated with later transfer to an altered implement, but the study is too small/nonrandomized to prescribe deliberate “high variability training.”

Confidence: **LOW-MODERATE for causal prescription / MODERATE for hypothesis support.**

### 18.4 Direct squat learning from NEU-11

PMID **37916599** already established that technique-related squat variables can show acquisition and delayed retention after feedback.

NEU-12 adds the learning-model boundary:

**the existence of skill learning does not prove that one explicit/implicit/constraints-led teaching model is universally best.**

## 19. What should be used in later resistance-exercise coaching

The current evidence supports a **hybrid adaptive model**, not an ideological method.

A later coach can legitimately combine:

- concise explicit explanation of task/safety;
- one or a few deliberate cues when needed;
- repeated execution;
- task-constraint manipulation;
- guided exploration;
- analogy if it helps;
- progression/regression;
- removal of support;
- target-condition practice.

The choice should be based on:

- current error;
- learner understanding;
- functional difficulty;
- task complexity;
- cognitive load;
- retention;
- transfer to working-load conditions.

This is a **practice synthesis**, not evidence that the hybrid is itself superior as one named intervention.

### Practical heuristic

> Give only enough explicit structure to make the task intelligible/safe, then let repeated task-relevant practice and informative constraints do part of the learning work; add or remove guidance based on retained execution rather than ideology.

Status: **PRACTICAL_HEURISTIC**, not a canonical causal claim.

## 20. Important non-equivalences

For project use:

1. **explicit instruction ≠ explicit learning process with perfect purity**;
2. **implicit-labeled method ≠ proof of implicit learning**;
3. **analogy ≠ necessarily implicit**;
4. **external focus ≠ necessarily implicit**;
5. **errorless practice ≠ universally better learning**;
6. **variability ≠ exploration**;
7. **exploration ≠ random movement**;
8. **constraints-led ≠ no instruction**;
9. **nonlinear pedagogy ≠ universal superiority**;
10. **challenge point ≠ fixed success percentage**;
11. **progression ≠ always easy-to-hard**;
12. **regression success ≠ target-task learning**;
13. **autonomous stage ≠ zero attention**;
14. **acute instruction effect ≠ durable motor learning**.

These boundaries are closure-critical.

## 21. Measurement boundaries

### Declarative-knowledge report

Useful as one probe of explicit knowledge.

Not a complete measurement of all deliberate strategy.

### Aim report / exclusion / process-dissociation measures

Useful in sensorimotor adaptation.

Do not automatically generalize their quantitative decomposition to complex strength technique.

### Dual-task cost

Can probe attentional demand/automaticity.

Not a pure measure of implicit learning.

### Movement variability

Must distinguish:

- outcome/error variability;
- solution variability;
- temporal structure;
- task-relevant covariance.

Magnitude alone is not exploration quality.

### Practice success rate

Can operationalize one aspect of task difficulty.

Not a universal measure of functional challenge.

### Immediate technique score

Measures current performance.

Does not establish retention.

### Delayed retention / transfer

Required when making durable-learning claims.

## 23. Established findings

### HIGH

1. Explicit and implicit contributions cannot be assumed to be perfectly separable/additive from common proxy measures.
2. “Implicit” instructional methods do not guarantee process-pure implicit learning.
3. Learning-method effectiveness must be judged with retention/transfer rather than immediate performance alone.
4. Movement variability is not synonymous with exploration.
5. Task, learner and environmental conditions interact to shape the motor problem.
6. No universal numeric optimal-difficulty/success-rate target is currently established.
7. Progression/regression must preserve eventual target-task specificity.

### MODERATE-HIGH

8. Fitts–Posner cognitive/associative/autonomous language is a useful descriptive heuristic when not treated as hard biological stages.
9. Structured exploration can support learning/transfer in appropriate tasks.
10. Constraints-led manipulation is a legitimate way to shape skill acquisition.

### MODERATE

11. Analogy instruction has promising average effects in some motor tasks, but heterogeneity/RoB prevent universal superiority claims.
12. Nonlinear/constraints-led pedagogy can be effective, but current comparative evidence does not show universal superiority for technical skills.
13. Resistance-exercise skill can likely benefit from hybrid explicit + exploratory/constraint-based coaching, but the optimal mix remains task/learner dependent.

## 24. Unresolved issues / gaps

These are **not blockers for PASS-01 content coverage**, but must be independently audited in PASS-02 before closure.

1. **Terminology heterogeneity:** “implicit learning,” “implicit instruction,” “nonlinear pedagogy,” “analogy,” “errorless learning” and “external focus” are sometimes bundled despite different mechanisms.
2. **Mechanism-to-method gap:** many intervention studies classify the intended teaching style without directly measuring what learning process occurred.
3. **Adaptation-to-skill transfer:** explicit/implicit decomposition is strongest in visuomotor adaptation but does not map cleanly onto complex resistance exercise.
4. **Resistance-training evidence scarcity:** direct long-term comparison of explicit vs analogy vs constraints-led methods in squat/press/deadlift-type tasks is sparse.
5. **Challenge-point quantification:** no validated universal metric or optimal success range.
6. **Exploration dose:** no defensible rule for “how much variability” a resistance-training learner should be given.
7. **Progression sequencing:** evidence is task dependent; specificity can outperform gradual progression when target-task exposure is limited.
8. **Individual differences:** working memory, prior skill and attention may modify response to instruction, but no stable learner-type assignment is justified.
9. **Safety boundary:** a constraints-led approach cannot override safety-critical direct instruction where a task has meaningful injury/setup risk.
10. **Outcome boundary:** technique quality remains owned by TEC/MEC; NEU-12 only establishes learning architecture.
