# Источники Stage 0B — область 16: коучинг, реализация и профессиональная практика

Дата: 2026-11-16.

1. NSCA — current CSCS Exam Description  
   https://www.nsca.com/certification/cscs/certified-strength-and-conditioning-specialist-exam-description/

   Practical domains separately include:
   - Program Design;
   - Exercise Technique;
   - Program Implementation;
   - Organization and Administration.

   Program Implementation includes coaching throughout sessions, selecting evidence-based tests, administering testing/monitoring and evaluating results.

2. ACSM — Certified Exercise Physiologist Exam Content Outline  
   https://www.acsm.org/wp-content/uploads/2024/12/ACSM-Certified-Exercise-Physiologist-Exam-Content-Outline.pdf

   Relevant domains:
   - Exercise Prescription and Implementation;
   - Exercise Counseling and Behavior Modification;
   - Risk Management and Professional Responsibilities.

   Explicit topics include active listening, feedback, communication channels, behavior-change techniques, referral, confidentiality, safe exercise environment and emergency action procedures.

3. NSCA Certification Handbook — Professional Practice  
   https://www.nsca.com/globalassets/certification/certification-pdfs/certification-handbook.pdf

   Used for scope of practice, allied-health referral, unsafe-training recognition and professional risk-management boundaries.

## Scope decision

Facility administration, staffing and litigation are retained only as conditional professional topics because the current project is one-person home training. Session implementation, communication, safety, scope, referral and privacy are directly relevant and receive full coverage.
