# 2. Qualitative Description (QD): canonical purpose

Sandelowski's qualitative description is a legitimate qualitative methodology for questions seeking:

> a comprehensive, practice-usable summary of events, experiences, views, barriers, facilitators or needs in terms close to participants' own language.

Its aim is not:

- phenomenological essence;
- cultural interpretation;
- grounded theory generation;
- highly abstract theorizing.

Its characteristic analytic position is often called **low-inference** or **data-near**.

### Critical rule

Low-inference does **not** mean:

> no interpretation.

Sandelowski explicitly revisited this misconception in 2010.

All qualitative description involves researcher selection, organization and interpretation.

The point is that interpretation stays relatively close to what participants said or what events showed.

---

# 3. QD is not "failed phenomenology"

A frequent methodological error is to take a straightforward descriptive study and relabel it:

- phenomenology;
- grounded theory;
- ethnography;

because those labels appear more sophisticated.

Sandelowski and Neergaard explicitly argue against this.

### Correct routing

If the actual question is:

> What barriers, facilitators and preferences do participants report?

and the analysis produces a direct organized summary of those reports,

then **qualitative description may be the more accurate design**.

This is not methodologically inferior merely because it uses less abstraction.

---

# 4. QD is not generic qualitative research by definition

There is overlap in the literature, and Kahlke discusses descriptive qualitative approaches within the broader generic family.

However, for this project:

## Qualitative Description

Record as a named methodology when authors explicitly use Sandelowski-style QD or a clearly aligned descriptive methodology.

## Generic qualitative

Use when the study:

- claims no established methodology;
- deliberately combines elements from several approaches;
- or uses a "basic/generic qualitative" label.

### Project rule

Do not collapse explicit QD into a vague "generic qualitative" category when a clear Sandelowski-style descriptive design is actually present.

---

# 5. Typical QD question types

QD fits questions such as:

- What barriers do people report?
- What facilitators help participation?
- What information do participants need?
- What preferences do users have?
- How do participants describe acceptability?
- What problems occur in implementation?
- What features of a program are valued?
- What concerns do athletes report?

Fitness examples:

- reported barriers to resistance training in older adults;
- preferred forms of home-training support;
- reasons women give for engaging in muscle-strengthening activity;
- reported facilitators of adherence to a supervised exercise program.

---

# 6. Sampling in QD

QD commonly uses purposive sampling.

Possible goals:

- capture relevant experience;
- maximize practical variation;
- include key stakeholder groups;
- cover a predefined service/user population.

Sampling can be:

- criterion-based;
- maximum variation;
- convenience plus eligibility;
- purposive stakeholder selection.

### Critical rule

Sampling should fit the descriptive target.

If the goal is to summarize views across substantially different subgroups, the sample should include those subgroups.

But QD does not become statistically representative merely because several groups are included.

---

# 7. Data collection in QD

Common sources:

- semi-structured interviews;
- focus groups;
- open-ended survey responses;
- observations;
- documents;
- combinations.

QD often uses a somewhat more focused interview guide than highly open phenomenological or ethnographic inquiry.

That is compatible with practice-oriented descriptive questions.

### Rule

Interview structure is not the design.

The defining feature is the descriptive inferential purpose.

---

# 8. Analysis in QD

QD commonly uses:

- qualitative content analysis;
- descriptive thematic analysis;
- framework-like organization;
- code/category summarization.

The final product should preserve:

- participants' terms;
- recognizable event/experience categories;
- low conceptual distance from data.

### Critical boundary

QD can still interpret.

But if the analysis develops:

- a theory;
- a deep hermeneutic account;
- an abstract explanatory model;
- a practice-oriented conceptual reframing far beyond surface description,

then the study may no longer be best classified as straightforward QD.

---

# 9. QD and thematic analysis

Thematic analysis (TA) is an analytic family, not automatically a parent study design.

Therefore:

> qualitative study + reflexive thematic analysis

does not by itself tell us whether the parent methodology is:

- QD;
- phenomenology;
- generic qualitative;
- case study;
- process evaluation;
- another design.

Braun & Clarke emphasize that thematic-analysis variants differ philosophically and procedurally.

### Project rule

Record TA separately:

1. parent design/methodology;
2. TA variant;
3. inductive/deductive orientation;
4. semantic/latent level where stated;
5. reflexive/codebook/coding-reliability orientation where relevant.

Do not infer:

> "themes were produced" = QD.

---

# 10. QD and content analysis

Qualitative content analysis can be used inside QD.

But content analysis is primarily an **analytic method/family**, not itself proof of a QD design.

Possible combinations include:

- QD + conventional content analysis;
- QD + directed content analysis;
- case study + content analysis;
- implementation study + content analysis.

### Rule

Analysis method and parent methodology stay separate.

---

# 11. Interpretive Description (ID): canonical purpose

Interpretive Description was developed by Thorne and colleagues for applied health disciplines.

Its target is not merely:

> describe what participants said.

Its target is:

> generate an interpretive, conceptually organized understanding of a clinically or professionally relevant phenomenon that can inform practice.

Typical ID questions ask:

- What patterns matter for professional decision-making?
- How do variations in experience change what practitioners should notice or do?
- What conceptual understanding can improve care/program design?
- What is the practice significance of the phenomenon?

### Core distinction

QD:
> what participants report / what patterns are directly present.

ID:
> what these patterns **mean for applied practice**, including relationships, variation and clinically useful interpretation.

---

# 12. ID is a distinct applied methodology

Thorne originally described ID as a "noncategorical qualitative alternative".

Later work developed it into a coherent applied methodology.

It draws pragmatically from traditions such as:

- naturalistic inquiry;
- grounded theory;
- phenomenology;
- ethnography;

without claiming to reproduce any one of them.

### Project rule

Do not classify ID as:

> "generic qualitative because it is noncategorical"

when the authors explicitly use Thorne's Interpretive Description methodology.

Preserve it as:

> **Interpretive Description (ID)**.

---

# 13. Epistemic orientation of ID

ID is commonly aligned with:

- constructivist/naturalistic assumptions;
- disciplinary knowledge;
- applied professional questions;
- acknowledgment that researcher interpretation is unavoidable.

It rejects both extremes:

- pretending the researcher is a neutral recorder;
- producing abstraction disconnected from practical disciplinary needs.

The researcher's professional/disciplinary position is therefore important metadata.

---

# 14. ID analysis

ID analysis aims to move beyond sorting/coding toward:

- pattern recognition;
- variation;
- relationships;
- conceptual organization;
- recontextualization;
- practice significance.

Thorne's methodology emphasizes that applied qualitative analysis should ask:

> So what does this mean for the discipline or practice?

### Critical rule

ID should not be reduced to:

> "QD plus more interpretation".

It has a distinct applied epistemic purpose and disciplinary orientation.

---

# 15. ID and prior disciplinary knowledge

Unlike classic claims that qualitative inquiry should enter the field theoretically blank, ID treats disciplinary knowledge as legitimate scaffolding.

Researchers should:

- know what the field already assumes;
- identify disciplinary preconceptions;
- use prior knowledge critically;
- remain open to data that challenge those assumptions.

### Rule

Prior theory is neither automatically forbidden nor automatically imposed.

The key issue is whether it becomes:

- transparent scaffolding;
or
- an unexamined frame forcing the findings.

---

# 16. ID rigor / credibility architecture

Thorne's current framework emphasizes methodological integrity rather than mechanical checklist compliance.

Frequently cited ID criteria include:

1. epistemological integrity;
2. representative credibility;
3. analytic logic;
4. interpretive authority.

### Project interpretation

For an ID study, extract:

- alignment of question and methodology;
- disciplinary position;
- sampling logic;
- analytic reasoning;
- documentation of interpretive moves;
- reflexivity;
- whether conclusions are recognizably grounded in data.

---

# 17. Generic qualitative research

Caelli et al. define generic qualitative research as work not guided by one explicit established qualitative methodology.

This can mean:

1. no named methodology;
2. deliberate combination of approaches;
3. basic/general qualitative inquiry around experiences or perspectives.

Generic qualitative research is not automatically poor quality.

But it creates a major burden:

> methodological choices cannot be justified merely by citing a named tradition.

Researchers must make their logic explicit.

---

# 18. Minimum requirements for generic qualitative coherence

Caelli et al. highlight four key issues:

1. researcher position;
2. distinction between method and methodology;
3. explicit approach to rigor;
4. analytic lens.

Kahlke similarly argues that generic approaches can be legitimate but require careful methodological congruence.

### Project router

For a generic study, extract:

- research question;
- epistemic/theoretical stance;
- why no established methodology fits;
- which traditions were borrowed from;
- why each method was chosen;
- how those choices remain coherent;
- researcher position;
- analysis lens;
- rigor/credibility strategy.

---

# 19. Generic does not mean "anything goes"

A generic qualitative study becomes weak when it combines incompatible practices without justification.

Examples:

- claiming constructivism but treating one coding result as objective truth;
- using phenomenological "lived experience" language but doing only frequency counts;
- claiming grounded theory while forbidding iterative sampling;
- using reflexive TA but demanding coder agreement as if one objective coding solution exists.

### Rule

The central question is **methodological congruence**.

Flexible ≠ incoherent.

---

# 20. Generic qualitative vs unnamed low-quality study

Not every paper that lacks a methodology label should automatically receive the respectable category:

> generic qualitative research.

The project should first inspect whether the study actually reports:

- coherent qualitative question;
- sampling;
- data generation;
- analysis;
- researcher positioning;
- inferential logic.

If those are absent, classification should record:

> methodology unclear / under-specified,

not silently repair it into "generic qualitative".

---

# 21. Descriptive qualitative labels in published research

Published papers use overlapping labels:

- qualitative descriptive;
- descriptive qualitative;
- basic qualitative;
- generic qualitative;
- exploratory qualitative;
- qualitative exploratory study;
- qualitative study using thematic analysis.

These labels are not interchangeable automatically.

### Project rule

Classification should be based on architecture, not title.

Ask:

1. Is a named methodology actually implemented?
2. Is the aim straight description?
3. Is there applied interpretation?
4. Is there a deliberate generic approach?
5. Or is the methodology simply under-specified?

---

# 22. "Exploratory qualitative" is not a complete design label

"Exploratory" describes purpose.

It does not by itself specify:

- methodology;
- sampling;
- collection;
- analysis.

Example:

An exercise trial sub-study using focus groups and thematic analysis may be described as an exploratory qualitative study.

Project classification should still record:

- parent trial/sub-study context;
- qualitative methodology if stated;
- collection method;
- analysis method;
- inferential target.

# 23. QD vs Interpretive Description

| Axis | Qualitative Description | Interpretive Description |
|---|---|---|
| Main purpose | direct comprehensive description | applied conceptual interpretation |
| Distance from data | relatively low | greater abstraction/recontextualization |
| Typical output | categories/themes close to participant language | patterns/relationships with practice meaning |
| Theory generation | not primary | not formal GT theory, but conceptual insight expected |
| Practice orientation | often practical | explicitly central |
| Researcher disciplinary knowledge | present but often background | explicitly important scaffolding |
| Interpretation | unavoidable but restrained | explicit and central |
| Typical question | What barriers/facilitators are reported? | What pattern of barriers/facilitators matters for professional action and why? |

### Caveat

This is a project routing table, not a claim that the boundary is perfectly sharp.

# 24. QD vs phenomenology

QD:
- direct account;
- barriers/preferences/views/events;
- low-inference summary.

Phenomenology:
- structure/meaning of lived experience;
- explicit phenomenological tradition;
- experiential/lifeworld interpretation.

Example:

What barriers do injured lifters report when returning to the gym?
→ QD candidate.

What is it like, bodily and emotionally, to re-enter heavy squatting after injury?
→ phenomenology.

---

# 25. QD vs grounded theory

QD:
- summarizes what is reported.

GT:
- develops a process theory through iterative comparison, theoretical sampling and category integration.

Example:

What reasons do people give for quitting training?
→ QD.

How do people move from disruption to lapse, disengagement and eventual re-entry?
→ GT candidate.

---

# 26. QD vs case study

QD:
- organized around the phenomenon/question.

Case study:
- organized around a bounded case/system.

Example:

What barriers to adherence do participants report across several exercise programs?
→ QD candidate.

How did Program A's staffing, scheduling and coach relationships shape adherence over one year?
→ case study.

---

# 27. ID vs grounded theory

ID may develop conceptual patterns and applied explanations.

But it does not require a full GT architecture such as:

- theoretical sampling;
- constant comparison as a formal core;
- theoretical saturation;
- formal/substantive theory generation.

### Rule

A practice-oriented conceptual model is not automatically grounded theory.

---

# 28. ID vs phenomenology

ID can explore experience but asks:

> what does this understanding mean for applied practice?

Phenomenology asks:

> what is the structure/meaning of the lived experience itself?

The same interviews can be analyzed differently depending on the scientific purpose and methodology.

---

# 29. Sampling and data adequacy across QD / ID / generic studies

There is no universal sample-size threshold.

Adequacy should reflect:

- specificity of aim;
- diversity required;
- richness/depth;
- number of stakeholder groups;
- analytic ambition;
- information power;
- practical constraints;
- methodology.

## QD

If the aim is to catalog a broad range of barriers, heterogeneity may matter.

## ID

If the aim is to understand patterns/variation relevant to practice, sampling should intentionally support contrast and conceptual variation.

## Generic

Sampling must be justified from the explicit inferential aim because no named tradition supplies a default rule.

### Saturation

Do not treat "saturation reached" as self-validating.

Extract:

- what was saturated;
- how assessed;
- whether the criterion fits the methodology.

---

# 30. Reflexivity

Even low-inference QD requires reflexivity.

Researcher decisions shape:

- questions;
- what counts as a category;
- grouping;
- salience;
- language used in reporting.

ID and generic qualitative studies especially need explicit researcher positioning because interpretation and disciplinary lens can materially shape findings.

### Rule

"Close to data" does not mean researcher-free.

---

# 31. What QD evidence can establish

QD can strongly support:

- reported barriers;
- facilitators;
- preferences;
- concerns;
- information needs;
- perceptions;
- acceptability;
- implementation experiences;
- common categories of experience.

It is useful for:

- intervention development;
- needs assessment;
- service design;
- questionnaire/item development;
- mixed-method qualitative components.

---

# 32. What QD cannot establish by itself

QD alone cannot estimate:

- prevalence of a barrier;
- population frequency;
- causal effect;
- intervention efficacy;
- biological mechanism;
- prediction performance.

If 18 of 24 interviewees mention time pressure, that does not imply:

> 75% of the population has time pressure as a barrier.

Qualitative frequency counts do not create probability sampling.

---

# 33. What ID evidence can establish

ID can support:

- practice-relevant conceptual patterns;
- important variations;
- relationships among experiential/contextual factors;
- interpretive explanations useful to professional decision-making;
- hypotheses and applied design principles.

It can bridge:

> participant experience → disciplined interpretation → practice implication.

---

# 34. What ID cannot establish by itself

ID does not by itself establish:

- average causal effect;
- prevalence;
- incidence;
- diagnostic accuracy;
- statistical prediction;
- biological mechanism;
- formal mediation.

Practice relevance is not equivalent to quantitative causal validity.

# 36. Contemporary exercise examples

## Women and muscle-strengthening exercise

A 2026 WISH qualitative study interviewed 24 women and used reflexive thematic analysis to identify barriers, facilitators and participation strategies.

Project routing:

- scientific purpose: descriptive/exploratory barriers/facilitators;
- collection: interview;
- analysis: reflexive thematic analysis;
- parent methodology: must be classified from the paper's stated design, not inferred from TA alone.

## Resistance exercise in older adults with diabetes/possible sarcopenia

A 2026 study explicitly used a descriptive qualitative design with purposive sampling, semi-structured interviews and directed content analysis.

Project routing:

- parent design: descriptive qualitative;
- analysis: directed content analysis;
- theoretical framework: Multi-Process Action Control;
- saturation claim: should be separately appraised/operationalized.

This is a canonical example of:

> methodology ≠ analysis method.

# 38. Do-not-confuse matrix

| Do not confuse | Why |
|---|---|
| qualitative description vs no methodology | QD is a legitimate named approach |
| low-inference vs no interpretation | all qualitative description involves interpretation |
| QD vs phenomenology | direct description vs lived-experience meaning/structure |
| QD vs GT | summary vs theory-generation architecture |
| QD vs case study | phenomenon-centered vs bounded-case architecture |
| ID vs QD | applied conceptual interpretation vs data-near description |
| ID vs GT | ID need not generate formal grounded theory |
| ID vs phenomenology | applied-practice interpretation vs phenomenological lived-experience target |
| generic qualitative vs low quality | generic can be rigorous if coherent |
| generic qualitative vs methodology unclear | under-reporting should not be repaired silently |
| exploratory vs design | exploratory is purpose, not methodology |
| interview vs design | collection method only |
| reflexive TA vs parent methodology | analysis family only |
| content analysis vs parent methodology | analysis family only |
| themes vs QD | many methodologies produce themes |
| qualitative frequency vs prevalence | no statistical population inference |
| practice relevance vs causal validity | useful interpretation is not causal identification |
