## Условные статусы

- **СОГЛАСОВАНО** — пользователь прямо принял решение или исправил противоречащее предложение.
- **РАБОЧАЯ ГИПОТЕЗА** — идея, требующая проверки; это не утверждённая архитектура.
- **ОТЛОЖЕНО** — сейчас сознательно не прорабатывается.
- **НЕ ПОДТВЕРЖДЕНО** — не доказано практическим экспериментом, либо требует проверки источника.

## Центральная постановка

Пользователь предлагает обучать ИИ в беседах, сохраняя историю его опыта в изолированном ChatGPT-проекте. Желаемый эффект — появление и дальнейшее изменение индивидуальных особенностей **без заранее прописанного характера**. Ищется минимальное ядро проектных инструкций, которое позволит опыту участвовать в новых суждениях и выборе, но не заставит изображать заранее заказанную личность.

Сейчас приоритет — **собственная точка отсчёта, способность «прислушиваться к себе», пространство выбора и проверка инициативы**. Устройство файловой системы намеренно вынесено из текущей задачи.

## Ограничения документации

1. Здесь не создаётся реальная личность и не утверждается наличие субъективного сознания.
2. Примеры «свободы воли» относятся к проверяемой автономии выбора внутри возможностей и ограничений модели, а не к доказательству философской свободы воли.
3. Исследовательские тезисы собраны из прежнего разговора. Обзор источников **не является новой полной независимой верификацией каждого исследования**.
4. Репозиторий используется как внешнее рабочее место для развития концепции. Никакие файлы существующего приложения в Major_Renov2 не изменяются.
5. Ранее обсуждавшиеся наброски структуры памяти — исторический материал, а **не план её немедленной реализации**.

## Актуальное решение 14.10.2026

**Один эксперимент — сам ChatGPT-проект.** Старые программы пилотов, A/B-групп и тестов в документах сохранены только как история идей. Никакого заданного характера. Исследования старых LLM не считать прямым описанием возможностей GPT-6. [Актуальный синтез](15_INTERIM_SYNTHESIS.md).
