## 1. Purpose / Question Card

### Decision

Translate the validated motor-learning architecture into resistance-exercise practice without:

- treating one good light-load set as proof that technique is learned;
- assuming the same movement solution simply scales unchanged as load rises;
- equating technical failure with momentary muscular failure, volitional failure, velocity loss, or any visible deviation;
- prescribing a universal percentage at which a learner should move from “practice load” to “working load”;
- treating exercise complexity as inherently valuable;
- treating variability as random perturbation or as universally superior to stable practice;
- assuming that similar exercises automatically transfer because they train similar muscles.

### Primary downstream context

Healthy adult novice/intermediate resistance trainees learning or refining compound and free-weight resistance exercises.

### Critical outcomes

- acquisition;
- delayed retention;
- load-specific execution;
- repeatability within justified task constraints;
- performance under fatigue;
- dependence on external feedback/cues;
- transfer to a defined target exercise or condition.

## 2. Core resistance-exercise learning model

Canonical project architecture:

`define task goal + justified execution criteria`
→
`scale load / complexity so the task is solvable`
→
`practice with task-relevant feedback`
→
`verify repeatable execution`
→
`verify delayed retention`
→
`progressively sample target load/context`
→
`define and monitor technical-failure boundary`
→
`add only task-relevant variability`
→
`test transfer in the actual target condition`.

This is a **PRACTICAL_HEURISTIC**, not a validated universal protocol.

It inherits NEU-11:

**practice performance ≠ learning**.

## 3. Learning a new resistance exercise

A new resistance exercise is a sensorimotor task, not merely a list of verbal rules.

Useful early-practice requirements are:

1. a clear task goal;
2. a small set of justified execution constraints;
3. a version/load the learner can execute repeatedly enough to generate informative attempts;
4. intrinsic feedback plus augmented feedback only where it adds missing information;
5. enough repetition to observe whether errors are systematic or variable;
6. later retention testing rather than judging learning from the coached session alone.

Direct resistance-exercise evidence exists but is limited.

Shin et al. (PMID **37916599**) randomized 30 healthy squat novices to visual feedback, tactile feedback, or control. Both feedback groups changed several squat variables during acquisition, but only the visual-feedback group retained several changes at later tests (3 days to 1 week depending on outcome).

This supports two narrow claims:

- squat execution can be acquired and retained through practice/feedback;
- acquisition effects and retention effects can diverge.

It does **not** establish one universal feedback modality or one universal “correct squat” geometry.

Confidence: **MODERATE-HIGH for direct acquisition/retention distinction; LOW for universal protocol**.

## 4. Technique stabilization

“Stable technique” should not mean identical joint trajectories on every repetition.

Project operational definition:

**Technique is stabilized when the learner repeatedly satisfies pre-specified task-relevant execution criteria under a defined condition and can reproduce them after a delay without requiring continuous external guidance.**

Stabilization therefore includes:

- acceptable repeatability;
- preserved task success;
- reduced dependence on corrective feedback;
- delayed reproducibility.

It does not require:

- zero movement variability;
- one visually ideal template;
- identical kinematics across loads;
- performance immunity to fatigue.

Upstream NEU-09 and NEU-18 remain authoritative:

**variability can be functional; visible deviation alone is not an error.**

Confidence: **HIGH as project operational boundary / MODERATE for exact measurement threshold**.

## 5. From light load to working load

No current evidence establishes one universal percentage of 1RM, repetition count, or time criterion at which a learner has “earned” progression from light practice to working load.

A defensible motor-learning rule is:

**progress the task constraint gradually while execution remains interpretable and the learner can repeatedly satisfy justified criteria; then explicitly expose the skill to the load range in which it must later function.**

Reasons:

- light-load performance does not demonstrate working-load control;
- load itself changes the motor problem;
- target-load exposure is necessary if target-load execution matters;
- exact progression increments are a PRO/TEC decision, not NEU-22 ownership.

The 2026 ACSM Position Stand (PMID **41843416**) supports progressive RT broadly but does not provide a motor-learning threshold for technique progression. Its outcome recommendations should not be misread as “learning-load” cutoffs.

Canonical boundary:

**light-load mastery ≠ working-load mastery.**

Confidence: **HIGH against universal threshold / MODERATE for graded target-specific exposure heuristic**.

## 6. Increasing load changes the motor solution

The strongest direct resistance-exercise evidence for Section 22 concerns load and fatigue.

Bakhshinejad et al. 2025 systematic review (PMID **41085612**):

- 22 studies;
- 293 experienced lifters;
- squat, bench press and deadlift;
- increasing intensity consistently reduced mean/peak velocity and increased concentric duration;
- joint mechanics and variability changed, especially around acceleration/sticking regions;
- fatigue produced overlapping but not identical changes;
- individual lifters could use different mechanical strategies as intensity increased;
- deadlift evidence remained sparse.

Earlier direct squat evidence (PMID **7846132**) also showed inter-joint coordination changing with load magnitude.

Therefore:

**heavier loading is not simply the same motor solution with more force.**

Project rule:

**compare execution against load-appropriate task criteria rather than demanding exact kinematic invariance from light to heavy loads.**

A load-related change can represent:

- an expected demand-dependent strategy;
- a capacity limitation;
- fatigue;
- a genuine task-criterion violation.

Movement appearance alone does not identify which.

Confidence: **HIGH that intensity changes movement mechanics / MODERATE for exercise-specific interpretation**.

## 7. Technical failure

Resistance-training literature does not use one universal definition of failure.

Pelland et al. (PMID **35247203**) documented between-study definitions including:

- momentary failure: inability to complete the concentric phase despite maximal effort;
- volitional failure: self-termination;
- undefined/other failure conventions.

Emanuel et al. (PMID **33194334**) used an experimental task-failure framework in squat and bench press in which termination could arise from:

- momentary failure;
- participant decision;
- experimenter-determined technical failure.

Participants also reported heterogeneous perceived limiting causes.

For this project, technical failure is therefore an **operational coaching construct**, not a synonym for physiological failure.

### Project operational definition

**Technical failure = the first repetition/set endpoint at which execution crosses a pre-specified, justified movement/performance criterion for that exercise and goal, even if another repetition might still be mechanically possible.**

Technical failure is **not automatically**:

- bar speed reduction;
- sticking;
- visible effort;
- torso-angle change;
- any rep-to-rep variability;
- momentary muscular failure;
- volitional termination.

The exact criterion must come from MEC/TEC/MED/competition/task-goal evidence, not from NEU alone.

Confidence: **HIGH for construct separation / MODERATE for project operational definition / LOW for universal lift-specific thresholds**.

---

## 8. Technical change under fatigue is not automatically unlearning

Fatigue can change:

- velocity;
- power;
- coordination;
- joint mechanics;
- movement variability.

The 2025 intensity/fatigue review (PMID **41085612**) directly confirms such changes in trained squat/bench/deadlift performance.

Therefore:

**late-set degradation must be separated from durable loss of skill.**

Operational check:

1. compare early vs late repetitions under the same load;
2. retest after recovery;
3. if the prior acceptable pattern returns, classify the change primarily as state-dependent;
4. if the deviation persists after recovery, investigate learning/capacity/constraint causes.

This inherits NEU-08, NEU-11 and NEU-18.

Confidence: **HIGH**.

## 9. When an exercise is too complex for its purpose

“Complexity” has no useful meaning unless tied to the target.

A resistance exercise can impose complexity through:

- degrees of freedom;
- balance/stability demand;
- coordination timing;
- equipment handling;
- setup;
- attentional/instruction demand;
- speed/trajectory requirements.

Project decision rule:

**an exercise is too complex for the current purpose when its added coordination/stability/instruction demands become the main performance limiter without serving the target adaptation, skill, or transfer goal.**

Examples of consequences:

- too little target loading/exposure;
- repeated criterion violations that prevent useful practice;
- excessive cue dependence;
- the limiting demand is unrelated to the desired outcome.

The 2026 ACSM Position Stand (PMID **41843416**) synthesized 137 systematic reviews (>30,000 participants) and reported that exercise complexity did not consistently affect the major chronic outcomes it evaluated. This is **not motor-learning evidence**, but it rejects the assumption that more complex RT is inherently better for general adaptation.

The free-weight vs machine meta-analysis (PMID **37582807**) found no direct overall advantage for hypertrophy/jump outcomes and showed strength gains were modality-specific.

Therefore:

- if the goal is general strength/hypertrophy, unnecessary coordination complexity is not mandatory;
- if the goal is mastery of a barbell/weightlifting/competition movement, the relevant complexity is part of the target task and cannot simply be removed.

Confidence: **MODERATE-HIGH for purpose-based selection / LOW for one validated complexity threshold**.

## 10. Stability versus variability

Stable practice and variable practice solve different learning problems.

### Stability is useful when

- task representation is still unclear;
- error magnitude is large;
- the learner cannot yet distinguish task success from failure;
- setup consistency is required to diagnose cause;
- safety-critical constraints must remain fixed.

### Variability is useful when

- the learner already has a viable solution;
- robustness/generalization is a target;
- the varied dimension is genuinely relevant to future task conditions;
- variability is structured rather than arbitrary noise.

A 2026 randomized squat study (PMID **42965663**, n=67) compared:

- non-variable target trajectories;
- structured variability;
- unstructured variability.

Structured-variability and non-variable groups achieved lower spatial error than the unstructured-variability group, while the structured group showed more organized temporal structure.

Important boundary:

**the study measured within-session execution/accuracy; it did not establish a delayed-retention or transfer advantage for structured variability.**

Therefore:

**variability ≠ randomness, and more variability ≠ better learning.**

Confidence: **MODERATE for structured-vs-unstructured immediate performance / LOW-MODERATE for long-term RT learning superiority**.

---

## 11. Exercise variation is not the same as motor-learning variability

Exercise selection variation changes the practiced task itself.

Movement variability changes execution within or around a task.

These must not be collapsed.

A systematic review of resistance-exercise variation (PMID **35438660**) suggests systematic exercise variation can support strength/hypertrophy outcomes, whereas excessive random variation may be counterproductive.

That evidence concerns chronic training adaptations, not direct motor-learning retention.

Project rule:

**use exercise variation because it serves adaptation/coverage/transfer goals; use motor-learning variability because it serves robustness/generalization goals. Do not infer one from the other.**

Confidence: **HIGH conceptual boundary**.

## 12. Transfer between similar resistance exercises

Transfer must be defined by the target task.

Similarity in:

- trained muscles;
- movement name;
- visual appearance;

does not by itself establish motor-skill transfer.

A stronger transfer hypothesis exists when source and target share relevant:

- task goal;
- action mapping;
- sensory information;
- dynamics/resistance profile;
- ROM;
- stance/grip/setup;
- stability requirement;
- velocity/load regime.

Current resistance-training literature strongly supports **strength specificity**, but direct evidence on motor-skill transfer between compound lift variants is sparse.

Saeterbakken et al. 2025 meta-analysis (PMID **40314751**, 43 studies, 1660 participants) found dynamic RT produced substantially larger gains in the trained dynamic strength domain than transfer to non-trained isometric strength. This demonstrates task-specificity of strength outcomes, not direct proof of compound-lift skill transfer.

Project rule:

**strength transfer ≠ motor-skill transfer.**

### Practical transfer test

For a source exercise A and target exercise B, assess B directly using:

1. baseline target-task execution;
2. early target-task error/criterion success;
3. number of trials or feedback needed to reach criterion;
4. delayed retention in B;
5. performance across the target load/context if relevant.

Transfer is supported when prior A practice reduces acquisition cost or improves retained B performance relative to the relevant baseline/comparator.

Confidence: **HIGH that transfer must be target-tested / LOW-MODERATE for exact compound-lift transfer rules**.

## 13. Important non-equivalences

1. Good practice performance ≠ learned technique.
2. Light-load technique ≠ working-load technique.
3. Technique stability ≠ identical kinematics.
4. Higher load ≠ the same motor solution scaled up.
5. Load-related deviation ≠ technical error by default.
6. Fatigue-related degradation ≠ loss of learning.
7. Technical failure ≠ momentary muscular failure.
8. Technical failure ≠ volitional failure.
9. Technical failure ≠ velocity loss alone.
10. Exercise complexity ≠ superior training stimulus.
11. Stable practice ≠ permanently fixed movement.
12. Variability ≠ randomness.
13. More variability ≠ better learning.
14. Exercise variation ≠ movement variability.
15. Similar muscle involvement ≠ motor-skill transfer.
16. Strength transfer ≠ motor-skill transfer.

## 14. Measurement boundaries

### Acquisition
Practice-phase improvement in the resistance task.

### Stabilized technique
Repeatable satisfaction of justified task criteria under defined conditions, with delayed reproducibility and reduced dependence on continuous guidance.

### Working-load control
Execution meeting the relevant criteria in the actual load range in which the skill must function.

### Technical failure
Crossing a pre-specified justified execution criterion before or at set termination; exact criterion is exercise/goal specific.

### Movement variability
Within-person variation in movement execution; must be distinguished from task-error variability.

### Exercise complexity
Task demand arising from coordination/stability/setup/information requirements; no universal scalar threshold retained.

### Transfer
Improvement in an explicitly untrained target task/condition attributable to prior practice; target must be directly measured.

## 16. Established content-level findings

### HIGH

1. Technique learning cannot be inferred from one practice session; delayed retention remains required.
2. Increasing resistance load changes the motor problem and can change kinematics/kinetics/coordination.
3. Technical failure must be separated from momentary and volitional failure.
4. Fatigue-related technical change is a state effect unless persistent loss is demonstrated after recovery.
5. Similarity of exercises does not prove transfer; target-task performance must be measured.
6. Strength transfer and motor-skill transfer are distinct outcomes.

### MODERATE-HIGH

7. Visual feedback can support squat acquisition and retention in novices in at least one direct RCT.
8. Exercise complexity should be justified by the target rather than treated as intrinsically beneficial.
9. Stable technique is better defined as repeatable acceptable control than identical kinematics.
10. Working-load execution requires exposure to the relevant load context rather than inference from light-load execution.

### MODERATE

11. Structured variability can preserve immediate squat accuracy better than unstructured variability.
12. Stable early practice can be useful before introducing task-relevant variability.
13. A purpose-based “too complex” rule is defensible but lacks one validated objective threshold.

### LOW / unresolved

14. One universal light-to-working-load progression percentage.
15. One universal technical-failure visual threshold.
16. One optimal variability dose/schedule for compound-lift learning.
17. One general transfer matrix between squat/hinge/press variants.

## 18. Evidence-ledger candidates

1. Resistance-exercise technique is a motor skill; acquisition performance alone does not establish learning.
2. Load is a task constraint and increasing intensity changes the motor solution.
3. Stable technique means repeatable acceptable control under defined constraints, not identical kinematics.
4. No universal evidence-based light-to-working-load learning threshold is established.
5. Technical failure is an operational task-criterion endpoint distinct from momentary/volitional failure.
6. Exercise complexity should serve the target; complexity is not intrinsically superior for general RT outcomes.
7. Structured task-relevant variability differs from random/unstructured variability; long-term RT learning superiority remains unproven.
8. Transfer between related lifts must be tested in the target task; strength transfer does not establish motor-skill transfer.
