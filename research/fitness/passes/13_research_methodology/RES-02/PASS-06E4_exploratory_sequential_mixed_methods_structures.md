# 3. Canonical definition

For RES-02:

> **Exploratory sequential mixed methods = a sequential mixed-methods architecture in which qualitative data are collected and analyzed first, those qualitative findings materially build the subsequent quantitative phase, and both phases are ultimately integrated to develop, operationalize, prioritize, test or validate constructs/interventions/instruments derived from the initial qualitative inquiry.**

Canonical route:

`QUAL collection → QUAL analysis`  
→ identify constructs/categories/needs/components  
→ **BUILD QUAN phase**  
→ `QUAN collection → QUAN analysis`  
→ merge/compare  
→ developmental/validation meta-inference.

### Critical rule

Chronology alone is insufficient.

`interviews → survey`

is not automatically exploratory sequential.

---

# 4. Defining dependency

The QUAN phase should exist in its actual form because the QUAL findings came first.

QUAL may determine:

- which variables are measured;
- which survey items are written;
- which response options are offered;
- which constructs/domains are included;
- which intervention components are built;
- which digital features are created;
- which determinants are later rated/prioritized;
- which hypotheses are tested.

### Project diagnostic

Ask:

> **What in the QUAN phase can be traced directly to the QUAL findings?**

If nothing material can be traced:

the study may be merely sequential multimethod.

---

# 5. Building is the defining between-phase integration mechanism

In exploratory sequential design, the most characteristic integration mechanism is:

**BUILDING**

Meaning:

> results from the qualitative phase are used to construct the quantitative phase.

Typical forms:

- theme → variable;
- code → item;
- participant quote → questionnaire wording;
- qualitative domain → subscale;
- identified determinant → rating item;
- user need → intervention feature;
- barrier → implementation component;
- lived-experience category → quantitative measure.

---

# 6. Connecting can also occur, but is not the defining feature

The second sample may be selected because of the first phase.

Examples:

- QUAL participants inform which population to survey;
- sites identified qualitatively become QUAN sampling strata;
- specific stakeholder categories are included quantitatively.

But unlike explanatory sequential:

> connecting is usually secondary to building.

### Critical rule

QUAL→QUAN chronology + connected samples is not enough if the quantitative content is unrelated to qualitative results.

---

# 7. Three major functional variants

D45/E4 synthesis supports three practical variants.

## A. Instrument / measurement development

QUAL  
→ constructs/domains/items  
→ QUAN psychometric evaluation.

## B. Construct / determinant / variable translation

QUAL  
→ identify concepts/determinants  
→ QUAN rate/prioritize/model/test them.

## C. Intervention / program / digital-tool development

QUAL  
→ needs/preferences/barriers/components  
→ build intervention/tool  
→ QUAN pilot/feasibility/usability/safety/early outcome testing.

### Project rule

Store the **functional variant** separately from the generic exploratory-sequential label.

---

# 8. Instrument-development variant

Canonical flow:

1. define construct/measurement purpose;
2. conduct QUAL concept elicitation;
3. identify domains/subdomains;
4. generate/refine items;
5. evaluate face/content properties;
6. conduct QUAN field testing;
7. evaluate measurement structure/properties;
8. integrate qualitative provenance and quantitative performance.

### Critical rule

A scale does not become valid merely because its items were derived qualitatively.

Psychometric validity is a separate quantitative measurement problem.

---

# 9. QUAL concept elicitation

Sources may include:

- interviews;
- focus groups;
- literature;
- stakeholder workshops;
- participatory exercises;
- observation.

### Stronger route

Target population contributes directly to:

- concept definition;
- item content;
- language;
- missing domains.

### COSMIN relevance

Current COSMIN guidance emphasizes content validity through:

- relevance;
- comprehensiveness;
- comprehensibility.

---

# 10. Construct definition precedes item generation

A common failure:

- gather many quotes;
- convert each quote into an item;
- call the result a validated scale.

### Better architecture

QUAL findings should support:

- construct definition;
- domain structure;
- conceptual framework.

Then item generation follows.

### Critical rule

More items do not compensate for unclear construct boundaries.

---

# 11. Theme → construct translation

A qualitative theme is not automatically a psychometric construct.

Example:

QUAL theme:

> “feeling welcome at the club.”

Possible construct candidates:

- belonging;
- social inclusion;
- coach support;
- environmental accessibility.

### Project rule

Store the translation decision:

- theme/code;
- proposed construct;
- rationale.

---

# 12. Construct → variable translation

Exploratory sequential studies may convert qualitative concepts into:

- continuous measures;
- categorical variables;
- ranking tasks;
- Likert ratings;
- checklist variables;
- behavioral indicators.

### Critical rule

Operationalization should preserve:

- conceptual meaning;
- relevant context;
- dimensionality.

---

# 13. Item generation

Items may be derived from:

- participant wording;
- qualitative themes;
- subthemes;
- existing instrument content;
- theory;
- expert input.

### Strong mixed-method integration

Traceability is explicit:

`quote/code → theme/domain → item`.

### Weak integration

Authors state:

> “items were informed by interviews”

without showing how.

---

# 14. Instrument-development joint display

Established exploratory-sequential joint-display structure:

| QUAL theme/code/quote | construct/domain | quantitative item/variable | later item performance |

### Scientific value

Makes visible:

- provenance;
- building;
- content coverage;
- eventual quantitative performance.

### Critical rule

A joint display is not mandatory, but the mapping it represents should be reconstructable.

---

# 15. Variable-development joint display

Not every exploratory sequential study builds a full instrument.

A display may map:

| QUAL finding | operational variable | measurement rule | quantitative result | meta-inference |

Example:

QUAL determinant:

- family encouragement.

QUAN variable:

- 7-point barrier/facilitator rating.

Result:

- average/cluster/consensus.

---

# 16. Content validity bridge

For measurement development, E4 separates:

1. **QUAL concept elicitation**
2. **content-validity evaluation**
3. **psychometric field testing**

These are related but not identical.

### Current COSMIN framework

Content validity asks whether instrument content is:

- relevant;
- comprehensive;
- comprehensible.

### Critical rule

Factor analysis cannot repair poor content validity.

---

# 17. Relevance

Ask:

> Does each item actually belong to the intended construct for the target population and context?

### Example

An item may correlate statistically with a scale but measure:

- a related;
- but distinct

construct.

That is not sufficient content validity.

---

# 18. Comprehensiveness

Ask:

> Are important aspects of the construct missing?

Exploratory qualitative research is especially valuable here.

### Risk

If the initial QUAL sample is narrow:

later quantitative validation may produce a statistically clean scale that omits important lived dimensions.

---

# 19. Comprehensibility

Ask whether:

- wording;
- instructions;
- response options;
- recall period

are understood as intended.

### Methods

Can include:

- cognitive interviewing;
- participant review;
- pilot administration;
- think-aloud;
- expert/user feedback.

### Critical rule

Internal consistency does not establish comprehensibility.

---

# 20. Expert review is not a substitute for target-population input

Experts can contribute:

- conceptual coherence;
- clinical/scientific relevance;
- terminology;
- item reduction.

But only target-population participants can directly show:

- lived relevance;
- natural language;
- misunderstood wording;
- missing experiences.

### Project rule

Store separately:

- expert input;
- target-user input.

---

# 21. Quantitative psychometric phase

Depending on instrument type, QUAN evaluation may include:

- item distribution;
- item-total relationships;
- EFA;
- CFA;
- IRT/Rasch;
- reliability;
- test–retest;
- convergent/discriminant validity;
- known-groups validity;
- responsiveness;
- measurement invariance.

### Critical rule

Exploratory sequential design does not prescribe one psychometric toolkit.

---

# 22. “Exploratory sequential” does not mean “EFA only”

This is a critical terminology boundary.

The word **exploratory** refers to the mixed-methods sequence:

`QUAL first → build QUAN`

It does **not** mean:

- the quantitative analysis must be exploratory;
- CFA is forbidden;
- confirmatory testing cannot occur.

### Current sport example

The LTPA social-inclusion scale used:

- QUAL item/factor generation;
- EFA;
- CFA;
- reliability/validity testing.

Still exploratory sequential mixed methods.

---

# 23. EFA and CFA are not themselves mixed-method integration

They test quantitative structure.

The mixed-methods integration occurred earlier when QUAL findings built:

- items;
- domains;
- scale content.

### Project rule

Store separately:

- integration procedure;
- psychometric analysis.

---

# 24. Independent quantitative samples may strengthen validation

For scale development, researchers may use:

- one sample for EFA;
- another for CFA.

### Current sport example

The older-adult LTPA scale used separate samples:

- EFA n=291;
- CFA n=290.

### Critical rule

This supports structural testing but does not automatically establish:

- cross-cultural validity;
- responsiveness;
- predictive validity.

---

# 25. Construct/determinant-translation variant

Canonical flow:

QUAL  
→ identify determinants/concepts  
→ translate into quantitative rating/priority variables  
→ quantify importance/consensus/patterns  
→ integrate.

### Scientific purpose

Not necessarily to create a reusable scale.

Instead:

- prioritize;
- rank;
- structure;
- compare

qualitatively generated determinants.

---

# 26. Direct PA exemplar — adolescents with mild intellectual disability

Ribeiro et al. 2026:

QUAL phase:

- experts;
- teachers;
- adolescents;
- context mapping;
- participatory methods;
- TDF/COM-B framework analysis.

Output:

- **29 PA determinants**.

QUAN phase:

- those QUAL-derived determinants were translated into inclusive pictorial rating instruments;
- adolescents rated them on a 7-point barrier→facilitator scale;
- descriptive statistics and hierarchical clustering examined importance/consensus.

### Taxonomy lesson

This is a strong **construct/determinant translation** exploratory-sequential route.

---

# 27. Same participants are not required across phases

In exploratory sequential work:

QUAL may use:

- small purposive stakeholders.

QUAN may use:

- larger target-population sample.

This is common in:

- scale development;
- determinant prioritization;
- intervention development.

### Critical rule

The key relationship is **content dependency**, not same-person linkage.

---

# 28. Sample transition must be justified

Ask:

1. Who generated the QUAL concepts?
2. Who receives the QUAN instrument/intervention?
3. Are they the same target population?
4. Are stakeholder perspectives being generalized to a different population?
5. Was language adapted?
6. Were missing groups excluded?

### Example

QUAL experts identify barriers.

QUAN adolescents rate them.

This is legitimate if the study intends to compare/prioritize expert-generated and youth-experienced determinants.

But it is not equivalent to:

> adolescents themselves generated every determinant.

---

# 29. Multi-stakeholder building

QUAL may combine:

- patients;
- clinicians;
- coaches;
- caregivers;
- administrators.

The later QUAN phase may then target one group.

### Project rule

Store provenance by stakeholder:

- who generated which construct?;
- who rated/tested it later?

This can reveal power/representation problems.

---

# 30. Participatory layer can coexist with exploratory sequential

The 2026 PA-determinant study combined:

- exploratory sequential mixed methods;
- participatory research;
- multistakeholder input;
- theoretical frameworks.

### Critical rule

Do not collapse these dimensions.

Canonical record:

mixed-method architecture  
+ participatory governance  
+ theoretical framework  
+ QUAL methodology  
+ QUAN analysis.

---

# 31. Intervention/program-development variant

Canonical flow:

QUAL needs/preferences/barriers  
→ design/refine intervention components  
→ pilot quantitative feasibility/safety/acceptability/outcome measures  
→ integrate  
→ refine program.

### Critical rule

The later QUAN phase may be developmental/pilot rather than confirmatory.

# 32. Direct rehabilitation exemplar — MS web exercise

Anderson et al. 2026:

QUAL:

- focus groups with adults with MS;
- needs/preferences/barriers;
- Reflexive Thematic Analysis.

Building:

- lived-experience findings informed:
  - video content;
  - modifications;
  - exercise options;
  - accessibility;

### Taxonomy classification

**exploratory sequential + co-innovation/intervention-development overlay**.

---

# 33. Intervention development is not instrument development

Instrument route:

QUAL  
→ items/constructs  
→ measurement validation.

Intervention route:

QUAL  
→ components/features  
→ feasibility/safety/acceptability/pilot outcomes.

### Critical rule

Do not apply psychometric criteria to intervention-development outputs.

Do not apply intervention-effect criteria to item-generation studies.

---

# 34. Digital-tool development

QUAL can identify:

- accessibility needs;
- interface barriers;
- preferred support;
- content needs;
- notification preferences;
- personalization needs.

These can build:

- app features;
- web content;
- digital intervention logic.

### Quantitative phase may assess:

- usability;
- feasibility;
- adherence;
- engagement;
- safety;
- preliminary outcomes.

---

# 35. Development vs evaluation

An exploratory sequential development study may both:

- build;
- test.

But the quantitative test must be interpreted at its actual stage.

### Pilot phase can support:

- feasibility;
- acceptability;
- safety signal;
- process refinement.

It generally does not support:

- definitive effectiveness;
- population benefit;
- clinical superiority.

---

# 36. Preliminary outcome improvement ≠ effectiveness

Example:

small pilot after QUAL-informed intervention development shows:

- improved mobility;
- improved adherence.

### Critical rule

Without appropriate causal design and power:

the correct interpretation is:

- preliminary signal;
- feasibility outcome;
- hypothesis-generating result.

Not:

- established treatment efficacy.

---

# 37. Instrument development vs validation

An instrument may move through:

1. conceptualization;
2. item generation;
3. content validity;
4. field testing;
5. structural validity;
6. reliability;
7. other measurement properties.

### Critical rule

Completing one exploratory-sequential study does not necessarily complete all validation stages.

# 40. Content-development traceability matters more than raw item count

A scale can start with:

- 302 statements;
- 130 items;
- 58 items.

That progression is not automatically strong.

### Appraisal asks:

- why were items merged?;
- who decided?;
- what content was lost?;
- which qualitative domains survived?;
- which were removed statistically?;
- did statistical reduction eliminate important content?

---

# 41. Statistical item removal can damage content validity

An item may have:

- weak loading;
- redundancy;
- poor distribution.

Removing it may improve:

- internal consistency;
- factor fit.

But can reduce:

- conceptual completeness;
- representation of minority experiences.

### Project rule

For exploratory-sequential instruments:

track both:

- psychometric performance;
- qualitative content role.

---

# 42. Joint display for instrument development

Canonical display:

| QUAL quote/theme | construct/domain | proposed item | expert/user refinement | QUAN performance | final decision |

### Value

Makes visible:

- development provenance;
- item retention/removal;
- QUAL→QUAN integration;

# 43. Joint display for intervention development

Possible structure:

| QUAL need/barrier | intervention component | quantitative pilot indicator | user feedback | design decision |

Example:

QUAL:

- fatigue makes long sessions difficult.

Component:

- 20–45 min modular videos.

Pilot:

- adherence/acceptability.

Meta-inference:

- flexible dose appears feasible enough for next-stage testing.

---

# 44. Final merging is still required

Building the QUAN phase from QUAL is strong integration.

But a full mixed-methods study should also integrate the later results back with the first phase.

### Good final integration

QUAL need  
→ QUAN-built feature/measure  
→ QUAN performance  
→ final developmental conclusion.

### Weak final integration

QUAL informed survey creation  
then:
- only psychometric results reported;
- no discussion of whether QUAL-derived constructs survived/changed.

---

# 45. Meta-inference in exploratory sequential studies

A good meta-inference answers:

> What did the quantitative phase establish or refine about the constructs/components originally identified qualitatively?

Examples:

- which determinants are shared vs individualized;
- which scale dimensions survive psychometric testing;
- which intervention features are feasible;
- which user-generated needs should remain in the program;
- which qualitative construct needs revision.

---

# 46. QUAN phase can contradict QUAL-derived assumptions

Example:

QUAL experts consider a determinant a barrier.

QUAN target users rate it as a facilitator.

### Current PA example

This occurred for several determinants in the 2026 adolescent PA study.

### Scientific value

The second phase can:

- challenge;
- reprioritize;
- refine

the first phase.

### Critical rule

Exploratory sequential does not mean:

> QUAN merely confirms QUAL.

---

# 47. Determinant prioritization

QUAL may generate many candidate determinants.

QUAN can then assess:

- direction;
- importance;
- distribution;
- agreement;
- clustering;
- ranking.

### Critical rule

A later rating phase does not transform qualitative discovery into population causality.

It estimates:

- reported priority/perception

under the quantitative sampling/measurement design.

---

# 48. QUAN phase need not be large or confirmatory

Exploratory sequential studies can use a small second phase when the purpose is:

- feasibility;
- pilot refinement;
- preliminary usability;
- initial ranking.

### Critical rule

The label “quantitative phase” does not imply:

- adequate power;
- confirmatory inference;
- population generalization.

---

# 49. Exploratory-to-confirmatory boundary

This is one of the most important E4 distinctions.

## Exploratory sequential mixed methods

Refers to:

**sequence and integration direction**.

## Confirmatory quantitative inference

Depends on:

- design;
- prespecification;
- sample size;
- measurement validity;
- statistical assumptions;
- multiplicity;
- replication.

### Critical rule

An exploratory-sequential study can include:

- confirmatory factor analysis;
- randomized pilot;
- hypothesis testing.

But the mixed-method design label itself does not make those analyses confirmatory.

---

# 50. Scale validation can be exploratory and confirmatory within the same program

Example:

QUAL item generation  
→ EFA  
→ CFA.

### Better practice

Use distinct samples or explicit cross-validation where feasible.

### Critical rule

If EFA and CFA are performed on the same sample without appropriate validation strategy:

do not interpret CFA as strong independent confirmation.

---

# 51. Instrument development and COSMIN content-validity standards

Current COSMIN guidance makes a critical point:

> content validity is foundational.

For an instrument to represent the target outcome adequately, its content should be:

- relevant;
- comprehensive;
- comprehensible.

### E4 consequence

Exploratory-sequential item generation is scientifically useful because QUAL can directly establish:

- what should be measured;
- how target participants describe it.

But later statistical fit cannot substitute for this content-validity work.

---

# 52. Face validity vs content validity

Face validity:

- does the measure appear understandable/appropriate?

Content validity:

- does the content adequately represent the intended construct?

### Critical rule

Expert agreement on wording is not the same as full content validity.

---

# 53. Expert consensus can be a bridge, not the parent design

Instrument-development programs may use:

- Delphi;
- expert panel;
- CVI/CVR;
- consensus.

### Project route

Exploratory sequential mixed methods  
+ consensus method  
+ psychometric QUAN phase.

### Critical rule

Delphi presence does not automatically convert the study into a Delphi design family for RES-02.

---

# 58. Exploratory sequential vs explanatory sequential

## Exploratory sequential

QUAL findings build QUAN.

`QUAL → QUAN`

## Explanatory sequential

QUAN findings drive QUAL follow-up.

`QUAN → QUAL`

### Critical rule

Direction of **dependency**, not just collection order, defines the distinction.

# 59. Exploratory sequential vs convergent

Exploratory sequential:

- second phase depends on first-phase QUAL findings.

- strands are largely independent before merging.

### Critical rule

A survey built directly from interview themes is not convergent merely because results are later compared.

# 79. Common failure modes

1. Calling any interviews→survey sequence exploratory sequential.
2. QUAL results do not materially shape QUAN content.
3. Survey items are researcher-written with no traceable qualitative provenance.
4. Themes converted directly to items without construct clarification.
5. Expert review replaces target-population input.
6. Factor analysis treated as evidence of content validity.
7. Cronbach alpha treated as full validation.
8. Statistical item removal erases important qualitative content without review.
9. Same QUAL and QUAN sample assumed mandatory.
10. Different samples used without explaining transition.
11. QUAL participants differ from later target users with no adaptation.
12. QUAN phase too small for claimed psychometric inference.
13. Pilot outcome improvement called effectiveness.
14. Exploratory sequential confused with exploratory statistics.
15. CFA interpreted as independent confirmation on inadequately separated data.
16. QUAL-derived determinant ratings interpreted as causal determinants.
17. Quantitative prioritization treated as universal prevalence.
18. Co-design called mixed methods despite absent quantitative phase.
19. Pilot study called exploratory sequential despite absent QUAL→QUAN building.
20. Joint display used decoratively without development trace.
21. Final integration omitted after building.
22. QUAN contradictions with QUAL are suppressed.
23. Participant language lost through expert/technical rewriting.
24. Scale developed in one culture assumed universally valid.
25. Author label trusted despite reversed enacted direction.
26. Instrument purpose, mixed-method architecture and psychometric design collapsed into one label.
27. AI/computational mapping treated as new parent methodology.
28. Development evidence inflated to confirmatory causal evidence.

# 82. Project taxonomy decision

Exploratory sequential mixed methods is confirmed as a stable core mixed-methods architecture.

**QUAL collection/analysis  
→ derive constructs/categories/needs/components  
→ BUILD QUAN phase

### Required functional subroute

Every E4 study should additionally be classified as one or more of:

1. **INSTRUMENT_MEASUREMENT_DEVELOPMENT**
2. **CONSTRUCT_DETERMINANT_TRANSLATION**
3. **INTERVENTION_PROGRAM_TOOL_DEVELOPMENT**
4. **OTHER_QUAL_BUILT_QUAN**

### Minimum classifier

A study should not be coded exploratory sequential solely because qualitative work happened before quantitative work.

At least one material bridge must be reconstructable:

- QUAL theme/code → QUAN item;
- QUAL construct → QUAN variable;
- QUAL determinant → QUAN rating/prioritization;
- QUAL need/barrier → intervention/tool component tested quantitatively;

and final integration should be present.
