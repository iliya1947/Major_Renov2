# NEU-22 — Application to resistance exercise

Статус: **CLOSED_FOR_PRACTICE v2.0 — revalidated 2026-11-19**  
Область: 04 — Neurophysiology / Motor Learning

## 0. Core decision

Resistance-exercise technique is a motor skill.

A practical project model is:

`define task goal + justified execution criteria`
→
`choose a solvable task/load/complexity`
→
`practice with task-relevant feedback`
→
`separate practice performance from learning`
→
`verify repeatability + delayed retention`
→
`expose the skill to the actual target load/context`
→
`interpret load/fatigue-related changes against justified criteria`
→
`use technical failure only with an explicit criterion`
→
`add structured task-relevant variability when robustness/generalization is a target`
→
`test transfer in the target exercise/condition`.

Project rule:

**do not infer learned technique, technical failure or transfer from appearance alone; define the task criterion and test the condition that matters.**

---

## 1. Learning a new resistance exercise

A new resistance exercise requires:

- task representation;
- perception;
- coordination;
- force control;
- intrinsic feedback;
- practice;
- retained execution.

Knowing verbal rules is insufficient.

Project rule:

**one good coached set or session is practice performance, not proof of durable learning.**

Direct squat evidence shows acquisition and delayed retention can diverge.

---

## 2. Acquisition vs learning

### Acquisition
Improvement observed during practice.

### Durable learning
Change that survives a delayed test under defined conditions.

Project rule:

**if retention was not tested, describe acquisition/performance rather than claiming the technique was learned.**

---

## 3. Technique stabilization

For project use, technique is stabilized when the trainee:

- repeatedly satisfies justified task criteria;
- does so under a defined condition;
- can reproduce acceptable execution after a delay;
- does not require continuous external guidance.

This is a project operational definition.

It does not require:

- identical repetitions;
- zero variability;
- one universal geometry;
- one morphology-independent template.

Project rule:

**stable technique = repeatable acceptable control, not visual sameness.**

---

## 4. Within-session stability vs durable stabilization

Repeated acceptable repetitions in one session demonstrate current performance stability.

They do not by themselves establish durable learning.

Project rule:

**use delayed retention when the claim is stable/learned technique rather than only current execution.**

---

## 5. Light load to working load

No universal motor-learning threshold is retained for:

- %1RM;
- number of repetitions;
- number of sessions;
- time practiced.

Historical load-progression rules and current RT loading recommendations are programming rules, not validated “technique learned” thresholds.

Project rule:

**progress the constraint while execution remains interpretable and acceptable, then directly verify the skill in the load range where it must function.**

Exact increments belong PRO/TEC.

---

## 6. Target-load specificity

If the target is:

- heavy squat;
- working-set bench;
- loaded hinge;
- another specific resistance task;

then execution must eventually be demonstrated in that context.

Project rule:

**light-load control does not establish working-load control.**

This does not imply that learning must begin heavy.

---

## 7. Increasing load changes the motor problem

Increasing intensity can change:

- velocity;
- concentric duration;
- force demands;
- joint mechanics;
- coordination;
- movement variability;
- sticking-region behavior.

Project rule:

**higher load is not merely the same light-load movement with proportionally more force.**

Different lifters may adopt different strategies.

---

## 8. Load-related movement change ≠ error

A load-related change can reflect:

- acceptable task adaptation;
- capacity limitation;
- fatigue;
- genuine criterion violation.

Project rule:

**judge the change against justified load-specific task criteria rather than against exact light-load kinematic invariance.**

Exact mechanics belong MEC/TEC.

---

## 9. Fatigue-related technique change

Fatigue can change:

- velocity;
- power;
- timing;
- mechanics;
- variability.

Project rule:

**late-set technical change is a state effect until durable loss is demonstrated.**

Useful check:

1. compare early vs late repetitions;
2. retest after recovery;
3. if acceptable execution returns, treat the prior change primarily as state dependent.

---

## 10. Technical failure

Resistance-training literature uses different failure constructs.

Project operational definition:

**technical failure = crossing a pre-specified, justified execution/performance criterion for the exercise and goal, even if another repetition may still be mechanically possible.**

It is distinct from:

- momentary muscular failure;
- volitional failure;
- simple velocity loss;
- visible effort;
- sticking;
- any rep-to-rep variation.

Exact criterion belongs MEC/TEC/MED/competition rules.

---

## 11. Technical failure requires a criterion

Do not retrospectively label a repetition “technical failure” merely because it looked different.

Project rule:

**define what unacceptable execution means before using technical failure as a set endpoint.**

---

## 12. Exercise complexity

Resistance exercises differ in technical demand through:

- coordination;
- stability;
- balance;
- degrees of freedom;
- equipment handling;
- timing;
- setup;
- attentional/instruction demand.

No universal complexity threshold is retained.

Project rule:

**complexity is useful only relative to the target.**

---

## 13. When an exercise is too complex

An exercise is too complex for the current purpose when its added technical demands become the main limiter while not serving the desired:

- adaptation;
- skill;
- transfer target.

If mastery of that complex movement is itself the goal, its complexity is target relevant.

Project rule:

**simplify irrelevant complexity, not target-relevant complexity.**

---

## 14. Complexity ≠ load

Technical difficulty and loading difficulty are separate.

An exercise can be:

- simple and heavy;
- complex and light;
- both complex and heavy;
- neither.

Project rule:

**diagnose “too heavy” and “too complex” separately.**

---

## 15. Stability and variability

Stable and variable practice are tools with different purposes.

Stable conditions are useful when:

- task criteria are unclear;
- error diagnosis requires comparability;
- safety-critical constraints should remain fixed.

Variability is useful when:

- the varied dimension belongs to the target task space;
- robustness/generalization is a real goal;
- variation is structured and interpretable.

Project rule:

**do not randomize practice merely because variability can be useful.**

---

## 16. Structured variability

Direct 2026 squat evidence shows that structured variability can preserve immediate accuracy better than unstructured variability.

However, direct resistance-exercise evidence has not yet established superior:

- delayed retention;
- transfer;
- long-term skill robustness

from structured variability.

Project rule:

**structured variability is plausible and usable, but long-term superiority remains unproven.**

---

## 17. Stable first ≠ universal law

No universal sequence is retained:

`constant practice first → variable practice later`.

A better rule is:

- stabilize what must remain fixed;
- vary what is relevant to future performance;
- keep variation interpretable;
- verify retention/transfer.

---

## 18. Exercise variation ≠ movement variability

### Exercise variation
Changing the selected exercise/task.

### Movement variability
Variation in execution within or around a task.

They are different training variables.

Project rule:

**do not use chronic exercise-variation evidence as direct proof of motor-learning variability effects.**

---

## 19. Transfer between similar exercises

Similar exercises do not automatically share one learned motor skill.

Potentially relevant overlap includes:

- task goal;
- action mapping;
- sensory information;
- resistance/dynamics;
- ROM;
- stance/grip/setup;
- stability demand;
- load/velocity regime.

Project rule:

**similar muscles or visual appearance do not establish skill transfer.**

---

## 20. Strength transfer ≠ motor-skill transfer

Resistance-training studies often measure transfer through:

- 1RM;
- isometric strength;
- power;
- muscle activation;
- hypertrophy.

These are not direct measures of:

- technical acquisition;
- retention;
- error reduction;
- cue dependence.

Project rule:

**do not relabel strength specificity/transfer as motor-skill transfer.**

---

## 21. Transfer must be target tested

For source exercise A and target exercise B, useful transfer evidence should come from B.

Candidate measures:

- baseline target execution;
- target-task criterion success/error;
- trials/feedback required to reach criterion;
- delayed retention;
- target-load/context execution.

This is a project measurement heuristic, not a validated universal composite score.

---

## 22. Canonical non-equivalences

1. Practice performance ≠ durable learning.
2. One successful session ≠ learned technique.
3. Technique stability ≠ identical kinematics.
4. Light-load technique ≠ working-load technique.
5. Programming progression rule ≠ motor-learning threshold.
6. Higher load ≠ same movement solution plus more force.
7. Load-related change ≠ error by default.
8. Fatigue-related degradation ≠ unlearning.
9. Technical failure ≠ momentary muscular failure.
10. Technical failure ≠ volitional failure.
11. Velocity loss ≠ technical failure.
12. Exercise complexity ≠ superior training.
13. Complexity ≠ load.
14. Variability ≠ randomness.
15. More variability ≠ better learning.
16. Stable-first ≠ universal learning sequence.
17. Exercise variation ≠ movement variability.
18. Similar exercises ≠ automatic skill transfer.
19. Strength transfer ≠ motor-skill transfer.

---

## 23. Scope boundaries

### MEC
Exact mechanics and load-specific movement interpretation.

### TEC
Exercise-specific technique criteria, regressions/progressions and exercise selection.

### PRO
Loading, volume, frequency and progression prescription.

### MED
Safety, pathology, contraindications and injury-risk claims.

### TST
Reliability, measurement error and formal decision thresholds.

### COA / IND
Individual implementation and decision rules.

NEU-22 owns the motor-learning architecture connecting these downstream domains.

---

## 24. Confidence

### HIGH

- acquisition ≠ durable learning;
- load changes observable resistance-exercise mechanics;
- technical failure is distinct from momentary/volitional failure;
- fatigue-related change is not automatically unlearning;
- transfer must be assessed in the target task;
- strength transfer ≠ skill transfer.

### MODERATE-HIGH

- stabilized technique is best operationalized as repeatable acceptable control rather than identical kinematics;
- target-load control should be demonstrated rather than inferred from light-load execution;
- complexity should be purpose relative.

### MODERATE

- structured variability can be useful when task relevant;
- stable conditions can aid early diagnosis/practice.

### LOW / UNRESOLVED

- one universal light→working-load cutoff;
- one technical-failure threshold across exercises;
- one optimal variability dose/schedule;
- one direct transfer matrix between common lift variants.
